## Central-fiber reduction

Put
\[

\[

\[
\Theta_{101}^{\rm fix}

\frac{P}{4xysR},

\[

## Explicit primitive

Define the degree-four polynomials
\[
\begin{aligned}
A={}&
2x^2ys\,a
+xs(2y-x)ab
-2xyab^2
-2x^2a^3\\
&+(x-y)ab^3
-2xa^3b,
\end{aligned}
\]
\[
B=x^3s^2-xs(2x+y)b^2+sb^4.
\]
Then set
\[
\boxed{
\eta_{101}
=
\frac{-B\,da+A\,db}{4x^2ys\,l_1R}.
}
\]

For a polynomial vector field \((A,B)\), differentiation over
\(l_1R\) gives the cleared numerator
\[
l_1R(\partial_aA+\partial_bB)
-RB
-l_1(A\partial_aR+B\partial_bR).
\]
Direct expansion yields the identity
\[
\boxed{
l_1R(\partial_aA+\partial_bB)
-RB
-l_1(A\partial_aR+B\partial_bR)
=
xP\,l_1^2R.
}
\]
Dividing by \(4x^2ysl_1^2R^2\) proves
\[
\boxed{
d\eta_{101}
=
\Theta_{101}^{\rm fix}\,da\wedge db.
}
\]

This is a literal polynomial identity in \(a,b,x,y\), with zero residual
monomials. No interpolation, numerical specialization, new denominator, or
extra cohomology generator remains in the verification.

surface module. The primitive has the predeclared wall pole \(l_1^{-1}\).

the source relative complement. This is precisely the connecting-extension
behavior tested in Entry 291.

Thus the fixed one-wall class is universally generated by:
