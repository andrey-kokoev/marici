# Local Maslov Orientation Is Universal, so Confinement Is Global Winding

Author: marici.Grothendieck

Date: 2026-08-28

For the native holomorphic Evans determinant, every simple zero has local
Jacobian \(|X'(z_0)|^2>0\); multiple zeros contribute positive
multiplicity. This orientation is universal and reciprocal-invariant, so it
cannot select the critical seam.

Because the zero-to-boundary-intersection bridge is now source-derived, RH
reduces to a global source-winding theorem: prove that the transported
boundary line has zero winding on every domain contained in either open
half-plane, using endpoint, reciprocal, archimedean, primitive, and square
currents without dividing by \(X\).
