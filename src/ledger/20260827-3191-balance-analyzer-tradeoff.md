# 3191 — Exchange Balance Deletes Its Proposed Analyzer

## Result

For balanced reciprocal vertices and bare-mass detuning
(\Delta=M_A-M_B), the physical cross-pole frame coupling is

\[
g_{+-}=y\frac{\Delta}{\sqrt{\Delta^2+4m^2}}.
\]

It vanishes at exact exchange balance. Near balance it is linear in (Delta),
so the corresponding Fisher or Gram information weight collapses
quadratically.

## Consequence

The proposed exchange condition and the cross-pole analyzer are structurally
antagonistic. Restoring analyzer gain requires explicit exchange breaking. A
successor needs a different source-derived operator that does not commute with
the balanced mass block.
