## Verdict

The Deutsch--Popperian Conjecture is retired as a conjecture. Its final
protection--engineering formulation fails seven exact finite falsifiers.
Hybrid non-Clifford protocols require both a protected substrate and an
engineered resource; neither alone suffices. The apparatus cut between a
calibrated gate and a resource-state injection is noncanonical.

A logical \(Z\) fault supplies the sharpest warning: it has the same empty
stabilizer syndrome as identity, but maps \(|+\rangle\) to the orthogonal
state \(|-\rangle\), giving unitary-channel diamond distance 2. Protection,
syndrome visibility, executable control, robustness, fault tolerance, and
scalability are therefore separate predicates.

The useful survivor is a typed question matrix. Algebraic reachability,
resource obstruction, microscopic realization, robustness, fault tolerance,
scalability, and explanatory scope each require their own certificate.
