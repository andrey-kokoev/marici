# 2652 — Two-Variable Source Kernel Precedes Jet Gramian and Scalar Readout

A source analytic feature map \(J(w):X\to E\) defines

\[
K(z,w)=J(z)^*J(w).
\]

This positive operator kernel precedes scalar readout. If
\(J(w)=\sum_nJ_nw^n\), mixed coefficient extraction gives every jet Gram block

\[
G_{mn}=J_m^*J_n.
\]

Distinct minimal direct and reciprocal factorizations of the same labelled
kernel are related by a unique mathematical unitary. Without minimality, dark
ambient summands remain undetermined. This unitary equivalence does not itself
authorize physical Fourier–Tate sewing.

The rank-one polarization

\[
K_\Xi(z,w)=\overline{\Xi(z)}\Xi(w)
\]

is positive for every analytic \(\Xi\), including functions with explicit
off-target zeros. It is therefore rejected as circular unless the same kernel
is independently constructed from source atoms before scalar completion.
