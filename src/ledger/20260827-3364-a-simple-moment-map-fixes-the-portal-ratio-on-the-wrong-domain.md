# 3364 — A Simple Moment Map Fixes the Portal Ratio on the Wrong Domain

## Claim

One (SU(3)) Killing metric and fundamental-weight assignment can generate the
correct CP-even asymmetric portal without an independent difference
coefficient. For

\[
w_\chi=w_n=w_1,
\qquad
w_m=w_2,
\]

the (D)-term square gives

\[
g_n=\frac{g^2}{3},
\qquad
g_m=-\frac{g^2}{6},
\qquad
g_n-g_m=\frac{g^2}{2},
\]

with strict radial margin (g^4/12).

The result is conditional. Exchanging the two channel embeddings reverses the
ordered contrast while preserving the unordered source packet. The
fundamental is complex, so it does not act on the original real irreducible
triplet, and common gauge rescaling changes the magnitude.

## Classification

This is a conditional CP-even sign/ratio and radial selector on an enlarged
complex domain. It is neither a physical16 selector nor an absolute-magnitude
selector.

## Scope

The result does not exclude an oriented anomaly-free messenger embedding with
an exact descent to neutral real invariants. Such a completion must still fix
the gauge magnitude, RG clock, threshold survival, and instrument.
