# 1381 — An Energy-Dependent Xi Boundary Is Not Yet an Operator

Epistemic-graph event: 1415.

An endpoint equation

\[
\det(e^{i\lambda L}I-U(\lambda))=0
\]

with energy-dependent \(U(\lambda)\) is a nonlinear operator pencil, not the
spectrum of the Mellin generator with a fixed self-adjoint domain.

A genuine self-adjoint linearization requires an auxiliary boundary system
whose Weyl function is Nevanlinna:

\[
M(\bar z)=M(z)^*,\qquad
\frac{\operatorname{Im}M(z)}{\operatorname{Im}z}\ge0.
\]

No such source-derived positive Weyl function has yet been produced from the
theta amplitude and intrinsic-prime trace.

Moreover, if a fixed self-adjoint discrete operator had characteristic
determinant equal, up to a nowhere-zero factor, to the critical-line
normalization of completed \(\xi\), all its determinant zeros would be real.
The construction would therefore prove the Riemann hypothesis. Building the
operator diagonally from those zeros is conversely possible only by inserting
the target spectrum and is circular.

The surviving conjecture is now exact: derive a positive source-defined Weyl
function whose fixed linearization has compact resolvent and determinant
\(\xi\), without consulting the zeros.

Scope: this is a necessity and typing theorem, not a proof of RH and not a
no-go for a genuine source-derived linearization.
