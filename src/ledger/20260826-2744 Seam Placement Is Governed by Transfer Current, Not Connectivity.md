# 2744 — Seam Placement Is Governed by Transfer Current, Not Connectivity

For a candidate seam row, the first-order change in a target resistance-energy
certificate is \(R|g|^2-E|\tau|^2\): state-gradient cost minus target
transfer-current benefit. A three-vertex hostile becomes better connected
while its target certificate worsens exactly as \(2+t\). Direct target seams
are universally nonincreasing; arbitrary seam rows are not.
