# 2703 — Norm Closure Preserves Invertibility Only with a Uniform Inverse Bound

Invertible (T_N\to T) in operator norm can converge to a singular limit when
inverse norms diverge, as (\operatorname{diag}(1,N^{-1})\to
\operatorname{diag}(1,0)). If (\sup_N\|T_N^{-1}\|<\infty), a Neumann-series
argument preserves invertibility and a uniform lower bound in the limit.
