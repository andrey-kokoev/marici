# 3147 — Tree Matching Does Not Determine the Messenger RG Completion

## Result

Disjoint and shared spin-one messenger architectures can both carry
independently adjustable \(J_n,J_m\) tree words, yet their one-loop scalar
support differs. Disjoint chains generate only separate norm terms. A shared
messenger additionally generates

\[
n\mathbin\cdot m,\qquad |n|^2(n\mathbin\cdot m),\qquad
|m|^2(n\mathbin\cdot m).
\]

Thus the WP651 low-energy matched packet does not determine the messenger RG
completion of the faithful frame.

## Consequence

A messenger topology and symmetry-charge assignment must be frozen
independently before complete beta functions can be derived. This is a
constructor ambiguity, not a numerical flavor selector.
