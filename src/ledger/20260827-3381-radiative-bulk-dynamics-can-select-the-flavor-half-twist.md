# 3381 — Radiative Bulk Dynamics Can Select the Flavor Half Twist

## Claim

Two valid \(S^1/Z_2\) boundary involutions admit a continuous relative
\(SU(2)_R\) rotation, so orbifold consistency alone does not quantize the
Scherk–Schwarz twist.

For the pure-bulk effective potential

\[
V(\omega)=A\cos(2\pi\omega),
\qquad A>0,
\]

the half twist \(\omega=1/2\) is a stable minimum with curvature \(4\pi^2A\)
and an attractive basin on the twist circle apart from the unstable zero
twist.

## Conditional portal prediction

With the same compactification radius supplying both masses,

\[
m_{\mathrm{soft}}^2=\frac{1}{4R^2},
\qquad
M_V^2=\frac{N^2}{R^2},
\qquad
\epsilon=\frac{1}{4N^2+1}.
\]

For the unit mode, the ordered portal contrast is \(g_*^2/10>0\). The radius
cancels from this dimensionless magnitude.

## Completion residual

A boundary-localized mass shift \(\beta/R\) continuously changes the result.
For \(N^2=1\), \(\beta=0\) gives \(\epsilon=1/5\), whereas \(\beta=1/2\) gives
\(\epsilon=1/2\), with exact residual \(3/10\). Threshold accessibility also
retains \(R\).

## Classification

Radiative bulk dynamics is the first conditional source selector in this
branch with a nonzero prediction and attractive basin. It becomes a complete
explanation only if a frozen anomaly-free bulk spectrum yields \(A>0\), the
full effective potential preserves the half-twist minimum, and the same source
forbids or normalizes every boundary-localized breaking term.
