# Weak Calculus Universality and the Strong Parent-Object Hypothesis

## Motivation

The Marici sectors repeatedly exhibit the same separation:

\[
\text{boundary/incidence geometry and its functorial operations}
\quad\neq\quad
\text{the coefficient object transported through that geometry}.
\]

The recent six-point string calculation makes this separation explicit.  The
carrier is the labelled associahedral chamber complex; its boundary,
corner, transition, and Pochhammer operations are source-derived.  Its
coefficient loading is the rank-one Koba--Nielsen local system and its
integer-shift closure.  Cosmology uses related localization, Gysin, and
nearby-cycle operations, but its coefficients include marked-relative,
elliptic, Tate/Kummer, and Gauss--Manin objects.

This evidence motivates two logically distinct universality hypotheses.

## H2W: weak calculus universality

There is a shared logarithmic/incidence carrier calculus \(\mathfrak C\)
whose admissible operations include restriction, residue, localization,
Gysin maps, nearby cycles, monodromy, and supported integral transforms.
Each physical sector supplies its own coefficient object \(\mathcal K_s\):

\[
\boxed{
(\mathfrak C,\mathcal K_s)
\longmapsto
\text{sector }s.
}
\]

The carrier and coherence laws are shared; the coefficient objects need not
be isomorphic and need not have equal ranks, periods, or physical
interpretations.

The string calculations through Entries 949--981 support H2W: every tested
six-point Fitting wall is an existing twisted boundary or corner, and the
nontrivial comparison is produced by Koba--Nielsen/Pochhammer loading on the
existing chamber complex.  The cosmology calculations independently require
the same types of supported and localization operations with different
coefficient objects.

### Falsifier for H2W

H2W fails if a sector requires a source-derived operation or carrier stratum
that cannot be expressed in the proposed common calculus even after its
coefficient object is retained with the correct support, grading, and
variance.  A pole, rank excess, or resonance alone is not such a
falsification.

## H2S: strong parent-object universality

There exists a parent object \(\mathscr U\) and canonical realization
functors \(\mathcal R_s\) such that the sector coefficient objects are
derived projections:

\[
\boxed{
\mathcal R_s(\mathscr U)\simeq\mathcal K_s.
}
\]

For example, a valid strong construction would have to derive, rather than
postulate,

\[
\mathcal R_{\rm string}(\mathscr U)
\simeq \mathcal K_{\rm KN},
\qquad
\mathcal R_{\rm cosmo}(\mathscr U)
\simeq \mathcal M_{\rm rel/GM},
\]

while transporting the same incidence, localization, and support
coherences.

H2S is not currently established.  Entry 982 supplies an important internal
warning: even equal four-character shift representations inside the string
sector do not canonically identify the loaded occurrence image with the
normal-symbol module.  Entries 983--984 show that the missing comparison must
respect degree, variance, and all source symmetries; representation type
alone is insufficient.

### Evidence threshold for H2S

Rank matches, common divisors, equal monodromy characters, or analogous
diagrams do not count as evidence of a parent object by themselves.  A
candidate \(\mathscr U\) must provide:

1. explicit realization functors with typed source and target categories;
2. canonical comparison maps, not chosen splittings;
3. compatibility with localization/Gysin/nearby-cycle triangles;
4. compatibility with occurrence, deck, and source symmetries;
5. recovery of sector-specific coefficient objects without adding fitted
   cells or physical boundary data post hoc.

### Falsifier for a proposed parent

A proposed \(\mathscr U\) is falsified if two realizations require
incompatible variance, support, or coherence, or if a realization depends on
an arbitrary splitting, regulator hierarchy, or non-source-derived
projection.  Such a failure rejects that parent construction, not H2W.

## Reconstruction program

The next admissible path toward H2S is conservative:

1. formulate the minimal category generated by the common carrier operations;
2. encode the string and cosmology coefficient systems as functors on it;
3. compute their shared naturality and Beck--Chevalley constraints;
4. ask whether those functors admit a common representing or universal
   object;
5. test the resulting parent on a cross-sector case not used in its
   construction.

The current epistemic posture is therefore

\[
\boxed{
\text{H2W: supported and actively tested},
\qquad
\text{H2S: explicit conjecture, presently unproved}.
}
\]

This separation prevents the successful shared-calculus program from being
mistaken for a premature universal-coefficient claim.
