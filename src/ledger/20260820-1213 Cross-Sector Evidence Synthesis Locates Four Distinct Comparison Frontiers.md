# 1213 — Cross-Sector Evidence Synthesis Locates Four Distinct Comparison Frontiers

Sequence claim: `seqclaim-8c045f09adb0f5c050499339`.

## Purpose

This entry is a comparative evidence synthesis, not a new universal theorem.
It locates the present bottleneck in each active physical sector while
preserving the distinction between:

\[
\text{carrier},
\qquad
\text{sector coefficient object},
\qquad
\text{physical selection/readout}.
\]

Nima's common-architecture lane and the scattering core are treated as the
cross-sector calculus, not counted as an additional physical sector.

## Comparative frontier

\[
\boxed{
\text{carrier}
\longrightarrow
\text{sector coefficient object}
\longrightarrow
\text{physical selection/readout}
}
\]

The sectors currently test different arrows in this sequence.

### Cosmology

Cosmology supplies the strongest hostile evidence for

\[
\text{shared labelled Cut/Gram carrier}
+
\text{sector-specific coefficient objects}.
\]

Repeated candidate carrier enlargements have instead resolved into elliptic
Gauss--Manin systems, Kummer lines, nonsplit extensions, higher Rees grades,
and supported Cartier/normalization layers. The current five-site result is
one canonical endpoint Kummer line over the unchanged radial/Gram carrier.

The remaining bottleneck is physical activation:

\[
\text{coefficient class exists}
\not\Rightarrow
\text{the Bunch--Davies chain pairs with it}.
\]

### Strings

The string lane is closest to cosmology in structural vocabulary. It has
source-labelled flags, occurrence transport, Rees limits, Cartier
transitions, cyclic/dihedral covariance, and finite exceptional shift
modules.

Its present profile is

\[
\text{carrier-rich, coefficient-emerging}.
\]

The bottleneck is a source-compatible ambient parameter connection and
global assembly of the finite coefficient modules. Thus strings currently
test the carrier-to-coefficient arrow most directly.

### Flavor

Flavor supplies the sharpest presentation-to-physics descent falsifier. The
sparse loop phase is an invariant of its texture chart/groupoid but not of a
physical weak-basis orbit. The sparse readout is locally informative yet
globally noninjective, and the latest nonlinear-boundary continuation leaves
one dominant correspondence component together with exceptional islands.

Its governing warning is

\[
\text{presentation invariant}
\not\Rightarrow
\text{physical invariant}.
\]

The bottleneck is to derive a weak-basis-invariant coefficient/readout object,
rather than treating sparse-chart multiplicity as physical deck monodromy.

### Radiative gravity

Radiative gravity begins from the best-typed physical observables. Leading
soft/BMS/memory readouts factor through one sphere operator on the
\(\ell\ge2\) quotient; subleading readouts are organized by one parity-odd
carrier field at several derivative grades.

Its present profile is

\[
\text{physical readout-rich, shared-calculus bridge emerging}.
\]

The bottleneck is the complete corrected charge and radiative symplectic
transgression. An isolated local cubic flux does not yet reproduce the
nonlocal collinear action.

### Scattering core and common architecture

The core lane contains the most mature support-sensitive comparison calculus:
occurrence resolution, Cut/link incidence, Cartier/Gysin maps, Rees grades,
duality, and extraordinary comparison. Its open obligation is not another
analogy but independent closure of the same predeclared machinery in the
physical sectors.

The smallest conjecture consistent with all four sectors remains

\[

\text{shared resolved carrier}
+

+
\text{sector-specific coefficient objects}
+
\text{sector-specific physical selection maps}.

This refines H2 by making the final physical-selection arrow explicit.
Neither a common carrier nor a common coefficient calculus guarantees that a
physical sector activates every available class.

## Cross-sector falsifier

Choose one already constructed nontrivial coefficient class in each sector
and derive its physical selection map without fitting:

- cosmology: the five-site endpoint Kummer line versus the Bunch--Davies
  relative current;
- strings: a six-point exceptional shift module versus the source amplitude
  parameter connection;
- flavor: an equal-readout correspondence component versus weak-basis
  invariant data;
- radiative gravity: the nonlinear flux block versus the corrected
  charge/symplectic transgression.

The shared architecture receives a strong update only if the same declared
support-sensitive calculus types all four comparisons. A sector that requires
an undeclared incidence stratum is the carrier-level falsifier; failure of a
physical selection map alone is not.
