# 3233 — Affine Threshold Matching Does Not Select

With independently free UV quartic boundaries, finite source-derived matching
acts as

\[
(\lambda,p)_{\mathrm{low}}
=(\lambda,p)_{\mathrm{UV}}
+(\Delta_\lambda,\Delta_p).
\]

Its boundary Jacobian is the identity. The map reaches every low-energy target,
including the high-contrast corridor, stable points outside it, and
\(p_{\mathrm{low}}=0\). In particular,
\(p_{\mathrm{UV}}=-\Delta_p\) cancels any positive threshold contribution.

Radiative matching therefore supplies operator support and presentation
rigidification, not a proper-subspace selector. A new noninvertible UV boundary
constructor is required.
