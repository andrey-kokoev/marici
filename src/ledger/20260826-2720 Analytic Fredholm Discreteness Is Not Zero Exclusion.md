# 2720 — Analytic Fredholm Discreteness Is Not Zero Exclusion

A norm-analytic compact family on one fixed source space, together with one
invertible base point, has a meromorphic inverse and only discrete
noninvertible parameters. This localizes but does not exclude off-seam
failures. Compactness alone supplies no Fredholm determinant, and a scalar
Tate readout need not detect an operator kernel; both scalarization and
trace-class control require separate source-derived theorems.
