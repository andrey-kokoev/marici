# 2739 — Bounded Resistance Does Not Imply Uniform State Observability

Resistance radius controls pointwise deviation from a scalar anchor, whereas
the grounded Laplacian gap controls the full state norm. In a growing star
family the resistance radius remains two while the grounded gap tends to
zero. Scalar normalization can therefore remain uniformly nonvanishing even
as global state observability collapses.
