# 3606 — Erratum: The Anti-Holomorphic Seam Selects a Current Quadrature; It Does Not Annihilate the Current

Ledger 3605 conflated holomorphic inversion `w -> 1/w` with the
anti-holomorphic seam involution `w -> 1/conjugate(w)`.

The holomorphic fixed points are only `w=±1`. The full unit seam is fixed by
the anti-holomorphic involution, under which

\[
J(1/\bar w)=-\overline{J(w)}.
\]

Consequently a seam current is purely imaginary, not necessarily zero. For
`w=(3+4i)/5`, the current `w-w^{-1}=8i/5` is nonzero.

The RH target must therefore concern polarization: a source-admissible zero
must have no normal current quadrature. A further faithfulness theorem is then
needed to identify vanishing normal quadrature with zero radial displacement.
