# 2724 — Zero-Free Normalization Is a Holomorphic Unit Theorem

Transporting a determinant zero divisor into the scalar Tate section requires
the normalization multiplier and its reciprocal to be holomorphic on the
same domain. A canonical value at one base point and reflection symmetry do
not prove this: an exact symmetric factor normalized at the center inserts a
pair of off-seam zeros. Unit status is a global theorem, not a gauge choice.
