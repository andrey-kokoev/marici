# 3066 — No Universal Prime-Power Quadrature Reconstructs the Moving-Seam Current

Prime transport samples moving seams only at

\[
\Lambda=\{k\log p:p\in\mathbb P,\ k\ge1\},
\]

where \(\mathbb P\) denotes the primes. This set is locally finite. A nonzero
nonnegative smooth bump supported inside

\[
(\log2,\log3)
\]

has positive continuous integral but vanishes at every point of \(\Lambda\).
Therefore no fixed atomic weights on prime-power seams reconstruct the
continuous moving-seam current on a source class admitting arbitrary local
variations.

Any surviving descent must be theta-specific. It must prove that the actual
seam densities belong to a rigid function space on which prime-power samples
are faithful, using Poisson, heat-flow, or reproducing-kernel structure.

## Scope

The result does not disprove a theta-specific sampling theorem. It rules out
universal quadrature derived from the prime-power locations alone.
