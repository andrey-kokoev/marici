# 1430 — The Exceptional Cartier Filtration Retains Only Global Deck Complement

## Question

Entry 1225 proves that the full five-site deck group

\[
G=(\mathbb Z/2)^5
\]

acts covariantly on the unspecialized coefficient–Betti pairing. Entries
1424–1427 equip the two-normal exceptional coefficient with the Cartier
filtration

\[
F^9\subset F^4\subset F^2.
\]

Does the full deck action preserve this filtration after exceptional
specialization?

## Interpretation

There is no contradiction with Entry 1225. The full deck group acts on the
unspecialized rank-32 coefficient–Betti system, but exceptional specialization
adds a chamber-relative filtration that is not \(G\)-stable.

Thus

\[
\boxed{
\text{full deck covariance before specialization}
\quad\not\Rightarrow\quad
\text{full deck action on the associated grading}.
}
\]

Only

\[
\mu_2=\langle\iota\rangle
\]

generated by global complement acts by honest graded automorphisms. The other
deck translations must be treated, if retained, as filtered correspondences
that move information between Cartier depths.

## Physical consequence

The frozen positive chamber occupies the order-nine sheet. The even
order-four and order-two grades are therefore not additional simultaneous
readouts of that chamber. They occur on deck-continued chambers whose infinity
filtration differs.

This sharpens the architecture:

\[
\boxed{
\text{carrier}
+
\text{specialization filtration}
+
\text{residual symmetry}
+
\text{chamber readout}.
}
\]

The residual symmetry is derived from the specialization; it need not equal
the transformation group of the unspecialized object.
