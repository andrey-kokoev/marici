upstream action required by the static-port no-go. It is source-aligned,
rank-one, continuous at its feasibility boundary, and reciprocal-sheet
covariant. For `J=diag(1,-1)`,

\[
JQ(r)J=Q(-r),
\qquad
J\Delta_*(r,f)J=\Delta_*(-r,f).
\]

But the repaired determinant is

\[
\det(Q+\Delta_*)=f^2>0.
\]

The update therefore repairs a finite local balance; it does not yet
transport a zero of the completed scalar theta readout into the joint kernel
of the incidence packet.

action witness gives the surviving target: construct a source-authorized,
sheet-covariant active connection whose admissible solution law propagates
the scalar boundary condition through the generated transport algebra. This
avoids the static linear factorization obstruction because it restricts the
state object before observation.
