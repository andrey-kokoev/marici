# 3143 — The Riemann Readout Is an Exterior Boundary Value of the Polarized Interval Kernel

For \(\Re s,\Re w>1/2\), the canonical positive kernel is

\[
K(s,w)=\zeta(s+\bar w),
\]

and its logarithmically weighted polarization is

\[
Q(s,w)=-2\zeta'(s+\bar w).
\]

The diagonal of \(Q\) is the full interval energy. The Riemann readout is
formally \(K(s,0)=\zeta(s)\), but \(w=0\) lies outside the Hilbert parameter
domain and represents the nonnormalizable constant observer.

## Scope

RH-bearing content is therefore the construction and orientation of a
source-authorized relative boundary morphism to this exterior observer, not
positivity of the interior kernel alone.
