# 2687 — Symmetry Selects an Actuator Origin Only When Invariant Shears Vanish

For a finite group acting affinely on the lift torsor (B_0+V), averaging
produces a mathematical equivariant lift when the actuator space is closed
under affine averages. Fixed lifts form a torsor over (V^G), so the origin is
unique exactly when (V^G=0). Unique equivariance still need not imply logical
nondisturbance or executable authority.
