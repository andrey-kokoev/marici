# 3968 — The Arithmetic Comb Has an Exact Weighted Duality Threshold

For \(a>0\), let

\[
\|h\|_a=\sup_{v\leq0}e^{-av}|h(v)|
\]

and define

\[
\mu_\beta
=
\sum_{n\geq1}n^{-\beta}\delta_{-\log n}.
\]

Then \(\mu_\beta\) is a continuous functional on this weighted
negative-ray space exactly when

\[
a+\beta>1.
\]

Indeed its operator norm is controlled by
\(\sum n^{-(a+\beta)}\); envelope-saturating finite test functions prove
necessity. The theta half-density comb therefore requires \(a>1/2\), while
the critically gauged unweighted comb requires \(a>1\).

The exponential character \(h_z(v)=e^{-zv}\) gives

\[
\langle\mu_\beta,h_z\rangle
=
\sum_{n\geq1}n^{z-\beta},
\]

which converges exactly for \(\Re z<\beta-1\). Pure Fourier characters are
outside the raw duality chamber. Critical spectral evaluation is therefore a
continuation operation across a typed domain wall, not an internal Fourier
readout already present in the arithmetic comb.

## Scope

This is an exact theorem for an elementary weighted Banach scale. It does not
construct the final adelic test space, Tate continuation, or RH orientation.
