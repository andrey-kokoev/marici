# 3194 — A Singular Spectral Weight Still Confines Positive-Weight States

For a skew-adjoint (A), a nonnegative but singular (P), and a nonzero state
satisfying

\[
(A+zP)\psi=0,
\qquad
\langle P\psi,\psi\rangle>0,
\]

the real-part identity forces (\operatorname{Re}z=0). Thus the theta tail
weight need not be regularized. The actual missing constructor is the adjoint
reverse incidence that would make the bordered carrier skew-adjoint. The
positive-weight gate must also exclude common null states.
