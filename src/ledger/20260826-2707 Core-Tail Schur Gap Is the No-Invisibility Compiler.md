# 2707 — Core–Tail Schur Gap Is the No-Invisibility Compiler

For a source Gram block matrix with positive core and tail blocks, finite
coercivity is equivalent to the normalized cross coupling having norm below
one. Completion-stable no-invisibility requires this Schur gap and the
diagonal lower bounds uniformly. Positive diagonal blocks alone fail at the
exact threshold, and cutoffwise positivity fails when the gap closes in the
limit.
