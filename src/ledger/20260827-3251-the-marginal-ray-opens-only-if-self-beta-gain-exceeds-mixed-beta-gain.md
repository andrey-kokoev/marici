# 3251 — The Marginal Ray Opens Only If Self-Beta Gain Exceeds Mixed-Beta Gain

At the regular WP708 boundary ray, let ((N,M,X,C)) denote independently
derived completion corrections to the normalized two self-quartic, mixed-norm,
and correlation beta data. The exact first-order displacement of the radial
stability margin is

\[
\delta D=\frac{N+M-X}{28}.
\]

Thus a proposed completion moves the ray into strict stability only if
(N+M-X>0). The correlation correction (C) changes the angular projective
coordinate but is radially invisible at first order.

This is an acceptance functional, not a selector: the present source does not
authorize the values or signs of the four corrections, and the radial response
has a three-dimensional kernel.
