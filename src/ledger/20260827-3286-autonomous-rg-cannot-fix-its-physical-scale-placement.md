# 3286 — Autonomous RG Cannot Fix Its Physical Scale Placement

Every nonconstant solution of an autonomous dimensionless RG system has a
translation family. Fixed points, projective rays, critical exponents, and
transverse basins can select an orbit but not its placement relative to a
physical energy. For a readout \(O\), the residual sensitivity is

\[
\frac{dO}{dc}=\nabla O\mathbin\cdot\beta.
\]

The smallest exact witness has fixed projective relation \(y/x^2=K\) but
\(y(0)=K/c^2\). One source-authorized dimensionful boundary condition fixes
the translation. No admitted flavor object currently supplies it: electroweak
and detector scales are calibrated readouts, messenger masses remain free,
and importing a Planck scale requires a named cross-sector interface.
