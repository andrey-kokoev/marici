# 2888 — Hurwitz Forbids Zero Creation by Stable Euler Completion

A locally uniform limit of nowhere-zero holomorphic finite Euler sections is
either nowhere zero or identically zero. Therefore the completed section with
isolated zeros cannot arise from stable ordinary Euler completion on any
domain containing those zeros. A valid determinant programme must change the
finite approximants, topology, transition data, or completed object by
source-derived relative boundary structure before reaching the divisor.
