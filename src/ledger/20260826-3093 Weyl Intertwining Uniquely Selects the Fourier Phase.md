# 3093 — Weyl Intertwining Uniquely Selects the Fourier Phase

The missing phase selector is naturally an intertwiner, not an operator
commuting with both Weyl polarizations.

For clock \(Z\), shift \(X\), and Fourier selector \(F\), require

\[
FX=ZF,
\qquad
FZ=X^{-1}F.
\]

Irreducibility makes the intertwiner space one-dimensional. The source
normalization sending the position vacuum to the uniform momentum vacuum
then fixes the remaining scalar.

Phase selection is therefore solved in the finite Weyl model without using
determinant or zero data. The next gate is whether the normalized adelic
Fourier graph is a maximal isotropic boundary relation for the doubled Dirac
carrier.

## Scope

Green-form maximality, and determinant comparison remain open.
