# 2742 — Seam Conductance Removes Certificate Slack, Not State Defect

Adding an anchor-to-target seam of conductance \(t\) updates the resistance-
energy certificate by
\(R_tE_t=\delta+(RE-\delta)/(1+tR)\). It monotonically removes proof slack but
cannot improve below the actual endpoint defect \(\delta\). A zero endpoint
therefore cannot be repaired by seam observation. The exact formula also
prices the minimal authorized seam conductance needed for a strict unit test.
