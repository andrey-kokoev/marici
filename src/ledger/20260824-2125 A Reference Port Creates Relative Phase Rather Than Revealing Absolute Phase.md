# 2125 — A Reference Port Creates Relative Phase Rather Than Revealing Absolute Phase

A cross-history comparison carries the character

\[
(\alpha_0,\alpha_1)\mapsto\alpha_1-\alpha_0.
\]

Its kernel is the diagonal common-phase line.  The port therefore reduces
independent history rephasings to their diagonal subgroup and creates a
gauge-invariant relative coefficient.

It does not reveal an absolute phase.  Even a two-quadrature reconstruction
recovers only the relative holonomy; common phase remains gauge.

Consequently an off-diagonal cosmological history comparison would be new
source structure, not a more precise version of the standard diagonal
equal-time readout.
