# Native Mellin Transport Has a Transverse First-Moment Defect

For horizontal Mellin transport,

\[
(Ah)(u)=uh(u),
\qquad
L(h)=\int h(u)\,du.
\]

The parallel-kernel defect is the first-moment covector

\[
LA(h)=\int uh(u)\,du.
\]

It is not proportional to `L`. The exact two-cell packet that is `+1` on
`(0,1)` and `-1` on `(1,2)` has total integral zero but first moment `-1`.
Hence the scalar-null hyperplane is not invariant under native Mellin
transport.

The active-connection route has therefore reached a real obstacle. A
completed connection must cancel the transverse first-moment class using
independently sourced prime, boundary, archimedean, or reciprocal-seam data.
An algebraically manufactured rank-one correction would be tautological.
