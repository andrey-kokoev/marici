# 3193 — Noncommuting Endpoints Still Need a Coherent Reference

## Result

The entrance projector does not commute with the balanced messenger mass
tensor. Nevertheless the isolated cross-endpoint propagator

\[
G_{AB}=\frac{m}{x^2-m^2}
\]

has a probability invariant under (m\to-m); for complex mixing, the rate
depends only on (|m|).

An independently normalized same-channel amplitude (r) would yield a
sign-sensitive interference difference (4mr/(x^2-m^2)). No such coherent
(QH\to Xq) reference amplitude is admitted.
