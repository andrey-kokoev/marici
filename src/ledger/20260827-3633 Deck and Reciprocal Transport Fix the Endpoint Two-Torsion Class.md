## Superseded object

\[

## Native transport

The deck involution \(W\mapsto-W\) exchanges the two sheets at each endpoint.
It sends

\[
\tau\longmapsto-\tau.
\]

The reciprocal chart transition \(t\mapsto1/t\), accompanied by the
source exchange \(x\leftrightarrow y\), exchanges zero and infinity on each
sheet. It also sends

\[
\tau\longmapsto-\tau.
\]

Their composite fixes the integral lift. More importantly, because
\(2\tau=0\), each involution individually fixes the actual torsion class:

\[
-\tau=\tau
\quad\text{in}\quad
\langle\tau\rangle\cong\mathbb Z/2.
\]

## Result

The source deck and reciprocal generators induce the trivial representation
on the endpoint two-torsion line. They do not supply a nontrivial discrete
holonomy or the labelled Cartan action excluded by Entry 3632.

The surviving datum is therefore a transport-invariant \(\mathbb Z/2\) class
on the generic locus. Its remaining possible physical content is a mod-two
pairing with a source-derived integral relative cycle or a supported
specialization on an existing discriminant locus.

## Scope

This computes the subgroup generated by sheet exchange and reciprocal
endpoint exchange. It does not determine transport around every discriminant
component of the full parameter base.
