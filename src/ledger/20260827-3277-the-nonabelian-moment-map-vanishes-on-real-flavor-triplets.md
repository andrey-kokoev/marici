# 3277 — The Non-Abelian Moment Map Vanishes on Real Flavor Triplets

For an adjoint triplet the standard non-Abelian moment map is

\[
\mu(\phi)=-i\phi^*\mathbin\times\phi.
\]

It vanishes identically on the admitted real-triplet flavor domain. Parallel
and orthogonal triplet frames therefore have distinct physical angular
invariants but the same zero moment-map readout. The direct unified D-term
candidate supplies neither angular rigidity nor an asymmetric portal.

Making the moment map nonzero requires complex-conjugate or cotangent
directions. That is an enlarged relational experiment with a changed state
domain, not descent of the operation to the existing `physical16` quotient.
The surviving source class must instead act directly on real triplets, for
example through a derived tensor or F-term constraint.
