# 3219 — A Visible Cubic Decay Separates the Portal Branches

vacuum norms, and \(\lambda_p=\pm1\), both branches have mass-squared spectrum
\(\{1,5\}\) and equal visible Higgs overlaps.

Their source-derived heavy-to-two-light cubic couplings are

\[
g_{HLL}^{(+)}=\frac{7\sqrt2}{2},
\qquad
g_{HLL}^{(-)}=0.
\]

The channel is open on shell because \(\sqrt5>2\). Visible decays of the light
states therefore separate the WP694 hostile pair without a direct exit port.
This identifies the branches conditionally; it does not select which branch
the source must realize.
