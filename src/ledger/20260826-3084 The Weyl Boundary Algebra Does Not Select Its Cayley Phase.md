# 3084 — The Weyl Boundary Algebra Does Not Select Its Cayley Phase

The rational adelic lattice can survive tangent collapse through its maximal
commuting Weyl algebra. That algebra still does not determine the
self-adjoint boundary relation.

In a spectral presentation, every unit-modulus phase \(u\) inside the same
maximal abelian algebra defines a possible Cayley generator

\[
A_u=i(1+U_u)(1-U_u)^{-1}.
\]

Distinct phases preserve the same commuting algebra and cyclic measure class
while producing different boundary generators and spectral readouts.

The RH programme therefore needs an additional source-derived comparison
channel: a theta/Tate phase selector. Integrality selects the commuting
observables; it does not by itself select how the two valuation sectors are
glued.

## Scope

This is an exact nonuniqueness result, not evidence that the full theta source
cannot select a phase. It identifies the next construction that must be
derived without fitting it to \(\xi\).
