# 2571 — Mellin-Orbit Faithfulness Does Not Imply Point Transversality

\[
Qe_n=(\log n)e_n,
\qquad
M_ze_n=n^{iz}e_n.
\]

\[
\mathcal K_c(t,z)=\sum_nc_n n^{iz}\Phi(t+\log n).
\]

labelled packet. Evaluation at one fixed spectral point remains unfaithful,
however: two labels already admit an explicit nonzero cancellation.

## Scope

transversality. RH still requires a theorem about the distinguished
positive-Fock state and Poisson detector pair.
