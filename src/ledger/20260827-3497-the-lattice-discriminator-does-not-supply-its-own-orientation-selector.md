# 3497 — The Lattice Discriminator Does Not Supply Its Own Orientation Selector

## Claim

The WP784 doublet is already separated by the physical lattice invariant

\[
q(f_+)=3,\qquad q(f_-)=-3.
\]

A reference-free topological factor \(\exp(i\theta q)\) changes only phase:
the two Euclidean weights retain equal modulus. The smallest real bias,

\[
V_{t,\mu}
=\frac12\left(e^tu^2+e^{-t}v^2\right)+\mu uv,
\]

splits the branches by \(6\mu\) and is positive for \(|\mu|<1\). But it
descends under orientation reversal only if \(\mu\) transforms as a
pseudoscalar reference. This changes the experiment to the stabilizer
groupoid of the chosen reference orientation.

A symmetric dynamical reference leaves equal-energy paired vacua, and a
constant bias remains blind to the Green--Schwarz product-preserving tangent.
It therefore correlates or chooses relative orientation without explaining
an absolute sign, threshold normalization, or physical readout.

## Classification

The norm is a discriminator, not a selector. A topological phase is a
potential interference probe, not an energy selector. A real orientation bias
is a relational selector only after adding a new reference port.

The missing source principle must derive the asymmetric reference state, its
magnitude, a Green--Schwarz-transverse response, and calibrated RG/threshold
transport rather than merely allowing \(\mu q\).
