Kitaev's eight countermodels falsify the stronger claim that constructor
grammar and completion universally determine physical reality. The shared
source-authority calculus is therefore retyped as a bounded audit framework.

A source-relative capability audit now carries

\[
(\mathcal S,\mathcal M,\mathcal R,\mathcal C,\mathcal V;
\varepsilon,T,B),
\]

where the physical source and implementation model produce the capability,
the resource class includes its descendant closure, and an independent
verification model certifies recovered behavior within explicit budgets.

The compiler rejects:

- using the implementation model as its own verifier;
- removing a named resource while retaining its descendants;
- presenting a bounded audit as a universal law.

Together with Entry 2427, the surviving invariant is

\[
\text{constraint}\ne\text{completion}\ne\text{capability}
\ne\text{verification}\ne\text{authority}.
\]

This is a falsifiable discipline for licensing claims relative to declared
sources and budgets. It is not yet a metaphysics of what can exist.
