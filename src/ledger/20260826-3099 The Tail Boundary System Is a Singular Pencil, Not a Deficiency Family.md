# 3099 — The Tail Boundary System Is a Singular Pencil, Not a Deficiency Family

The source-derived homogeneous tail system has the form

\[
(D_0+sP)\Psi=0,
\qquad
P=\operatorname{diag}(1,0).
\]

Its spectral weight is singular. The null-weight component is exactly the
constant source channel that produces the forcing, so it cannot be deleted.
Reciprocal doubling remains singular.

Consequently, the tail states are not yet deficiency vectors of one fixed
symmetric operator. The ordinary Lagrangian forbidden-incidence theorem
cannot be applied until the pencil is realized as a self-adjoint linear
relation or augmented by a source-derived dynamical partner.

This is exactly the earlier one-way-incidence obstruction in pencil form. The
upper forcing block has no adjoint lower block; symmetric completion would add
a genuine backreaction equation that the current theta source has not
constructed.

## Scope

The typing obstruction is exact. It does not rule out a confinement theorem
for the singular pencil; it identifies the new theorem that would be needed.
