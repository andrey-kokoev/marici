# The Exceptional Prime-Current Adjoint Relation Is Global, Not Seam-Local

For a real source, each reciprocal prime-power boundary current satisfies

\[
C_{k,p}(-\overline z)=\overline{C_{k,p}(z)}
\]

for every complex (z). Whenever the exceptional (k=1,2) prime sums
converge, their limits inherit the same identity. Hence the adjoint relation
previously proposed for the completion-class jump is not confined to the
critical seam; it is ordinary global real structure.

The jump still explains what changes at every scalar zero, but it cannot
explain where zeros occur. A surviving completion attack must construct a
mixed-depth extension class not reducible to separate termwise adjointness.
