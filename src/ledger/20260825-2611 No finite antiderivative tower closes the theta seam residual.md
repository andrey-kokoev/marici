# 2611 — No Finite Antiderivative Tower Closes the Theta Seam Residual

residual, but differentiation creates the next level with residual row

\[
r_{j+1}=r_jA_z.
\]

\[
\det A_z=-|z|^2.
\]

if its last nonzero row annihilated \(A_z\), which is impossible.

Thus no finite antiderivative tower closes the generic theta forcing. The
complete infinite-dimensional shift state, or independently closed source
dynamics, is mandatory.
