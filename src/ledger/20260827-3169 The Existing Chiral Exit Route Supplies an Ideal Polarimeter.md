# 3169 — The Existing Chiral Exit Route Supplies an Ideal Polarimeter

## Result

The protected decay \(A\to B+n\), followed by the existing chiral exit
\(B\to q_R+X\), admits compatible flip charges and simultaneous positive
threshold margins.

In the massless perfect-transfer limit, the exit-quark angular distribution
has signed moment

\[
3W\langle\cos\theta\rangle=u-v,
\qquad W=u+v.
\]

The two-port response determinant is minus two. No reverse decay or added
reference port is required.

## Limit

resolution, and covariance remain uncalibrated. This is a source-derived ideal
cascade, not yet an actual detector instrument or numerical selector.
