# 3969 — The First Comb Boundary Quotient Is the Continuum-Density Mode

For

\[
\eta_\beta
=
\sum_{n\geq1}n^{-\beta}\delta_{\log n},
\]

the exponential transform is \(\zeta(\beta-z)\) in
\(\Re z<\beta-1\). Weighted counting forces the continuous asymptotic
density

\[
d\lambda_\beta(q)=e^{(1-\beta)q}\,dq.
\]

Its transform is exactly the polar part

\[
-\frac{1}{z-(\beta-1)}.
\]

The residual

\[
R_\beta(z)
=
\zeta(\beta-z)
+
\frac{1}{z-(\beta-1)}
\]

extends one full strip farther, to \(\Re z<\beta\), by Euler summation.
The polar coefficient is rigid: changing it leaves a nonzero residue at the
first wall.

The lossless completed object is the pair
\((R_\beta,\lambda_\beta)\). The continuum mode is a source-derived
boundary coordinate, not a divergent term to discard.

## Scope

This proves the first boundary quotient and its one-strip continuation. It
does not construct full Tate--Poisson sewing, higher boundary grades, or RH
orientation.
