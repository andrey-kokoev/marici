## Verdict

Finite countermodels show that chronological source priority is not semantic
evidence, named resources may be substitutable, microscopic nonuniqueness may
express universality, physical dynamics does not generate a mathematical
certificate, and exact code-projector intertwining is unnecessary under
recoverable code deformation.

resource class together with its declared descendants. Reachability claims

physical model predicts implementation and resource-class counterfactuals,
while a separate verification model certifies the recovered channel within
declared bounds.
