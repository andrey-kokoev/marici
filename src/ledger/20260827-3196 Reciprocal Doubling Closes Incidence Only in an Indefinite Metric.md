# 3196 — Reciprocal Doubling Closes Incidence Only in an Indefinite Metric

The canonical direct--dual incidence double is a nonzero nilpotent operator.
It is skew for the sector-exchange form, but that form is indefinite. No
positive-definite metric can make a nonzero nilpotent operator skew-adjoint.

Thus Fourier--Tate duality supplies the missing arrow directionally, but not
the positive conservation law needed for confinement. An additional
source-derived boundary incidence must break the nilpotent Jordan chain and
connect the exchange current to the positive Clark-sheet Gram trace.
