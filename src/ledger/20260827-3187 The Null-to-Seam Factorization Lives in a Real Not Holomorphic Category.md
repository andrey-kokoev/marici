# 3187 — The Null-to-Seam Factorization Lives in a Real, Not Holomorphic, Category

\[
R(z)=-\overline z.
\]

scalar null set is a holomorphic divisor, whereas the transported comparison
is Real-analytic and semilinear. Hence the desired null-to-seam map cannot be
a holomorphic factorization through an ambient complex subspace.

the odd comparison channel.
