## Frozen background

The source relates the flat-space toy-model coupling to the FRW warp factor by

\[
\lambda_k(\eta)
=
\lambda_k[a(\eta)]^{,2+(d-1)(2-k)/2}.
\]

For \(d=1\), it identifies the non-power-law solution

\[
a(\eta)=a_0e^{A_0\eta},
\qquad A_0>0,
\]

which vanishes as \(\eta\to-\infty\). The coupling becomes, independently of
the valency \(k\),

\[
\lambda_k(\eta)=\lambda_ka_0^2e^{2A_0\eta}.
\]

This normalization is frozen from the source before comparison with the
Marici carrier.

## The endpoint is a finite-proper-time Big Bang

Cosmic proper time satisfies

\[
dt=a(\eta)d\eta.
\]

Choosing the endpoint origin gives

\[
t=\frac{a_0}{A_0}e^{A_0\eta},
\qquad
a=A_0t.
\]

Thus \(\eta=-\infty\) is the finite proper-time endpoint \(t=0\), with
\(a=0\). Unlike the generic power-law discussion, this source example is a
literal finite-time Big-Bang boundary.

## Exact site kernel

At one interaction site, let \(E_s\) denote the sum of incident energies in
the time-evolution exponential. The source time factor is

\[
\int_{-\infty}^{0}
e^{2A_0\eta}e^{iE_s\eta},d\eta
=
\boxed{\frac{1}{2A_0+iE_s}}
=
\frac{1}{i(E_s-2iA_0)}.
\]

Therefore the usual linear site-energy wall is translated to

\[
E_s=2iA_0.
\]

For fixed nonzero \(A_0\), scaling only the physical energies does not act
homogeneously:

\[
\frac{1}{2A_0+iRE_s}
\neq
R^{-1}\frac{1}{2A_0+iE_s}.
\]

The simultaneous spurionic scaling \((E_s,A_0)\mapsto R(E_s,A_0)\) restores
homogeneity, but that is not the physical all-soft normal scaling with the
background held fixed.

## Classification

The source introduces no new incidence label: each translated denominator is
attached to the same labelled site occurrence as the original partial-energy
factor. What changes is its coefficient/kernel geometry over the background
parameter \(A_0\).

The narrow surviving hypothesis is therefore

\[
\boxed{
\text{existing labelled energy/Cut carrier}
+
\text{an }A_0\text{-dependent translated coefficient object}.
}
\]

This is evidence for H2, not H1. Calling \(E_s-2iA_0=0\) a new carrier wall
would be premature: it is a source-derived deformation of an existing
labelled wall and collapses to it at \(A_0=0\).

## First radial correction

Around the power-law/conical limit \(A_0=0\),

\[
\frac{1}{2A_0+iE_s}
=
\frac{1}{iE_s}
-
\frac{2A_0}{(iE_s)^2}
+O(A_0^2).
\]

The first nonhomogeneous radial datum is a double pole on the existing site
wall. It is coefficient/Rees data unless sewing forces an additional
incidence object.
