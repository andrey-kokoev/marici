# 928 — The Rank-Two Normal-Symbol Module Is Not Closed Under Serialized Differentiation

## Connection-existence gate

Entry 927 proves that the kernel relation

\[
M_x+M_y-M_z=0
\]

is constant. It does not prove that the rank-two image generated by two branch
symbols is preserved by tangential differentiation. Before constructing a
\(2\times2\) connection matrix, closure must be tested.

## Tensor form of the symbol module

After the frozen Cartier regularizations, the three symbols have the form

\[
M_i=v_i\otimes r,
\]

where the target vectors \(v_i\) span rank two and the source row \(r\)
spans rank one. Therefore

\[
\mathcal N_{\rm sym}=V_2\otimes\langle r\rangle,
\qquad
\operatorname{rank}\mathcal N_{\rm sym}=2.
\]

For a tangential derivative \(\partial_\mu\),

\[
\partial_\mu M_i=v_i\otimes\partial_\mu r.
\]

If \(r\) and \(\partial_\mu r\) are projectively independent, the
derivative closure has rank \(2\cdot2=4\).

## Exact closure test

Entry 927's projective Wronskians are nonzero for every tested tangential
variable:

\[
A_2,\qquad A_3,\qquad B_{24},\qquad B_{34}.
\]

For each variable, three Wronskians are nonzero. Hence

\[
\operatorname{rank}\langle r,\partial_\mu r\rangle=2
\]

and

\[
\boxed{
\operatorname{rank}
\langle\mathcal N_{\rm sym},\partial_\mu\mathcal N_{\rm sym}\rangle
=4.
}
\]

Thus

\[
\boxed{
\partial_\mu\mathcal N_{\rm sym}
\not\subseteq
\mathcal N_{\rm sym}
}
\]

in the serialized transition frame.

## Consequence

No canonical rank-two tangential connection can be extracted from the
transition matrix alone. Doing so would require one of:

- the independently derived ambient connection on the six-word source bundle;
- a source-derived projection back to \(\langle r\rangle\);
- a larger derivative-closed coefficient module.

Choosing a complement or projection by sparsity would be post hoc.

The constant syzygy remains valid: it is a relation in the kernel of the
branch presentation. What fails is closure of its rank-two image under the
bare serialized derivative.

## Narrow conclusion

The current object is

\[
\boxed{
\text{rank-two algebraic normal-symbol module}
+
\text{constant syzygy}
+
\text{rank-four first derivative closure}.
}
\]

It is not yet a rank-two local system. This is a coefficient-typing
obstruction, not evidence for a new carrier stratum.
