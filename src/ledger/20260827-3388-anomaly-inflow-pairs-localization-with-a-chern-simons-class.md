# 3388 — Anomaly Inflow Pairs Localization with a Chern–Simons Class

## Claim

For one cancellable anomaly channel on an interval,

\[
A_0=b_0+\frac{B}{2}+k,
\qquad
A_\pi=b_\pi+\frac{B}{2}-k.
\]

Global cancellation fixes

\[
b_0+b_\pi+B=0
\]

but does not constrain the Chern–Simons level \(k\). If \(k\) is adjustable,
each localization imbalance is paired with

\[
k=-b_0-\frac{B}{2}.
\]

## Smallest witness

The same \(+1,-1\) four-dimensional chiral packet is locally consistent with
both modes in the bulk and \(k=0\), or split across opposite boundaries and
\(k=-1\). The bulk spectral counts differ by two.

## Classification

Anomaly inflow is a cofiber of localization and inflow classes, not a
localization selector. A higher-dimensional anomaly polynomial or UV
completion must independently fix the complete Chern–Simons level vector
before local anomaly equations can constrain the WP754 lift.
