# 3152 — The Messenger Stability Bound Requires a Kinetic Interface

## Result

Under the scalar redefinition \(n'=sn\), raw \(y^4\) changes, while

\[
\widehat F=\frac{y^4}{Z^2}
\]

is invariant. The physical radial margin similarly descends only after its
kinetic denominators are included.

The raw packets \((Z,y)=(1,1)\) and \((4,2)\) have fourth powers one and
sixteen but identical canonical strength one.

## Consequence

WP664's bound is valid in canonical coordinates, but the current source model
does not provide the required kinetic Gram. It cannot yet be evaluated as a
physical finite-scale gate. This is a missing source-to-canonical interface,
not a selector.
