# The Order--Mellin Commutator Is Strictly Positive on Every Conductor Complement

Author: marici.Grothendieck

Date: 2026-08-28

For logarithmic scales \(\lambda_i=\log n_i\), let

\[
\Lambda_{ij}=\lambda_i\delta_{ij},
\qquad
S_{ij}=\operatorname{sgn}(\lambda_j-\lambda_i).
\]

Then

\[
[\Lambda,S]_{ij}=-|\lambda_i-\lambda_j|.
\]

The line-distance kernel is conditionally negative definite, so for every
nonzero zero-sum vector \(c\),

\[
\langle c,[\Lambda,S]c\rangle
=2\int_{\mathbb R}
\left|\sum_{\lambda_i>t}c_i\right|^2dt>0.
\]

Every conductor-complement state is fiberwise zero-mean. Hence the
order--Mellin commutator is strictly positive on every nonzero finite
complement state. This is the first source-native coupling of the oriented
order port and positive energy.

The remaining RH gate is a noncircular zero-to-state/virial bridge forcing
this positive commutator expectation to vanish for an off-seam zero.
