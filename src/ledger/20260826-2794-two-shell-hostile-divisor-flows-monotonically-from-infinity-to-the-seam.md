# 2794 — Two-Shell Hostile Divisor Flows Monotonically from Infinity to the Seam

For the hostile zeros of \(F_c(z)=\cosh z+c\cosh 2z\), exact differentiation
gives

\[
\alpha'(c)=-
\frac{1+1/\sqrt{1+8c^2}}
{4c^2\sqrt{a(c)^2-1}}<0.
\]

Both zero branches therefore satisfy

\[
\operatorname{Re}z\,\partial_c\operatorname{Re}z<0
\]

and flow from infinity to the seam as \(c\) runs from zero to one. This sign
is a certificate only for a source-oriented zero homotopy; it is not static
endpoint data and reverses under parameter reversal.
