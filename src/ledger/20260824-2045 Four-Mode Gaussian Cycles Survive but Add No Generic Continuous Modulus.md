# 2045 — Four-Mode Gaussian Cycles Survive but Add No Generic Continuous Modulus

## Hostile question

At four pure Gaussian modes, do locally symplectic-invariant cycle traces carry information not already present in the local and pair invariants?

The predeclared candidate was

\[

\operatorname{tr}(JC_{12}JC_{23}JC_{34}JC_{41}).
\]

The stronger test requires the complete degree-four cyclic packet, not this trace alone.

## Full degree-four cyclic packet

Set \(X_{ij}=JC_{ij}\). Under independent local gauges,

\[
X_{ij}\mapsto S_i^{-T}X_{ij}S_j^T,
\]

so traces of closed labelled walks are invariant.

Every degree-four closed walk containing an immediate backtrack reduces to lower pair determinants through

\[
JC_{ij}JC_{ji}
=
-(\det C_{ij})I_2.
\]

Modulo these reductions, the primitive degree-four cyclic space is represented by the three unoriented Hamiltonian cycles of \(K_4\):

\[
L_{1234},
\qquad
L_{1243},
\qquad
L_{1324}.
\]

All three are nonzero on the exact source packet.

Thus outcome 1 is falsified:

\[
\boxed{
\text{pure four-mode Gaussian cyclic memory survives.}
}
\]

## Does it define a new information grade?

Serafini--Adesso's generic pure Gaussian standard-form count gives

\[
\frac{n(n-1)}2=6
\]

local-symplectic moduli at \(n=4\).

Use the six pair invariants

\[
d_{ij}=\det C_{ij},
\qquad 1\le i<j\le4.
\]

Their exact \(6\times6\) Jacobian with respect to the six source coordinates has rank six. Consequently the \(d_{ij}\) form local coordinates on the generic six-dimensional quotient represented by this source family.

Therefore every locally symplectic invariant—including the three nonzero Hamiltonian traces—is locally an algebraic function of the lower pair packet. Infinitesimally,

\[
\boxed{
\frac{\langle dL_{1234},dL_{1243},dL_{1324}\rangle}
{\langle d(\det C_{ij})\rangle}
=0.
}
\]

This selects outcome 2 on the generic local locus:

\[
\boxed{
\text{a nonzero four-cycle survives, but it adds no continuous information grade beyond pair invariants.}
}
\]

The calculation does not yet exclude a global finite branch ambiguity: two disconnected pure states might share all lower invariants while differing by a discrete cycle value. Outcome 3 is ruled out locally, not globally.

## Three-mode-prefix extension residue

\[

\[
\boxed{

\[
\boxed{

\[

\[

\[

\[
\boxed{

\longrightarrow

\]

However, that residue does not create an independent four-cycle modulus on the generic quotient. The cycle is a composite readout of the same legal extension data.
