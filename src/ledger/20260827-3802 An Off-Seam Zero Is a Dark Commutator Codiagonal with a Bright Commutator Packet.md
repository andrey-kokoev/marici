# 3802 — An Off-Seam Zero Is a Dark Commutator Codiagonal with a Bright Commutator Packet

For the oscillatory sheet state \(v_t=(e^{itu},e^{-itu})\), opposite Mellin
transport \(T_a\), and sheet swap \(S\),

\[
[T_a,S]v_t
=2\sinh(au)(e^{-itu},-e^{itu}).
\]

Its codiagonal is

\[
-4i\sinh(au)\sin(tu).
\]

After source integration this is the antisymmetric real quadrature, so it is
automatically dark at every completed scalar zero. But the full packet norm is

\[
8\int_0^\infty k(u)\sinh^2(au)\,du,
\]

which is strictly positive whenever \(a=\operatorname{Re}z\ne0\).

Thus a hypothetical off-seam zero is precisely a dark commutator codiagonal
with a bright commutator packet: Aspect's transmission-zero and incidence-
alias pattern.

The incidence axis must split. Canonical source incidence is matched, while
commutator observation incidence is aliased. The missing RH action is a
canonical-incidence descent theorem making the codiagonal faithful on the
scalar-null family.
