# 1692 — The First Cubic Density-State Tangent Is a Third Cumulant

## Falsifier

Entry 1691 proves that the source Gaussian moment cone is represented by
positive trace-class density operators.  Test whether Entry 1630's unbounded
degree-four coordinate is the first cubic tangent out of that cone.

## Exact density-state orbit

For `[Q,P]=2i`, freeze the source cubic unitary

\[
U_t=\exp(-itQ^3/6).
\]

It gives the exact Heisenberg transformation

\[
U_t^\dagger P U_t=P-tQ^2.
\]

Let the initial state be centered, parity-even, and Gaussian, with

\[
\langle Q^2\rangle=a.
\]

After recentering momentum,

\[
\Pi_t=P-t(Q^2-a).
\]

Wick reduction then gives the connected third moment

\[
\boxed{
\kappa_{QQ\Pi}(t)=-2ta^2.
}
\]

It is generically nonzero at first order.  Every point on this orbit is a
physical density state because

\[
\rho_t=U_t\rho_0U_t^\dagger.
\]

## Degree-four comparison

For Entry 1630's coordinate

\[
Z=\operatorname{Re}\langle Q^2S\rangle,
\qquad
S=(Q\Pi+\Pi Q)/2,
\]

the cubic correction is

\[
-t(\langle Q^5\rangle-a\langle Q^3\rangle)=0
\]

by parity.  The connected fourth-cumulant directions of Entry 1627 also have
zero linear term on this orbit.

## Narrow result

\[
\boxed{
\text{the first source cubic tangent from a centered Gaussian density state is rank three, not Entry 1630's degree-four }Z\text{ direction.}
}
\]

This rejects one proposed provenance for the unbounded truncated packet.  It
does **not** prove that nonzero-`Z` packets fail to extend to density operators.
That remains a distinct noncommutative moment-extension problem.

## Architectural consequence

The source filtration must retain odd cumulant grades before the first
non-Hamiltonian fourth-cumulant layer.  No new carrier stratum is indicated:
the new datum is a sector-specific coefficient grade generated by the exact
cubic unitary.
