# An Off-Sector Zero Is a Quantized Poisson Phase Delay

For a right-half-plane zero `w=a+ib`, its Blaschke factor has boundary phase
velocity

\[
\frac{d}{dt}\arg b_w(it)
=-\frac{2a}{a^2+(t-b)^2},
\]

whose integral is `-2 pi`. Thus every interior zero contributes one quantized
Poisson phase-delay packet while leaving boundary magnitude unchanged.

Under the appropriate Hardy or bounded-type normalization, the residual
between actual boundary phase velocity and the Hilbert-transform phase forced
by log-magnitude is exactly the inner-factor record, up to separately audited
singular-inner data.

The equivalent operational target is a normalized causal theta filter with a
source-authorized stable inverse in each open sector. A Blaschke-modified
hostile has the same boundary magnitude but its inverse has an interior pole.
Fourier--Tate reflection is not this inverse.
