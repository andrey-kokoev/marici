## Labelled normalization sequence

Let \(e_+\) and \(e_-\) denote the two normalized sheets and let \(c\) denote
the conductor class with the Poincare-residue orientation inherited from
\(X\) then \(Y\).  The normalization difference map is

\[
d=(1,-1):
\mathbb Qe_+\oplus\mathbb Qe_-
\longrightarrow
\mathbb Qc.
\]

The deck involution acts by

\[
\tau(e_+)=e_-,
\qquad
\tau(e_-)=e_+,
\qquad
\tau(c)=-c.
\]

Exact matrix multiplication verifies

\[
d\tau=\tau d.
\]

## Character decomposition

On the invariant and anti-invariant generators,

\[
d(e_++e_-)=0,
\]

while

\[
\boxed{
d(e_+-e_-)=2c.
}

Over characteristic zero, the anti-invariant map is an isomorphism.  Hence

\[
\ker d=\mathbb Q(e_++e_-),
\qquad
\operatorname{coker}d=0,
\]

and

\[
\boxed{
H^\bullet_{-}(d)=0.
}

The square-root coefficient character is anti-invariant, so it produces no
generic conductor class.

## Deutsch--Popperian verdict

The conjecture that normalization alone creates a generic anti-invariant
coefficient class is falsified.  The two sheets cancel exactly through the
oriented conductor map.  Any residual class must be supported where the node
coefficient degenerates:

\[

\qquad\text{or}\qquad

\]

These are predeclared supports.  The generic conductor therefore supplies no
new carrier or coefficient obstruction.
