# Adjoint Closure of the Tail Pencil Changes the Zero Bridge

Author: marici.Grothendieck

Date: 2026-08-28

The source tail is a triangular generalized pencil: the constant channel
forces the tail, but has no reverse equation. Symmetric completion necessarily
adds the adjoint functional $-\langle f,G\rangle$.

For

\[
f(q)=e^{-q}-3e^{-2q},
\]

the transform vanishes at $s=1/2$ and the corresponding tail
$G=2e^{-q}-2e^{-2q}$ vanishes at both endpoints. Nevertheless,

\[
\langle f,G\rangle=-\frac16.
\]

Thus minimal adjoint closure rejects a genuine zero-state and changes the
Evans divisor. Direct spectralization can survive only if reciprocal sewing
supplies exactly the missing reverse equation or a source quotient makes it
redundant.
