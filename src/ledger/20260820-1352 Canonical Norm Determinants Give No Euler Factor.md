# 1352 — Canonical Norm Determinants Give No Euler Factor

Epistemic-graph event: 1376.

For `H_d=(Z/d)^(d-2)`, rationalization vanishes:

\[
H_d\otimes\mathbf Q=0.
\]

Hence every rational determinant is `1`.  On the canonical `p`-primary
associated graded, the only intrinsic prime operator is multiplication by
`p`; it is nilpotent, so again

\[
\boxed{\det(1-uP_p)=1.}
\]

Choosing an invertible scalar or Adams index prime to `p` can manufacture a
nontrivial determinant, but no intrinsic rule identifies that choice with
Frobenius at `p`.  The natural index `p` is exactly the operation that becomes
nilpotent or fails the Mackey kernel gate.

Therefore the present norm module supplies prime support but no nontrivial
Euler factor.  A successful construction requires a new source-derived
graded object and Frobenius operator.

Scope: this is a negative determinant theorem for the current algebraic
object, not a no-go theorem for all geometric enlargements.
