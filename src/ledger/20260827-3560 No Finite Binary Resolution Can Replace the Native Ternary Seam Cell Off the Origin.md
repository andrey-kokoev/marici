# 3560 — No Finite Binary Resolution Can Replace the Native Ternary Seam Cell Off the Origin

Aspect's arity gate allows a native ternary residual to be resolved either by a
direct ternary mate or by coherent binary factorization. The latter is ruled
out for every finite source-antiderivative tower off the seam origin.

Binary primitive repair advances the residual row by

\[
r_{j+1}=r_jA_z,
\qquad
\det A_z=-|z|^2.
\]

For \(z\ne0\), \(A_z\) is invertible, so no nonzero residual row can terminate
after finitely many steps.

The live choices are therefore a direct source-derived ternary moving-seam
cell or the complete infinite shift-space associator/current. Adding another
finite binary rung cannot close the obstruction.
