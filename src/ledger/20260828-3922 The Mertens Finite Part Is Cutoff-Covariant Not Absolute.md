# 3922 — The Mertens Finite Part Is Cutoff-Covariant, Not Absolute

Under the clock change `Y=X^alpha`, subtracting the counterterm attached to
the old clock produces the false finite anomaly

\[
M(X^\alpha)-\log\log X-\gamma\longrightarrow\log\alpha.
\]

Using the actual source cutoff scale instead gives

\[
M(X^\alpha)-\log\log(X^\alpha)-\gamma\longrightarrow0.
\]

Therefore the Mertens finite part is a relative scalar on a finite Euler
boundary carrying its norm scale, not an absolute scalar on an unlabelled
limit. The scale coordinate lives in the primitive logarithmic current and
must remain explicit in any completion or relative-determinant comparison.

This correction removes regulator-clock artifacts without removing the BSY
divisor anomaly.

## Scope

This proves cutoff covariance. It does not prove compatibility with
theta--Tate completion, control the square current, or prove RH.
