# The Toeplitz Boundary Index Is the Euler Logarithmic Derivative

For one prime, the depth-`k` unilateral valuation shift has defect projection

\[
P_k=I-V^kV^{*k},
\qquad
\operatorname{Tr}P_k=k.
\]

Pairing this boundary index with the connected Euler coefficient gives

\[
\frac{z^k}{k}\operatorname{Tr}P_k=z^k.
\]

Therefore the Toeplitz boundary map implements the Euler logarithmic
derivative. With `z=p^{-s}`, Mellin differentiation supplies `log p`, so every
prime power receives exactly the von Mangoldt weight `log p`.

The nested difference `P_k-P_{k-1}` has rank one: each prime-power depth adds
one boundary cell. The result explains the arithmetic coefficient but not RH;
Fourier exchanges the two valuation cones and reverses the relative boundary
orientation, whose global archimedean sewing remains open.
