# 3761 — Local Quantization Allows Shifts but Poisson Self-Sewing Selects the Integer Origin

Every shifted right-endpoint quantizer on a positive ray has a positive
Gaussian Haar deficit. Thus local monotone quantization does not distinguish
the integer origin.

For the shifted comb,

\[
\mathcal F\Delta_{\mathbb Z+\beta}
=e^{-2\pi i\beta\xi}\Delta_{\mathbb Z}.
\]

The Fourier transform restores unshifted support and records the shift as a
dual character. It can be a scalar multiple of the original shifted comb only
when

\[
\mathbb Z+\beta=\mathbb Z,
\]

so \(\beta=0\) modulo one. Nonzero shifts also displace the archimedean
boundary and lose the rational carrier cancellation.

Therefore the integer origin is selected by global same-object Poisson
coherence, not by local positivity. Shifted sources require an enlarged
support-plus-character type and different boundary data.
