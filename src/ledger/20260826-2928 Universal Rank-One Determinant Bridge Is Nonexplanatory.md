If \(K(z)=\langle\Omega,u_z\rangle\) and \(a(z)=z^2-1/4\), then

\[
T_z=I+a(z)|u_z\rangle\langle\Omega|
\]

satisfies

\[
\det T_z=1+a(z)K(z)=2\Xi(z).
\]

This exact zero-to-kernel bridge is universal: every hostile scalar overlap
admits the same rank-one construction.  Its inverse contains \(2\Xi(z)\) as
the sole denominator, so invertibility merely restates scalar nonvanishing.

A meaningful bridge must instead derive a labelled source-local operator from
theta/Tate transport, obtain \(\Xi\) only after elimination, and carry an
independent kernel conservation law that hostile multipliers cannot lift.
