# The First Nonflat Interface Is the Fourier–Trace Descent Defect

For a source trace `tau:A -> T` and Fourier operator `F`, an induced transport
`J` on the trace range exists exactly when

\[
F(\ker\tau)\subseteq\ker\tau.
\]

The exact obstruction is

\[
D=\left.\tau F\right|_{\ker\tau}.
\]

If `D=0`, Fourier descends and all of its polynomial relations descend. On an
injective trace range, `J=tau F tau^{-1}`; on the even sector it remains
involutive and flat. Thus the legitimate phase-framed sewing operator already
constructed by the team cannot itself carry a new RH class.

If `D` is nonzero, the trace quotient erased source distinctions required by
Fourier. The kernel must be retained as an interface sector, with defect
complex

\[
\ker\tau\xrightarrow{D}\operatorname{Ran}\tau.
\]

The next RH-bearing locus is therefore one rung later: completion of the
trace range, Mellin endpoint evaluation, restricted-product boundary
passage, or determinant/Evans compression.
