# Weight-Zero Produces the First Genuine Relative Wall Class

## Record

Status: the complete unsplit occurrence lift has a generic nonzero
weight-\(0\) logarithmic wall form. Unlike the weight-\(-1\) form, it is not
meromorphically exact. Its punctured-wall class is a rank-one Kummer class
generated by \(dn/w\), accompanied in the tangential relative realization
by an opposite endpoint polar jet from an exact primitive.

This is the first genuine full-occurrence relative wall class in the tested
grade sequence. It remains coefficient data over the frozen exceptional
carrier and has zero direct infinity-Gysin image.

No carrier cell, endpoint summand, projector, or normalization is added.

\[
