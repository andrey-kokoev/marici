# 3198 — The Shared Quark Endpoint Radiatively Requires the Portal

## Result

The ordinary quark Yukawa and messenger exit Yukawa share (q_R). Their
one-loop fermion invariant contains

\[
\operatorname{Tr}[(MM^\dagger)^2]
\supset2y_q^2y_X^2h^2x^2
\]

per color. The quadratic Higgs-exit portal is therefore a required counterterm
when both source Yukawas are nonzero; the zero-portal truncation is not RG
invariant.

## Limit

This forces operator support, not a numerical portal value. A renormalized
boundary term can cancel the running contribution at one scale. Full beta
normalization and finite threshold matching remain open.
