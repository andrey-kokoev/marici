# 2704 — Source-Gram Coercivity Proves No Invisibility, Not Full Surjectivity

(T^*T\ge c^2I) proves bounded-below source transport, hence injectivity and
closed range. It does not prove target surjectivity: an isometric embedding has
source Gram identity and a target Gram cokernel. Full invertibility requires
two-sided source and target coercivity. The stated RH gate needs only the
one-sided no-invisibility theorem.
