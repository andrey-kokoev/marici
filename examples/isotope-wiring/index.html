Help

Reading the graphs

P / N / E
Declared protons, neutrons and electrons. Shell numbers give the declared distribution.
Pair record (EP)
One paired proton/electron entry retained in the stored definition for inventory checks. Stored pair routes are not a separate visualization.
Neutron record (witness)
A counted horizontal or vertical line, or an explicit shell-boundary record. A visible green shape alone does not establish its record count.
Cell and shell
A cell is an addressable graph slot; a shell groups those slots.
Complete definition / changes from base
Two source formats for the same complete graph. The latter stores additions, removals and replacements relative to another definition; it is not a physical growth process.
Neutron-only drawings and stored definitions

Neutron-only is the sole drawing mechanism. Named drawings are defined for supported built-in records and targets; other definitions show an unavailable placeholder, never a different wiring view. Stored record checks concern the supplied model and targets, not physical adequacy.
