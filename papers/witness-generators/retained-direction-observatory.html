What this experiment establishes

The matrices are generated from the source’s twelve triangle frames. For each frame, v = X(1,ω,ω²), with ω = (−1+√−3)/2. The aligned reversed-cycle readout is A = v vᵀ/(v* v). Both interfaces read the same retained real vector.

Two interfaces on different faces reconstruct that vector. Two on the same face retain a common invisible normal. Reading the first output with another projector is a different operation: it cannot recover information already discarded.

When the direction is discarded, this page shows that sequential operation separately. It does not present it as a second measurement of the original direction.

All twelve interfaces come from the existing coefficient construction. This page models access to a retained input, not measurement disturbance or a time-evolution law.
