What this demonstrates

The fourth return combines the retained belt geometry and its mode signs with the spinor projection procedure. Frame normalization preserves both input components. The matrix bridge to the electron construction is checked independently.

This establishes one comparison square. It does not establish all relationships of a meta-tetrahedron: the original proton and belt returns each select one complex mode, while these two returns retain two components. No particle name, charge or mass is assigned to the fourth.
