# Standard Model graph

An interactive reference map of the Standard Model particle species and the strong, electromagnetic, weak, and Yukawa interaction families.

<StandardModelGraph />

## Reading the graph

The nodes represent field species, with antiparticles implied. Links indicate participation in an interaction family; they do not encode coupling strengths or constitute a Feynman diagram. This is a reference graph of established Standard Model structure, separate from Marici's conjectural particle constructions.
