Source rule and the count it actually gives

This version chooses an explicit demonstration graph: four vertices s, A, B, C, with both directions on each tetrahedral edge. A path cannot immediately traverse an edge backwards. Later reuse is allowed. Both outward and incoming families contain all nonempty paths of lengths one through three; this is a bounded enumeration, not all path lengths.

The three edge labels are the tetrahedron’s three perfect matchings. Repeating a label immediately would reverse the previous edge. There are 3, 6 and 12 paths at depths 1, 2 and 3 in either direction. Incoming paths are produced by reversing paths in the same graph, not by introducing partner types or cut marks.

All outward endpoints have distribution (s:6, A:5, B:5, C:5). Incoming origins have the same distribution. Hence there are 6² + 5² + 5² + 5² = 111 endpoint-matched pairs. Of these, 39 immediately reverse the previous edge at the seam; 72 satisfy the whole-path rule. Pairs retain their decomposition, so different cuts of the same closed walk are not deduplicated.

Neither count is 1836. The earlier 36 × 51 page counted a declared record vocabulary, not returns generated by this graph. No source-derived bridge from these returns to that arithmetic has been supplied.

The first three arrows use a tetrahedral frame. Later copies unfold path occurrences toward the meeting region. Each local branching fan rotates by 90° at the third step; this is a display embedding, not an additional graph operation.
