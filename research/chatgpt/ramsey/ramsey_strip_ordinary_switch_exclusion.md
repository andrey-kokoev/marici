# Why an ordinary change of switch cannot fool the checkpoint

Consider a reflected ten-position strip with one used switch V and spare U. The columns U and V are adjacent and differ from both gate columns. Align the candidate return with the swap at both gates and one of visits 4,7. By girth the three-edge segment from the checked gate is prescribed; orient from that end. It starts on the intended rim. Exclude fixed-interior excursions for this argument.

A return with k ordinary crossings has 8-k corners in k+1 runs. Each run needs at least two corners: the only midpoint accessible from any one corner is its own, so a simple path cannot enter and exit the run through distinct midpoints in just one corner. Hence k<=2. Zero crossings cannot fit (each lifted eight-cycle lost outward corners). Two crossings would force exactly two corners per run and midpoint visits 4 and 7, whereas on the one-switch intended route both 4 and 7 are corners. Thus exactly one crossing is possible. It starts and ends on the intended rims and therefore at the same lifted gate-adjacent corners.

The outward path occupied a consecutive four-corner run on one lifted eight-cycle, a three-corner run on the other. The intended return uses their antipodal copies (opposite vertices in the eight-cycle). After deleting the outward path the available rim intervals therefore have respectively four and five vertices. On the four-vertex interval the intended return uses everything; on the five-vertex interval its three-corner run occupies the middle three.

Suppose an alternative switches at U instead of V. At the four-vertex interval the gate end is fixed. The switch end must move to the adjacent column U. This can only shorten that run by one: a three-step retreat reaches the gate's own column, not U. The other run must lengthen from three to four. From its fixed gate end (one vertex in from the end of the five-vertex interval) that can be done only by extending past V to U. Thus in projection the entire change replaces three consecutive edges around the lateral U,V hexagon with its other three edges. These arcs do not have the same lifted endpoints: traversing that hexagon swaps copies, since a closed six-edge lift would contradict girth eight. Consequently the attempt misses the prescribed return copy. This excludes ordinary spare-switch crossings without enumerating route words. It does not by itself classify longer excursions using the fixed spine.
