## Theorem A — Universal based reflection residue

Let `X` be any connected space with an involution `rho`, let `x` be a point, and choose a path `p: x -> rho(x)`. For a based loop `w` at `x`, define

```
Phi(w) = p · rho(w) · p^-1,    z = p · rho(p).
```

Then

```
Phi^2(w) = z · w · z^-1,     Phi(z) = z.
```

Proof: expand the definition twice, use `rho^2=id`, and cancel `rho(p)^-1 rho(p)`; the expression for `Phi(z)` follows by substituting `rho(z)=rho(p) p`.

For our source `p=AB` and `rho(p)=BA`; thus **z=AB·BA** is not an optional input. A strict unbased involution generically produces a based action whose square is conjugation by a surviving loop, rather than strict identity. This is a source-derived *loop/obstruction boundary*, **not a nullhomotopy**.

For the free graph, choose base loops `x=AB BC CA`, `y=AD DB AB^-1`, `z=AB BA`. The exact free-group calculation in the Stage 3 checker gives

```
Phi(x)=z y,  Phi(y)=x z^-1,  Phi(z)=z,
Phi^2=conjugation by z.
```

## Theorem B — The quotient presents the green attaching word as a square

**Extra premises:** Add R and B triangular 2-cells to the six-distinct-edge realization:

```
R : AB BC CA
B : AD DB BA
```

The involution freely exchanges R with B. The quotient has two vertices `U={A,B}`, `W={C,D}` and three oriented edge orbits:

```
a = {AB, BA}: U -> U
b = {BC, AD}: U -> W
c = {CA, DB}: W -> U.
```

The R/B triangle orbit gives a single quotient 2-cell of boundary `a b c`. Thus

```
pi1((R+B)/rho) = <a,b,c | abc=1, b is a spanning-tree edge> = <a> = Z.
```

The two candidate green faces are the reflected pair

```
G1 : AB DB^-1 AD^-1
G2 : BA CA^-1 BC^-1.
```

Both project to one quotient face with attaching word `a c^-1 b^-1`. The R/B relation gives `b c = a^-1`, hence

```
a c^-1 b^-1 = a (bc)^-1 = a^2.
```

Consequently, **adding G is exactly adding the relation `a²=1` to the reflection quotient**. A lift of the path `a` from A is AB ending at B; the lift of its square is precisely `AB BA = z`.

This is a canonical *boundary word* conditional on supplied R/B faces; it does not independently construct a disk filling that word.

## Theorem C — Exact covering-group progression

The reflection exchanges every open vertex, edge, and (when admitted) face cell with a distinct cell; it is fixed-point free on these realizations.

| Complex | Covering space fundamental group | Quotient fundamental group | Description |
|---|---|---|---|
| Free graph | `F3` | `F2` | Index-two free-group inclusion, as expected from Nielsen–Schreier |
| Add R and B | `Z`, generated by `z` | `Z`, generated by `a` | The covering injection sends `z` to `a²` |
| Add G1 and G2 | `1` | `C2` | Cover is `S²`; quotient is `RP²` |

For the complete four-face Δ-complex, the direct checks verify `V=4,E=6,F=4`, all edges have two incidences, and each vertex link is a connected circle. Thus it is an orientable closed surface of Euler characteristic 2, hence S². Its involution is free. The quotient is RP² (closed surface of Euler characteristic 1, or by its covering action).

The quotient cellular boundary operators can be written using edge basis `(a,b,c)`:

```
∂2(R) = ( 1,  1,  1)
∂2(G) = ( 1, -1, -1).
```

`ker ∂1` is generated by `a` and `b+c`. The two boundary columns have coordinates `(1,1)` and `(1,-1)`, determinant `-2`. Therefore after G,

```
H1(quotient;Z)=Z/2, H2(quotient;Z)=0.
```

Before G the quotient has `H1=Z`, consistent with the group presentations. This recovers the usual degree-two 2-cell of RP² without presupposing RP² as a construction target. Reference for the standard CW model: [Hatcher, Algebraic Topology, Example 2.42](https://math.uchicago.edu/~farb/algtop2023/Hatcher.pdf).

## Theorem D — Reflection does not select the effect-level green comparison

Two *different* reflection actions on effect data fit the same source involution. They must not be confused.

**Policy I: Preserve edge-orbit effects.** In a one-object group interpretation set

```
AB=BA=a, BC=AD=b, CA=DB=c.
```

The R/B triangle closure conditions reduce to `abc=1` (and its cyclic conjugate). Hence `c=(ab)^-1`. The green path defect is `a²` (or its inverse, depending on boundary orientation). This can be nontrivial, central, or trivial. An explicit additive integer model has `a=1,b=0,c=-1`: R/B close, but the green defect is `2≠0`.

Thus **there is no universal inference from graph reflection + R/B face closure to an effect-level green equality**, valid for this policy.

**Policy II: Sign-reverse additive effects.** Let reflection act on effect values by negation. Then edge weights satisfy

```
w_AB=k,  w_BA=-k;
w_AD=p,  w_BC=-p;
w_DB=q,  w_CA=-q.
```

Both R/B triangles close precisely when `k=p+q`. That very equation forces both green defects to vanish:

```
w(G1)=k-q-p=0,
w(G2)=-k+p+q=0.
```

This is valid for any additive coefficient group, including groups with 2-torsion. The two source occurrences AB and BA remain distinct, but their *effects* are stipulated opposite. The green comparison is a consequence **of this additional contravariant effect law**; it is still not a 2-cell in the free source realization.

The two policies differ in the action imposed on effects, not in the source graph or its involution. Stage 5's `a²` obstruction is not universal across those policies.

## Theorem E — General reflection norm and the exact strict-coherence criterion

The two effect policies in Theorem D are special cases of **one formula**. Let `G` be any (possibly noncommutative) group and let `theta:G→G` be an involutive group automorphism. Assign group-valued effects to source occurrences equivariantly:

```
AB=a, BA=theta(a),
AD=b, BC=theta(b),
DB=c, CA=theta(c).
```

Because `theta²=id`, the red and blue triangular closure constraints are equivalent:

```
R: a theta(b) theta(c)=1
B: b c theta(a)=1
    equivalently, bc=theta(a)^-1.
```

Compute the oriented green loops:

```
G1 = a c^-1 b^-1 = a theta(a),
G2 = theta(a) theta(c)^-1 theta(b)^-1 = theta(a) a.
```

The green residues are **conjugate**, not necessarily equal:

```
G2 = a^-1 G1 a.
```

Therefore **both strict green comparisons exist in a discrete group-effect interpretation exactly when**

```
          theta(a) = a^-1,
```

or equivalently the *twisted norm* `N_theta(a)=a theta(a)` is the identity. This is precisely the 1-cocycle condition for a generator of `C2` acting on `G` via `theta`. The admissible strict choices comprise the cocycle set `Z¹(C2,G)`, and their equivalence classes under a supplied twisted-gauge relation form the nonabelian cohomology set `H¹(C2,G)`. This is an identification of a **conditional effect-model solution set** with standard mathematics, not a source-generated rule selecting `theta` or `a`. For background see [Nonabelian Cohomologies of Cyclic Groups](https://citeseerx.ist.psu.edu/document?doi=11ecd4c27e76a86d94110c3908ae41323ef1c089&repid=rep1&type=pdf).

For an additive coefficient group `A`, the norm specializes to

```
N_theta(k) = k + theta(k).
```

Thus `theta=+1` leaves the doubling obstruction `2k`, `theta=-1` cancels it, and a mixed involution cancels only selected components. Over a rational vector space, `N_theta=2P_+` where `P_+=(I+theta)/2` projects onto the reflection-even subspace.

Exact finite controls:

| Effect group | Reflection action | R/B-closed models | Strict G models |
|---|---|---:|---:|
| `S3` | identity | 36 | 24 |
| `S3` | inner conjugation by an order-2 element | 36 | 24 |
| `Q8` | identity | 64 | 16 |
| `Q8` | inner conjugation by `i` | 64 | 48 |

Further tests exhaust 9,032 R/B-closed assignments on `(Z/m)²`, for `m=3,4,5,6` under four involutions (identity, negation, one plus/one minus, and coordinate swap). In every case the computed green defect equals `N_theta(k)`; the kernel size matches the independently calculated norm kernel.

**Structural consequence:** Given a reflection action `theta` on effects, a genuine strict-green admissibility condition is available: select the theta-twisted involutions `a`. The source incidence alone neither provides that action nor forces the selected element to satisfy the cocycle equation. Nontrivial central norms, as in `Q8`, remain candidates for *higher* projective coherence rather than strict 2-cell fillings.

## Missing generator, precisely stated

The source **does** generate the closed loop `z=p rho(p)` in the free path-groupoid interpretation. In any subsequently specified group-effect representation with involution `theta`, the corresponding defect is its twisted norm `a theta(a)`. When R and B fillings are additionally given, the quotient green boundary is `a²`, with lift `z`. To generate an *actual green 2-cell* one needs at least one of the following separately justified operations:

1. A source-admitted nullhomotopy/2-cell `z ⇒ 1`, invariant under reflected transport and all allowed continuations;
2. An effect representation selecting an explicit equality between interpreted routes, with the full distinct source histories retained;
3. A higher comparison object whose boundary is a possibly nonzero return residue, with its own coherence laws (a projective/weak filling), rather than pretending the residue is zero.

Reflection itself determines none of these three choices. The canonical operation is **defect formation**, not **defect annihilation**. The no-go is witnessed by the quotient `π1=Z` and the explicit `a=1` integer-effect model.
