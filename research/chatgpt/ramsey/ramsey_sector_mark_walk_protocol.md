# Mark-relative walk, frozen before score

Reuse the directed side-crossing and disjoint-pair domain. Mark exactly the sectors incident to the supplied geometric point (actual tetrahedral corner or face centroid). Define height of a sector as shortest directed distance to that set. Shortest connectors only; retain every tie. Predict red iff in BOTH directions some shortest connector makes an inward step and then an outward step (visits a valley relative to the mark); compare the same rule for all eight states. Independently test sufficiency of the full toward/level/away trace multiset, unordered between directions. Refine by retaining absolute initial height, then whether steps are face turns or seam crossings. For each refinement report within-state indistinguishability and train lookup only on 000, test on seven other states without assigning defaults to unseen signatures. This tests shortest walks and a given mark, not all marked paths; no relabeling of the state-to-point binding after scoring.
