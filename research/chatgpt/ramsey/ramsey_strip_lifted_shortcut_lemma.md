# A copy-switching shortcut: alternating-cycle surgery

Let a simple even cycle in a bipartite graph consist of a path between two fixed poles and its reflected copy, disjoint in their interiors. Use one alternating perfect matching on the cycle and any fixed matching on its complement. On the outward path let an internal arc from x to y have length 2k+1, k>=1, with neither pole on the arc. Suppose a shortcut edge x--y' exists, where prime denotes reflection (and hence x'--y exists). Replace the arc by this edge, follow the reflected suffix to the far pole, and reflect the new path for the return. Use the same alternating phase at the starting pole. Match each released run of 2k interior vertices consecutively (1--2, 3--4, ...); keep all previously exterior matches. Write s for the number of vertices strictly between y and the far pole on the original path.

**Claim.** The symmetric difference is one alternating cycle of length 2(s+k+2). Thus the relative permutation of partners has one nontrivial cycle of length s+k+2, sign (-1)^(s+k+1).

**Trace.** Suppose the first arc edge at x is selected in the original matching; otherwise exchange primed and unprimed labels. Reflection fixes each pole and exchanges its two incident cycle edges, so the reflected arc has opposite phase. On that arc the old matching already pairs the released vertices consecutively: all those edges cancel. On the unprimed arc the old odd-indexed edges alternate with the newly assigned interior pairs, giving the entire x-to-y path in the difference. The new selected shortcut y'--x closes the splice. Prefix edges cancel. The shortcut has the same length parity as the old arc but switches copies, so every edge on the two suffixes changes phase, giving the full path y--...--far pole--...--y' of length 2(s+1). Concatenation gives (2k+1)+2(s+1)+1 edges, with no repeated vertex by the disjointness hypothesis. On a bipartite alternating cycle of length 2m the partner permutation has one m-cycle. QED.

Without the copy switch, the suffix edges cancel instead, and an available same-copy shortcut gives a local difference of length 2k+2. Changing the exterior completion independently need not obey either formula. The sign is a statement about matchings, not generally a graph-isomorphism invariant; the 139/137 identification is specific to the Hall construction.
