## Question

Does the six-arrow Marici source have an internally determined reversal that was missed by the previous *identity-on-objects dagger* test? If yes, does it generate the green comparison without selecting it by hand?

## 1. Frozen source

`ActualSeedEndpointTable.agda` contains vertices `A,B,C,D` and exactly these directed occurrences:

```
AB: A→B      BC: B→C      CA: C→A
AD: A→D      DB: D→B      BA: B→A
```

There are no source-supplied equations filling the two triangle cycles, and `BA` remains a separate occurrence from the reversed presentation of `AB`.

Define the triangles as directed cycles based at A:

```
R = AB · BC · CA
B = AD · DB · BA
```

These are *potential* face boundaries, not filled faces in the original free source.

## 2. Exhaustive source symmetry classification

Enumerate all 24 permutations of the vertex labels, requiring the image of each primitive occurrence to be an existing primitive occurrence, either covariantly (`u→v` maps to `f(u)→f(v)`) or contravariantly (`u→v` maps to `f(v)→f(u)`). Every endpoint pair is represented by at most one primitive occurrence, so a vertex permutation uniquely determines the edge permutation when it exists.

Exactly two covariant symmetries exist:

- Identity.
- `σ: (A B)(C D)`, with edges `AB↔BA`, `BC↔AD`, `CA↔DB`.

Exactly two contravariant symmetries exist:

- `τ: (C D)` (fixes A and B), acting `AB↔BA`, `BC↔DB`, `CA↔AD`.
- `στ: (A B)` (fixes C and D), acting `AB↦AB`, `BA↦BA`, `BC↔CA`, `AD↔DB`.

The four covariant/contravariant symmetries form a Klein four-group under composition, with parity remembering variance. All are involutions.

There is **no contravariant source symmetry fixing every vertex**, consistent with the prior failure of an identity-on-objects dagger. But there is an **object-changing anti-involution** `τ`.

For any composable source paths `p,q`, it extends uniquely to the free path category by

```
τ(p·q)=τ(q)·τ(p),     τ²=id.
```

It sends `τ(R)=B` and `τ(B)=R` exactly (including their A-based words). Under the covariant symmetry `σ`, R and B also exchange, up to rebasing the starting point of the oriented cycles. The two symmetries are **not the same operation**.

`σ` can be realized as geometric point reflection of an appropriate four-vertex embedding. The contravariant `τ` fixes two distinct vertices and is **not** point inversion in any faithful Euclidean embedding. Neither source symmetry, by itself, is a certificate of executable reverse motion or an inverse-effect law.

## 3. The red/blue pair is generated by one twisted comparison boundary

Set

```
p = AB : A→B
q = AD·DB : A→B
τ(p)=BA : B→A
τ(q)=BC·CA : B→A.
```

Thus

```
R = p · τ(q),
B = q · τ(p) = τ(R).
```

This identity is **source-derived**, requiring only typed path concatenation and the combinatorially determined anti-involution. In a τ-equivariant effect interpretation, the B relation follows from the R relation when its effect is the identity; it is not an independent operational constraint.

The proposed green relations are `p≈q` and `τ(p)≈τ(q)`. The difference or return norm of `p` is the actual source loop

```
z = p · τ(p) = AB·BA.
```

Moreover `τ(z)=z`, while z remains nontrivial in the source free groupoid and in the R/B-completed fundamental group. Reflection self-duality does not imply norm triviality.

## 4. Conditional theorem in an involutive groupoid

Let `F` interpret the source paths in an effect groupoid equipped with an involutive contravariant operation `†`, with a typing-compatible identification `F(τ(w))=F(w)†`. For the simple one-object group case every edge has a value in a group with anti-involution. Let `P=F(p)`, `Q=F(q)` and assume the R triangle is strictly filled:

```
P Q† = 1.
```

Then

```
Q = (P†)^−1,
Q P† = 1,                 [the B triangle automatically closes]
P = Q   ⇔   P P† = 1.    [strict green condition]
```

The reflected green equality follows by applying `†` to the first one. Thus, in the interpreted effect groupoid, **green closure is equivalent to dagger-unitarity of the forward operation**.

The result applies only where the effect anti-involution is actually matched to source `τ`, and the stipulated triangle relation is admitted. The bare directed table supplies neither an effect groupoid nor such an interpretation nor the triangle filler.

For an involutive groupoid, the two-sided unitary condition follows from `P P†=1` since P is invertible. Without invertibility, one-sided cancellation is insufficient.

## 5. Continuation-stable norm transport

For composable effects P and Q, define `N(P)=P P†`. Contravariance yields

```
N(PQ)=P N(Q) P†.
```

Consequently the class of dagger-unitary effects is closed under arbitrary admissible composition. Nontrivial norm defects are transported by the already generated operations.

This differs fundamentally from Stage 8, which used a **covariant** involutive automorphism `θ` and yielded commutator defects for products of individually θ-admissible operations. The two calculations use different types of reversal and cannot be equated.

## 6. Adversarial exact effect models

All examples below use the same A/B/C/D source and the **same source-derived τ**. Each source vertex is interpreted as the same two-dimensional rational vector space and `†` is matrix transpose. Given any invertible rational 2×2 matrix P, define `Q=(Pᵀ)^−1` and assign

```
AB=P;  BA=Pᵀ;
AD=I;  CA=I;
DB=Q;  BC=Qᵀ.
```

Every assignment respects the source τ as transpose, and both red and blue cycles evaluate to I. Green closes if and only if `P Pᵀ=I`.

- Nonunitary shear `P=[[1,1],[0,1]]`: `N(P)=[[2,1],[1,1]]`, so G does **not** close.
- Nonunitary scale `P=diag(2,1)`: `N(P)=diag(4,1)`, so G does **not** close.
- Orthogonal quarter-turn `P=[[0,-1],[1,0]]`: `N(P)=I`, so G closes.
- Orthogonal reflection `P=diag(1,-1)`: `N(P)=I`, so G closes.

An exhaustive check of all 496 invertible integer 2×2 matrices whose entries belong to `{-2,-1,0,1,2}` confirmed the criterion; precisely 8 satisfy the strict green condition. All computations use exact rational arithmetic.

**Important distinction from Stage 12.** Its order-three unitary countermodel obeyed the *covariant* edge symmetry (`AB=BA=U`). It does not obey the present contravariant dagger law `BA=AB†=U⁻¹` for U of order three. It therefore does not refute this conditional theorem; it refutes its derivation under weaker symmetry assumptions.

## 7. What has and has not been derived

**Derived from incidence:** the two covariant and two contravariant source symmetries, the unique τ exchanging R/B as A-based cycles, its action on both green boundary questions, and the formal return norm `z=AB·BA`.

**Derived under explicit additional inputs:** the unitary criterion for G, redundancy of the reflected B face given a τ-equivariant effect interpretation and filled R, and continuation stability of unitary effects.

**Not derived:** a source-authorized operational interpretation of τ as `†`; a selected effect groupoid, positive pairing or conserved norm; admission of the red face filling; a canonical new 2-cell in the original free geometry; R/B/G triangulation for branching trees; a Ramsey obstruction.

**Logical warning:** imposing `P P†=1` specifically to force G is merely a restatement of G under the theorem. A useful operational principle must justify norm preservation **independently** (for example from a separately established evaluation/transport/energy contract), and then survive branching without modifications.

## 9. A minimal no-go theorem for pairing selection

The already available dual-vector construction does not select a metric. Given an invertible effect `P:V→V`, its canonical action on covectors is the contragredient `(P⁻¹)ᵀ:V*→V*`. The evaluation pairing is preserved for **every** invertible P:

```
⟨(P⁻¹)ᵀ φ, P v⟩ = ⟨φ,v⟩.
```

This does not imply `P Pᵀ=I`: the nonunitary shear above preserves evaluation with its dual action and still fails green closure.

Nor can a nonzero bilinear form on an arbitrary rational vector space be invariant under *every* reversible linear transformation. If M were such a form, applying the invertible scalar map `P=2I` would demand

```
Pᵀ M P = M  ⇒  4M=M  ⇒  M=0.
```

Thus bare invertibility plus all-map covariance cannot canonically force a positive self-pairing or unitarity. A source-admitted restricted transformation class, chosen polarization, or independent norm resource is mathematically necessary for that route. This no-go theorem is about unrestricted linear actions; it does not rule out an intrinsic metric on a richer source with more data.
