# Three-plane pilot: vertex identifiability (not a change to the registered T184 claim)

For each unordered pair of anchors a,b in a labelled (3,7;22) graph, let N be red neighbourhood. For every x outside the anchors retain A=(ax red?, |N(x)∩N(a)|), B analogously. Test two third coordinates: a deterministic product of the two counts (negative control); J=|N(x)∩N(a)∩N(b)|, the number of SAME intermediaries supporting both counts. Interpret planes as level sets of these vertex observables, not Euclidean geometry. Falsifiable strong claim: some anchor pair has singleton triple intersections on all 20 other vertices. We deliberately give the rule an oracle for anchor selection; failure still excludes every source selector within this definition. Weak claim: joint incidence splits some equal-A,B classes. Check 191 archived graphs, all anchor pairs, full distribution of best class counts. Test also if edge color between distinct exterior sites depends only on their two triple addresses (allow entries within one address class); this is weaker than identifying vertices. No extra graph labels or recursive refinement. Graph is input, not prediction.
