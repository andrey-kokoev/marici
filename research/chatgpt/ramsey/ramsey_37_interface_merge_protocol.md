# Joint reconstruction: scoped interface merge pilot

Input: two nonempty binary groups A and B, represented by their nonempty supports in {+,−}. Use the four named Boolean readings in the comparison-interface conjecture without identifying them with graph vertices. No graph, order or target count enters. Cells are the three specified perfect matchings on the four readings. Workload: for a matching, can both readings of some matched pair hold simultaneously? This query is invariant under relabeling the pairs and their endpoints. Across all nine support profiles compare cell response columns with each other, each primitive reading, and functions of all primitive readings. A differing row refutes identification as the same response column. Exact decoding from primitives means no additional stored bit is necessary given those primitives. Control: forget which of the two mixed matchings is queried and retain their unordered answer pair. Scope excludes existence of a vertex, any assignment of occurrence witnesses to graph sites, and threshold conclusions.
