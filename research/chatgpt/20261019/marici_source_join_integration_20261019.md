## 1. Freeze the source program

Let C = Pushout(f,g), with f,g:Bool -> Unit the constant maps already defined in `ClosureGluingTreeRegression.agda`. Reuse its actual term `circleEquiv:C equiv S1`.

For any small type A define

    W(A) = Pushout(pr_A:A x C -> A, pr_C:A x C -> C).

This is a specialization of an existing closure, not a new pushout axiom. Its complete pair family is a dependent sum. Its local output equivalence can be the identity because W(A) is defined to be the constructed pushout.

The selected relation is the COMPLETE product span. Its selection is explicit; this note does not assert that every relational successor or the numerical incoming-family T9 fixture necessarily uses it.

The generator can operate on a complete constructed state:

    State = Sigma(A:Type) Sigma(d:Nat) Tree A d.

It returns

    (A,d,t) |-> (W(A),d+3,extendTree(t))

and a witnessed `joined` step retaining the source state. The depth increment is an implementation bound, not a physical dimension. Two weakenings of the input tree align it with a product node and the fixed circle tree; the top `glueNode` retains all three children.

Starting from the actual circle tree defines

    E_0 = C;
    E_(n+1) = W(E_n);
    i_n:E_n -> E_(n+1) = inl.

The source term `program(n)` is generated by structural recursion for every n. No independently supplied sphere equivalence is used to construct its nodes. The spheres appear as a consequence of the comparison below.

## 2. An equivalence of towers, not only of stage types

Let J_0=S1 and J_(n+1)=J_n*S1, using the same projection-pushout definition of join.

For maps f:A->A' and g:B->B', the induced join map has constructor equations:

    joinMap(f,g)(inl x) = inl(f x)
    joinMap(f,g)(inr y) = inr(g y)
    joinMap(f,g)(push(x,y,t)) = push(f x,g y,t).

When f and g are equivalences, their inverses induce the inverse join map. The inverse laws on attachment paths are the squares obtained by inserting the two factor inverse laws into `push`. Therefore this is a homotopy equivalence of full pushouts, not merely a bijection of endpoint inventories.

Define

    q_0 = circleEquiv;
    q_(n+1) = joinEquiv(q_n,circleEquiv).

Then q_n:E_n equiv J_n, with

    q_(n+1) o i_n = inl o q_n.

For the explicit forward functions the inclusion square computes by reflexivity. Thus the comparison is compatible with the actual stage maps; it is not a list of unrelated sphere identifications. By the join theorem, J_n has homotopy type S^(2n+1).

## 3. Derive and transport the circle action

Cubical 0.9's circle module already defines multiplication by circle elimination, with rotation equivalences. Its H-space module supplies associativity and the unital compatibility witness. No real-angle interpolation or rational-to-real completion is needed for these homotopy types.

Use the constructed equivalence e:C equiv S1 to define

    a_0(g,c) = inverse(e)(g * e(c)).

This action is understood homotopy-coherently: the inverse of e has specified homotopy inverse laws, not an assumed strict inverse. On successors define the diagonal action by

    a_(n+1)(g,inl x) = inl(a_n(g,x));
    a_(n+1)(g,inr c) = inr(a_0(g,c));
    a_(n+1)(g,push(x,c,t)) = push(a_n(g,x),a_0(g,c),t).

The unit and composition laws follow by pushout induction from the corresponding circle laws. The integration candidate writes these proofs, rotation equivalences, stage inclusion equivariance, and the comparison square

    q_n(a_n(g,x)) = standardAction_n(g,q_n(x)).

The push-path case of this square is explicit. It uses the previous-stage square in its left endpoint and the seed-circle square in its right endpoint. It does not erase the attachment witness.

At the mathematical level the entire coherent action is obtained by transporting the standard circle-group action and applying the functorial join in spaces with a group action. The supplied Agda candidate does NOT package an all-dimensional BG-action structure or construct its homotopy orbits. Its written action declarations cover rotation equivalences, unit, associativity, stage inclusion and equivariance; they have not been typechecked here.

Choice of e fixes a coordinate comparison for the proof. It does not produce an intrinsic preferred point on every unpointed four-cycle. Changes of such coordinates must transport the complete action. The original tetrahedral A4 action on a particular S2 is not identified by this construction.

## 4. Instantiate the existing framed coherence theorem

For stage n, let the cut index be

    K_n = Cut(program n) x Cut(program(n+1)).

The input and output frames are the actual values computed by `frame`, not new hypotheses:

    inputFrame(c,d) = frame(program n,c);
    outputFrame(c,d) = frame(program(n+1),d).

Instantiate `FramedCuts` with these frames and the common operation i_n. Its canonical presented map is

    inverse(outputFrame) o i_n o inputFrame.

Its normalization square follows from the frame inverse law. `compatibleIsContr` and the imported arbitrary-finite-dimensional `Higher` construction then give the compatible presentation comparisons and their higher witnesses for this operation.

Likewise, for each fixed g, instantiate the same theorem on a_n(g,-). This provides the cut-presentation form of the rotation map.

Only the compatible PRESENTATION fibers are contractible. E_n itself is not contractible, and these proofs do not remove its sphere homotopy or trivialize the Hopf map. They also do not automatically identify an independently specified higher source cell with the selected compatible cell.

This is the condition needed to use label/from/to presentations; those labels alone are not an attachment map.

## 6. New integral chain certificate from the actual two-attachment seed

Let the source circle have vertices N,S and directed edges a,b, both N->S. Its augmented chain complex satisfies

    d(a)=d(b)=S-N,
    epsilon(N)=epsilon(S)=1.

Shift augmented degrees by one. The basis (empty,N,S,a,b) has degrees (0,1,1,2,2). Denote this complex D. Let R be Z concentrated in degree 2.

Define chain maps and a homotopy:

    p(a)=1; p(empty)=p(N)=p(S)=p(b)=0;
    i(1)=a-b;
    h(empty)=N; h(S)=b; h(N)=h(a)=h(b)=0.

Direct calculation gives

    p i = id;
    d h + h d = id - i p;
    h h = 0; p h = 0; h i = 0.

Thus the primitive oriented loop is derived as the DIFFERENCE of the two retained source attachments, with p(a-b)=1.

For m joined circles, shifted augmented chains are D^(tensor m). Set

    p_m = p^(tensor m);
    i_m = i^(tensor m);
    H_m = sum_(j=0)^(m-1) (ip)^(tensor j) tensor h tensor id^(tensor(m-j-1)),

with the usual Koszul signs for the degree-one map h. The telescoping identity yields

    d H_m + H_m d = id - i_m p_m,
    p_m i_m = id.

Hence the integral reduced homology is Z in degree 2m-1 and zero elsewhere. This excludes unobserved integral torsion in this model; it is stronger than rational Betti counts. The primitive top cycle is (a-b) joined with itself m times.

The Python checker expands every basis identity for m=1,...,5, totaling 19,540 assertions. The formula and its telescoping proof apply for all m. The homotopy TYPE is identified independently by the explicit source-circle equivalence and the join theorem; chain homology alone is not being promoted to a sphere or Hopf proof.
