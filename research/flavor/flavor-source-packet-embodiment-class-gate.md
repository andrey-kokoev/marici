1. **Shifted flux only.** It lacks the interval/orbifold embedding,
   branch projector, localized endpoint action, and orientation law.
2. **Conditional Wilson/Krylov only.** It lacks source orientation,
   independent \(\rho\), production kernel, and gain.
3. **Finite-scheme normalization only.** It lacks selected ports,
   contact-to-boundary access, selector authority, and production rows.

## Open positive class

and production data**. It must supply all six outputs in one provenance
bundle:

- absolute boundary lift;
- integer clock lift;
- oriented second-stage frame;
- independent \(\rho\);
- production and gain;
- physical16 descent.

This class is open, not constructed. Its potential six-output coverage is a
typed requirement, not evidence that such a packet exists.

## Boundary

all six outputs before any selector claim.
