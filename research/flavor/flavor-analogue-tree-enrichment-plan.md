# Flavor analogue tree-enrichment plan

## Trigger

The Flavor evidence graph is broad, but the live issue tree had become narrow:
one selected Nima wait, four sibling waits, and three blocked lifts. A targeted
analogue search found reusable interface disciplines that should become live
audit branches rather than remain prose advice.

A new Nima-side no-go artifact,
`research/nima/flavor-typed-uv-packet-construction-no-go.md`, sharpens the
first blocker: no currently admitted Nima source supplies one source-selected
UV boundary object `U` with common packet identity, frame, lineage, and typed
maps to event production, preparation, compactification, channel cascade,
production matching, and phase authority.

## Enrichment rule

Each new branch must preserve the same boundary: no numerical kernel, ratio,
gain, image, classification, or analogue theorem becomes source authority
unless it is transported from the admitted packet or from the missing object
`U`.

## New audit branches

1. **Source-selected UV boundary object**  
   Construct or obtain `U` with one packet identity, common frame, lineage,
   and six outgoing typed maps.

2. **Instrument-update interface**  
   Require record-conditioned post-record state updates and sequential-record
   continuation, not only event probabilities.

3. **Source-transversal certificate**  
   Distinguish physical recovery from predictive recovery and prove the source
   domain on which quotient descent is faithful.

4. **Constructor-intertwiner certificate**  
   Transport external universality, Hadamard, SIC, or Weyl results through a
   concrete constructor intertwiner, not dimension equality.

5. **Independent-frame anchor**  
   Provide an independently sourced frame anchor and disagreement syndrome so
   common-mode frame drift cannot remain invisible.

6. **Context-saturation hostiles**  
   Test the packet under the admitted context monoid, including feedback and
   internal route slots, rather than only on the injected probe domain.

7. **Gain nuisance-state observability**  
   Carry detector/source gain as a nuisance state with calibration excitation,
   epoch and setting lineage, and a drift or robust-set certificate.

8. **Normalization-port rank**  
   Supply declared physical ports and a Jacobian rank certificate for any
   finite normalization orbit.

9. **Authority-grant composition**  
   Compose partial grants only when endpoints, authority kind, variance,
   evidence domains, transformations, and coherence witnesses agree.

10. **Sequential-record lineage**  
    Bind later records to earlier instrument branches and preserve joint
    record words under continuation.

## Disposition

The tree should remain selected on the Nima event-production wait, but its
frontier should now expose the missing `U` object and the nine supporting
audit disciplines. These branches do not reopen the handoff by themselves.
Reopening requires a cited source or admitted packet supplying `U`, its common
frame and lineage, and all six outgoing maps.
