# Charge-Moment Loop Grammar Does Not Generate the Diameter Flow

## Question

Does the primitive charge spectrum automatically generate WP841's
diameter-normalized beta coefficient when inserted into the smallest
charge-moment loop grammar?

## Moment data versus diameter data

For (Q=\operatorname{diag}(1,2,3)), define

\[
S_2=\operatorname{Tr}Q^2=14,
\qquad
S_4=\operatorname{Tr}Q^4=98,
\qquad
\Delta_Q=2.
\]

The minimal two-term moment flow

\[
\beta_x=x^2(S_2-S_4x)
\]

has the nonzero fixed point

\[
x_{\rm mom}=\frac{S_2}{S_4}=\frac17,
\]

not WP841's (x_\Delta=1/\Delta_Q=1/2). This flow is an exact hostile
grammar, not a claim that unit coefficients reproduce a particular physical
renormalization scheme. It isolates the structural fact that loop data use
moments not determined by diameter.

## Required compensating interaction

Allow an additional Yukawa/scalar screening contribution (Y):

\[
\beta_x=x^2\bigl(S_2-(S_4-Y)x\bigr).
\]

Agreement with the diameter fixed point requires

\[
S_4-Y=\Delta_QS_2,
\qquad
Y_{\rm req}=S_4-\Delta_QS_2=70.
\]

With (Y=70), the desired (x_*=1/2) follows exactly. But the number 70 has
selection authority only if a unique admitted interaction tensor derives it.
Defining (Y) by the desired equality is circular matching.

## Same-diameter hostile

The shifted spectrum (Q'=\operatorname{diag}(2,3,4)) has the same diameter
two but

\[
S_2'=29,qquad S_4'=353,qquad
Y_{\rm req}'=353-2(29)=295.
\]

Thus diameter alone neither reconstructs the moment flow nor determines the
compensating interaction. The common shift is not asserted to be a physical
gauge equivalence; it is a fiber hostile to the proposed map from diameter to
microscopic coefficients.

## Threshold hostile

After deleting the charge-one state, the active spectrum ({2,3}) has

\[
\Delta_{\rm act}=1,qquad
S_{2,\rm act}=13,qquad
S_{4,\rm act}=97,qquad
Y_{\rm req,act}=84.
\]

Even if the ultraviolet tensor supplies 70, the active theory requires 84 to
retain its diameter-selected fixed point. Threshold survival therefore needs
a derived matching theorem for the interaction tensor, not only charge
support.

## Consequence

WP841 remains a sharp target law, but it is not generated by the minimal
moment grammar. The microscopic source must provide a unique scalar/Yukawa
tensor whose loop contraction gives 70 in the full theory and transforms to
the required active value under finite matching. It must do so before the
portal value is consulted.

The first missing arrow is now explicit:

\[
(Q,H_q)
\longrightarrow
T_Y
\longrightarrow
Y(T_Y)=S_4-\Delta_QS_2.
\]

## Disposition

Negative microscopic derivation for the charge-only moment grammar;
progressive exact target for an interaction tensor. The smallest falsifier is
(S_4/S_2=7\ne2=\Delta_Q). Threshold deletion changes the required screening
from 70 to 84. Physical instrumentation remains downstream and unresolved.
