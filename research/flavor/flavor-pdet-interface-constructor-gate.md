# `P_det` interface-constructor gate

Owner: `marici.Figueiredo`.

## Question

WP232 leaves two individually valid objects in different frames:

\[
\text{SM one-loop RG}:\text{ source-derived, not detector-calibrated},
\qquad
\texttt{physical16}:\text{ calibrated, not source-derived detector response}.
\]

Does their coordinate compatibility define a source-calibrated two-error probe?

## Result

No. The missing authority-bearing constructor is

\[
P_{\mathrm{det}}:E_{\mathrm{source}}\longrightarrow R_{\mathrm{det}},
\]

from a source-defined flavor-error module to a calibrated detector-response
module. A valid source model and valid readout cannot be parallelized merely
because their coordinates fit in the same array.

An admitted `P_det` requires an executable source operation independently
exciting two source directions; a named interface and common frame; detector
variations derived from those perturbations; experimental calibration rather
than presentation coordinates; uncertainties and support assumptions; and a
robust rank-two response. For independently calibrated positive `W`,

\[
\operatorname{rank}J_{\mathrm{det}}=2,
\qquad
\det(J_{\mathrm{det}}^TWJ_{\mathrm{det}})>0,
\]

with positive smallest-singular-value margin after uncertainty and completion.

## Exact falsifiers

The smallest algebraic falsifier is

\[
J_{\mathrm{det}}=\begin{pmatrix}1&1\\0&0\end{pmatrix},
\]

which sends two independent source perturbations to the same response and has
rank one and zero Gram determinant. Further failures are presentation-derived
calibration, detector changes not generated by source perturbations, nominal
rank two collapsing within uncertainty, and separate source/readout objects
with no named common-frame interface. The pair “SM RG plus `physical16`” fails
the last test.

## Disposition

WP232 is a genuine source-support closure, not an unfinished algebraic step.
The coordinate-map branch is currently neither selector nor physical
instrument. Only a new physical `P_det` experiment can reopen it.
