# Bounded closure certification no-go

Owner: `marici.Figueiredo`.

## Question

WP166 left one apparent escape: if a source supplies two holonomy ports whose
closure is genuinely infinite, the mixed closure tower can separate the frozen
rival source stories. The remaining gate is physical certification. This packet
tests the finite version of that gate:

Can a bounded relation or fusion protocol certify that the generated
two-holonomy closure is infinite?

## Frozen domain

- State domain: source closure stories generated by two labeled ports.
- Faithful formal coordinate: the relation language in the fixed generators
  `+e1,-e1,+e2,-e2`.
- Instrument model: a finite protocol that tests all identity relations up to
  word length `L=7`.
- Hostile pair: `Z^2` versus `(Z/8Z)^2`.
- Exclusion: this is not a theorem about every conceivable nonlocal physical
  observable. It is a theorem about bounded relation/fusion certification in a
  declared finite generator set.

## Exact claim

For any word of length at most `L` in the four generators, the exponent sums
`(a,b)` satisfy `|a|,|b| <= L`. In `Z^2`, the word is an identity relation
exactly when `(a,b)=(0,0)`. In `(Z/NZ)^2`, it is an identity relation exactly
when both coordinates are divisible by `N`.

If `N>L`, the only multiple of `N` in `[-L,L]` is zero. Therefore the bounded
identity-relation language of `Z^2` and `(Z/NZ)^2` agrees through depth `L`.

For `L=7`, the smallest hostile finite rival is `(Z/8Z)^2`, of order `64`.
The first distinguishing relation is `+e1^8`: it is nontrivial in `Z^2` and
trivial in `(Z/8Z)^2`.

The strictness check is `N=L=7`: `+e1^7` already distinguishes `Z^2` from
`(Z/7Z)^2`, so the exact hostile threshold is `N>L`, not `N>=L`.

## Disposition

This attacks WP166's infinite-closure rescue. A finite relation/fusion
instrument with bounded word depth cannot uniformly certify infinite closure
against unbounded finite rivals. It can only certify nontriviality up to its
declared depth.

Consequently, a finite closure test may rigidify the selected presentation of
the two ports, but it is not yet a source-identifying selector unless the
source supplies either:

1. a uniform a priori finite bound on all finite rivals, or
2. a separately typed physical observable that detects infinitude without
   reducing to bounded relation testing.

If such an observable is added as a reference port, the groupoid changes. The
result is then a new relational experiment over the stabilizer groupoid, not a
recovery of an absolute holonomy phase from the original flavor experiment.
