# Quotient anomaly invariance: WP1149

## Question

Do anomaly or Green-Schwarz data distinguish the three quotient matching
classes?

## DPC resolution

- **Problem:** test whether localized-cell anomaly data select a reweighting
  matching.
- **Conjecture:** anomaly or Green-Schwarz data select one quotient class.
- **Rivals:** class-selective anomaly channel; shared anomaly vector;
  matching-dependent Green-Schwarz split; no anomaly distinction.
- **Risky consequences:** all classes share the five-channel vector
  \((1/2,1/4,0,2,2)\), the seven-channel vector
  \((1/2,1/4,0,2,2,-1/4,0)\), and the shifted coset
  \((1/2,1/4,0,0,0,3/4,0)\).
- **Falsification attempt:** all pairwise class differences vanish exactly;
  matching changes event reweighting, not the localized-cell anomaly channels.
- **Residual:** boundary S-matrix phase data may still distinguish classes.
- **Disposition:** reject anomaly selection across quotient matching classes.
