# Typed UV packet handoff request

## Purpose

Request one actual typed UV event-production packet for the Flavor selector.
This is a request and admission boundary, not evidence that the packet exists.

## Source-selected boundary object

The packet must be transported from one source-selected UV boundary object `U`.
The object `U` must carry packet identity, common frame, preparation and
messenger lineage, and typed maps to event production, preparation,
compactification, channel cascade, production matching, and phase authority.
Without `U`, kernels, ratios, gains, and images are inserted fixtures rather
than derived physical data.

## Single shared-frame packet

The reply must provide one packet, not five unrelated partial answers. All
objects must share packet identity, preparation lineage, epoch, messenger lineage,
compactification frame, momentum frame, and provenance references.

## Rejection classes

Do not submit or accept:

- narrative or variable names without typed fields;
- kernel-only packets without channel basis or provenance;
- H6 phase gauges without selected-packet preservation;
- readout maps without the exact event image;
- mock or fixture packets treated as source packets;
- separate preparation, clock, channel, matching, and phase replies without a
  shared frame and lineage;
- equal matrices, support counts, anomaly vectors, closure audits, or corpus
  mentions treated as the packet.
