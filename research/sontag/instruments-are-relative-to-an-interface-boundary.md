# Instruments Are Relative to an Interface Boundary

## Attack on instrument sufficiency

A record-labelled system update can still be only a marginal of the physical
process. Two instruments may give the same record and the same reduced
post-record system state while leaving different correlations or memories in
an environment. Whether that difference belongs to the Marici object depends
on the declared future interface.

## Minimal classical hostile

Let the accessible system bit be \(s\) and a retained environment bit be
\(m\). Two realizations produce the same first record and reduced system
state:

\[
I(x)=(0;(s,m)=(0,0)),
\qquad
J(x)=(0;(s,m)=(0,1)).
\]

After discarding \(m\), both reduced instruments are

\[
x\longmapsto(0,s=0).
\]

Every future Task restricted to the system bit alone gives the same records.
Now admit a recall operation

\[
C(s,m)=(m,m),
\]

which couples the retained memory back into the accessible system. A system
probe after \(C\) returns zero for \(I\) and one for \(J\).

Thus equality of reduced instruments is predictive only relative to an
interface that permanently excludes the memory port.

## Boundary contract

The Task alphabet must declare more than operation names. It must declare the
interfaces those operations may access:

- which Carrier ports remain open after each record;
- which ports are irreversibly discarded;
- which environment or reference systems may be supplied later;
- which correlations and lineage links survive;
- which reopening or feedback operations are admitted.

Call this the **interface boundary**. Predictive equivalence is relative to
that boundary. Enlarging it can split a previously valid quotient without
changing any current system record.

The distinction is not ontological environment bookkeeping. A hidden variable
behind a permanently closed boundary may be safely quotiented from the
predictive Carrier. A variable reachable through an admitted future coupling
is part of the live capability state even when it is absent from the current
readout.

## From instruments to processes

An isolated instrument has one open input slot and one conditioned output
state. A continuation-closed object must also specify how later instruments
plug into its remaining interfaces. In stochastic and quantum settings this
is process or comb structure: a multilinear rule assigning joint record
statistics to every compatible sequence of inserted instruments.

Accordingly, the progressively stronger shadows are:

1. present record;
2. effect or record probability;
3. reduced conditioned system update;
4. update on the complete declared live interface;
5. multi-time process accepting every admitted later insertion;
6. physical realization behind that process.

Each level can coincide while the next differs.

## Consequence for the Marici object

The current strongest candidate is not a closed packet in the sense of having
no ports. It is closed under a declared plugging law: every open interface is
typed, every admitted insertion composes, every resulting record word is
defined, and every discarded interface is explicitly outside the frozen
future family.

This changes the meaning of completion. Completion is not possession of all
internal variables. It is closure under all source-authorized future slot
fillings at the declared boundary.

The capability witness must therefore include:

- record-labelled Carrier updates;
- persistent memory and correlation ports that remain reachable;
- the interface signature for future Task insertions;
- the plugging/composition law;
- sequential record evaluation and lineage.

## Deutschian pressure

The hard-to-vary explanation is not “the environment matters.” That statement
can absorb anything. The explanatory claim names the exact port and the exact
future coupling that converts its latent difference into a record. The recall
word \(C\) is the finite counterfactual witness.

If no such admitted word exists, retaining the hidden bit is not forced by
predictive closure. If one exists, deleting the bit destroys a stated
capability.

## Verification boundary

The dependency-free checker verifies equality of present records and reduced
instruments, equivalence under the system-only Task alphabet, and separation
after one memory-recall insertion. This is a finite deterministic process
hostile. It does not prove quantum comb reconstruction or determine the final
Marici interface grammar.
