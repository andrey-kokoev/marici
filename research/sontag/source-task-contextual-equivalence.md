# Source-task identity is contextual

## Criticism addressed

The source-task irreducibility witness showed that unlabeled dynamics cannot
choose between incompatible success relations. It did not prove that every
syntactically distinct source task must remain distinct forever.

Nima's criticism is that source-task identity is intrinsic only relative to a
jointly conservative family of authorized future contexts. This packet tests
that correction.

## Exact hostile

There are three presentations: two duplicates of target-zero and one
target-one. The current interface exposes only a constant coarse readout. All
three presentations are therefore behaviorally equivalent now.

A later source-authorized replay context asks whether the fixed plant state
zero satisfies the presented task. It returns true for both target-zero
presentations and false for target-one.

The replay operation is not well-defined on the earlier one-class quotient.
The quotient must refine before replay can act. After refinement, replay
descends and the duplicate target-zero presentations remain identified.

## Corrected theorem boundary

The source task cannot be reconstructed from unlabeled raw dynamics. However,
its internal presentation is retained only to the extent required by all
authorized future contexts.

Thus neither absolute task identity nor current behavioral equivalence is
correct. The governing relation is contextual equivalence under a
continuation-closed, source-authorized family of criticisms.

If no possible authorized extension can distinguish two task presentations,
their difference is idle and should be quotiented. If a later authorized
extension separates them, an earlier quotient that merged them was only valid
for the earlier protocol epoch and cannot be transported unchanged.

## Effect on the Marici explanation

The two-layer account survives with a correction. The first layer is not an
absolute source predicate stored outside behavior. It is the source problem as
resolved by the jointly conservative contextual capability law. Some source
distinctions remain necessary because future contexts consume them; others are
gauge or redundant presentation.

The deeper invariant is therefore one relation, viewed from two sides:

- source provides the distinctions whose constructive preservation is at
  issue;
- future contexts determine which of those distinctions remain operative.

Neither side can be minimized independently of the other.
