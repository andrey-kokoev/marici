# Source task is an irreducible relational boundary

## Bounded question

Can the source task or success relation be reconstructed from a raw process
algebra, making even that part of the Marici packet dispensable?

## Exact no-go witness

Use one two-state plant with three actions: no-op, set-zero, and set-one. Keep
the entire transition table fixed.

The same process supports two incompatible tasks:

- target zero, where state zero is correct;
- target one, where state one is correct.

Each task has a different unique minimum-intervention repair policy. Nothing in
the unlabeled transition table selects between them.

Adding a success-valued effect separates the tasks, but this does not derive
the task from raw dynamics. It transports the missing distinction into the
effect signature.

## Explanatory consequence

Capability alone is incomplete grammar. “Possible transformation” does not say
which transformation answers the problem being explained. A control system
cannot derive its own reference relation from state transition syntax.

Therefore a Marici object is irreducibly relational. It is an object for a
source-defined task, or for a task generated by a declared lower-rung
constructor. Moving the task into a base category, effect type, logical
predicate, or source map can improve composition, but cannot eliminate the
explanatory boundary.

This is not an appeal to arbitrary human purpose. In physical and mathematical
sectors the task relation may be generated by boundary conditions, preparation
maps, equations, incidence data, conservation laws, or a parent constructor.
The no-go says only that whatever supplies the distinction must be typed and
cannot be recovered from unlabeled dynamics alone.

## Revised synthesis

The current invariant candidate has two layers.

First is an irreducible problem relation: the source task whose preservation or
construction is at issue.

Second is a contextual capability coalgebra: the minimal law of how constructive
availability, records, and successor states vary under admitted controls,
disturbances, authority changes, resource changes, and continuation budgets.

A closed packet is a finite presentation or section of these layers. Its
stored fields are required exactly when future context variation cannot
reconstruct them from the process law.

## Deutschean force

This explains why the structure cannot be freely varied. Change the source
task and the identity of repair changes even when every raw transition remains
fixed. Change the contextual capability law and the possible continuations
change even when the current value remains fixed. Those are the two independent
ways a rival ceases to explain the same constructive object.

## Claim boundary

The no-go is finite and structural. It does not identify an ultimate source of
all tasks. Marici can descend one explanatory rung by deriving a task from a
parent constructor, but at every declared rung some problem relation remains
the boundary relative to which objecthood is stated.

## Successor correction

`source-task-contextual-equivalence.md` supersedes any absolute reading of the
last sentence. Raw dynamics still cannot derive which relation counts as the
task. But distinct task presentations need remain distinct only when some
source-authorized future context separates them. A jointly conservative
continuation family, not syntax alone, determines the operative source
boundary.
