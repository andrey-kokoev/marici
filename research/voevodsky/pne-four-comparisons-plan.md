# Plan: resolve NN into four ordered comparisons

Status: proposed source test, not a result or a new native operation. PN1, N1N2, N2N1, N2E are comparison names, not a time history.

1. Freeze the original radial windows, slot order, kind/index projection and C2 attachment. Use occurrence records (window, ordered slot numbers, source site IDs). Candidate: N1 is N restricted to the P overlap (M0,C1); N2 is N restricted to the E overlap (C1,M1). Both are readings of N, not extra vertices. Name this convention before testing other interpretations.
2. Build four records in the source before projecting. PN1: compare P slots 2,3 with N slots 1,2. N1N2: compare N slots 1,2 against 2,3 at shared C1. N2N1: reverse the comparison operands, without reversing the native order inside either leg. N2E: compare N slots 2,3 against E slots 1,2. For each record keep operand order, incidence dimension, shared site IDs, both slot orders, and the unmatched ends. Distinguish equality of leg support, agreement of direction on a common leg, and a one-site junction (no common leg direction). A common endpoint is not an inverse map.
3. Compare outer records PN1 and N2E, then inner records N1N2 and N2N1. Compare the two comparison results with types intact. State whether a correspondence exists between these types of result, not just whether two Boolean flags agree. Do not concatenate four record names into a physical walk.
4. Test candidate perspective operations X (within reading), Y (between readings) on the marked records. Require explicit source definitions, domains and target records. Apply the existing two-perspective gate: I,X,Y,XY,YX plus reversal controls, all pair comparisons and both comparisons of comparisons. Report partial if undefined; do not force an involution for a change of projection. Separate square D4 actions from changes between coordinate views. A projection alone cannot identify the external C2 with the facet center.
5. Only then erase one distinction at a time: occurrence labels, directions, or depth. Report first equality after erasure and a source observation distinguishing the original records. Verdicts: marked identity, identity only for named readout, obstruction with witness, or unresolved correspondence. No cross-system transfer until the four records and the surviving relation are specified.
