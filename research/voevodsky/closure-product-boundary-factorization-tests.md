# Testing Pi-and-boundary presentations in the cofiber model

## Outcome

The proposed product-and-boundary signature is realizable in a concrete nontrivial instance of the current cofiber model. It is not forced in every instance. A dependent boundary is the generally available form once a family observation has been specified.

Code: `agda/ClosureProductBoundary.agda`.
Regressions: `agda/ClosureProductBoundaryRegression.agda`.

## Positive construction

`PointedModel` takes a pointed type X and uses the actual filtration Bool -> Unit -> X. Its nested quotient is equivalent to cofib(Unit->X) by the existing canonical rejoin theorem, and that cofiber is equivalent to X by the identity-leg pushout theorem.

For X = P × R, with P a dependent function type `(i:I) -> B(i)`, `Split.factorization` consequently proves that the nested quotient is equivalent to `(Pi B) × R`. Both reconstruction laws are exported.

This target is deliberately product-shaped. The proof establishes realizability of the signature and compatibility with the model's maps, not an independently discovered factorization of an unspecified analytical target.

The concrete regression uses:

- I=Bool, with B(i)=Bool at both indices;
- P=Bool->Bool, a family with four configurations;
- R the circle.

There is no singleton-index or Unit-boundary padding. An explicit retraction verifies retention of the circle boundary.

`SplitMap` proves that the actual target-induced map between double cofibers agrees, in these product coordinates, with a specified map of family values and boundary values. In the regression it flips both Boolean family coordinates and reverses the circle loop.

The four signatures are constructed in the same module:

- F1: single input cofiber -> single output cofiber;
- F2: single input cofiber -> output family × output boundary;
- F3: input family × input boundary -> single output cofiber;
- F4: input family × input boundary -> output family × output boundary.

The input/output rejoin maps are equivalences. The module checks reassembly of F2, the F4/F3 square, and comparison of F4 with F2 after input reassembly. F4 is obtained from the independently constructed canonical target-transport map, not defined as a coordinatewise function merely to make its law tautological.

## The general dependent form

For ANY chosen observation `observe:X->P`, `Observation.dependentPresentation` constructs

`X ≃ Sigma (p:P), fiber(observe,p)`.

Here `fiber(observe,p)` consists of x:X together with a path observe(x)=p. It retains both the residual object and its boundary identification.

`productFromFibers` proves the sufficient condition for replacing this dependent pair with a product: a fixed type R and a coherent family

`(p:P) -> fiber(observe,p) ≃ R`.

The resulting product equivalence preserves the observation by a checked equation. Equal arities or equal scalar dimensions do not supply this family.

These are standard HoTT constructions applied explicitly, not claims of a new general theorem. In particular, a map to the proposed family type P still has to be specified; it is not generated by the arity label.

## A genuine obstruction to a uniform residual

The negative example keeps P=Bool->Bool and defines R(p) to be Unit when p(false)=false and Bool when p(false)=true. The pointed target is Sigma P R and is realized by the same Bool -> Unit -> X cofiber construction.

Its observable is the first projection after rejoin. `fiberIdentification` identifies the ACTUAL homotopy fibers of that observable with the specified R(p).

One fiber is Unit and another is Bool. A uniform residual would give Bool equivalent to Unit, contradicting false≠true. The module therefore proves:

- `noUniformBoundary`: no fixed residual with coherent fiber identifications;
- `noProductOverObservation`: no equivalence to P × R0 preserving this chosen P-observation, for any R0.

The dependent Sigma presentation nevertheless exists for precisely that same observable and is checked in the regression.

The obstruction is relative to the chosen family observation. It is not a classification of all unlabelled product decompositions of the total type, nor a claim that the user's intended analytical observation has this obstruction.

## Consequence for the proposed formulas

The robust proposed output shape is a dependent pair over the product family, with residual R(p). The plain product `(Pi B) × R` is a special case requiring coherent trivialization of that boundary family.

To test the original f(a,a), f(b,b), f(a), and f(b) formulas rather than these controlled examples, the next input is the intended family observation on the actual source and target objects. Its fibers can then be computed and tested for such a trivialization. The present checks do not supply that analytical identification automatically.
