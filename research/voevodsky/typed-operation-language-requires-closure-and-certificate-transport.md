# Typed operation languages need closure as well as one-step descent

Fix typed carrier domains D_i and quotient maps q_i:D_i->Q_i. For every label a:i->j, require its actual relation R_a to have successors IN D_j. The quotient successor relation exists exactly when q_j[R_a(x)] is constant on every q_i-fiber in D_i. Closure plus this one-step congruence yields a finite-word congruence by induction: every intermediate successor stays in the declared next domain, so the next quotient step can be applied. If closure fails, a one-step descent theorem cannot be iterated. The four-point control `check_partial_operation_square.py` exhibits this: public-saturated subsets admit a one-step fine projection even for a non-public fine predicate, but fine updating a saturated subset can exit that restricted domain. Enlarging to all subsets restores closure but destroys fine-update representative independence. No quotient for arbitrary fine continuations follows.
