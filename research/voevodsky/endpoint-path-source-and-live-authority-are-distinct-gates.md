# Endpoint, path, source binding and live authority are distinct gates

A finite decision gate now classifies the contrasting source-edit examples without promoting one check into another. Against old rows, endpoint and P->Q->P path equations verify and the archived root matches, but no owner capability exists. After a y-high edit, endpoint P remains valid while the path fails at Q. After the coupled bound edit, both endpoint and path equations hold, but the OLD record root mismatches the new manifest. Even if a locally reverified packet is relabelled with the new digest, it still has no authenticated owner capability. Fresh `check_path_identity_authority_gate.py` checks all four status vectors and refuses protected use with separate INVALID_PATH, FOREIGN_SOURCE_RECORD and NO_OWNER_CAPABILITY results.

The reverified new-digest case is a LOCAL mathematical thought experiment, not a real owner-published successor. Hash equality is not authority. The old archived proof remains true about its original source in every scenario, independently of whether future use on a different source is denied. This closes the source-manifest-change research question at a crisp typed boundary rather than claiming either that every edit invalidates all mathematics or that successful revalidation transfers execution rights.

A nonredundant successor is to measure minimal dependency RETENTION for these four distinctions: which old row statements, multipliers, intermediate path nodes, edge syzygies, generation IDs and issuer decisions must be kept to replay each verdict, with an explicit hostile omission and no claim of universal storage minimality. Analytic S,A,R,C,G correspondence remains deferred.
