# Source-factored native WG chart interpretation

## Declared source and target

The source is the exact input/query **P/E fragment** constructed in `RamseyExactSource`: context/color input atoms, native P families and native E selection, including the three-part retained query history and refusal packages.

The target is the existing `NativeTableRules.Native` P/E signature with `NativeTableResolution.Full`. Its input policy admits only a fixed canonical local-context record and the supplied color at each input slot. It does **not** admit the exact translated-context atoms as target seeds.

For an input at shift s, construct a target native E package with index type Shift, constant canonical input fiber and index s. Every premise is the existing canonical input certificate. The exact shift is retained in a real native operation, not an external untyped marker or a chosen query answer. This construction runs for the whole input family before any request selection; it does not seed a monochromatic witness.

## Arity and operational boundary

Shift is an unbounded integer type. The premise generator is a constant lambda returning the same input certificate, hence a finite description of an admitted higher-order rule instance. This is **not** a finite enumeration or finite unfolding of all Shift premises. The input region and fixed-length request domains are finite, but that does not make the chart-index type finite.

The target is a higher WG chart object, not a globally moved particle in Number-valued coordinates. No physical trajectory, all-twelve-generator interpretation, all-cache equivalence, or finite particle controller is asserted. These distinctions must survive every net/graph disposition.

## Forward realization and commuting cells

A source fragment syntax is interpreted twice using the actual native constructors and independently declared source/target input policies. Both interpretations have actual `Resolve` derivations. The target input proof uses E and a canonical seed only. P and E nodes are mapped structurally, preserving every source selector and outer family/rule structure, with additional chart-introduction nodes explicit at the input leaves.

A structural type isomorphism maps each source context/color value to its exact shift, canonical context and color; it lifts through P by pointwise functions and through E by preserving its dependent index. A commuting value cell is proved for every program. A further full-package equation identifies the source interpretation of the query program with the previously constructed **actual uniform query package**, including input/program/answer history components. Thus this is not only a model of an unrelated toy language.

The isomorphism is between the declared value fibers. It is not an equality of seed policies or a claim that source exact-context atoms belong to the target policy. A negative target-seed fixture enforces that distinction.

## Full reference binding before scalar readout

The canonical record contains all five references of the actual root local P/PN interface. The retained native E shift translates every canonical barycentric reference. The formal reference square proves equality with the exact source context for C0,M0,C1,M1,C2; the color square retains the supplied color. The source projection and substitution theorems therefore transport to this chart interpretation. The root P/N interface and complete five-slot permutation are checked through the current source API; native P/E operations here remain distinct from particle P/N and shared-edge triangle P/E labels.

A fixed local PN or inverse-PN observation can be translated with the chart index unchanged. This local reference correspondence does not prove arbitrary target continuations or operation preservation for generators not in the declared source fragment.

## Rival absolute-coordinate port

The direct absolute Number-coordinate map is not an alternative proof of the same statement. At the exactly representable zero-sum shift (-2^53,2^53,0,0), the existing lattice-item constructor rounds the e1 increment because 2^53+1 equals 2^53 as a Number. Its M0 reference differs from the exact local template even though the original shift is representable. A finite exact reference mismatch refutes that **particular** global-number port, not every native representation, the exact integer theorem or the governing Ramsey claim.

The positive target keeps its canonical local coordinates small and retains the large exact shift as native data. It does not repair or silently extend the numerical geometry implementation.

## Uniform task-package corollary (prospective full-node attempt)

The separate contract `contracts/ramsey-uniform-task-package-attempt.v1.json` targets the existential-policy task-package conjecture, not the whole-space identification conjecture.

For any finite labelled S in D3, apply the explicit integer inverse to obtain its source shifts. For any N, use the finite complete region proved by the all-index inverse/box argument. For the given complete coloring, the target policy admits precisely the canonical local-context/supplied-color rows indexed by that region. This policy is independent of the request and monochromatic answer. For arbitrary r and n, instantiate the already proved exact uniform query constructor and its chart interpretation. The actual target result derivation, whole-package correspondence and full reference/color cells provide the requested source-native query; nonmembership yields the retained refusal. The projected variable-word law and positive multiplicity provide the same-source substitutions.

Thus, if the frozen tests validate these required cells, the complete quantified task-package statement follows **under this explicitly constructed native WG chart policy**. This does not additionally assume that the exact translated atoms are target-admitted. It also does not identify this input/query interface with the whole intended particle space. The latter remains the separate `space-admission` obligation, and forcing remains separate. Requiring those larger parent results before this existential-policy lemma would reverse the declared dependency order.

The proof uses admitted higher-order native P/E rules with explicitly unbounded index types; it does not claim a finite unfolding or physical implementation of those indices. The kernel checks the interpretation, policy factorization and uniform query correspondence; the region/D3 inverse and completeness remain the stated written all-index arguments.

## Controls and residual

Erase the chart index, alter an input color, drop the outside C2 reference or swap a request selector: the corresponding observation must fail. Fresh formal controls reject a false reference square, an exact-source atom inserted as a target seed, and a wrong native selector.

The result establishes the declared P/E query-fragment interpretation. Applying it to a broader intended operational interface still requires an explicit source/target policy and any additional generator/continuation cells. No communication or typechecking result automatically admits those extra operations or a physical policy.

Initial trials (`96067b51b515e965`, `25e1e9a3f3f3afec`) completed the runtime/source and Number-port controls, then exposed a local name collision and a missing extensional equality between two empty-family presentations. Revised sources are refrozen before testing again.
