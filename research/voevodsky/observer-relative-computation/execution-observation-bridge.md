## A checked converse obstruction

The static comparison path can be reversed. The machine run cannot: the final number has no outgoing Step, and there is no Run back to the supplied program. Therefore no function can turn every support path between configuration points into a directed Run with those endpoints.

This is a precise limitation on this bridge, not a proof that every possible observation model fails to describe execution. The chosen support regards generated steps as invertible comparisons, while the machine's grammar specifies directed reductions. Comparing these different carriers without retaining that distinction would manufacture reverse executions.

## Interpretation

The static support was constructed FROM operational data; it does not derive the rewrite rules from positivity. Generator labels retain their source Step witnesses, so the construction is not a claim of total erasure of operational information either. Traversability of a comparison path is different from admissibility of a directed operational history.

A value observer sees equal meanings at the stages, not a primitive clock. But existence of an observed connection and positive support alone does not reconstruct that machine's execution. To use conventional execution terminology, the directional admissibility condition must be retained somewhere.
