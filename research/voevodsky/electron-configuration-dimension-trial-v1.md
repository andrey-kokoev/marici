# Electron packet trial: a two-direction base with retained phase

## First result

The existing electron-like spinor supports a useful n=2 candidate: a local two-real-dimensional configuration base, with phase and path information retained in its supporting complex. Erasing that retained information fails an existing amplitude-sensitive continuation.

An n=1 model works for a restricted one-parameter orbit. It does not faithfully represent the full smooth spin-state family. A one-complex-dimensional invariant carrier is a different proposal and is already obstructed by the retained binary tetrahedral action.

These are scoped tests against the declared mathematical carrier, not a physical electron identification or a complete minimal-packet theorem.

## What n means in this experiment

For this test, n measures independent local smooth real configuration directions. It is distinct from:

- complex vector-space dimension;
- raw embedding dimension;
- number of primitive control generators;
- count of dependency sectors or retained coefficient transfers.

The proposed packet could use a base with additional retained fiber data. In that case base dimension and the full state space's dimension must both be stated.

A proton/electron comparison must use the same dimension convention. The native proton return has complex rank one and the native spinor return has complex rank two; neither rank alone establishes the proposed proton n=3/electron n=2 assignment. The proton's three configuration directions and this spinor's two ray coordinates still require a common source-level interpretation. This trial identifies a concrete electron-side candidate, not that common identification.

## The n=2 base

A normalized spinor z=(alpha,beta) determines the rank-one projector rho=zz*. The phase-blind spin state is its ray. Its Bloch coordinates satisfy:

\[
r=(2\operatorname{Re}(\overline\alpha\beta),\;2\operatorname{Im}(\overline\alpha\beta),\;|\alpha|^2-|\beta|^2),\qquad |r|^2=1.
\]

This is a two-real-dimensional sphere, locally parameterized by the real and imaginary parts of w=beta/alpha. A second chart v=alpha/beta covers the missing pole; on the overlap wv=1. The source unitaries act on it by rho mapping to U rho U*. Exact tests verify this action for all 24 retained binary rotations and the chart formulas on declared rational samples, including both poles.

A source ray is therefore a concrete candidate for a two-direction configuration base. A global pair of fixed axes is not supplied by one chart: local directions and transitions must be retained when moving between charts. The n=2 packet geometry would have two signed one-dimensional dependency families, giving 2 times 2 sectors, and two outgoing directions. Their source-grounded port operations and higher witnesses remain to be built.

## The phase-erasure hostile

Two actual retained rotations U,V have:

\[
UVU^*V^*=-I.
\]

That closed word sends z to -z. The ray and Bloch coordinates are unchanged, while the source encoding sends Jz to -Jz. Both amplitudes recover correctly from the retained face blocks.

For the existing bilinear continuation B(p,e)=p_0 e_1-p_1 e_0, a fixed retained reference p=(1,0) and e=(0,1) give B(p,e)=1 and B(p,-e)=-1. Thus the ray alone cannot recover the signed amplitude continuation or the source lift. This is a phase-sensitive amplitude comparison with its reference retained. An isolated-state projector measurement and |B|^2 do not distinguish the two signs.

This suggests the packet interpretation:

> The electron-like candidate has a two-direction ray base, while its label references the retained phase fiber, transport and comparison data needed for subsequent use.

That is the proposed next construction, not a completed claim that a bare n=2 packet already supports every source continuation. A generic normalized spinor has three independent local real directions: two change the ray and one changes phase. The trial verifies those tangent ranks exactly using normalized rational curves. Retaining phase in the complex therefore carries substantive data; it cannot be treated as a free erased coordinate.

Coherence here must respect the actual lifted transport. The known -I loop cannot silently be replaced by identity on amplitudes. Inverse transport still supplies exact recovery. Preserving a witnessed connection and its holonomy is different from requiring every geometrically closed path to act trivially.

## What n=1 can preserve

A selected real meridian of the spinor family has a one-real-parameter rational description and is preserved by a selected source rotation. This gives a usable restricted orbit. Another actual binary tetrahedral rotation sends a state out of that meridian. The full ray family has local rank two, excluding a faithful smooth one-coordinate local presentation of that family.

Separately, a one-complex-dimensional representation cannot retain the source central commutator as -1: scalar invertible actions commute. This is the earlier logical-line obstruction, not a proof identifying complex dimension with configuration n.

At n=1 the proposed codimension-one support consists only of a zero-dimensional mark. That count does not provide the missing operations for a full spinor realization.
