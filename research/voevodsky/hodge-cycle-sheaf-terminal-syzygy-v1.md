# The terminal syzygy retains the unknown cycle's Weil component

## Fresh task and allowed input

Execute cycle-sheaf-terminal-syzygy-audit. Work on the unchanged smooth projective sixfold X with ample H, e=c1(H) in Chow, and cohomology class E. Let Z be an arbitrary integral codimension-three closed subvariety, supplied as an input. No smoothness, local complete-intersection property or known Weil component is assumed for Z.

The construction below works on any such input. It does not manufacture a Z representing the unresolved R.

## Six ample-twist presentations, with a locally free terminal kernel

Set F0=O_Z. For i=0,...,5 choose m_i sufficiently large that F_i tensor H^(m_i) is globally generated. This is Serre generation for a coherent sheaf. Choose a finite surjection

    P_i=(H^(-m_i))^(direct sum N_i) -> F_i,
    F_(i+1)=kernel(P_i->F_i).

All kernels are coherent. Every local ring of smooth X is regular of dimension at most6. Finite modules over such a ring have projective dimension at most6, so the sixth syzygy F6 is locally free. Write K6=F6. This produces

    0 -> K6 -> P5 -> P4 -> P3 -> P2 -> P1 -> P0 -> O_Z -> 0.

There is no claim that K6 is a sum of line bundles, is simple semihomogeneous, or belongs to the previously generated class B. A locally free resolution and a resolution entirely by sums of line bundles are different conclusions.

## Exact K-class and leading Chern character

Regularity identifies coherent G0 with vector-bundle K0. The exact sequence gives

    [O_Z]=sum_(i=0)^5 (-1)^i[P_i]+[K6].

The positive terminal sign is because six is even. More generally, after d steps the terminal term is (-1)^d[K_d].

The standard leading-cycle property of the coherent Chern character says

    ch_j(O_Z)=0 for j<3,
    ch3(O_Z)=[Z] in CH^3(X)_Q.

This property uses codimension and generic length, not a smooth embedding formula for Z. For a scheme with several dimension-three components, the leading class uses their generic multiplicities. Rational signed cycles are handled by rational linear combinations of their structure-sheaf classes.

Put S_j=sum_(i=0)^5 (-1)^i N_i m_i^j. The displayed resolution then gives the exact rational Chow identities

    rank(K6)=-S_0,
    ch1(K6)=S_1 e,
    ch2(K6)=-(S_2/2)e^2,
    ch3(K6)=[Z]+(S_3/6)e^3.

These follow by expanding ch(P_i)=N_i exp(-m_i e). In particular all the uncertain primitive information survives in the terminal bundle, rather than disappearing in the line-bundle presentations.

## Weil readout and the third Chern CLASS

Apply the retained cohomological projector

    P_W(c)=c-(integral_X c E^3/2160)E^3.

Then

    P_W(cl(ch3(K6)))=P_W(cl[Z]).

For a d-step resolution the corresponding formula has factor (-1)^d. This sign is part of the construction, not a choice to ignore in a virtual class.

Moreover the lower characters of K6 are explicitly divisor-valued. The Newton identity therefore gives

    c3(K6)=2[Z]+(S_3/3+S_1 S_2/2+S_1^3/6)e^3,
    P_W(cl(c3(K6)))=2 P_W(cl[Z]).

The factor2 distinguishes c3 from ch3. Thus an arbitrary algebraic cycle with a Weil component would produce an actual algebraic vector bundle with that component in ch3, and twice it in c3. No condition in the previous bounded-bundle theorem forces this terminal bundle into B.

Conversely Chern classes and Chern-character components of actual algebraic vector bundles are algebraic cycle classes. This is a source-typed reduction between cycle and bundle readouts, NOT an independent obstruction or a new proof of either verdict. A nonzero readout would certify that this particular terminal bundle escapes the bounded generated class; existence of such an input Z has not been established.

## The complete-intersection control really has a line-bundle resolution

For Z0 cut out by three regular sections of L=H^k, the actual Koszul sequence is

    0 -> L^(-3) -> (L^(-2))^3 -> (L^(-1))^3
      -> O_X -> O_(Z0) -> 0.

Here the terminal bundle at step3 is L^(-3), with NEGATIVE sign, and

    [O_(Z0)]=(1-[L^(-1)])^3,
    ch(O_(Z0))=(1-exp(-k e))^3.

The components below degree3 vanish and ch3=k^3 e^3. Its Weil projection is zero, as required. This is a genuine resolution entirely by line bundles, supplied by the regular sequence; it cannot be generalized to every Z merely from projectivity of X.

Even for this control, an arbitrary alternative six-step choice need not give a terminal object visibly in B. Its divisor-valued readout follows from the K-class calculation, not an unproved membership assertion.

## Disposition and exact residual

Rejected: extending the semihomogeneous-generated annihilation result to all cycles by pretending the final kernel of an ample-twist resolution is again generated by those inputs. Constructed: a bounded six-step resolution and an exact formula locating the unknown Weil component in an actual terminal vector bundle, with lower Chern characters controlled.

This reduction supplies no new cycle at the original source. It exposes the missing completeness claim instead of repackaging the original universal gate as a fresh obstruction.
