# Natural transformation versus source element

## Corrected type gate

An `ElementLift` is a source element `h` with `d h=k`; no materialized source has one.

The natural comparison has direction

`Res composed with R_log : S -> B_flag`

versus `R_flag:S -> B_flag`. On the Gersten generators these maps agree strictly, so the canonical chain homotopy between them is zero. The earlier equation using an unspecified inverse map from flags back to logarithmic forms was not sourced.

A nonzero degree-minus-one homotopy could be additional structure, but it is not forced by the residue square and cannot be inferred from the formal cone cell.

## Disposition

Element lifts remain excluded. Regulator compatibility supplies a strict commuting square, not a nonzero horn-valued homotopy. The full generator audit is recorded in the successor packet.
