# Live tags reconstruct, but garbage canonical ordering needs review

Fresh inspection of `check_reachable_family_diamonds.py` shows its serializer omits tags. Under the unified invariant this omission has a conditional justification: there is at most one COPY; its principal meets the first original node; original successors form exactly its finite B/N source suffix; all other data nodes are COPIED. Therefore a kind- and port-preserving graph isomorphism preserves the unique COPY and that chain, hence preserves every live provenance tag. When COPY is absent, every data node is COPIED. Deleted constructor history is not reconstructed; the claim concerns live tags and operational graph structure, not arbitrary origin metadata.

Fresh `check_structural_tag_reconstruction.py` reconstructs tags without reading either tags or origin history, agreeing with runtime tags on 219 states and 452 edges. This is bounded implementation evidence accompanying the conditional structural argument, not a universal serializer test.

A separate canonicalization concern emerged: detached-component fallback selects by `(kind(x), x)`, where x contains allocation serials. Multiple detached eraser chains of different lengths can be ordered differently after alpha-renaming. Thus the current serializer is not justified as a complete canonical quotient. Such ordering variation can cause false distinctions (overcounting), not necessarily false equality; historical counts should be called serialized-state counts until checked. A full serialized adjacency equality still supplies a port/kind isomorphism, provided the serialization is complete.

Next implement a name-independent forest serialization: encode a port-labelled tree rooted at every possible vertex, choose its minimum encoding for each unrooted component, preserve OUT channel kinds, sort component encodings, optionally include reconstructed tags. Test permutations of serial names and different garbage-chain lengths; compare historical counts before promoting any alpha-class counts. This is a nonredundant correctness gate before further confluence experiments.
