# Tangent-envelope conjecture falsified

## Falsifier

Six non-quantile singleton columns were selected, one median column in each `(k_pole,g1_level)` stratum. Every column was fully back-substituted to original source rows before evaluating the proposed envelope.

The pole bound survived all six tests, and every tangent marked-\(q\) row still used only `g1`. The proposed equivalence

```text
T marked-q correction present iff target g1 level = 2
```

failed in three strata:

- `k0_g1_2`: no tangent marked-\(q\) correction;
- `k1_g1_2`: no tangent marked-\(q\) correction;
- `k2_g1_1`: tangent `g1` correction present despite target `g1` level 1.

## Disposition

The five-sample activation rule is withdrawn. Target `g1` level alone does not determine tangent marked-wall support. The weaker observations remain finite evidence:

- tangent pole levels did not exceed the target pole in eleven tested samples;
- observed tangent marked-wall rows used only `g1`.

Neither is promoted to theorem.

The tangent-envelope leaf is exhausted by counterexample. The issue tree is rescored toward the independent \(K\)-multiplication absorption mechanism, where all derivative rows are generated by monomial shifts of a single directional derivative polynomial.
