# The common pencil direction is exactly alpha12

## Fixed sectors

Let \(L_b\subset E_7\) be the primitive \(A_1^3\) lattice generated by the four split-fiber component differences in the \(b/h\)-pencil.

The global reflection \(r_a\) acts fiberwise on this pencil and fixes each oriented component-difference class. Hence

\[
L_b\subset E_7^{r_a=+1}.
\]

Both sides have rank three: \(L_b\cong A_1^3\), while the Lefschetz calculation gives \(\operatorname{rank}E_7^{r_a=+1}=3\). Therefore

\[
L_b\otimes\mathbb Q=E_7^{r_a=+1}.
\]

Similarly, for the site-exchanged \(a/h\)-pencil lattice \(L_a\),

\[
L_a\otimes\mathbb Q=E_7^{r_b=+1}.
\]

## Identification of the common line

On the \(b\)-pencil primitive frame, the global \(b\)-reflection acts by

\[
r_b|_{L_b}=\operatorname{diag}(1,-1,-1)
\]

on \((\alpha_{12},\alpha_{13},\alpha_{14})\). Thus

\[
L_b^{r_b=+1}=\mathbb Z\alpha_{12}.
\]

The joint-character calculation shows that the ambient common fixed sector has rank one. Consequently

\[
\boxed{
(L_a\otimes\mathbb Q)\cap(L_b\otimes\mathbb Q)
=
\mathbb Q\alpha_{12}.
}
\]

So the previously abstract common pencil direction is exactly the normal-jet/\(e_6\) direction.

## Character placement of the route planes

The fixed \(b\)-pencil complement is the joint-character sector

\[
\langle\alpha_{13},\alpha_{14}\rangle_\mathbb Q
=E_7^{(r_a,r_b)=(+,-)},
\]

which has dimension two. The \(a\)-pencil complement is

\[
E_7^{(r_a,r_b)=(-,+)},
\]

also dimension two.

Thus the missing return comparison has the precise type

\[
E_7^{(-,+)}\cap L_a
\longrightarrow
E_7^{(+,-)}\cap L_b.
\]

It must cross joint-character sectors; ambient intersection supplies no nonzero route vector. This rules out constructing the return map by projection through the common \(e_6\) line.

## Information flow

\[
L_a\cap L_b
=	ext{the }e_6\text{ line},
\]

while all \(v_{\rm alg}\) route information is transported between the two disjoint rank-two character sectors. The missing coherence comparison is exactly that off-character transport.
