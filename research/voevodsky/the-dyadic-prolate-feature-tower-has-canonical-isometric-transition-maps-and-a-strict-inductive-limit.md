# The dyadic prolate feature tower has canonical isometric transition maps and a strict inductive limit

## Positive contraction

Fix one cutoff and write

\[
B=PQP,
\qquad
0\le B\le I.
\]

Let `H_2` denote the Hilbert--Schmidt feature target after observer insertion. All functional-calculus operators below act by left multiplication on this target.

The initial positive feature is

\[
x_0(g)
=B^{1/2}A_g.
\]

## Elementary defect-splitting isometry

For any positive contraction `C`, define

\[
\boxed{
W_C:
H_2
\longrightarrow
H_2\oplus H_2,
\qquad
W_Cx
=
\begin{pmatrix}
Cx\\
(I-C^2)^{1/2}x
\end{pmatrix}.
}
\]

Then

\[
\begin{aligned}
\|W_Cx\|^2
&=
\|Cx\|^2
+
\|(I-C^2)^{1/2}x\|^2\\
&=
\langle x,
(C^2+I-C^2)x\rangle\\
&=
\|x\|^2.
\end{aligned}
\]

Therefore

\[
\boxed{
W_C^*W_C=I.
}
\]

This is an exact isometry, not an asymptotic comparison.

## First split

Take

\[
C_0=B^{1/2}.
\]

Then

\[
W_{C_0}x_0(g)
=
\begin{pmatrix}
BA_g\\
[B(I-B)]^{1/2}A_g
\end{pmatrix}.
\]

Thus the initial feature splits into:

- concentrated bulk `BA_g`;
- first prolate defect `[B(I-B)]^(1/2)A_g`.

## General dyadic split

After `n>=1` splits, let the concentrated bulk slot be

\[
\boxed{
x_n(g)
=B^{2^{n-1}}A_g.
}
\]

Set

\[
C_n
=B^{2^{n-1}}.
\]

Then

\[
C_nx_n(g)
=B^{2^n}A_g
=x_{n+1}(g),
\]

and

\[
\begin{aligned}
(I-C_n^2)^{1/2}x_n(g)
&=
(I-B^{2^n})^{1/2}
B^{2^{n-1}}A_g\\
&=
[B^{2^n}(I-B^{2^n})]^{1/2}A_g.
\end{aligned}
\]

This is exactly the `n`-th dyadic defect feature.

## Finite-depth feature spaces

Define

\[
\mathcal K_n
=H_2^{\oplus(n+1)}.
\]

Order its slots as

\[
(\text{bulk at depth }n,
\text{defect }n-1,
\ldots,
\text{defect }0).
\]

Define the observer feature

\[
\boxed{
\Phi_n(g)
=
\begin{pmatrix}
x_n(g)\\
d_{n-1}(g)\\
\vdots\\
d_0(g)
\end{pmatrix},
}
\]

where

\[
d_j(g)
=
[B^{2^j}(I-B^{2^j})]^{1/2}A_g.
\]

For `n=0`, use `K_0=H_2` and `Phi_0=x_0=B^(1/2)A_g`.

## Transition maps

Define

\[
\boxed{
J_n:
\mathcal K_n
\longrightarrow
\mathcal K_{n+1}
}
\]

by applying `W_(C_n)` to the bulk slot and carrying every existing defect slot identically:

\[
J_n
(x,d_{n-1},
\ldots,d_0)
=
(C_nx,
(I-C_n^2)^{1/2}x,
d_{n-1},
\ldots,d_0).
\]

For `n=0`, take `C_0=B^(1/2)`.

Because `W_(C_n)` and all identity maps are isometries,

\[
\boxed{
J_n^*J_n=I_{\mathcal K_n}.
}
\]

Moreover,

\[
\boxed{
J_n\Phi_n(g)
=
\Phi_{n+1}(g).
}
\]

## Strict coherence

For `n<m`, define

\[
J_{n,m}
=J_{m-1}
\cdots
J_n.
\]

Associativity of operator composition gives

\[
\boxed{
J_{m,k}J_{n,m}
=J_{n,k}
\qquad
(n<m<k).
}
\]

No higher choice or phase occurs: every map is a fixed functional-calculus expression in the same positive contraction `B`.

Thus the dyadic depth diagram is a strict functor

\[
\boxed{
(\mathbb N,\le)
\longrightarrow
\mathsf{Hilb}_{isom}.
}
\]

## Inductive-limit feature space

Form the Hilbert inductive limit

\[
\boxed{
\mathcal K_\infty(B)
=
\varinjlim_n
(\mathcal K_n,J_n).
}
\]

Since the transition maps are isometries, each finite-depth feature embeds without changing norm.

The compatible observer family defines

\[
\boxed{
\Phi_\infty(g)
=[\Phi_n(g)]
\in
\mathcal K_\infty(B),
}
\]

independent of `n`.

Its norm is

\[
\boxed{
\|\Phi_\infty(g)\|^2
=
\|B^{1/2}A_g\|_{HS}^2.
}
\]

Thus refinement redistributes positive mass among bulk and defect coordinates but never changes the total positive form.

## Concrete terminal decomposition

Spectral calculus identifies the limit with the orthogonal feature decomposition

\[
\boxed{
\mathcal K_\infty(B)
\supseteq
P_{\{1\}}(B)H_2
\oplus
\bigoplus_{j\ge0}
\overline{
[B^{2^j}(I-B^{2^j})]^{1/2}H_2
}.
}
\]

For observer features,

\[
\Phi_\infty(g)
\longleftrightarrow
\left(
P_{\{1\}}(B)A_g,
(d_j(g))_{j\ge0}
\right).
\]

The equality of norms follows from the dyadic partition of `B`.

The displayed inclusion may be proper as an abstract inductive-limit carrier because each `K_n` contains arbitrary slot vectors not generated by the constrained functional-calculus ranges. Restricting to the closed observer-generated subspace gives the canonical terminal decomposition.

## Naturality

If a unitary `U` intertwines two prolate contractions,

\[
UB=B'U,
\]

then functional calculus gives

\[
Uf(B)=f(B')U
\]

for every function used in the tower. Hence `U` induces compatible maps on every `K_n` and on the inductive limit.

Therefore the construction is natural under exact unitary comparison of cutoff pairs.

## Dependence on the cutoff

For each `Lambda`, the contraction

\[
B_\Lambda
=P_\Lambda Q_\Lambda P_\Lambda
\]

produces its own strict depth tower

\[
\mathcal K_\infty(B_\Lambda).
\]

The maps in the `n` direction are now complete. What remains is comparison in the cutoff direction:

\[
\mathcal K_n(B_\Lambda)
\longrightarrow
\mathcal K_{n'}(B_{\Lambda'}).
\]

Because `B_Lambda` and `B_(Lambda')` act on one carrier but generally do not commute, these maps do not follow from scalar functional calculus alone.

## Joint indexing category

The positive refinement should be indexed by pairs

\[
(\Lambda,n).
\]

Depth transitions

\[
(\Lambda,n)
\to
(\Lambda,n+1)
\]

are the exact isometries constructed here.

Cutoff transitions

\[
(\Lambda,n)
\to
(\Lambda',n')
\]

require a prolate comparison correspondence and the cofinal condition

\[
2^{n'}
\varepsilon_{\Lambda'}
\asymp1.
\]

## Relation to simplicial coherence

Each `J_n` replaces one bulk node by a two-output positive colligation. Since the maps compose strictly, all simplices involving only depth refinement commute on the nose.

Therefore no new horn obstruction occurs in the dyadic direction. New coherence is required only for squares mixing:

- depth refinement `J_n`;
- cutoff enlargement;
- place-set enlargement;
- opposite-polarity sewing.

## Disposition

The dyadic-depth transition problem is solved:

\[
\boxed{
J_n
=
W_{B^{2^{n-1}}}
\oplus
I_{\text{existing defects}}
}
\]

with the initial convention `J_0=W_(B^(1/2))`.

These are canonical isometries satisfying strict composition. They define a positive inductive-limit feature tower. The remaining construction is the noncommuting cutoff-direction comparison between towers for different `Lambda`.
