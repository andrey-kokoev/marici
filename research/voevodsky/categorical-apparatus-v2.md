# Coherence-pyramid categorical apparatus v2

## Question

Can the accumulated categorical components be exposed through one canonical dependency-checked entry point?

## Claim boundary

The manifest organizes declared layers and bounded results. It does not convert their scope boundaries into a global completeness theorem.

## Layer order

The apparatus has eight layers:

1. base computad;
2. cells and laws;
3. partial completion;
4. filler-fiber and selection extension;
5. certificate-transfer contract;
6. sector-overlap admission;
7. typed horn tower;
8. bounded completeness predicate.

Their dependency graph is acyclic. The checker computes a topological order and verifies every imported artifact and schema identity. Ordinary document schemas and JSON Schema `$id` identities are normalized without conflating them.

## Realization status

The manifest distinguishes architecture from realization:

- Markov supplies a bounded realization through degree 4 for declared laws;
- cross-sector realization still has no admitted edge;
- the RH completed filler lacks coherent natural contraction and completed descent;
- no unbounded global claim is present.

## Disposition

Version 2 is the canonical layered entry point for the current apparatus. It prevents consumers from importing only the base computad while omitting filler semantics, certificate dependencies, overlap admission, or bounded completeness gates.
