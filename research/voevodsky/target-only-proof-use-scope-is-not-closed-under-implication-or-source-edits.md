# Target-only proof-use scope is not closed under implication or source edits

A HYPOTHETICAL grant can quantify over ANY valid proof packet for the EXACT frozen square target normal (1,0), bound 2, and explicit proof-use action. Fresh `check_exact_target_grant_scope.py` validates two distinct packets for x<=2 under the same row source, but refuses the stronger x<=1, weaker x<=3, a different target normal, and a manifest with only an unused primitive row edited. Both stronger and weaker targets are mathematically related to x<=2; that relation does not enlarge an exact publication grant.

Packet validity is still checked against the complete ordered row coefficients and surplus. The chosen target-only predicate is an INTERFACE DESIGN, returning `TEST_ONLY_TARGET_SCOPE_MATCH_NOT_AUTHORIZED` even for matching packets. The real row request has no issuer or generation. A real policy would need an explicitly signed quantifier (packet-specific, exact target, or wider family), scope manifest, action, source event and live grant; no inference from semantic implication can substitute.

Next test a target-FAMILY predicate, e.g. all x<=b for a rational interval, and demonstrate that describing a numerical interval is not enough when source generation changes or a row is edited while endpoints remain provable. Keep requested scope finite/test-only, and analytic S,A,R,C,G deferred.
