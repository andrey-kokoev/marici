# The existing centered arithmetic incidence cannot supply the divisor-surviving correction to the bordered state

The obvious correction to the bordered history would add an arithmetic source
coordinate `x_s` through the existing incidence `B_Sigma`.  At a divisor point,
the paired equations would have to preserve the theta forcing/mismatch while
cancelling the lower residual.

Prior source results exclude this within the current centered carrier.  The
distinct seam walls make the centered incidence injective, and an exact theta
forcing lift into its range forces

\[
x_s=0.
\]

Moreover

\[
\ker B_\Sigma^\dagger\subseteq\ker V^\dagger,
\]

so the two lower Green equations reduce to the single residual

\[
B_\Sigma^\dagger u_s=0.
\]

At the certified first zero the unchanged state fails the required membership
condition.  Since any existing arithmetic coordinate compatible with the exact
upper forcing must vanish, it cannot correct that failure.

Therefore a proposed modification

\[
\chi_s=B_\Sigma x_s
\]

using only the current centered arithmetic source law is unavailable.  Choosing
`D_U` or `x_s` specifically to cancel `B_Sigma^dagger u_s` at Xi zeros would
fit the arithmetic law to the target divisor and violates provenance.

This exhausts the existing auxiliary source ports as candidates for the
characteristic-to-Green map.  A successful correction must change the history
through a genuinely new divisor-preserving chain comparison—one whose source
constructor is not a coordinate of the current centered incidence and whose
reciprocal seam mismatch remains the original Xi section.

The search space is consequently narrower:

- endpoint-wall augmentation supplies the nonvanishing bordered state but not
  Green membership;
- current arithmetic incidence cannot repair it;
- bounded `tau`-multiple corrections vanish at the divisor;
- fitted singular corrections are forbidden.

Only a new source-derived modified-history constructor remains.
