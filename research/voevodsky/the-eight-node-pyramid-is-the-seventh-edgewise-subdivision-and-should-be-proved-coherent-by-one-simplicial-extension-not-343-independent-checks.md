# The eight-node pyramid is the seventh edgewise subdivision and should be proved coherent by one simplicial extension, not 343 independent checks

## Canonical combinatorial object

A tetrahedron with eight lattice nodes on each edge has seven elementary intervals per edge. Its canonical simplicial model is the seventh edgewise subdivision

\[
\boxed{
\operatorname{esd}_7(\Delta^3).
}
\]

Its vertices are the barycentric lattice points

\[
(a_1,a_2,a_3,a_4)
\in
\mathbb N^4,
\qquad

a_1+a_2+a_3+a_4=7.
\]

Therefore

\[
\boxed{
f_0=
\binom{10}{3}
=120.
}
\]

The subdivision has normalized volume

\[
\boxed{7^3=343,}
\]

so every unimodular edgewise triangulation has 343 top-dimensional tetrahedra.

## Wrong proof strategy

The brute-force strategy would assign to each of the 343 tetrahedra:

- six edge maps;
- four face homotopies;
- one tetrahedral coherence proof.

This would massively duplicate shared edges, faces, and naturality arguments. It also obscures whether neighboring choices agree.

## Correct proof object

Let `N(C)` be the nerve or homotopy-coherent nerve of the target category of semilocal geometric presentations. The entire pyramid should be one simplicial map

\[
\boxed{
\Phi:
\operatorname{esd}_7(\Delta^3)
\longrightarrow
N(\mathcal C_{semi}).
}
\]

Then:

- vertices map to semilocal presentation objects;
- edges map to typed equivalences;
- triangles map to commuting homotopies;
- tetrahedra map to coherence fillers.

Proving that `Phi` is a simplicial map proves compatibility on all shared boundaries automatically.

## Skeleton-extension strategy

Construct `Phi` in stages:

\[
\Phi_0:
\operatorname{sk}_0
\operatorname{esd}_7(\Delta^3)
\to N(\mathcal C),
\]

then extend to

\[
\Phi_1,
\qquad
\Phi_2,
\qquad
\Phi_3.
\]

The obligations are:

1. **vertex typing:** every lattice node has a well-defined semilocal object;
2. **edge naturality:** every elementary conductor transfer has a typed map;
3. **face interchange:** each elementary triangle has a specified comparison homotopy;
4. **tetrahedral coherence:** every 3-horn has a compatible filler.

The point is to define these by uniform formulas in the barycentric index, not by listing cells.

## Strict categorical target

If `C_semi` is an ordinary category and `N(C_semi)` is its ordinary nerve, then the nerve is 2-coskeletal. Once vertices and composable edge maps are given and every triangle expresses ordinary composition, every tetrahedron is forced by associativity.

In that case:

\[
\boxed{
\text{edge naturality}
+
\text{triangle commutativity}
\Longrightarrow
	ext{all 343 tetrahedral coherences automatically}.
}
\]

No separate tetrahedral equations are required.

## Bicategorical target

If semilocal equivalences commute only up to nontrivial 2-cells, the appropriate Duskin/homotopy-coherent nerve is 3-coskeletal under standard hypotheses. Then the tetrahedral identity is genuine but only a finite set of **natural transformation types** must be proved.

A uniform tetrahedral modification

\[
\mathsf K_{i,j,k}

\mathsf H_{i,k}
\circ
(d_k\ast\mathsf H_{i,j})
\Rightarrow
\mathsf H_{i,jk}
\circ
(\mathsf H_{j,k}\ast d_i)
\]

is instantiated at every barycentric position. Naturality under translation of the index proves every instance simultaneously.

## Prototype arrow types

An elementary edge transfers one barycentric unit:

\[
d_{ij}(\alpha):
X_\alpha
\to
X_{\alpha-e_i+e_j}.
\]

Up to vertex relabeling, all elementary edges have one transfer type. With orientation retained, there are the ordered types

\[
(i,j),
\qquad
i\ne j,
\]

at most 12 before source-specific typing identifies or separates them.

An elementary triangle is generated by two transfers. Its type is determined by the incidence pattern of their indices, for example:

- chain: `i -> j -> k`;
- common source: `i -> j` and `i -> k`;
- common target: `i -> k` and `j -> k`;
- disjoint transfers.

An elementary tetrahedron is determined by three compatible transfer patterns. These finite patterns, not 343 positions, are the independent coherence prototypes.

## Translation/naturality law

For every admissible barycentric translation `tau`, require

\[
X_{\alpha+\tau}
=
T_\tau X_\alpha,
\]

\[
d_{ij}(\alpha+\tau)
=
T_\tau d_{ij}(\alpha),
\]

and similarly

\[

\mathsf H(\alpha+\tau)
=T_\tau\mathsf H(\alpha),
\qquad
\mathsf K(\alpha+\tau)
=T_\tau\mathsf K(\alpha).
\]

Once these are genuine naturality identities, a proof for one representative of each incidence type propagates to every interior lattice position.

## Boundary prototypes

Translation does not move an interior cell across a boundary while remaining admissible. Therefore boundary strata require separate prototypes:

- vertex neighborhoods;
- edge neighborhoods;
- face-interior neighborhoods;
- volume-interior neighborhoods.

The symmetric group on the four tetrahedral vertices reduces these further if conductor labels are functorial under relabeling. Polarity doubles a prototype only when the involution does not derive the opposite proof automatically.

## Polarity

Let

\[
\dagger:
\mathcal C_{semi}^+
\to
(\mathcal C_{semi}^-)^{op}
\]

be the primal/contragredient involution. Require

\[
\Phi^-
=
\dagger\Phi^+r,
\]

where `r` reverses the relevant orientation of the subdivided tetrahedron.

If this equality holds, only the positive-polarity prototypes need independent proof; all negative-polarity cells follow by involution.

## Minimal proof count

The number of independent obligations is therefore not 343. It is

\[
\boxed{
N_{proof}
=
N_{edgetypes}
+
N_{triangletypes}
+
N_{tetrahedrontypes}
+
N_{boundaryexceptions},
}
\]

possibly doubled by polarity if dagger does not determine the opposite side.

The exact numerical value depends on which semilocal operations label the four barycentric directions. It cannot be computed from the lattice alone.

The previously constructed tetrahedron

(6,0,1,0),

\quad

## Verification strategy

The recommended proof sequence is:

1. define `Phi` on vertices by a barycentric semilocal formula;
2. define the universal transfer transformations `d_ij`;
3. prove their typing and naturality once;
4. classify triangle incidence types and prove one interchange law per type;
5. classify tetrahedral incidence types and prove one modification law per type;
6. prove boundary restriction compatibility;
7. derive the negative polarity by dagger;
8. invoke coskeletality to fill every remaining cell.

## Disposition

The full eight-node pyramid should be treated as

\[
\boxed{
\operatorname{esd}_7(\Delta^3),
}
\]

with 120 vertices and 343 maximal tetrahedra. The optimal coherence proof is a single simplicial extension into the semilocal nerve. Under strict composition, all tetrahedral equations follow from associativity; under weak composition, only finitely many naturality prototypes require proof.
