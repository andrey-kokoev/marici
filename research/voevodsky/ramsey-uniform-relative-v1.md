# Quantified relative native query compiler

This is a scoped progress result on the existing `native-task-package-lift` conjecture, **not** its resolution.

## Source operation and quantified types

`RamseyUniformRelative.agda` constructs actual existing native WG P/E derivations for arbitrary natural k,m,n,r, labelled pattern functions, finite declared point arrays, opaque context strings and finite palette values. The source policy admits exactly the supplied context/color rows, independently of the requested word or any monochromatic answer. The length-indexed request carrier is a WG data type, not an unbounded extension of the earlier bounded P/N packet-trace codec.

The compiler computes Phi by folding the supplied letters, then exhaustively searches the finite declared point array using decidable equality. The query interface has no region-index/point/color-answer parameter. A found branch uses native E over **all** region premises. A missing branch retains its computed proof of absence as a native E index; its premises are zero-arity native P derivations. Empty initial seeds do not imply empty native closure.

A native P-history bundle retains the original supplied family, the word-indexed program and the query. The correct readout certificate uses the actual native package values. It certifies either a selected supplied row whose declared point is Phi and whose context/color are unchanged, or inequality of Phi with every supplied point.

## Composition and substitution

A structural induction proves the variable-word equation for every finite template in a discrete commutative monoid:

Phi(template[a]) = base(template) + repeat(variable-count(template), letter[a]).

A template containing a variable has positive multiplicity. Substituted requests are constructed and certified under exactly the same seed policy, with their own histories retained. They are not identified as whole native packages merely because a scalar point formula agrees.

`RamseyUniformSigned.agda` constructs the discrete commutative geometry of all signed integer triples using proved Cubical integer laws; the geometry axioms are not postulates. It also instantiates empty words, a radius-zero declared list and a negative-letter refusal. The relative generic theorem permits additional inputs (such as an empty declared list), but these are not falsely identified with complete L_0, which contains the origin.

## Precise remaining source witness

The parameters `at` and `contexts` are independent in this theorem. No type asserts that the context at a slot actually realizes its declared point. Nor does the theorem construct a complete finite enumeration of L_N for every N. Thus the relative constructor does **not** prove uniform sector-family admission by assuming it as an invisible input.

The strong rival deliberately pairs a genuine sector context at the origin with declared point 110. The relative native program and its declared-point certificate must still typecheck. The sector-binding check must reject that input, and a formal assertion equating its actual and declared points must fail. This makes the missing source witness concrete rather than administrative.

To close the parent conjecture, construct one uniform exact source context/region family and prove both complete L_N coverage and point/context coupling, compatibly with coloring restriction and source references. The earlier 171/365 actual-sector instances are evidence at their cutoffs, not an all-N proof. Physical admissibility, arbitrary-scale execution of the current numerical sector API, and native Ramsey forcing remain separate open questions.

## Prospective adversaries and artifacts

The controls include wrong lookup, false refusal, wrong variable multiplicity, misbound context, free target-index injection and invalid/missing palette values. Runtime arithmetic uses decimal BigInt coordinates, including values beyond machine-number exactness; this is not a claim that the sector's numerical geometry API realizes those large contexts.
