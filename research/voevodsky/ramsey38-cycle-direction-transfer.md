# An alternating six-cycle does not by itself select the repair

Frozen experiment: `checkers/ramsey38_cycle_direction_trial.py`, `results/ramsey38_cycle_direction_predictions.json`, `results/ramsey38_cycle_direction_comparison.json`. The candidates come from the 25-vertex induced graph and a red pair, up to exchanging its endpoints. Selection used no shelling result. Ten distinct labeled core cases, catalogue records 8–11 (not ten independent graph families). Compare exact single-hidden-row sets on common short-row labels before/after closing the six-cycle. Eight cases gain at the endpoint whose neighbor set is unchanged and lose at the other. In the two failures the former gains nothing. All ten lose at least one choice at the changed endpoint; some also gain choices there. This tests repair direction, not the actual color.

Reason for a finer prediction: write u for the unchanged-root end, v for its partner, and x for the optional neighbor added to v. In the rooted array at u the columns stay fixed. Only row x changes, from S to S union {v}. If both supports are short, and a *different* row is to be the sole hidden short row, any valid exposed enlarged support exposes S as a subface. The same ball then works before the change. A new release of a different row is impossible in this case. If a three-label S grows into a required tetrahedron, only its existence as a face is guaranteed; S need not lie on the boundary. A gain is possible, not necessary. Every genuinely gained other-row certificate must have S inside: otherwise it already certifies the original release. This deduction is specific to the intact-support boundary rule. At v the change adds a column, so the same implication does not follow by transposition.

In the sample, both failures changed an edge into a triangle; all eight gains changed a triangle into a tetrahedron. In all 18 gained-row certificates the old triangle is off the boundary. Freeze this refined rule before testing new supports; the six-cycle alone has already failed as a universal predictor.
