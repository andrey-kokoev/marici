# Generated attachment loops: no second phase closure

## Construction

Keep the same local generation and frame-registration rules. Take the full retained proton L/G/N protocol and the full reversed-cycle protocol with conjugated coefficients. Join corresponding raw AB x/y/z ports using the phase map derived from their generated modes, D=diag(v/conjugate(v)); use D inverse for the return bridges. No twist or extra carrier is inserted.

This is an explicit joined coefficient network, not a completed spatial barycenter pullback. It has 216 typed ports and 3678 arrows: 1836 in each protocol and six directed interface arrows. Its connected underlying graph has 3463 independent cycles.

## Exact result

All 3463 fundamental cycle products have positive real values. Therefore their full phase holonomy is trivial. Magnitudes are not asserted to equal one.

This includes the cycles created by attaching the two networks, not merely cycles confined to either original component. Algebraic reverse traversal in the spanning-tree calculation is used to evaluate graph holonomy, not to grant free physical inverse traversals.

There is also a general proof beyond enumeration. At each host port choose its nonzero generated mode component b; at the corresponding electron port choose conjugate(b). Every original or generated coefficient satisfies

```text
h(s→t) = a(s→t) b_t / b_s,    a(s→t) > 0 real.
```

The checker verifies this on every edge. Attachment edges have a=1. Along any closed path the b factors telescope, leaving a positive real product. The proof applies to any subset of matching-port bridges generated by the same ratio, so choosing another such attachment channel cannot generate a twist.

## Minus-sign control

A squared-phase test h/conjugate(h) cannot detect a negative real loop product. This checker uses the full complex product and tests an intentionally sign-flipped interface edge. The change is detected even though its squared phase is unchanged. There is no hidden sign holonomy in the unmodified construction.

## Outcome for the conjecture

The claim that this generation-and-attachment rule produces a second closure with nontrivial phase holonomy fails. Its generated connection is globally phase-trivial, including across the interface.

Thus the present construction does not generate neutron-as-holonomy. Adding more loops made from these same globally defined frame ratios cannot change that result. Inserting a twisted edge would change the generation rule; the negative control does not count as a derived second isotope.

This is stronger than an unsuccessful search for a particular loop: the global coefficient factorization excludes every loop built under this rule. The original proposition that a different, non-globally-trivial attachment structure might exist remains a separate conjecture, not an outcome of these calculations.
