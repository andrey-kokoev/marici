# Pipeline composition audit and observable quotient correction

Critical-path reassessment: compositional evidence must preserve the identities used in the theorem. Fresh inspection of `forest_canonical.py` revealed that ordinary mode strips numeric suffixes from every OUT name. This was appropriate for fixed OUT1/OUT2, but pipeline outputs are OUT_serial and their ordered identities are observable. Stage annotations are also omitted in ordinary mode. Thus earlier four-fixture pipeline counts (142 classes/290 edges) cannot be used as exhaustive evidence for stage-contract and ordered-snapshot properties without a corrected quotient. No counterexample to execution semantics is asserted; this is a flaw in the coverage argument.

New `check_pipeline_program_grammar.py` labels each canonical node with its stage and, for OUT nodes, its position in the compiled outputs list. The snapshot key now preserves both proof and observable identity. It tests every program of length 0..2 over add(0), add(2), member(0), member(2), union([]), union([0,1]), from [],[0],[1]. All 129 fixtures pass: 2,742 labelled classes and 4,684 individual-redex edges. Unified contract and live denotation are checked before deduplication and after every edge; each fixture has one labelled correct normal form. This includes adjacent union splices, empty programs, query permutations and out-of-range insertion.

The written proof of pipeline closure and denotational simulation does not rely on historical counts and is unchanged. The correction strengthens implementation evidence only. Next isolate a reusable observation-preserving pipeline key and add a negative control showing that swapping two different Boolean answers changes the key, while renaming allocation IDs does not. Then consolidate the pipeline theorem with explicit equivalence: preserve RET, ordered OUT identities, agent kinds/ports, with stage annotations either preserved for validation or forgotten only after semantic reasoning. Do not call terminal graphs unique under an equivalence that silently permutes query snapshots.
