## Claim boundary

The audit preserves the witness's 15 passing checks. It classifies the arrow type; it does not reassess Flavor's calibration contract or Sontag's control conclusion.

## Verified arrow

Sontag's result explicitly depends on Flavor's WP549 calibration result. It proves that an evidence-backed calibration validity state changes the admissible action set even when the presented numerical row is held fixed. This is a source-derived cross-sector evidence dependency.

## Missing computad interface

Neither the witness result nor its declared interface names:

- any of the five computad object sorts;
- a map into the Markov analytic section;
- a common overlap object;
- restriction maps from the Sontag and Flavor objects;
- a comparison cell.

Therefore the evidence dependency is not a sector-overlap edge in the coherence-pyramid nerve.

## Three arrow types

The census must distinguish:

1. evidence dependency: one sector's checked result is input to another argument;
2. semantic comparison: two sectors instantiate a shared proposition or obstruction pattern;
3. computad overlap: both sectors map to a typed common object with comparison data.

Only the third contributes edges and horns to the sector-overlap nerve. The Sontag–Flavor witness currently has the first type and supports the second interpretation, but not the third.

## Disposition

The witness remains verified and cross-sector, while the coherence-pyramid edge count remains zero. A future overlap claim must specify the common computad sort, both incidence maps, and the comparison cell rather than relying on the phrase `cross-sector witness`.
