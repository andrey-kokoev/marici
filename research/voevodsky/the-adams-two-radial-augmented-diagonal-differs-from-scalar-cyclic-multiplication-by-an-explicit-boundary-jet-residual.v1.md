# The Adams-two radial augmented diagonal differs from scalar cyclic multiplication by an explicit boundary-jet residual

## Question

Does the independently constructed radial bordered diagonal act entrywise as multiplication by \(1-p^{-2s}\) on the full bordered response?

## Claim boundary

Aspect v9 adopts the source-derived radial response diagonal \(B_{X}^{\mathrm{rad,aug}}=\bigoplus_{p\le X}A_{\mathrm{aug},p}\), where \(A_{\mathrm{aug},p}(q,a_0,a_1,\ldots)=((1-p^{-s})q-a_0,a_1,a_2,\ldots)\). The Adams-two comparison uses the same holomorphic family at parameter \(2s\).

Put \(\lambda_{p,2}(s)=1-p^{-2s}\) and define \(A_{\mathrm{aug},p}^{(2)}(s)=A_{\mathrm{aug},p}(2s)\). Then \(A_{\mathrm{aug},p}^{(2)}(s)(q,a_0,a_1,\ldots)=(\lambda_{p,2}q-a_0,a_1,a_2,\ldots)\).

Cyclic-observable multiplication acts on the same displayed coordinate packet by \(M_{\lambda_{p,2}}(q,a_0,a_1,\ldots)=(\lambda_{p,2}q,\lambda_{p,2}a_0,\lambda_{p,2}a_1,\ldots)\).

Their exact entrywise residual is \((A_{\mathrm{aug},p}^{(2)}-M_{\lambda_{p,2}})(q,a_0,a_1,\ldots)=(-a_0,a_1-\lambda_{p,2}a_0,a_2-\lambda_{p,2}a_1,\ldots)\).

This residual is generically nonzero. The first coordinate is the retained endpoint atom \(-a_0\), and the remaining coordinates compare boundary-jet shift with scalar Euler multiplication. Hence the radial augmented diagonal and cyclic scalar multiplication are different operators on the full bordered carrier.

The exact source relation is the augmented intertwiner \(J_pD_{\mathrm{jet}}=A_{\mathrm{aug},p}J_p\). Its scalar Euler projection has defect \(\pi_qA_{\mathrm{aug},p}-\lambda_p\pi_q=-\pi_0\). At Adams two, the same relation reads \(\pi_qA_{\mathrm{aug},p}^{(2)}-\lambda_{p,2}\pi_q=-\pi_0\).

The cyclic-observable square remains exact because its response packet is a coefficient object under \(\operatorname{Tr}(L(s)^2-)\), while the radial augmented carrier includes an active boundary-jet differential. Their lawful comparison is a relative or mapping-cone square retaining \(-\pi_0\) and the boundary shift.

## Disposition

The requested entrywise equality is rejected by an explicit source-derived residual. Gate 3 must compare the cyclic scalar action with the invariant Euler subobject of the radial augmented diagonal and retain the boundary-jet quotient plus extension class as the relative correction. The first residual is exactly \(-a_0\), followed by the jet-shift residuals \(a_{k+1}-\lambda_{p,2}a_k\).
