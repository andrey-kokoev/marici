# Relative base--fiber comparison gate for the p-normal filler

## Question

Does retaining the base-dependent \(c\) pivot in a relative total space solve the \(\tau_p\) source problem?

## Claim boundary

This packet tests the type of the relative base--fiber route. It does not construct the required kernel section, Bockstein class, global contour, or physical period.

## Disposition

The gradient-pivot prior art uses pivots

\[
(a,b,c),
\]

while the fixed target fiber has coordinates

\[
(a,b).
\]

The projection from the relative pivot space to the fixed fiber is

\[
\begin{pmatrix}
1&0&0\\
0&1&0
\end{pmatrix},
\]

with kernel generated by

\[
(0,0,1).
\]

Retaining \(c\) restores a three-chart relative source domain. It also introduces a kernel invisible to the fixed-fiber target. Without a section of this kernel into the logarithmic residue exact sequence, the sourced column remains the Čech-face leg

\[
(0,1)
\]

in rows \((\Xi_{\log},-\sigma_{123})\). The \(\tau_p\) contract requires

\[
(1,1).
\]

Over \(\mathbb F_{101}\) and \(\mathbb F_{103}\), the projection has rank \(2\), retaining the \(c\)-kernel gives rank \(3\), the current column has rank \(1\), and adjoining the required \(\tau_p\) column raises rank to \(2\).

Thus the relative base--fiber route is the correct typed home for the \(c\) pivot, but it does not by itself solve the lift. It converts the problem into constructing a source-derived section of the \(c\)-kernel whose \(\Xi_{\log}\) coefficient is a unit.
