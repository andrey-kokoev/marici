## Selected facet components are coherent only with the facet retained

Keeping a specific parent facet gives a singleton component. The corresponding selected maps have identity round trips and108 checked vertex component triangles, including repeated objects.

But these selected choices cannot all be represented by a function of chart and vertex alone. There are four concrete conflicts: at an M vertex the same chart occurs through two different selected parent facets, requiring two different outputs from the same purported chart/vertex input.

The facet index therefore carries necessary information. This is not an objection to the original face-specific retained policy, which permits that information; it rejects only forgetting the facet while pretending all selections are preserved.
