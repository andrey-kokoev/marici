# The volume divergence is an infinite-dimensional translation module, not a single Eisenstein feature line

## Question

Can the regulated positive feature have an ordinary Hilbert-space asymptotic

\[
Q_\Lambda P_RU_S(g)
=
\sqrt{2\log\Lambda}\Xi_S(g)
+
F_{\Lambda,R,S}(g)
\]

with one cutoff-independent vector `Xi_S(g)` carrying the volume divergence?

A translation model already answers this negatively.

## Logarithmic translation model

Let

\[
H=L^2(\mathbb R),
\]

and let `A` be convolution by a nonzero kernel `a`. After applying a fixed Fourier multiplier/cutoff `Q`, write the resulting convolution kernel as `k`, with

\[
k\in L^2(\mathbb R),
\qquad
k\ne0.
\]

Let

\[
P_M=1_{[-M,M]}
\]

be the logarithmic volume cutoff. The kernel of

\[
QP_MA
\]

has the model form

\[
K_M(x,y)
=1_{[-M,M]}(y)k(x-y).
\]

## Exact Hilbert--Schmidt growth

Translation invariance gives

\[
\begin{aligned}
\|K_M\|_{L^2(\mathbb R^2)}^2
&=
\int_{-M}^{M}
\int_\mathbb R
|k(x-y)|^2dxdy\\
&=
2M\|k\|_2^2.
\end{aligned}
\]

Thus

\[
\boxed{
\|QP_MA\|_{HS}^2
=2M\|k\|_2^2.
}
\]

For `M=log R`, the divergence is proportional to `2 log R`. Its coefficient is the trace-per-unit-volume density `||k||_2^2`.

## Normalized cutoff features do not converge strongly

Define

\[
v_M
=
(2M)^{-1/2}K_M.
\]

Then

\[
\|v_M\|=
\|k\|_2.
\]

For `0<M<=N`, direct integration gives

\[
\boxed{
\langle v_M,v_N\rangle
=
\sqrt{\frac{M}{N}}\|k\|_2^2.
}
\]

In particular, along `N=2M`,

\[
\|v_{2M}-v_M\|^2
=
2\left(1-\frac1{\sqrt2}
\right)
\|k\|_2^2.
\]

This does not tend to zero. Hence `(v_M)` is not Cauchy and has no strong Hilbert-space limit.

Therefore there is no cutoff-independent vector `Xi(g)` such that

\[
K_M
=
\sqrt{2M}\Xi(g)
+o(\sqrt M)
\]

in Hilbert--Schmidt norm.

## Geometric meaning

The divergent feature is the family of translates

\[
\{k(x-y):y\in\mathbb R\}.
\]

Unless `k=0`, this is not one Hilbert line. Its closed span is a translation-invariant module, generally infinite-dimensional.

The scalar divergence collapses to one number only after taking trace per unit volume:

\[
\frac1{2M}
\|QP_MA\|_{HS}^2
=
\|k\|_2^2.
\]

Confusing this one-dimensional scalar density with a one-dimensional feature subspace is the same type error as replacing an infinite-rank sewing operator by one endpoint coordinate.

## Semilocal consequence

The semilocal scaling direction has the same translation-volume mechanism. Consequently the ansatz

\[
Q_\Lambda P_RU_S(g)
=
\sqrt{2\log\Lambda}\Xi_S(g)
+
F_{\Lambda,R,S}(g)
\]

cannot hold in ordinary Hilbert--Schmidt norm with a single fixed vector `Xi_S(g)`, except under an additional quotient that has already collapsed the translation orbit.

Moreover, the leading outside divergence naturally depends on `log R`, not solely on `log Lambda`. Any correlated limit must specify

\[
\frac{\log R}{\log\Lambda}
\]

or remove the translation volume before comparing the two cutoffs.

## Correct bulk object

The volume direction should be represented by a Hilbert module over the scaling-group von Neumann algebra, or equivalently by a direct-integral/trace-per-unit-volume object.

The canonical scalar density is the semifinite Plancherel trace

\[
\tau_S
\left(
U_S(g)U_S(g)^*
\right)
=h(1)
=
\|g\|^2.
\]

Thus the correct positive bulk subtraction is not an orthogonal projection away from one vector. It is a **relative Hilbert-module construction** removing the free translation module with Murray--von Neumann dimension/trace density `h(1)`.

Schematically, the replacement is

\[
\boxed{
\text{regulated Hilbert--Schmidt feature}

\sim
\text{free scaling Hilbert module}
\oplus
\text{relative boundary feature},
}
\]

where the displayed symbol denotes an asymptotic module decomposition, not an ordinary vector-space direct sum already proved.

## Relation to the Eisenstein radical

The assertion that the radical is generated by `ran E_S` remains compatible with this correction only if `ran E_S` is treated as a translation-invariant module, not as a rank-one line.

Required properties are:

1. `overline(ran E_S)` is invariant under the scaling von Neumann algebra;
2. its regulated Hilbert--Schmidt mass has trace density `h(1)`;
3. quotienting/conditioning is defined in the Hilbert-module or relative-trace category;
4. the quotient retains the prolate/Sonin boundary feature;
5. the construction is compatible with the two cutoff orientations.

## Revised next theorem

The viable theorem is a module-level relative convergence statement. Let

\[
\mathcal M_S
=VN(C_S)
\]

with semifinite trace `tau_S`. Construct a regulated feature correspondence `X_(Lambda,R,S)` and a free bulk subcorrespondence `X_bulk,S` such that

\[
\boxed{
\operatorname{dim}_{\tau_S}
(X_{bulk,S}(g);[-\log R,\log R])
=
2\log Rh(1)+o(\log R),
}
\]

and prove convergence of the relative class

\[
[X_{\Lambda,R,S}(g)]
-
[X_{bulk,S}(g)]

\in
K_0^{rel}(\mathcal M_S,\tau_S)
\]

or in an explicitly defined relative Hilbert-module completion.

The precise relative category remains to be selected; ordinary Hilbert quotient by one feature line is ruled out.

## Refinement impact

The ten-node candidate refinement remains structurally useful, but stage 7 must be corrected:

- not `one Eisenstein asymptotic feature`;
- instead `the translation-invariant Eisenstein/bulk module with trace density`.

Stage 8 is correspondingly:

- not an ordinary quotient by one divergent vector;
- instead a relative Hilbert-module quotient or conditioning operation.

## Disposition

The simplest positive asymptotic ansatz is falsified:

\[
\boxed{
\text{volume divergence does not converge to one fixed normalized feature vector}.}
\]

It is an infinite-dimensional translation module whose scalar coefficient appears only after trace per unit volume. The next positive construction must be performed in a semifinite Hilbert-module/relative-trace category.
