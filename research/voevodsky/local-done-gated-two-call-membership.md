# Local DONE-gated two-call membership

Implemented GATE(p,s,r,b,o,c): p awaits the first call's DONE; s holds the retained support endpoint, r leads to RET, b holds the second unary budget, o its OUT, and c the final ACK. Before release there is no second COPY or query agent. All resources are wired at construction; runtime never calls start or polls stage completion to select a rule.

The single GATE--DONE rule consumes those two agents and introduces a COPY plus return-bearing QB. COPY.p takes s, COPY.a takes r, COPY.b meets QB.a; QB.p takes b, QB.r takes o, QB.c takes c. Every outside slot is used once. Eligibility checks only the principal pair, not the graph-wide cleanup predicate. The latter is asserted by the tests as a consequence, not used by the engine.

Fresh `check_gated_membership.py`: 858 two-call runs over words n<=3 and indices through n+2, using deterministic and seeded random choices, pass 18,682 rewrite checks. At every enabled gate, first-call COPY/Q/EA are absent and its answer is correct. The second output remains connected to the gate until release. Final support and both answers are correct; final ACK has DONE. The count is 4n+i+j+7, two single-call costs plus one gate rewrite.

Important topology change: keeping both retained-data and acknowledgment paths attached to one gate introduces an undirected cycle before completion. The old forest invariants and forest-only canonicalizer must NOT be applied to this combined graph. Port symmetry is checked, but tests here are schedule samples, not an exhaustive cyclic-graph quotient.

A scoped safety argument is suggested by interface substitution: before GATE--DONE, GATE has no rule with data or an acknowledgment-carrying auxiliary, so it is a passive context for the first operation. Its extra connections do not modify that operation's internal principal pairs. The previously proved first-call DONE implication then permits gate release only after its work is finished. The gate creates exactly the second call with completed input. To promote this into a full general proof, justify this passive-context extension without the forest premise, or prove it directly with a cut-interface invariant. Next audit that cyclic passive context and exact boundary replacement, rather than claiming old forest proofs automatically cover it. Multi-operation barriers, dynamic branching and arbitrary cyclic nets remain out of scope.
