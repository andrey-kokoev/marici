# Ratio-normalized grade makes fixed-ratio cycle graphs canonically isomorphic

## Question

Can the denominator-dependent fixed-ratio grades be normalized so reciprocal reflection and the cycle radical become blockwise canonical?

## Claim boundary

Yes for the actual consecutive-prime catalogue. Write a reduced ratio as \(m/n=a/b\), so \((n,m)=(kb,ka)\). Define the intrinsic edge labels \((j,k)\) and normalized grade

\[
\overline W(j,k)=\log(kp_jp_{j+1}).
\]

This grade is independent of \(a,b\), proper on each ratio block, and exactly invariant under reciprocal reflection \(a/b\leftrightarrow b/a\).

## Canonical graph comparison

The interval edge in the \(D=\log(a/b)\) block has multiplicative endpoints

\[
kbp_j\longrightarrow kbp_{j+1}.
\]

Dividing every vertex by \(b\) gives

\[
kp_j\longrightarrow kp_{j+1}.
\]

Hence every fixed-ratio interval graph is canonically isomorphic, through its reduced denominator, to one universal labelled graph \(G_*\). This preserves incidence, connected components, cycle rank, spanning forests, and forest-presentation transition maps. The four-term multiplicative rectangle generated by two shells occurs in every ratio block after multiplication of all vertices by \(b\).

This comparison is not a physical scale identification. It is a source-label graph isomorphism before analytic readout.

## Relation to the endpoint product grade

The earlier grade recovered directly from endpoints is

\[
W_D(j,k)=\log(kb p_jp_{j+1})
=\overline W(j,k)+\log b.
\]

Therefore, on one fixed block,

\[
q_\delta^{W_D}=b^\delta q_\delta^{\overline W}.
\]

The two grades define exactly the same projective topology. The normalized grade removes the blockwise denominator shift without changing continuity.

## Intrinsic cutoffs and reflection

Use

\[
E_L^*=\{(j,k):kp_jp_{j+1}\leq L\}.
\]

The same finite label set is used in every ratio block. Under reciprocal reflection, \((a,b)\) is exchanged while \((j,k)\) and \(\overline W\) are fixed. Thus cutoff inclusions, greedy forests from one global label order, cycle coordinates, and reflection now form strict blockwise comparisons rather than comparisons with rescaled cutoff thresholds.

The interval length obeys

\[
\log(p_{j+1}/p_j)
\leq \overline W(j,k)
\leq\delta^{-1}e^{\delta\overline W(j,k)},
\]

so the half-line continuity estimate remains uniform in both cutoff and ratio denominator.

## Disposition

Adopt \(\overline W=\log(kp_jp_{j+1})\) as the ratio-normalized source grade candidate. It is topologically equivalent to the endpoint product grade on each block but makes the universal cycle graph and reciprocal comparison strict. No uniform topology over an unbounded coproduct of ratio blocks is claimed; that requires a separately declared weight in \(a,b\).
