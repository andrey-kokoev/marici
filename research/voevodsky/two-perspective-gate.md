# Two-perspective gate — required for a full comparison at four-role-relational-carrier

Before a test, freeze the carrier, two marked roles on each side (including N1/N2 if appropriate), switches X and Y, readout, and comparison rule. X changes the perspective within a reading (P/E or B/R). Y changes the reading (PE/NN or BR/NN); its source definition is still open. A switch can reindex a static relation; it need not be an operation in time. Preserve marks and support until all comparisons are complete. Never infer admissibility from the names.

Record the five source readings I, X, Y, XY, YX; letters are in application order. Do not merge the last two. Record XX and YY controls to test reversal. Compare all pairs of available corner records, including both paths to the nominal fourth corner. Compare the effect I→X against Y→YX and I→Y against X→XY using the frozen comparison rule; retain the two comparison records themselves, not only two Boolean answers. Test whether XY and YX agree with marks intact. If XX/YY fail to recover I or XY differs from YX, report it rather than imposing a Klein four action. If a second reading or arrow is undefined, label the result partial; do not insert a synthetic identity. Quotient only afterwards, as a separate result.

Use `python research/voevodsky/checkers/two_perspective_gate.py receipt.json` for a completeness check. Each entry is a nonempty record with `result` and `evidence` (source path, witness ID or reproducible reference). For the receipt layout run `--template`. Exit 0 = all required records supplied, not a verdict that symmetries hold. One-switch experiments remain useful controls but cannot count as full two-perspective evidence. This is a local review gate, not a change to publication authority.
