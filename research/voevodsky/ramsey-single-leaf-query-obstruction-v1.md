# One canonical native reader leaf cannot provide every word query

## Exact rival

Net node `single-leaf-query-completeness` asks whether the successful bounded selected-point construction extends to every word using only paths from the same canonical seed and the same first-window geometric observation. This is a rival strategy for `native-task-package-lift`, not a prerequisite that every alternative must satisfy.

The rival is false if the stated local reference-height invariant holds. For the source-bound pattern (000,110,101), word 111 requires point (3,3,0), inside L_3. The canonical native first-window points are restricted to y=0,1,2, so no such path can select that point.

## Source invariant and induction

Strominger's existing `four-progression-directions-v1.md` identifies the preserved M-plane h(b)=b0+b2. Rather than importing its scientific outcome, the new probe freshly checks the reference-height strengthening needed here on the actual source templates and all admitted outgoing operations.

For any admitted planar P/N chart with M-height m:

- M0 and M1 have height m;
- C0,C1,C2 have height m-1 or m+1;
- every native successor preserves these constraints, including the additional M2 reference of a terminal E chart;
- E has no outgoing operation.

The local coverage consists of both translated regular orientations and all four split-octahedron components, with every ordered marking and its native reference completion. Native constructors commute with exact integer translations. Availability depends on marked geometry, not absolute realization origin or coefficient permutation; those are retained and transformed by the source rules. Thus the local check extends by induction over successful finite exact-integer native paths, not by extrapolating a depth search.

Every native geometric point lies on sum(b)=1, and the established projection satisfies F_y=b1+b3=1-h. The canonical seed has M-height zero. Its first-window occurrence is therefore always in y=0,1,2, while the required query (3,3,0) has y=3. A finite input region containing the query does not remove this operational obstruction.

A related consequence is stronger than loss of word syntax: under this same observed-point policy, coloring by y mod 3 prevents any positive-integral homothetic copy of the triangular pattern inside the canonical slab. Such a copy contains points of heights a_y and a_y+m. Slab containment allows only (a_y,m)=(0,1),(0,2),(1,1); all three pairs have different colors. This is a consequence for the restricted observable domain, not a refutation of the full-lattice Ramsey theorem.

## Surviving scope

The bounded length-two native query result remains valid: its points all lie in the allowed slab. Retaining more event history alone does not create the missing point under this exact geometric observation. Merely translating or rotating a diagram is not a path generated by the declared operations.

The broader task-package conjecture may use a different independently justified source policy, multiple prepared source leaves or a different admitted representation. Those are not refuted. The first concrete alternative to investigate is an indexed family of source-completed local contexts prepared over the supplied region independently of the requested word or monochromatic answer, followed by a genuinely justified selection/composition interface. A list of host records is not automatically an admitted native family.

Verification level: written exact-integer local-to-path induction and exhaustive source-template controls, with independent query arithmetic; not a kernel proof, hardware restriction or universal Marici no-go.
