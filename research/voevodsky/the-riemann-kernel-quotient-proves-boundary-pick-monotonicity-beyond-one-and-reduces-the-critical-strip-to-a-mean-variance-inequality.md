# The Riemann-kernel quotient proves boundary Pick monotonicity beyond one and reduces the critical strip to a mean--variance inequality

## Objective

Exploit the coupled theta-kernel quotient on the real boundary of the Pick domain.

The logarithmic derivative of the Riemann-kernel integral has an exact probability interpretation. It yields unconditional boundary monotonicity for \(s\ge1\) and isolates the remaining centered strip as one explicit mean--variance inequality.

## Real centered coordinate

Let

\[
z
=
x>0,
\qquad
s
=
\frac12+x,
\qquad

t
=
x^2.
\]

Write

\[
D(x)
=
\Xi(x)
=
\int_0^\infty
\Phi(u)
\cosh(xu)
\,du,
\]

and

\[
N(x)
=
\Xi'(x)
=
\int_0^\infty

u
\Phi(u)
\sinh(xu)
\,du.
\]

Since \(\Phi>0\),

\[
D(x)>0,
\qquad
N(x)>0
\]

for \(x>0\).

The endpoint-reduced function is

\[
F(x^2)
=

c(x)

m(x),
\]

where

\[
c(x)
=
\frac{
4x^2-1
}
{
2x
}
=
2x-
\frac1{2x},
\]

and

\[
m(x)
=
\frac{
N(x)
}
{
D(x)
}
=
\frac{
\Xi'(x)
}
{
\Xi(x)
}.
\]

## Tilted Riemann probability measure

Define

\[
d\mathbb P_x(u)
=
\frac{
\Phi(u)
\cosh(xu)
}
{
D(x)
}
\,du.
\]

This is a probability measure on \((0,\infty)\).

Then

\[
\boxed{

m(x)
=
\mathbb E_x
[

u
\tanh(xu)
].
}
\]

Differentiating the quotient gives

\[
N'(x)
=
\int_0^\infty

u^2
\Phi(u)
\cosh(xu)
\,du,
\]

so

\[
\boxed{

m'(x)
=
\mathbb E_x
[

u^2
]
-

m(x)^2.
}
\]

This is nonnegative. Indeed,

\[

m(x)^2
=
\mathbb E_x
[

u
\tanh(xu)
]^2
\le
\mathbb E_x
[

u^2
\tanh^2(xu)
]
\le
\mathbb E_x
[

u^2
].
\]

Thus

\[
\log\Xi(x)
\]

is convex on the positive real centered axis.

## Exact derivative of the Pick boundary function

Differentiate

\[
F(x^2)
=

c(x)
m(x).
\]

Since

\[
c'(x)
=
2+
\frac1{2x^2},
\]

we obtain

\[
\boxed{
\frac d{dx}
F(x^2)
=
\left(
2+
\frac1{2x^2}
\right)

m(x)
+
\left(
2x-
\frac1{2x}
\right)
\left[
\mathbb E_x(
u^2)
-

m(x)^2
\right].
}
\]

Since

\[
\frac d{dt}
F(t)
=
\frac1{2x}
\frac d{dx}
F(x^2),
\]

the same sign controls boundary Loewner monotonicity.

## Exterior half-line

If

\[
x
\ge
\frac12,
\]

then

\[
c(x)
=
2x-
\frac1{2x}
\ge0.
\]

Every term in the derivative formula is nonnegative, and the first is strictly positive. Therefore

\[
\boxed{
\frac d{dt}
F(t)
>0
\qquad
(t\ge1/4).
}
\]

Equivalently, on the real \(s\)-axis,

\[
\boxed{
F
\text{ is strictly increasing for }
s\ge1.
}
\]

This conclusion is unconditional and uses only positivity of Riemann's theta kernel.

By centered reflection, the corresponding opposite exterior half-line follows with the appropriate orientation.

## Centered critical interval

For

\[
0<x<
\frac12,
\]

one has

\[
c(x)<0.
\]

The variance term now enters with the hostile sign. Boundary monotonicity is equivalent to

\[
\boxed{
\left(
2+
\frac1{2x^2}
\right)

m(x)
\ge
\left(
\frac1{2x}
-
2x
\right)
\left[
\mathbb E_x(
u^2)
-

m(x)^2
\right].
}
\]

After multiplying by \(2x^2\), this becomes

\[
\boxed{
(
4x^2+1
)
m(x)
\ge
x(
1-4x^2
)
\left[
\mathbb E_x(u^2)
-
m(x)^2
\right].
}
\]

The factor \(x\) on the right is essential: it produces the cancellation of the singular prefactor at the branch point.

This is the exact remaining boundary inequality.

## Interpretation

The left side is the tilted mean response

\[

m(x)
=
\mathbb E_x[
u\tanh(xu)].
\]

The right side is the residual second-moment spread

\[
\mathbb E_x(
u^2)-m(x)^2.
\]

Thus the critical-strip boundary problem asks whether the mean generated by the hyperbolic tilt is large enough to dominate its residual spread with the rational coefficient

\[
\frac{
1-4x^2
}
{
1+4x^2
}.
\]

This is a concrete inequality for one explicit positive probability measure, not a gamma-versus-prime sign comparison.

## Small-\(x\) limit

Let

\[
M_{2k}
=
\frac{
\int_0^\infty

u^{2k}
\Phi(u)
\,du
}
{
\int_0^\infty
\Phi(u)
\,du
}.
\]

As \(x\downarrow0\), quotient expansion gives

\[
m(x)
=xM_2
+x^3
\left(
\frac{M_4}{6}-
\frac{M_2^2}{2}
\right)
+O(x^5).
\]

Put

\[
a
=
\frac{M_4}{6}-
\frac{M_2^2}{2}.
\]

Then

\[
m'(x)
=M_2+3ax^2+O(x^4).
\]

The difference between the two sides of the critical inequality is

\[
x^3
\left(
8M_2-2a
\right)
+O(x^5),
\]

or

\[
x^3
\left(
8M_2+
M_2^2-
\frac{M_4}{3}
\right)
+O(x^5).
\]

Thus the branch-point boundary gate begins with the explicit theta-moment inequality

\[
\boxed{
M_4
\le
3M_2^2+24M_2.
}
\]

The leading \(xM_2\) terms cancel exactly, as required by the removable \(t=x^2\) coordinate.

## Exact identities retained

Independently of the final Pick orientation, the following identities are exact:

\[

m(x)
=
\mathbb E_x[
u\tanh(xu)],
\]

\[

m'(x)
=
\mathbb E_x(
u^2)-m(x)^2
\ge0,
\]

and

\[
\frac d{dx}
[

c(x)m(x)
]
=

c'(x)m(x)
+

c(x)m'(x).
\]

These identities give a coupled positive-kernel reduction of every real-boundary derivative question.

## Resolvent calibration

The sign agrees with the known conditional resolvent formula

\[
F(t)
=
4
\sum_\lambda

m_\lambda
-
\sum_\lambda
\frac{

m_\lambda(
1+4\lambda
)
}
{
t+
\lambda
}.
\]

Its derivative is

\[
F'(t)
=
\sum_\lambda
\frac{

m_\lambda(
1+4\lambda
)
}
{
(
t+
\lambda
)^2
},
\]

which is positive when \(\lambda\ge0\). This fixes the intended boundary orientation.

## Disposition

The theta quotient provides an unconditional exterior monotonicity mechanism and an exact mean--variance reduction on the centered interval:

\[
(1+4x^2)m(x)
\ge
x(1-4x^2)m'(x).
\]

Near the branch point its first nontrivial coefficient is the theta-moment inequality

\[
M_4\le3M_2^2+24M_2.
\]

The remaining question is whether the full mean--variance inequality holds for every \(0<x<1/2\).
