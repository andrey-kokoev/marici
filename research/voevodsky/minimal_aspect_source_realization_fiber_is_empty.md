# The audited source-realization fiber of the minimal Aspect map is empty

## Question

Can the formal generator mapping to \((\Xi_{\log},-\sigma_{123})\) be identified with any already audited geometric source object?

## Claim boundary

This audit composes the minimal formal map with three Benincasa source audits. It concerns the currently audited candidate subcategory. It does not prove that no suitable geometric source exists outside that envelope.

## Required realization

The formal generator \(e\) must be replaced by one source object carrying the data needed for the target column \((1,1)\):

- a unit logarithmic/principal leg;
- the ordered exceptional Čech face leg;
- the required boundary and labels;
- a comparison map into the logarithmic Čech--de Rham target.

## Candidate census

1. **Blow-up exceptional simplex.** It is sourced but maps to \((0,1)\). It supplies the face leg and lacks the \(\Xi_{\log}\) unit leg.
2. **Cayley--Menger fiber-cycle family.** It is oriented and sourced, but the audited local monodromy is identity and no weighted-Rees specialization, exceptional coefficient map, or logarithmic comparison is present.
3. **Physical-wall mapping cone.** It is closed with zero pairwise residue differential but selects no absolute lift.
4. **Ordered relative-face cone.** It derives the closed class \(\Xi_{\log}-\sigma_{123}\). A sourced unit exceptional face leg would force the primitive column \((1,1)\) uniquely, but that statement is conditional and supplies no incoming generator.
5. **Minimal extension candidates.** No audited object simultaneously carries the principal leg, ordered boundary, both required labels, and comparison map. The source-realization fiber is empty already at object assignment.

## First missing constructor

The narrowest surviving construction is a weighted exceptional specialization of the sourced Cayley--Menger incidence family, together with typed comparisons to both \(\Xi_{\log}\) and the blow-up face. Its image must be the primitive column \((1,1)\).

## Disposition

No existing audited object realizes the formal sphere generator. The physical descent branch stops at object assignment, before naturality, contraction descent, mapping-cone interpretation, or physical readout. Reopen only when the weighted exceptional source object and both comparison legs materialize.
