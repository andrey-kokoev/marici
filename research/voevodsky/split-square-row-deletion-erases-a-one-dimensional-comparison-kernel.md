# Split square-row deletion erases a one-dimensional comparison kernel

For square rows plus the exact redundant row z:`x+y<=2`, retraction to old multipliers is `(a,x,b,y,z)->(a,x+z,b,y+z)`. The first four basis vectors map to the old basis, so rank is four. With five input coordinates its signed kernel is ONE-dimensional, generated by `(0,-1,0,-1,1)`; that vector has zero target normal and bound. Fresh `check_split_deletion_signed_kernel.py` checks five distinct nonnegative proofs `(0,1-z,0,1-z,z)` for z=0,1/4,1/2,3/4,1. All prove the same exact target and retract to the SAME old packet. All ten pairwise nonzero signed comparisons are killed by deletion.

To recover a NEW packet from its old retraction, retain the deleted-row multiplier z: `new=include(old)+z*kernel`. This is minimal LINEAR packet recovery for this one-row split, not historical recovery. A historical comparison additionally requires the row-introduction record and comparison/path edges; the coefficient z alone cannot establish which execution occurred. Thus noninvertible deletion erases a real comparison even though it preserves endpoint certificates.
