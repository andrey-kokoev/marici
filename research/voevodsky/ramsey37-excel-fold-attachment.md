# Does a reversible terminal swap identify equivalent graph attachments at (3,7)?

**Question:** As a scoped candidate, take an occurrence to be a terminal block placement, its fixed tail, and one of its two witnessed swap choices in the ten literal width-seven rows. Forget the last choice once. Can we realize both rows on the same labeled graph interface and then forget that choice without changing which exterior attachments are legal? This is a test of a proposed quotient, not a definition of the operator's intended linkage.

**Answer:** No for the following forward realization. Use positions 1–7 as the vertices of a red path, with all other pairs blue. Join vertex 8 in red to the three red positions of its row S. No red triangle is formed because the positions are separated. This path realization is a model choice, not inferred from a Ramsey catalogue. For each label j attach vertex 9 red to 8 and j only. Declare the readout to be legality of the same complete labeled nine-vertex coloring for each j: no red triangle and no blue seven. The result is legal exactly when j is outside S. If j is inside S, the three vertices j,8,9 are a red triangle. If not, there is no red triangle. In either case the red path contains at most four mutually blue vertices, so even with the two extra vertices no blue seven exists.

Thus `146` and `246` admit the same number of probes but disagree on the probe at 1. Their folded display can still store both alternatives. It cannot replace them by one state with the same legal futures. All ten distinct literal rows have distinct labeled probe sets; all six witnessed terminal swaps fail, including the reflected cases. The [exhaustive checker](checkers/ramsey37_excel_fold_attachment.py) checks both forbidden colors for each row and label. The proof does not require enumerating all possible attachments: one distinguishing attachment suffices. It does not exclude folding repeated occurrences of an identical row for this readout.

**Unanswered:** Path reversal acts by i ↦ 8−i on positions and transports each probe accordingly. One-site cyclic translation does not preserve the path or even the full row family (`137` wraps to `124`). No parameter exchange is supplied by this construction: exchanging red and blue and the forbidden clique sizes on the graph does not turn a width-seven three-red path table into an intrinsic (7,3) table. No 4D/8D trace or span, intrinsic parameter readout or extra-cell count is established. Do not promote a failed attachment quotient to a registered lift. Another readout or realization needs a separate test.
