# Thin Tamari enrichment closes formal pentagons by forgetting paths

There IS a clean mathematical construction for the finite bracket problem, but it changes the comparison contract. Start with the free directed rotation graph on five ordered leaves and form its reachability POSET (the thin Tamari category): between comparable bracket trees there is one arrow, irrespective of which rotation word witnesses reachability. Fresh `check_tamari_thin_enrichment.py` checks 14 objects, 21 generating rotations, 68 reachable ordered pairs, antisymmetry and transitivity. Nineteen comparable pairs have more than one rotation path; the extreme left-to-right pair has NINE distinct paths. The map from free path words to the thin category is therefore nonfaithful.

The thin category satisfies pentagon and five-leaf overlap equations STRICTLY because all parallel arrows are definitionally the same reachability arrow. It is a **NEW quotient/enrichment** for public bracket reachability; it is not a source-derived higher pentagon 3-cell identifying already recorded Farkas proof histories. A fine replay control can still return nine different paths for the extreme pair, while the thin arrow forgets which one occurred. Using the quotient to assert actual-history equivalence would silently change permitted continuations.

This resolves the local existence-vs-authority distinction: the formal coherence problem has a well-defined mathematical quotient, but proof-relevant coherence remains unsupported without independently sourced higher constructors.
