# The pure Hardy mismatch strip is asymptotically common under a bounded Tate--Hankel perturbation

## Correct reference sector

Let \(P\) be the fixed Hardy projection and let

\[
Q_L^0=U_LPU_L^*,
\qquad
U_L=M_{e^{2iLs}},
\]

with the orientation \(Q_L^0\le P\). The pure reference mismatch projection is

\[
E_L=P-Q_L^0.
\]

It is an exact projection onto the Hardy strip of width \(2L\). For an observer localization map \(M_g\), define

\[
X_L^0g=E_LM_g.
\]

On every finite observer packet \(E\), its Gram satisfies the exact Plancherel law

\[
(X_L^0)^*X_L^0
=2L\,G_{Pl,E}
\]

with the declared Fourier normalization.

This, rather than a pure dyadic prolate defect, is the extensive positive reference edge.

## Tate perturbation

Let \(\Gamma=M_{\gamma}\) be the Tate scattering multiplier and

\[
Q_L^T=U_L\Gamma P\Gamma^*U_L^*.
\]

After the full Halmos decomposition of \((P,Q_L^T)\), collect its exact mismatch and generic-angle boundary legs into one positive feature

\[
X_L^T:E\to\mathcal H_L^T.
\]

The physical alignment problem asks for a comparison of this complete feature with \(X_L^0\), not merely of their signed traces.

Choose isometric embeddings into a common carrier and write

\[
\boxed{X_L^T=V_LX_L^0+K_L,}
\]

where \(V_L\) is an isometry on the reference generated range and \(K_L\) is the Tate--Hankel perturbation. The exact transport must construct this decomposition; the estimates below state what it buys.

## Finite-packet angle lemma

Fix a finite packet \(E\) on which

\[
G_{Pl,E}\succeq m_EI,
\qquad
m_E>0.
\]

Assume

\[
\|K_L|_E\|\le C_E
\]

uniformly in \(L\). For \(u\in E\),

\[
\|V_LX_L^0u\|
\ge\sqrt{2Lm_E}\,\|u\|.
\]

Therefore the relative feature error obeys

\[
\boxed{
\|K_Lu\|
\le
\frac{C_E}{\sqrt{2Lm_E}}
\|V_LX_L^0u\|.
}
\]

Set

\[
\varepsilon_{L,E}
=\frac{C_E}{\sqrt{2Lm_E}}.
\]

Then

\[
(1-\varepsilon_{L,E})
\|X_L^0u\|
\le
\|X_L^Tu\|
\le
(1+\varepsilon_{L,E})
\|X_L^0u\|.
\]

After squaring,

\[
\boxed{
(1-\varepsilon_{L,E})^2G_L^0
\preceq
G_L^T
\preceq
(1+\varepsilon_{L,E})^2G_L^0.
}
\]

Thus the Tate and pure mismatch features have principal angles tending to zero on every fixed coercive packet.

## Approximate common-strip extraction

The source-labelled map

\[
T_L:X_L^0u\mapsto X_L^Tu
\]

is well-defined on a sufficiently large finite packet and satisfies

\[
\|T_L^*T_L-I\|
\le
2\varepsilon_{L,E}+
\varepsilon_{L,E}^2.
\]

Let

\[
T_L=W_L|T_L|
\]

be its polar decomposition. Then \(W_L\) is an isometry between the generated feature ranges and

\[
\boxed{
\|T_L-W_L\|
=O_E(L^{-1/2}).
}
\]

Consequently

\[
W_LX_L^0
\]

is a physically embedded common mismatch-strip feature up to a source-Gram error of order \(O_E(\sqrt L)\), or relative error \(O_E(L^{-1/2})\).

If the centered Tate--reference Gram difference is actually bounded, the linear cross term in

\[
(X_L^T)^*X_L^T-(X_L^0)^*X_L^0
\]

must cancel, improving the Gram error from \(O_E(\sqrt L)\) to \(O_E(1)\). The feature-angle conclusion itself needs only bounded \(K_L\).

## Relation to Douglas leakage

Let

\[
D_L=G_L^T-G_L^0.
\]

On a fixed packet, bounded centered convergence gives \(\|D_L\|=O_E(1)\), while

\[
G_L^{T,0}\succeq c_ELI.
\]

Hence

\[
\|(G_L^T)^{-1/2}D_{L,+}^{1/2}\|^2
\le
\frac{\|D_L\|}{c_EL}
=O_E(L^{-1}).
\]

In particular,

\[
\boxed{
\kappa_{L,+}(E),\kappa_{L,-}(E)
=O_E(L^{-1}),
}
\]

which is stronger than the \(1+o(1)\) threshold needed for extractability. The extensive mismatch strip absorbs every bounded Jordan correction on a fixed packet.

This recovers finite-packet common-edge removal from the corrected Hardy geometry without invoking a nonexistent pure prolate defect.

## Source form of the Tate--Hankel remainder

The deviation from nesting is generated by the scattering commutator. At the projection level,

\[
Q_L^T-Q_L^0
=U_L(\Gamma P\Gamma^*-P)U_L^*.
\]

Since

\[
\Gamma P\Gamma^*-P
=[\Gamma,P]\Gamma^*,
\]

the perturbation is the transported Hankel operator

\[
\boxed{H_\gamma=[P,M_\gamma].}
\]

Observer localization replaces the generally non-Hilbert--Schmidt bare operator by

\[
H_\gamma M_g.
\]

A sufficient source estimate for bounded packet perturbation is

\[
\boxed{
\sup_{L\ge1}
\|H_\gamma M_g\|_{\mathcal L^2}
\le C\|g\|_{\mathscr E_S}
}
\]

on the phase-energy observer core, with the angular sum included. The \(L\)-uniformity is natural because \(U_L\) is unitary; the substantive issue is the semilocal observer-weighted Schatten bound and endpoint domain.

## Global weighted version

The completed space has no uniform lower bound for \(G_{Pl}\) along arbitrary packets. Replace scalar coercivity by the Plancherel energy norm. The required global estimate is

\[
\boxed{
\|K_Lu\|
\le C\|u\|_{\mathscr E_S},
\qquad
\|X_L^0u\|^2=2L\|u\|_{Pl}^2.
}
\]

To suppress escaping near-null modes, one additionally needs compactness or tail-smallness of the Tate--Hankel map relative to the phase-energy filtration:

\[
\boxed{
\sup_{L\ge1}
\|K_L(I-P_n)u\|
\le
\eta_n\|u\|_{\mathscr E_S},
\qquad
\eta_n\to0.
}
\]

On \(P_n\mathscr E_S\), the previous angle lemma applies. On the complement, the displayed tail estimate prevents recurrence of the noncommuting two-dimensional hostile.

## Concrete analytic target

The global common-strip problem is therefore reduced to an observer-localized Hankel theorem for the Tate phase:

\[
\boxed{
[P,M_{\gamma_S}]M_g:
\mathscr E_S\to\mathcal L^2
\text{ is bounded and filtration-compact}.
}
\]

Characterwise, a standard sufficient condition is a weighted Besov/Hankel estimate for \(\gamma_\chi\), followed by summation using rapid angular decay of \(g\). This estimate is finer than the signed logarithmic-derivative trace: it controls the feature angle, not only its polarized trace.

## Sonin sector

The argument concerns the extensive mismatch strip and gamma-induced generic-angle feature. Any complementary Sonin atom must be split off before applying the angle lemma. If it has zero signed readout, it remains as a balanced positive summand and is not absorbed into \(K_L\).

## Disposition

After correcting the reference geometry, the common positive edge has a precise physical source: the exact pure Hardy mismatch strip.

A bounded, filtration-compact observer-localized Tate--Hankel perturbation makes this strip asymptotically common and yields vanishing Douglas leakage on every coercive packet. The next source theorem is the semilocal weighted Schatten/compactness estimate

\[
\boxed{[P,M_{\gamma_S}]M_g\in\mathcal L^2}
\]

with uniform phase-energy and angular-tail bounds.
