# Fiber saturation locates the exact storage obstruction

## Owning source section

Use the independently verified tail zero-frame family. Define a finite section S: x is identically zero, and y is either zero or one half at each of the ten declared even probe coordinates, zero elsewhere. All 1,024 section points are genuine admitted infinite tails. The checker independently verifies 307,200 interval inequalities; zero extension and increasing interval capacity handle later endpoints.

For each retained zero-frame set J, let C_J be the section points vanishing at J. Observe the first eight coordinates with L. These are possibility carriers, not selected actual source points.

## Exact saturation classification

The shared source model and image reconstruct

    Sat_L(C_J)=S intersect L^-1(L(C_J))=C_(J intersect visible).

Thus precisely 256 of the 1,024 carriers are saturated. The other 768 impose at least one hidden zero restriction. There are 256 distinct visible images, each shared by four carriers differing only in their two hidden restrictions.

For a hidden zero frame at coordinate 22, reconstruction restores the genuine tail with y_22=1/2 and all other coordinates zero. The actual retained carrier rejects the feasibility query y_22>=1/2; the reconstructed carrier admits it. The difference is an explicit source witness, not a hypothetical coding collision.

## What the filling picture resolves

Model-based upgrade reconstructs the whole visible filling fiber. The storage obstruction concerns which subfamily of that fiber remains admitted after hidden evidence. These are different questions.

For saturated carriers, the source and visible image determine the subfamily exactly, and no hidden frame journal is needed. For unsaturated carriers, several source-admitted subfamilies have the same image. A source model alone cannot identify the retained one. The two missing membership distinctions in this example are exactly the missing fiber restrictions.

In this independent-coordinate section, every nonempty visible singleton fiber has all four hidden assignments. Consequently a hidden zero restriction cannot become redundant under a nonempty refinement involving only visible coordinates. This contrasts with the coupled mass example where a visible total bound can imply a hidden bin bound. Whether later visible evidence permits forgetting is therefore a geometric property of the source fibers.

## DPC boundary

The saturation criterion reconciles the positive upgrade theorem with the unbounded-query storage obstruction. Exact upgrade is available at fixed points of source-relative image/preimage closure. A bounded representation cannot represent every arbitrary hidden subfamily when the declared queries distinguish unboundedly many such subfamilies.

This result uses a finite section of the owning relaxation; it does not replace the full carrier by that section without declaration. Its reopened witnesses are genuine full-carrier tails, so the exhibited unsafe upgrade remains a valid obstruction.
