# An independent path-DAG replay refuses stale and forged support

A separate exact checker reconstructs the square-source P->Q->P proof path from primitive rows, endpoint/intermediate multiplier vectors, signed zero-bound kernel and the source-generation digest. It DERIVES row dependencies from every nonzero coefficient (including the signed edge vector), requires an exact source-rooted DAG shape and checks normal/bound equations at each node. Fresh `verify_source_bound_path_dag.py` verifies the archived old-generation mathematical path. It refuses a claimed old generation against edited rows, and also refuses an attempted new-generation rebind because Q is invalid. Omitting y-high from the edge dependencies or inserting a self-reference is rejected by exact support shape.

This exposes two distinct failure locations: stale SOURCE ID when a historical packet is mislabeled against the changed manifest, versus invalid INTERMEDIATE when it is rechecked against the new manifest. The original mathematical path does not retroactively become false on its old source. A digest match and acyclic DAG remain local mathematical checks; they do not authenticate an issuer or confer live execution authority.

The next discriminating test is a partial source edit that preserves EVERY node's arithmetic but changes the manifest digest: it should require explicit re-binding even though re-verification succeeds. This tests whether the programme is properly separating proof validity from source identity rather than deriving one from the other. Analytic S,A,R,C,G assignment remains deferred.
