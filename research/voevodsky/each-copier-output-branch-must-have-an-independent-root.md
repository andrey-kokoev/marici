# Each copier output branch must have an independent root

Fresh `check_copy_frontier_branch_anchors.py` removes the live COPY agent virtually and explores the two COPY auxiliary sides separately. It demands that they are disjoint and that EACH contains an OUT or ERASE root. This holds for all 86 n<=2 initial inputs across 6,400 alpha states and 13,431 individual-redex transitions (COPY exists in 3,250 state instances); it rejects the previous well-wired counterexample in which one side had a B--NIL tail but no root. The check is not a symbolic arbitrary-n preservation theorem.

A useful local preservation lemma is now visible: for COPY--NIL, original NIL has no auxiliary edges and disappears; COPY's two output sides become two components, each already rooted. A fresh NIL principal is attached to each former COPY auxiliary boundary port, so each side remains rooted, and Q/E waits become enabled. For COPY--B, each side receives a fresh copied B whose auxiliary meets the fresh COPY.a/b, while the fresh COPY.p owns the remaining original suffix. Their roots remain on their original sides. Both arguments presuppose port-linearity, disjointness of the two sides after COPY is cut, and that original-source suffix is attached only through COPY.p. They do NOT yet show that Q/ERASE reductions preserve side disjointness/anchoring, or that no new detached rootless component appears.
