# The idelic-to-retained comparison should be tested on restricted-tensor generators before the Xi state

No source packet presently constructs the external idelic-to-retained span.
Testing it first on the Xi state would ask directly for the RH-strength bulk
balance.  The noncircular construction order is to define and verify the
comparison on a dense source generator class before specialization.

The Schwartz--Bruhat source is generated by restricted pure tensors

\[
\phi=\phi_\infty\otimes\bigotimes_p'\phi_p,
\]

with almost every finite component equal to the unramified unit.  A candidate
comparison must assign to each such tensor a retained graph vector

\[
\kappa_z(\phi)\in D_{\rm ret}
\]

and pass the following generator tests:

1. the archimedean component produces the declared reciprocal forcing and both
   Volterra histories;
2. each nontrivial finite component produces its prime and valuation-grade
   labels without scalar aggregation;
3. the unramified local unit maps to the normalized neutral packet;
4. restricted tensor products map to the completed labelled graph with a
   cutoff-uniform bound;
5. additive adelic Fourier transform intertwines `J_0` with retained sewing;
6. endpoint, primitive, square, connected, seam, and infinity coordinates
   agree componentwise;
7. the construction is continuous, so equality extends from generators.

The existing five-cell and fixed-forcing maps verify parts of this contract on
one theta-generated orbit.  They do not define the local finite-place maps for
arbitrary Schwartz--Bruhat generators or prove restricted-product continuity.

This creates a clean dichotomy:

- prove generator-level naturality first, then evaluate the independently
  constructed comparison on the Xi pair state;
- or assert equality only on the Xi state, in which case the assertion is the
  terminal confinement theorem rather than a constructor derivation.

The next audit should therefore inventory the seven generator conditions,
not numerically compare the two currents at a zero.
