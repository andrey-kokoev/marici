# A retained word-history lift through actual native packet steps

## Result and exact claim

For a **fixed supplied codebook**, bounded finite words can be encoded and recovered through actual `GenerativeAssemblyRules` packet transitions, not only spatial primitive-neighbor calls. Each step comes from `outgoing` and passes the existing `validateTransfer`. The trace retains occurrence order, complete packet/chart data, faces, five-slot permutations, realization origins, phase frames and actual reader-phase witnesses.

Two negative projection results are equally important: this compiler's endpoint does not recover its word, and its deduplicated transition support does not recover multiplicity. These are explicit counterexamples for the defined encoding, not a no-go theorem for every possible endpoint code.

Verification level: written bounded source-code argument and exact executable model-native replay/decoder controls. No new proof-assistant theorem or derived physical law is claimed.

## Prior source recovery and why this is not the old recovery theorem again

`research/strominger/native-domain-coverage-audit-v1.md` already records formal whole-retained-derivation recovery for the named native WG table signature under a supplied source policy. It explicitly distinguishes an actual derivation from an arbitrary package accepted by an encoder. We do not reopen that recovery theorem or infer admission of our package from it.

Here the concrete source is the sector-specific JavaScript `GenerativeAssemblyRules`, including its native reference and phase laws. Its operational paths are not silently identified with Agda `Resolve S q` terms of a different signature. No such adapter or fresh formal compilation is supplied.

The implementation uses only existing source operations and the canonical default seed. It does not modify production source. Reader advance retains the source's declared outside-reference coefficient law; the source witness's `physicalLawDerived:false` remains explicit. This is native **model** replay, not empirical particle dynamics.

## The word code

For k supplied distinct alphabet labels, use fixed binary width max(1,ceil(log2(k))). The alphabet header is a declared task reference. Index words, not arbitrary label strings or template coordinates, are carried by the native operation path itself.

At each P packet:

- **0:** take PN, then inverse-PN. The complete packet returns, including chart roles, origin and the full five-slot coefficient permutation. Numerical coefficient values are not fields of this source packet and are not invented by the encoder.
- **1:** take the actual P `reader-phase-advance`, including its full `phaseAdvanceWitness`; the realization origin increases by one.

These are source operations selected by kind from the current admitted packet. They are not invented transfer matrices. Both code boundaries are again P packets, so finite concatenation is available while those source operations remain within the declared execution envelope.

The zero-loop claim follows directly from the source: the shared marked face is retained, inverse-PN reconstructs the original P reference, origin is unchanged, and the PN permutation is an involution. For the one-step, the source explicitly constructs the next P reference, with its next-occurrence checks and fixed five-slot permutation. Their index equalities remain consecutive after each allowed origin shift. The source's existing reference law is used, not derived.

The implementation does not take these claims on faith: every chosen operation and complete phase-bearing event is independently replayed against a fresh source instance. Canonical source allocation IDs are retained and reproduced by the same rooted prefix; invariance under arbitrary cache/ID renaming is not claimed.

## Decoder, append and retention argument

Read the ordered event stream. A P reader advance yields bit one. A PN event must be followed immediately by inverse-PN restoring the whole source packet; that pair yields bit zero. Reject incomplete pairs, non-P reader steps and unused binary codes. Split the resulting bits into fixed-width symbol blocks.

This gives a left inverse on all encoded words in the envelope: the two macros have distinct first operation kinds, fixed-width blocks are uniquely parsed and every index is in the supplied codebook. Empty input gives the rooted empty trace. Appending first replays the full prefix into the actual source and then appends the new macros. Therefore decoding append gives concatenation; appending empty input preserves the trace, and nested appends agree with direct concatenation under the same canonical source replay.

The compiler's choice of code bits and the decoder are host-side adapters. This proves a capacity to represent a supplied word using real native packet operations. It does not supply native color comparison, conditional forcing control, an internal Hales–Jewett proof, or admission of the arbitrary alphabet/header as a native seed package.

## Exact projection failures

### Endpoint erasure

Word `[0]` and word `[0,0]` both return to the same complete canonical P packet. Their event streams are different. Thus no decoder from that endpoint alone can recover both words under this compiler.

The bounded suite also compares `[0,1]` and `[1,0]`: a zero macro is a packet identity, so these words have the same endpoint while retaining differently ordered native histories. The relevant equality is checked on actual complete endpoint snapshots, not merely equal geometric positions.

### Cached graph and support erasure

After the first zero loop, the source caches its P/N outgoing operations. Repeating that loop can leave the entire cached model state unchanged. The selected native transitions are again legal, but their repeated occurrences are not added to the cached operation inventory.

Consequently `[0]` and `[0,0]` have the same deduplicated transition support. Keeping every kind of transition is not the same as keeping the ordered sequence with multiplicity. Deduplication can yield another **valid** native trace for a different word; validity alone does not establish recovery of the requested history.

These examples do not show that native endpoints can never encode data, that realization origin has no information, or that every history code must use this construction. They show exactly why these two projections cannot replace this compiler's retained trace.

## Relation to the Ramsey net

This is the first packet-step binding of the proposed word-history interface, beyond the earlier geometry-only marked-patch constructor. It supplies an independently tested candidate for retained native histories.

It does **not** close `native-forcing-construction`: the Ramsey coloring, its comparisons, termination/control logic and the binding from decoded word to a marked lattice witness are still host-side/classical interfaces. Nor does it prove that these path packets form one simultaneously admissible occupied assembly or a certified E-exit configuration. No such configuration is passed to `describe`/`inspect` as an inferred consequence of path validity.

The remaining admission question is specific: which source policy licenses the complete codebook/history/query package and its native forcing controls? It is not a request to repeat the already-established generic retained-derivation recovery theorem.
