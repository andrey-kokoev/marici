# Count the minimum two-link attachments on one missed blue edge

On a valid width-ten completion, reject an outside blue edge unless it flanks one movable pair X and its endpoints are adjacent to neither site of the other pair Y. For a passing edge, delete its endpoints from the pentagon. The remaining sites induce one red edge ab and an isolated site h. Let n count physical path adjacencies between {a,b} and Y. They form a matching: a,b cannot touch both ends of a consecutive pair, and each site in Y has only one path neighbor besides its partner. Write M=2 if n=0 and M=1 otherwise. This counts bijections from {a,b} to Y that use no physical adjacency: one forbidden entry blocks one bijection; two disjoint forbidden entries block the same bijection.

The same-site construction chooses either end of X for the two single-movable rows, then chooses a bijection. Its count is 2M. For opposite-site constructions the fixed site must not touch the missed edge. Different outside pairs fix the assignment of a,b to the X ends via the pentagon and leave M bijections. Equal outside pairs instead put the same one of a,b in both double-movable rows. That endpoint must avoid both sites of Y. There are 2−n eligible endpoints; for each, the two Y sites can be assigned in either order to the distinct X sites. Thus the count is 2M plus M+2(2−n) if the fixed site is clear. Distinct choices within a type give different labeled rows; the number of movable sites distinguishes the singles from the doubles, so the three types do not overlap. The missed edge itself is recoverable from the row supports, so summing counts across edges introduces no duplication.
