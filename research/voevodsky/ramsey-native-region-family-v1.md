## Conjecture and scope

Node `native-region-family-admission` is the bounded family-construction component of `native-task-package-lift`. Its region is exactly L_3, with 171 points. No requested word, selected point or monochromatic answer is an input to the preparation procedure.

This deliberately changes the **input policy**. It does not make a path from the old canonical seed cross its preserved M-plane. The original single-leaf obstruction remains valid.

## Source preparation, independently of the query

For every p=(x,y,z) in the complete region, use the exact sum-zero shift

$$
t(p)=\tfrac12(-x-y-z,\ x+y-z,\ x+z-y,\ y+z-x).
$$

The even-sum condition makes every coordinate integral. The existing geometry API registers the translated regular primitive, and `completeP` supplies its full native reference. `packet` creates the identity five-slot packet at origin zero. Its actual available PN interface is checked by `validateTransfer`.

The first P phase-window occurrence projects to p. All five reference vertices, not just the marked point, must equal the canonical reference translated by t(p). Preparation covers the entire region before any word is known; it therefore does not seed only a desired answer. The native packet bank spans seven M-plane heights, including a prepared first-window point (3,3,0), without claiming a transition from the canonical leaf to that point.

These are **indexed alternative input contexts**, not a simultaneous occupied assembly. Applying the existing assembly `describe` operation to all prepared contexts must expose their global C/M-role conflict. Treating that failed assembly as a valid family assembly would be a false promotion.

## Actual native-family binding

A generated safe Cubical module quotes every complete externally validated context, not merely its hash or coordinate. Its data type `RegionIndex` has exactly 171 constructors. The literal row value is the pair (complete context string, supplied color). Colors are a formal parameter `RegionIndex -> Nat`, not preselected query outputs.

The prepared policy is explicit:

$$
\operatorname{Admit}(q)=\sum_{i:\mathrm{RegionIndex}}\bigl(q=\operatorname{fiber}(i)\bigr).
$$

For every index i, the pair (i,refl) is an actual seed certificate. `NativeTableResolution.Full` is instantiated with this policy, then its real `Resolve.apply` constructor applies the existing `NativeTableRules.P-kind` and `E-kind`. This is not a host array labelled native and not a proof of a new generic recovery theorem.

The module proves that the native P value returns the whole input row at each index, that E returns the supplied index together with its row, and that **every** E selection retains **every** indexed seed premise. E does not permit omitting an unselected row. A negative module that supplies one seed for all P premises must fail typechecking.

## What is and is not verified

The geometry and packet contents are checked by fresh JavaScript source execution and independent integer arithmetic. Safe Cubical Agda checks the native P/E derivation and value/premise equalities **under the declared literal prepared-input policy**. It does not interpret the JSON geometry or prove JavaScript implementation correctness, physical admissibility of the policy, or that prepared literal seeds belong to the old canonical closure.

The source-admission audit in `research/strominger/native-domain-coverage-audit-v1.md` was recovered first. Atom formation is not being substituted for admission: the policy and each seed certificate are present. Conversely, the already established recovery theorem is not being reopened or reproved.

A supplied region index is still an input to E. There is no native word-to-index constructor here. The uniform all-region/pattern task package, native control, common-source transport/sewing and Ramsey forcing remain separate open obligations.
