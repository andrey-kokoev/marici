# Cayley–Menger positivity cannot select the site-energy basepoint chamber

## Question

Can the source-defined semialgebraic contour in external parameters \((P_1,P_2,P_3)\) select the triangle chamber for the quartic variables \((x,y,z)\)?

## Source typing

The frozen kinematic source distinguishes site energies \((X_1,X_2,X_3)\) from external magnitudes \((P_1,P_2,P_3)\). It defines

\[
E=X_1+X_2+X_3,
\qquad
\nu_i=P_i^2-X_i^2.
\]

The Cayley–Menger contour constrains the \(P_i\) together with loop variables through nonnegative minors. The infinity quartic and its discriminant chamber are written in the site-energy variables

\[
(x,y,z)=(X_1,X_2,X_3).
\]

Thus triangle inequalities for \(P_i\) would not be triangle inequalities for \(x,y,z\) without an additional relation between the two triples.

## Independence obstruction

Prior exact work proves that

\[
(X_1,X_2,X_3,P_1,P_2,P_3)
\longmapsto
(E,\nu_1,\nu_2,\nu_3)
\]

is dominant. One Jacobian minor is

\[
8P_1P_2P_3,
\]

so \(E\) and the three labelled differences \(\nu_i\) are generically algebraically independent.

Therefore Cayley–Menger positivity in the \(P_i\) cannot generically determine the signs

\[
X_2+X_3-X_1,
\qquad
X_1+X_3-X_2,
\qquad
X_3-X_1-X_2
\]

that select the quartic basepoint chamber.

## Rejected shortcut

The specialization

\[
P_i=X_i
\]

would transfer triangle inequalities, but it forces \(\nu_i=0\) and is a special homogeneous locus. Prior work explicitly finds no source-derived splitting or reverse map authorizing this identification. It cannot be imposed to choose a favorable chamber.

## Consequence

The semialgebraic physical contour and the quartic based-path problem remain different typed objects. Shared positivity language does not provide a path from one to the other.

The first missing datum remains an explicit source map from the physical contour parameters to the site-energy quartic, including a regular basepoint and global branch-path homotopy. Existing source work proves generic independence rather than supplying that map.

## Disposition

The Cayley–Menger positivity route to a canonical quartic chamber is closed. No nonredundant source-internal calculation can select the ambient two-bit thimble parity without new global Betti/Picard marking or a physical parameter-comparison map.
