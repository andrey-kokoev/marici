# Local commuting diamonds with fixed public roots

Status: written conditional local-commutation argument plus executable audit on reachable bounded states, not a general graph-isomorphism solver or formal confluence certificate.

An agent has one principal port and each wire one peer. Distinct enabled principal pairs therefore share no agents. A deterministic typed rule for either pair removes only those agents; the other pair's principal wire survives, so its residual remains enabled. Auxiliary wires may cross between the pairs, including within an undirected cycle; this does not identify their principal pairs.

Represent each replacement as a linear matching of exposed boundary slots and fresh ports. If cross-pair auxiliary wires exist, executing both replacements composes the two local matchings along those wires. Substitution on disjoint slot sets gives the same final matching in either order. This argument requires well-defined representable substitution (in particular, no disappearing closed wire-only component); linear slot counting alone does not establish that premise for arbitrary imported graphs. Constructor-reachable phase invariants supply the intended domain. Do not extend the claim to arbitrary syntactically linear graphs without checking that premise.

Allocation order changes numeric names. Match fresh agents by (which redex, allocation ordinal within that rule), fixing all surviving old agents and port labels. Rule selection and allocation counts depend on the typed principal heads, not fresh numeric suffixes or global scheduling metadata. With a fresh monotone allocator, both orders allocate the same total number of names and yield graphs isomorphic by this explicit bijection, regardless of cycles. Public roots are surviving old agents, hence fixed. Diagnostic release order is not generally quotient-invariant, but reachable strict programs never enable two instruction releases together.

`check_local_diamonds.py` constructs that exact bijection for every pair of enabled redexes in the four complete bounded state graphs. It checks residual enabledness, disjoint removed pairs, fresh-kind/ordinal agreement, total bijection, every typed port and wire, equal allocator/step counters, metadata and public observations. All93 diamonds across577 states pass. Concurrent kinds include COPY with QB/QR/EA, insertion phases with EA, and JOIN with EA. No forest canonicalization is used.

The result supports local scheduling independence on the tested reachable contexts. To upgrade the written argument to a complete combined confluence theorem, next enumerate all reachable concurrent rule-family pairs using the phase invariant, and discharge representable boundary substitution for each family (especially splice rules). Termination is already established for constructor-generated programs; local confluence modulo fresh renaming would then yield unique normal forms modulo root-fixing renaming. The present bounded enumeration is evidence, not that exhaustive family proof.
