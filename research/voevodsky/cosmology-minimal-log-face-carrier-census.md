# Minimal log/face carrier census for the triple-incidence Bockstein gate

## Question

Can the smallest source-local logarithmic carrier for

\[
q_3=q_1+q_2+p,\qquad p=x+y+3z
\]

already supply the missing relative carrier data for the p-normal Bockstein test?

## Claim boundary

This packet constructs only the generic Cayley--Menger-nonsingular, source-local logarithmic wall carrier. It does not add a bulk--face mapping cone, a primitive from a larger de Rham complex, a global contour, or a physical period. It tests whether the first missing gate is merely the Cayley--Menger face stability check.

## Disposition

The minimal carrier has bases

\[
C^0=R\langle 1\rangle,
\quad
C^1=R\langle d\log q_1,d\log q_2,d\log q_3\rangle,
\quad
C^2=R\langle \omega_{12},\omega_{13},\omega_{23}\rangle.
\]

The logarithmic generators are closed, so the displayed differential matrices are zero and \(d^2=0\). The generic source triple-incidence point is not on the Cayley--Menger face \(K=0\), so the minimal local \(E_{\rm CM}\) has no generators and is differential-stable.

The special circuit row \((1,-1,1)\) is visible by specialization. Over \(\mathbb F_{101}\) and \(\mathbb F_{103}\), the generic relation rank is \(0\), while adjoining the special circuit row has rank \(1\), reducing the degree-two quotient rank from \(3\) to \(2\).

This still does not construct the Bockstein. With \(J=0\), the circuit class survives but no degree-one cochain can have differential \(p\Xi\), because the differential is zero and \(p\) is not made a zero divisor. With \(J\) generated by the circuit row, stability is automatic but the target class is killed by definition, which is the tautological quotient forbidden by Aspect's audit.

Thus the first new missing datum is not just an \(E_{\rm CM}\) stability proof. It is a source-derived bulk--face differential or primitive \(H_p\) whose boundary is the p-multiple of the logarithmic circuit class.
