# Source-authority audit for grade-selective defect tasks

## Question

Are the independent grade-selective interventions used in the Deutschian minimality test source-derived operations, or only endomorphisms available after choosing atomic coordinates?

## Claim boundary

The retained valuation carrier canonically supplies grade idempotents and therefore an algebraic intervention calculus. The reviewed sources do not supply a physical control interface implementing every such intervention. The finite minimality theorem is consequently valid for the declared algebraic task category but has not been promoted to a physical constructor theorem.

## Bold conjecture

The source valuation structure itself authorizes independent grade-selective tasks, rather than merely making the corresponding projectors definable in an external coordinate algebra.

## Named rivals

1. Grade projectors are bookkeeping labels with no permitted intervention semantics.
2. Only the Adams reindexing \(k\mapsto2k\) is source-authorized; arbitrary grade selection is external.
3. Divisibility filters are source-derived irreversible tests, but reversible grade-selective transformations require an additional control constructor.
4. Every projector supplies a reversible phase intervention by functional calculus, without further physical data.

## Source-derived algebra

The retained label carrier is

\[
\mathcal L=\ell^2\{(p,k)\},
\]

with canonical idempotents

\[
P_{p,k}=|e_{p,k}\rangle\langle e_{p,k}|.
\]

These idempotents are not reconstructed from analytic output orthogonality. The source decomposition defines them before scalar pushforward. The represented history, Fourier action, and completed Green normal form commute with them, while Adams transport satisfies

\[
A_2P_{p,k}=P_{p,2k}A_2.
\]

A second source model gives the divisibility operators

\[
P_{p,k}e_m=\mathbf1_{p^k\mid m}e_m,
\]

and reconstructs logarithmic degree by

\[
\sum_{p,k}(\log p)P_{p,k}=L.
\]

Thus grade selection is intrinsic to the declared arithmetic source object. It is not an output-only coordinate choice.

## Algebraic intervention category

For any finitely supported scalar family \(\lambda=(\lambda_{p,k})\), the diagonal map

\[
T_\lambda
=I+\sum_{p,k}(\lambda_{p,k}-1)P_{p,k}
\]

is a source-defined endomorphism of the labelled carrier. If every \(|\lambda_{p,k}|=1\), then \(T_\lambda\) is unitary in the declared orthogonal label norm. Choosing one nontrivial coefficient gives a grade-selective phase map.

This establishes an algebraic task family without appealing to the window or Wronskian outputs. The earlier quotient argument applies to any task category containing all coordinate projectors, or equivalently enough diagonal endomorphisms to separate every grade, together with the augmentation readout.

## Strongest falsification attempt

The strongest source-based rival is that only the Adams map is authorized. Adams doubling does not generate arbitrary coordinate projectors: it moves \(e_{p,k}\) to \(e_{p,2k}\), preserves prime, and is not an independently tunable family indexed by every grade. The analytic Green and Fourier operators merely commute with the projectors. Commutation establishes superselection of labels under those operators; it does not construct controls that act differently on chosen grades.

The divisibility realization strengthens observability: each \(P_{p,k}\) is an exact arithmetic predicate. But an exact predicate or spectral projector still does not, by itself, provide a physical actuator, measurement instrument, reversible gate, energy budget, or source-authorized readout record.

Therefore rival 2 survives against the physical interpretation, while it fails against the algebraic interpretation: arbitrary diagonal maps exist canonically in the source endomorphism algebra, but the reviewed constructor contains no interface declaring them physically executable.

## Exact residual

The first missing typed object is a control or instrument morphism

\[
\mathsf{Ctrl}_{p,k}\longrightarrow
\operatorname{End}(\mathcal L\widehat\otimes\mathcal H)
\]

whose image contains a grade-separating family such as \(T_\lambda\), together with an admitted record map and compatibility with the retained Green–Ward graph. For a reversible-task interpretation, the image must contain the unitary phase maps and the source must specify their admissible composition. For a measurement interpretation, it must instead supply an instrument whose effects are the \(P_{p,k}\), not merely the abstract projections.

An acceptance test must exhibit that morphism from an independent source constructor and verify:

1. grade selectivity;
2. preservation of prime and cutoff embeddings;
3. compatibility with the joint graph coordinates;
4. declared readout or reversible-action semantics;
5. no inference of physical time from grade or composition order.

## Disposition

The conjecture splits.

- **Algebraic version:** survives. The source-labelled carrier canonically contains the complete diagonal endomorphism algebra, so grade-selective transformations are source-defined mathematical operations.
- **Physical constructor version:** not established. Existing sources provide idempotents, covariance, and observability, but no control or instrument morphism.
- **Minimality theorem:** remains valid conditionally for any task category admitting the full grade-separating diagonal algebra and augmentation. It cannot yet be advertised as a theorem about physically possible tasks.

Further manipulation of the same idempotents cannot close the physical branch. It is blocked until a distinct source-derived control or instrument object appears.
