- Form witnesses: `h=14e_AB-e_AD-e_CA-e_DB-e_BC` has analytic image zero, norm **2100**, energy **980**. At R_0, `v=e_AD-e_BC` also maps to zero but has norm and energy **20**. These are cheap first tests for a successor.

- The signed Weil form is not the auxiliary positive coefficient/evaluation norm. A new form comparison needs the actual domain and normalization.

1. Add the note/checker/receipt to `artifacts` and cite its ID in the affected node's `evidence`.
2. Record the exact verdict and scope. If a substantive map/form/domain changed, add a successor node with an explicit dependency on the rejected candidate; do not overwrite the rejection.
3. Resolve only that scoped node. Recompute `frontier`; update branch `entry_nodes` to the remaining ready tasks and `recommended_start` to a ready task. When no frontier remains, evolve the contract/checker explicitly rather than inventing a placeholder task.
4. Use a new source-pin filename for a reviewed new snapshot; `--pin` refuses to overwrite existing pins. If the work contract changes, also revise the parent's source-pin filename and re-pin after review. Parent and work pins are intentionally separate to avoid a circular hash dependency.
5. Run the command above. Update this handoff's short entry table when the frontier changes.
