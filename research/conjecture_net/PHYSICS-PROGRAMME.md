## Update and review workflow

1. Add the bounded note/checker/receipt to `artifacts`, including its exact source path and verification level.
2. Attach it to the precise node or pending contribution review. Preserve source IDs, assumptions, candidate lineage and residuals.
3. Record the node's scoped disposition. Changed domains, operations, normalizations or target sets require an explicit versioned successor/review.
4. Update target/interface/overlap/empirical records only with their named evidence. Recompute readiness and update `frontier`/`priority_order`; every current frontier task receives one priority.
5. For changed source evidence, review the differences, choose a new pin snapshot and run `--pin`. Existing pins are retained. The accepted overlap continues to use its original live-admission validator.
6. Run the SCC command below. It regenerates the port graph, validation receipt and research dashboard.

If the source snapshot drifts, validation fails with the exact path. No automatic re-pinning or scientific disposition changes occur.
