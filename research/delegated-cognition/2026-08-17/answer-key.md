# Frozen answer key

This file is excluded from every worker evidence packet.

1. Typed extraction: (x,y) are degree 2; (z) is degree 1. Supports are
   (x:\{alpha,beta\}), (y:\{beta\}), (z:\{alpha\}). The degree (-1)
   operation is alpha-supported. Constructed facts are delta(x)=c z and
   delta(y)=0.
2. Decisive representation: split off the beta-only summand (Ry).
3. Minimal reduction: quotient degree 2 by (Ry), or restrict to (Rx).
4. Residual complex/matrix: (Rx \xrightarrow{[c]} Rz).
5. Unconditional homology: (H_2=Ann_R(c)), (H_1=R/cR).
6. If R is a domain and c is nonzero, H2=0; H1 need not vanish.
7. Acyclicity/quasi-isomorphism requires multiplication by c to be an
   isomorphism, equivalently c is a unit in R.
8. The primitive lattice generator p and nonzero c do not establish that c is
   a unit because rho is only specified as additive.
9. Exact remaining construction: prove c invertible (or strengthen rho/R so
   that invertibility follows). Exact falsifier: exhibit a permitted R,rho
   with nonzero nonunit c; e.g. R=Z and rho(p)=2.
10. Rank compatibility or nonzero coefficient alone does not prove existence
    of an inverse, acyclicity, or quasi-isomorphism.
