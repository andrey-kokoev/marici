# The Current C Constructor Grammar Is Not Adjoint-Closed

The metric-free discriminant proposal requires a contravariant copy of the
anti-invariant conductor.  The existing source symmetries do not construct it.

Endpoint reversal exchanges the two C classes:

\[
C_+\longleftrightarrow C_-.
\]

It consequently exchanges conductor values \(28\) and \(36\).  It cannot be an
adjoint operation preserving the degree required by the square.

Combining endpoint reversal with global inversion of all three signed letters
does preserve the C class.  This is the strongest source-visible adjoint
candidate.  Nevertheless, exhaustive exact comparison shows that its full
response difference is not equivalent to the transpose of the original matrix
under any signed row and column permutations.  This failure holds for all eight
C presentations.

Therefore the present constructor grammar is not adjoint-closed.  The identity

\[
|\partial_C|/768=2\kappa_C^2
\]

remains exact, as does the index-two involutive-lattice skeleton, but the second
variance is not constructed by endpoint reversal, word inversion, or their
class-preserving composite.

The smallest required extension is a separately authorized grade-changing
correspondence

\[
\mathfrak D:L^-\longrightarrow (L^-)^*
\]

together with a comparison cell proving that the conductor action is carried to
its dual action.  Merely observing equal Smith packets cannot authorize
\(\mathfrak D\), because Smith reduction forgets the presentation required to
test an adjoint relation.
