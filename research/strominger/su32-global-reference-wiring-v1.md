## No opposite-tip teleportation

A grouped channel contains either one or two actual N cells. Every peripheral lane must satisfy

```
source charged cell → the SAME actual N occurrence → reflected target cell.
```

Both hops must be original shared faces. A lane cannot enter one tip and exit its distant partner merely because they share a channel name.

The complete plan is fixed first; these conditions are verification constraints, not local choices used to grow a wiring.

## Candidate relay rule and provenance

Only the entry receives the input registry. Every other site obtains its data solely from incoming messages. The rule is:

- retain original record identities and opaque contents;
- require equality when the same identity arrives through multiple incidences;
- send only the record subsets already specified by the complete plan.

Outgoing messages are not populated by looking up an omniscient registry at each site, nor is a cached desired output returned. The opposite boundary reconstructs all four original records from messages actually propagated through the selected face graph.

Repeated appearances are references to the same original records, not newly independent inputs. This classical information-level policy is an added construction assumption; it establishes neither physical copying nor a native interaction law.

Both original central reconciliation trees remain in the retained plan. Reversing the plan reverses edges, layer order, lane endpoints and boundary presentations, while keeping preparation provenance. Reversal twice recovers the exact plan. Running the candidate relay backward from its forward result recovers the input and reproduces the same record assignment at every cell.

This is not reversal of the original constructor history. Nor does it claim that the four output records alone encode the whole wiring certificate: the plan and its provenance are retained separately.
