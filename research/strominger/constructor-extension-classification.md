# Classification of constructor extensions

This packet classifies which exponent-set changes are licensed by the proved
engine theorem and which require a new source or kernel theory.  “Algebraically
definable” is not treated as “authorized.”

## Class I: theorem-preserving inclusions

Any finite

\[
A\subset2\mathbb Z_{\ge0}
\]

with any finite Laurent window is a column restriction of a consecutive even
constructor.  These inclusions are covered by the global parity-kernel theorem
and the naturality packet.  They preserve old columns, old relations, parity
reconstruction, rational exactness, and the residue augmentation.

This is the maximal constructor class presently authorized by the proved
kernel theorem.

## Class II: shifted congruence constructors

A set in

\[
c+h\mathbb Z_{\ge0}
\]

is algebraically meaningful because the sparse column formula accepts every
integral depth.  If it is not a subset of the original even lattice, however,
it is not a theorem-preserving source inclusion.

In particular, the positive odd lane `1+2*Z_{>=0}` is a disjoint alternate
constructor, not an enlargement of the original one.  Bounded audits find no
extra circuits in isolated odd prefixes, but no unbounded odd-lane theorem or
physical source authorization is claimed.

## Class III: the all-integer constructor

The union of even and odd depths is a genuine algebraic enlargement, but it is
not conservative for either single parity port.  The smallest mixed-parity
counterexample occurs at

\[
g=2,\qquad A=\{0,4,5\}.
\]

Beyond the three towers and `E_1`, the magnetic kernel contains

\[
C_6^-=
z^0\bar z^{-7}+5z^{-4}\bar z+4z^{-5},
\]

\[
C_7^-=
-\bar z^{-8}+5z^{-4}\bar z^2+4z^{-5}\bar z.
\]

The electric partners are

\[
C_6^+=
-\bar z^{-7}+5z^{-4}\bar z+4z^{-5},
\]

\[
C_7^+=
\bar z^{-8}+5z^{-4}\bar z^2+4z^{-5}\bar z.
\]

Every participating column is nonzero.  These are mixed-congruence alignment
circuits, not fixed-orbit towers.  The joint `(E,M)` observer remains injective
on the audited block, so the enlargement creates new single-port aliases but
not transport loss.

Therefore the even theorem cannot be extended to all integer depths by
changing only the quantifier on `A`.  A new component classification is
required.

The arithmetic statement that odd depths remove an even-constructor 2-adic
index remains correct for the residue polynomial considered by itself.  It
must not be promoted to the cohomology of the enlarged magnetic kernel until
the new mixed circuits are classified.

## Class IV: cyclic-cover or fractional constructors

A cyclic cover `z=w^N` is authorized only after pulling back:

1. both derivatives and connection factors;
2. the measure/Jacobian if part of the intended object;
3. reflection and deck actions;
4. source and target local systems;
5. boundary and descent maps.

Ordinary scalar descent requires the reflected branches to have compatible
deck type.  For reflection distance `q`, the necessary condition is

\[
2q\in\mathbb Z.
\]

The virtual rational interference values `q=35/3,55/3` fail this condition on
every finite cyclic cover.  Their scalar codiagonal is therefore not ordinary
equivariant descent.  Sector-specific charged adapters could define a new
interface, but their relative normalization is additional source data.

## Authority verdict

\[
\begin{array}{c|c|c}
\text{constructor change}&\text{engine status}&\text{authority status}\\
\hline
A\subset2\mathbb Z_{\ge0}&\text{proved and natural}&\text{authorized theorem lane}\\
\text{odd/shifted lane}&\text{algebraically defined}&\text{alternate, unproved}\\
\text{all integer depths}&\text{defined but nonconservative}&\text{new kernel theory}\\
\text{fractional/cyclic cover}&\text{conditional pullback}&\text{requires equivariant source data}
\end{array}
\]

No physical source-to-engine map or proof that the physical target is the full
Laurent target is presently available.  Thus even the authorized theorem lane
is an engine capability classification, not a claim that its exceptional
classes are physically constructible modes.
