Each vertex is an actual lattice node. Three tetrahedral cells partition a triangular prism between adjacent R planes, preserving the P/N/E incidence chain. These lattice cells are not the earlier regular tetrahedra.

Lattice node addresses

    Typed planar axes

    2 × M± + 1 × C±

    Each axis is labeled with its assigned type and sign: M+, M-, C+, C-. One pair repeats. The repeated type exchanges on each R step. The reference choice at R=0 sets the alternating sequence.

    Realization continuation

    θ[n + 1] = θ[n] + Δθ · default 60°
    M[n] ↔ C[n + 1]

    R is the discrete normal realization axis. The planes are parallel; their typed axes rotate together around R. Each step exchanges M and C on all three axes. The exceptional axis rotates with the frame and changes type.

    Click any R label or node to toggle that plane between full rendering and faint traces. R = −1, 0, +1 start fully shown; the outer planes start as traces.
