# DPC classifies horns relationally

The mixed-coherence coordinate does not necessarily return a distinguished
filler. For a typed contravariant-covariant boundary \(K\), it returns an
authorized filler object

\[
\mathcal R(K).
\]

There are three basic cases:

- \(\mathcal R(K)=\varnothing\): the mixed configuration is inadmissible;
- \(\mathcal R(K)\) is a singleton: the source fixes the comparison cell;
- \(\mathcal R(K)\) is an unpointed module or torsor: composition has a
  relational residue but no distinguished amplitude.

This corrects a hidden selection assumption in the first double-category
model. Universal composability may determine a complete rank-one residue
without choosing a vector on that line.

A physical realization is separately indexed by an instrument:

\[
\rho_I:R_D\longrightarrow P_I\otimes O_I.
\]

A scalar additionally requires a preparation point in \(P_I\) and a detector
functional on \(O_I\). This instrument relation is transverse to the universal
tower structure; it is not automatically another universal tower.

The magnetic curvature cell over \(\mathbb Q\) is source-fixed and therefore
singleton-valued. Over \(\mathbb Z\) its filler object is empty. By contrast,
the cosmological rank-one extension residue is presently unpointed; an
available detector without a preparation port still yields no scalar.

Thus the static \(3+2+1\) object is more accurately a relational or
profunctorial double structure than an ordinary double category with a chosen
cell in every admissible square.
