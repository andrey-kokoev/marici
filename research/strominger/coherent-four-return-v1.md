# A coherent cyclic action on dependent return records

## Question and claim boundary

Does the canonical shift on `Per4 G = Σ a, G⁴(a) ≡ a` admit a homotopy-coherent C4 action, without assuming the state type is a set?

**Yes, in the classifying-space-family formulation.** `agda/CoherentFourReturn.agda` constructs the action and identifies its generator with the original shift. Fresh safe Cubical Agda verification passes.

The construction establishes existence of a coherent action with that generator. It does not yet identify its chosen fourfold-return coherence with the earlier explicit `shift-four` homotopy, nor identify all comparison data with the previously proved first equivariance square. It supplies no native edge-five successor or payload-return operation.

## Classifying space, not a finite list of coherence tests

The index structure is a four-element set with cyclic successor. `FourTorsor` is its connected component in the univalent type of successor structures: a structure together with a propositionally truncated identification with the standard four-cycle.

The module proves:

- `connected`: every torsor is merely connected to the standard one;
- `torsorGroupoid`: this space is a 1-type;
- `torsorLoops`: the complete based loop type is equivalent to four elements;
- `label-compose`: composition of loops corresponds to cyclic addition;
- `generator-label`: the chosen loop has the primitive index 3, not order two.

Classification uses the structure identity principle. Every successor-preserving automorphism is determined by its value at one index; the four possible values give exactly the four rotations. This distinguishes C4 from the Klein four-group and identifies the classifying space, rather than merely exhibiting four permutations.

Propositional truncation is used only to specify membership in the component of index structures. It does not truncate the state type or discard return witnesses.

## The family and its fibre

For a torsor with index type T and successor s, define the fibre as

```
Σ (v : T → S), (t : T) → G(v t) ≡ v(s t).
```

Thus an element retains every vertex reference and every directed equality witness around the index cycle. A genuine dependent family over the classifying space supplies transport along paths and higher paths, rather than postulating successive coherence laws independently.

At the standard torsor, the fibre is equivalent to `Per4 G`. The proof converts the four-coordinate diagram to a nested dependent chain and contracts the three intermediate singleton choices. This is an equivalence, not proof irrelevance for the final return witness.

The resulting package `Action.coherentAction` is a family over `FourTorsor` with its fibre equivalence to `Per4 G`.

## Identification of the generator

The explicit index loop is reversed because sections reindex contravariantly. `rotation-over-generator` constructs a dependent path whose endpoints are a cycle and its one-position rotation. `generator-computes` then identifies actual family transport with that rotation.

`normal-shift` compares rotation of the canonical four-coordinate presentation with the original `shift (a,p) = (G a, cong G p)`. Its dependent edge witnesses are retained. Combining these comparisons with the fibre equivalence proves:

```
generator-is-shift : (x : Per4) → generatorOnPer4 x ≡ shift x
```

No assumption that G itself is invertible is needed. The witnessed-periodic sector can carry this symmetry even when G on the full state type does not.

## Disposition

The abstract coherent-action existence problem is resolved at the safe Cubical Agda level, for arbitrary S and a supplied G. The type `Per4 G` can be empty: neither a periodic state nor a source-canonical successor is generated by the theorem. Reflection/duality and reversible edge-five paths still do not supply the missing native successor and return comparison.
