# Quarter Gram–Hall interface preflight

## Question

Can the retained positive-real diagonal Gram certificates currently compose with the exact source-interlacing Hall transport backend?

## Claim boundary

The Gram backend contains 21 exact records indexed by `(n,shift)` and proves positive diagonal quadratic forms. The Hall backend contains 769 exact cases indexed conceptually by `(S,i,j)` and signed source vertices. Neither artifact declares a map from Hall cases, source terms, or interlacing edges to Gram coordinates or quadratic weights. Their composition is therefore undefined; this does not refute the existence of such a map or weaken either separate bounded certificate.

## Disposition

Block the Gram-to-Hall branch at the first missing typed object: a source-derived map from `(S,i,j)` and each signed source term to Gram coordinates whose positive quadratic weights induce interlacing-edge capacities. Reopen only when that map reconstructs every bounded term and capacity with verified conventions and has an all-order proof. Reallocate work to a distinct executable rival rather than inventing successor abstractions from this interface absence.
