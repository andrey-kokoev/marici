# Affine dualization supplies the binary germ but not its physical realization

## Question

Does the affine source map already generate the dual marked germ and native
binary pairing required by Aspect's arity gate?

## Dual germ is functorial

The affine frame is a map of finite free integral lattices

\[
F:\mathbb Z^2_{\mathrm{src}}\longrightarrow\mathbb Z^2_{\mathrm{tgt}},
\qquad
F=\begin{pmatrix}2&7\\3&7\end{pmatrix}.
\]

Applying the ordinary integral dual functor gives

\[
F^*=F^T:
(\mathbb Z^2_{\mathrm{tgt}})^*
\longrightarrow
(\mathbb Z^2_{\mathrm{src}})^*.
\]

Thus the dual discriminant

\[
D_{F^T}=\operatorname{coker}F^T
\]

is not an independently invented coefficient object. It is generated
functorially by the same source arrow, provided the source and target lattices
retain their canonical evaluation pairing.

## Reflected dual refinement

Modulo seven, the image of \(F^T\) is the coordinate line generated by
\((1,0)\). Reflection exchanges it with the line generated by \((0,1)\).
They are transverse, so

\[
\operatorname{im}F^T\cap X\operatorname{im}F^T=7\mathbb Z^2.
\]

The stable dual packet is therefore another copy of

\[
\widehat D_{F^T}\cong(\mathbb Z/7)^2.
\]

Its direct odd quotient is detected by

\[
q_-^*(x,y)=y-x.
\]

This produces the independently typed seven-class dual germ required by the
binary phase target.

## Canonical linking pairing on the stable packets

The original affine map supplies

\[
F^{-1}=
\begin{pmatrix}
-1&1\\
3/7&-2/7
\end{pmatrix}.
\]

Since \(7F^{-1}\) is integral, the formula

\[
\widehat\lambda_F([x],[y])
=y^TF^{-1}x\pmod{\mathbb Z}
\]

is well defined on

\[
\widehat D_F\times\widehat D_{F^T}.
\]

It is not perfect on the full 49-by-49 stable packets: it is the pullback of
the one-chart linking form and therefore retains radicals. This is not a
defect for the declared odd target.

Let

\[
a=(1,-1)
\]

generate both direct odd lines. Then

\[
\widehat\lambda_F(ta,sa)
=\frac{2ts}{7}\pmod{\mathbb Z}.
\]

Because two is a unit modulo seven, this restriction is a perfect pairing of
the two seven-class odd germs. It is also reflection invariant: reflection
multiplies each odd input by minus one, and the two signs cancel bilinearly.

## Updated Aspect verdict

The first two gates now close algebraically.

### Fiber gate

Each odd input is reduced to the coarsest quotient on which the restricted
linking target is defined. No 49-class unary carrier is required.

### Arity gate

The target is retained as a genuinely binary map

\[
\lambda_-:
G_-\times G_-^*\longrightarrow\tfrac17\mathbb Z/\mathbb Z.
\]

Neither input is replaced by a unary cardinality match.

### Authority gate

This gate remains open. Integral dualization constructs a mathematical dual
germ and pairing, but it does not prove that the physical magnetic apparatus
realizes the dual input or evaluates \(\lambda_-\).

## Smallest remaining constructor

The missing object is now narrower than before:

```text
PhysicalDiscriminantPhaseRealization
  primal_odd_germ_realization
  dual_odd_germ_realization
  binary_phase_evaluator
  reflection_covariance
  executable_domain
  source_authority
```

No additional finite coefficient module is needed. The remaining question is
whether the physical source exports the already constructed binary germ as an
executable phase relation.

## Hostile boundary

Replacing the binary pairing by a unary lookup table with seven or 49 entries
fails the arity gate. Treating the transpose lattice as a physical dual state
without a realization arrow fails the authority gate. Claiming perfectness on
the full stable packets fails the exact rank calculation; perfectness holds
only after restriction to the declared odd germs.
