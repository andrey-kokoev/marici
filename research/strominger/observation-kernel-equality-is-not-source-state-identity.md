# Observation-kernel equality is not source-state identity

## False promotion

Let (R:S\to O) be the unary magnetic valuation readout. The valid relation

\[
R(0)=R(1)
\]

places grades (0) and (1) in the kernel pair

\[
S\times_O S.
\]

The invalid step is to promote that kernel pair to an ontological quotient of source states:

\[
R(a)=R(b)\quad\Longrightarrow\quad a=b\text{ as source states}.
\]

The authorized positive constructor refutes the promotion:

\[
R(1)\ne R(2).
\]

Thus the kernel pair is not a constructor congruence.

| repair | prediction restored? | source change | new port |

| add a residual bit distinguishing the grades | yes | yes | yes |
| retract the false state-identification equation | yes | no | no |

The second is source-preferred. It preserves the independently validated observational equality and the existing grade constructor. Only the unauthorized ontological identification is removed.

A contextual trace may organize the retained incidences, but it is not required to justify the retraction.
