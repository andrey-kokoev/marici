# The C Square Is a Candidate Root Norm, but the Gram Constructor Is Missing

## Exact identity

All eight signed C presentations obey

\[
\partial_C
=
-\sigma_{\mathrm{first\ tail}}\,768\,
\langle \kappa_C\alpha,\kappa_C\alpha\rangle_0,
\]

where

\[
\alpha=(1,-1),
\qquad
\kappa_C=4(8-\omega),
\qquad
\langle\alpha,\alpha\rangle_0=2.
\]

The fixed factor is the content of every full C response difference:

\[
768=2^8\cdot3.
\]

Consequently one rank-one connecting arrow can carry the observed square through
a quadratic self-pairing.  Two independent connecting channels are unnecessary.

## Authority boundary

The arithmetic identity does not yet establish the root-norm explanation.  The
current source packet supplies two labelled tail coordinates and their opposite
polarity, but it does not declare a Gram constructor selecting the ordinary
coordinate pairing.

This omission is material.  The same root has norm zero for the rank-one sum
pairing and norm \(-2\) for the hyperbolic pairing.  Therefore the signed ports
alone do not select the required quadratic form.

The smallest missing explanatory object is a source-authorized bilinear pairing
on the tail-port lattice that is preserved by endpoint reversal and the admitted
atomic operations.  If that constructor uniquely yields the ordinary pairing,
the square becomes a genuine root-norm theorem.  If several admissible pairings
survive, the norm language remains presentation-dependent.
