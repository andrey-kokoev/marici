# Testing the native-continuation conjecture

## Question and frozen claim

Operator requested execution of the proposed falsifiable conjecture:

> Su-32's native layer-4 comparison is more than a lossless reference join: a closed change-of-reference cycle can restore all four records while leaving a transformation detectable by a subsequent native comparison.

A successful witness must use the same independently specified downstream operation and matched preparation, not merely inspect route names or import our new cochain model. The strong falsifier would be factorization of every allowed native continuation through the recovered four-record assignment.

SCC obligation: **source attachment before readout compatibility**. The immediate test is whether an existing operation accepts the two reconciliation packets at all. A different carrier's successful discriminator does not satisfy this gate.

## Target pair

The checker constructs the existing E-reference and P-reference reconciliation packets at the same actual central N, with identical anchor, binding and recovered four-record registry. Their child derivations differ and are retained. The receipt contains both full packets.

These are the existing set-valued comparison candidates at native incidences; their common endpoint does not itself supply a native dynamical state transition.

## 1. The implemented regrouping task has no extra closed-cycle action

Fresh execution checks all 127 direction words through length six, totaling 642 regroup/restore steps on the actual 64-wire model. Every result equals the input rows.

The source provides the stronger argument for this interface: `groupSulfurPayloads` places each row once according to its fixed wire ID, and `restoreSulfurPayloads` flattens and sorts those same rows. Each regroup/restore command is therefore identity on valid serializable **wire-indexed assignments** for this fixed model; composition remains identity for every finite command word. Array presentation is canonically sorted, so this is not identity on arbitrary input array ordering.

This is a theorem about the **64-wire row interface**, not factorization through the four signed records. No authoritative map between those two domains was assumed. Supplying four rows directly is rejected by the existing API.

Missing/duplicate wire controls are rejected. A changed payload is preserved as changed rather than normalized away.

## 2. Two attractive but invalid witnesses were rejected

**Carried route tags.** Attach different audit-history tags to otherwise identical rows. Restored outputs differ, but erasing only the carried tags makes them identical. This is faithful metadata retention, not a subsequent comparison detecting a transformation.

**Different incoming-bundle endpoints.** For each fixed p/e pair the candidate has four a/b choices and four different output slots. All four input slots are also different. This is neither matched preparation nor a closed reference cycle. The source explicitly declares these routing conventions, rather than deriving a signal interaction.

## 3. A genuine native observer exists on another carrier

The positive control uses a neutron reader advance actually generated by `GenerativeAssemblyRules`, with `validateTransfer` checking its marked-chart occurrence transition. The observer is the unchanged source function

```
spectralReadout('neutron', applyPhasePermutation(value, operation.permutation)).
```

Take the five-slot coefficient packets

```
a = (1,2,3,4,5),
b = (1,2,3,4,6),
```

with zero imaginary parts. Their current active neutron face `(2,3,4)` agrees. Their retained context differs. The actual reader permutation `[0,3,4,1,2]` produces active faces

```
a -> (4,5,2),
b -> (4,6,2).
```

The preexisting spectral readout distinguishes them. The active-coordinate difference is exact integer arithmetic; the source Fourier readout is evaluated in its existing numerical implementation.

This verifies that retained context can have operational consequences in that model. Its source explicitly marks outside-context coefficient retention as a reference law, not derived particle dynamics. It does **not** verify the proposed Su-32 claim: the complete coefficient packets already differed, the active readout has three coordinates rather than our four signed records, and no source-defined signed-record/chart encoder connects the target pair to these inputs. Four coefficients supplied directly are rejected by the five-slot API. Arity rejection alone is not an impossibility theorem for an encoder; it locates the absent adapter.

## First missing typed object and stopping condition

Missing: a source-bound continuation invocation on the actual Su-32 reconciliation packets. For the coefficient-reader candidate this would require a map into its marked primitive chart, occurrence and complete five-coefficient state, preserving the native attachment and common preparation. It must derive the compared states from the operations, not choose different extra coefficients because the route labels differ.

Acceptance test: supply the source-defined map, validate both mapped packets and the same downstream command at their actual occurrences, recover the required four records, and exhibit a non-label output difference invariant under the admitted changes of description. No padding rule, cochain readout or independently assigned phase is installed to meet this test.

This branch stops at that absent binding. No waiting-only issue or further hypothetical detector is generated.

## Disposition

**No valid Su-32 distinguishing continuation was obtained.** The implemented wire regrouping task supports the simpler retention model. The preexisting coefficient continuation demonstrates a real context effect on a different, unbound carrier.

The bold conjecture is neither verified nor universally falsified. It currently lacks a source-supported witness and must not be used as an explanation of Su-32. The strong universal falsifier is also unavailable because a complete native continuation task on these four-record packets has not been specified.

The earlier cochain constructions remain mathematical candidates, not evidence that this extra native transformation exists.
