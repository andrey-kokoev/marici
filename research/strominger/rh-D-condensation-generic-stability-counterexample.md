# Generic condensation stability counterexample

## Question

Does the condensation operator preserve Hurwitz stability for arbitrary stable input pairs?

## Claim boundary

The exact pair `1+4x+x^2` and `3+2x+x^2` is stable while its condensation is `2x-2`, which is unstable. This refutes generic preservation but not D-specific structure.

## Disposition

Reject the generic-stability rival; require any surviving theorem to use typed cross-input D-family relations.
