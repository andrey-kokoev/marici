## Exact source factorization and normalization

Read the existing common-assembler proton/neutron packets and verify their historical source and packet pins before use. Each actual return N is a metric-orthogonal rank-one projector. Choose its first nonzero diagonal column j and set

    K=N e_j, D=N_(j,:)/N_jj,
    D K=1, K D=N, rho=K* M K=M_jj N_jj>0.

The checker verifies the full outer product, not just its rank, and D=K* M/rho in the ORIGINAL native metric M. For these source choices,

    rho_proton=1/180,
    rho_neutron=777785/19914297.

Use the exact tagged representation (x,rho), denoting x/sqrt(rho), rather than approximate a new square root or replace the source metric. A normalized state is represented by numerator x=K lambda with |lambda|=1. The packet is

    [archive; lambda, i lambda].

The archive binds the native assembly-packet digest, initial unit phase and complete command word. Recovery returns the identical numerator, normalization tag and archive. The tangent i lambda has unit real norm and is real-orthogonal to lambda. Thus the full normalized return fiber is S1, with one real tangent direction; its phase-erased projective carrier is a point.
