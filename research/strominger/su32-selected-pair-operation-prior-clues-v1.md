# Prior clues for making the selected pair operational

## Strongest positive lead: active pair support already gates native operations

Read:

- `aligned-pair-channels-v1.md`;
- `aligned-native-growth-v1.md`;
- implementation `aligned-native-growth-model.mjs`.

This is more relevant than another passive comparison wrapper. Its declared active matching is actually consumed by the operation matcher. The implementation embeds a source-defined native coefficient permutation into a retained reference bank, identifies the coordinates it moves, and admits the operation only when every moved pair belongs to the active matching. Multiple eligible operations are rejected rather than resolved by a fitted tie-breaker.

Under that experiment's declared policy, PN uses coefficient pair 03 and NE uses pair 14. The recorded example builds a native-certified three-cell chain. These are source coefficient indices, **not** our P+/P-/E+/E- records.

**Transferable test:** on a completely specified global candidate, check whether each required operation's actual reference support is permitted by the selected pair placement. Hold the operation, preparation and readout fixed while changing only the selected placement. Unlike the transparent relay, this predicate would genuinely consume the selection.

**Missing applicability:** the model uses an eight-reference bank and marked primitive charts, not the four directional Su-32 records. A source-bound map between the actual references/occurrences/faces is required. No identification by cardinality or label similarity is justified. Its single-frontier growth algorithm must not be adopted as our construction method; the global-construction directive requires complete assignments first, followed by these checks.

## Second positive lead: context must be aligned by occurrence transport

The same native-growth experiment reports that naively gluing stage samples fails: an actual native swap changes the field. Each sample retains its stage and accumulated coefficient transport. Pulling observations back to a common initial reference bank restores exact agreement.

This is directly relevant to the imported context in our middle cones. Once operations actually change a state, equality of raw values at differently situated occurrences is not the correct compatibility test. The transport maps must be supplied first, and overlap comparison must use the corresponding common frame.

It does not supply those Su-32 maps. The old model explicitly excludes reference-changing NN continuation and distinguishes contravariant pullback from native reverse growth.

## A genuine filler construction exists, but on another source

`context-composition-fillers-v1.md` constructs actual comparison fillers in a fixed shared-leg DG complex:

```
delta K(M,N) = F_M F_N(abase) - F_(NM)(abase).
```

Its degree-two differential has 109 unique pivots and is injective; the reported ranks give vanishing H1. Thus the actual composition defect has a unique filler, and equality of boundaries forces triple coherence. The report retains an explicit 18-term nonzero example and checks 25 context pairs and 125 triples.

This offers a concrete method: supply actual context maps, calculate their defect, then solve and verify the boundary equation in a source-defined complex. It is not authority to declare our empty Su-32 filling slots zero. No map from the six Su-32 cones to that DG complex is supplied by the cited work.

Related warning: `../nima/seed-seam-native-witness-construction-audit.md` shows that the inspected native comparison constructors require supplied equivalences and higher witnesses. Common endpoints and incidence do not generate them automatically.

## Important negative lead: a declared task need not select a unique class

`task-relative-selection-falsification-v1.md` strengthens the earlier task-selection caution. A frozen reversible memory task admits multiple implementations with different responses to the same already authorized continuation. A four-state example has identity versus nontrivial return-loop actions, so the distinction survives arbitrary state-frame relabelling.

Therefore a selected-pair task may produce a well-defined family of implementations without choosing one orbit. Classification and selection remain separate. No reason was found to prefer our `{2,2}` distance class merely because it looks more local.

## Two useful experimental-design controls

### Dependence on the selected structure

`../nima/seed-exchange-structural-dependence-audit.md` removes surrounding edges while holding preparation and event maps fixed. A purported triangle-related response survives with neither triangle present; it was responding only to the executed local labels.

For Su-32, the analogous hostile control is to exchange or remove the selected-pair annotation while keeping the fixed relay intact. Our latest result already predicts unchanged relay output. A future discriminator must demonstrate genuine dependence on a source-bound operation or its admissibility, not just read an orbit label added to the output.

Unavailable operations must be marked unavailable, not assigned a zero response.

### Correct joint domain, not a product of marginals

`../nima/seed-joint-question-readout.md` gives a positive result on a supplied two-row joint relation: an existing arrival reader recovers the whole selected row. The same reader fails on the enlarged four-corner product and on accumulated histories.

For the overlapping cones, use the actual jointly admissible placement/context domain. Do not independently combine marginal record or port choices and assume all resulting corners are supplied. Conversely, do not import a rectangular interchange theorem without its four required corners and witness types.

## Recommended next bounded target

**An operation-support admission audit**, not a new optimization rule:

1. Fix the sixteen complete candidates and their contextual inputs.
2. Identify one existing source operation and its actual moved-reference support.
3. Supply or refute the reference/occurrence/face binding into the chosen Su-32 comparison sites.
4. Only after that binding, evaluate the same support-admission predicate across all candidates.
5. Compare transported outputs or retain the actual composition defect; never normalize it to zero without a witness.

This could distinguish the two families, leave both admissible, or expose an absent binding. Each is informative. The search found a genuine pair-sensitive native-operation precedent, **not an already applicable Su-32 selection law**.
