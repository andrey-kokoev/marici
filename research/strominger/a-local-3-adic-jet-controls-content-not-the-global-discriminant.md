# A local 3-adic jet controls content but not the global discriminant

## Refutation

The mod-\(9\) response jet explains the observed period-three change in matrix content. It does not determine the snake square class.

Because the neutral commutator response has order three modulo \(9\),

\[
C^{n+3}\equiv C^n\pmod9.
\]

The tested orbit contains five pairs with the same mod-\(9\) response jet:

\[
(-3,0),\quad(-3,3),\quad(-2,1),\quad(-1,2),\quad(0,3).
\]

Every pair has a different snake square class.

## Meaning

The constructor has several arithmetical resolutions.

The first 3-adic jet detects a local divisibility event:

\[
d_1(A_n)=2304
\]

on the observed residue class \(n\equiv2\pmod3\).

But the full Smith quotient

\[
rac{d_3(A_n)}{d_2(\pi A_n)d_1(A_n)}
\]

depends on information not retained modulo \(9\).

So one finite local jet may explain one Smith layer without explaining the completed torsion invariant.

## Correct hierarchy

The evidence now distinguishes:

1. abelian charge, which misses the neutral constructor entirely;
2. a 3-adic response jet, which detects the content cycle;
3. the integral response matrix, which determines all Smith divisors;
4. the rational square class, which is a global arithmetic quotient.

This is a concrete instance of typed explanatory scope. The mod-\(9\) jet is explanatory for \(d_1\), but explanation-inert for the full discriminant once equal-jet counterexamples are admitted.

## Consequence for finite summaries

No claim that “the 3-adic jet explains the Fox discriminant” survives.

A stronger finite-summary conjecture would need:

- several primes;
- greater depths;
- or a source-derived bound proving those observations jointly determine the relevant Smith divisors.

Without such a bound, the safe complete invariant remains the integral representation—or an equivalent exact recurrence—not any fixed congruence projection.
