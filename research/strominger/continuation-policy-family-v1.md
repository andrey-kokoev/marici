# Bounded policy family and explicit selection conditions

## Frozen task, not a newly inferred task

The existing net local contract supplies the all-outgoing request `Out(v)`, actual retained derivations, and target-side continuation. These conventions predate the present construction and were not selected to obtain a desired circle, gauge target or physical model. This packet classifies a bounded family **relative to that declared task**, not every policy permitted by the unrestricted native schemas.

The family has exactly three presentation constructors: target, source-indexed, and synchronized. Its common input is the actual Body comparison with inherited witnesses and one synchronized request tuple. The presentation tag is an explicit program control. Independent pairs and raw-source-return semantics are outside this output contract.

## New typed assembly

`agda/ContinuationPolicyFamily.agda` implements a total evaluator into the three existing native adapters on a common return frame. Every member has its actual native derivation and a derived pointed, full-reader native comparison to the target presentation. No additional equivalence or filler is an evaluator parameter.

For any universe level and any supplied task predicate on the shared return vertex, an inhabitant of that predicate gives both a target-tagged and a source-tagged admissible choice. Their tags are provably distinct, so the choice type is not a proposition. This is **representational nonuniqueness**, not inequivalent semantic outcomes: the carrier equivalences were already constructed.

Conversely, an explicitly supplied constraint `tag = chosen` has a contractible choice type. This states exactly what additional representation-selection input suffices; it is not an algorithm discovering a preferred tag from source incidence.

## Disposition

This satisfies the policy gate's bounded-family deliverable: frozen supplied task/program controls, constructed native alternatives and comparisons, explicit obstructions and selection conditions. It does not derive the original task, claim exhaustiveness over all policies, or choose one uniquely.
