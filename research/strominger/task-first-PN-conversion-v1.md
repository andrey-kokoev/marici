# Frozen task: full-field PN conversion versus return-only certification

## Task contract, before execution

This is a finite mathematical transport task, not a proposed laboratory
constructor. Inputs are all36 complex P amplitudes in the supplied metric.
Outputs are the existing36-component N chart. Retain the original metric,
projectors, geometric C3 actions, markings and phase conventions. Surroundings
in this task are these fixed reference structures; occupancy and a spatial
exterior are outside its declared domain.

Admissible implementations are invertible linear S satisfying
S* M_N S=M_P, S L_P=G_N S and S G_P=L_N S. The frozen success requirement
additionally demands U_N S=S U_P, using independently sourced geometric
order-three rotations. The same linear rule must work on every input and be
reusable without changing the declared source data; this is algebraic
repeatability, not a demonstrated physical constructor.

The desired symmetry group and four-state carrier do not enter this task.

## Fixed rival and probes

Rival: agreement of the return readouts of rotate-then-convert and
convert-then-rotate certifies full rotation-compatible conversion on the
alignment subspace. Freeze the return readout N_N and the task comparator,
the full native target-metric norm of the route difference, before execution.
Do not add a detector after observing a failure.

Use the existing independently chosen global PN factor-rotation candidate for
an explicit implementation of the coarse metric/projector task. The full
obstruction must hold for every admissible S, not only this chosen complement.
Use a normalized nonzero column of G_P-N_P as a reproducible relative probe.
The universal projector identity is the evidence for the whole probe family;
one concrete state is only an independently evaluated counterexample.

## Expected falsifiers and boundaries

The source rotation-square result predicts, for E=(U_N S-S U_P)G_P,

    E^sharp E = 3(G_P-N_P),    N_N E=0.

Freshly rerun that exact source calculation and the coarse PN construction.
Evaluate both routes for the actual candidate and normalized probe. Full
success requires zero discrepancy; the identity predicts squared norm3 on
every unit relative-alignment input, while return-only discrepancy is zero.
This rejects the rival certificate and the strict task's implementability
within the frozen linear class. It does not exclude PN conversion with a
changed geometric action, weaker task or additional physical resources.

This is a new task formulation/application of an existing obstruction, not a
new discovery of that obstruction. Its explanatory content is the mismatch of
independent retained C3 representations. It does not explain why those source
representations describe nature, nor derive a four-state carrier.
