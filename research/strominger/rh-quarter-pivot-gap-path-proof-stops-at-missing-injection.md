# Quarter pivot-gap path proof stops at a missing injection

## Question

Does condensation expose the pivot-curvature gap as an immediately positive planar-network object?

## Claim boundary

The cancellation identity is exact. Positivity of its two product terms does not order them, so no all-degree monotonicity theorem follows without an additional path comparison.

## Disposition

Applying condensation twice cancels both \(q_a(0)\) terms and gives

\[
D_{n+1,a}D_{n-1,a+2}D_{n-1,a+1}^2
-D_{n,a+1}^2D_{n,a}D_{n-2,a+2}.
\]

The identity and positive sign hold in 247 exact cases. The first missing object is a sign-preserving injection between the paired nonintersecting-path ensembles, or an equivalent compound-network minor representation. Acceptance requires constructing that map and proving its unmatched weight positive. This branch is deferred; no further abstract successor is created from the same blocker. Work reallocates to the independent executable leaf `quarter-y-system-barrier-test`, which tests explicit upper and lower barriers using the proved global unit-interval property.
