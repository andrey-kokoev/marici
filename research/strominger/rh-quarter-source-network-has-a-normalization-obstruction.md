# Quarter source network has a normalization obstruction

## Question

Can the determinant-ratio moments be obtained by row and column scaling of a positive numerator path matrix?

## Claim boundary

The obstruction excludes only direct separable normalization of the numerator matrix. It does not exclude a larger network with coupled normalization or a different representing measure.

## Disposition

Write the condensation identity as

\[
B_k=A_k+C_k,
\qquad
\Theta_{k+2,a}=A_k/B_k,
\]

where all three terms are positive partition products. Thus each scalar cross ratio is exactly a normalized two-class event weight. For all 117 tested shift-index pairs,

\[
B_kB_{k+2}-B_{k+1}^2>0.
\]

Hence the Hankel denominator array has rank greater than one and cannot factor into row and column gauges. Direct Lindström linearization by scaling the numerator matrix is obstructed. The next leaf is `quarter-cross-ratio-condensation-coupling`, seeking a coupled partition ensemble whose marginals give the normalized event weights without separable gauges.
