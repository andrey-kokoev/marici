# Quarter-source canonical monotone transport

## Question

Does any preregistered canonical source order make exact Hall transport a monotone noncrossing coupling?

## Claim boundary

Exact northwest-corner transport was tested for lexicographic, colexicographic, and sum-lex source orders across all 769 bounded Hall cases. The admissible counts are 217, 295, and 217 respectively. Each order has an exact forbidden interlacing edge; colex performs best only as a bounded count and still fails first at base `(1,2)`, endpoints `3,5`, on transport `(1,2,5)` to `(0,3,4)`. This rejects these three canonical monotone mechanisms, not arbitrary source orders or branching networks.

## Disposition

Reject the full preregistered canonical monotone-order rival. Preserve unrestricted exact interlacing max-flow feasibility. The nonredundant frontier is a genuinely branching source network or recurrence whose transport support is not forced by a total-order northwest-corner rule.
