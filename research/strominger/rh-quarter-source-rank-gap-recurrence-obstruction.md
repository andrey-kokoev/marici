# Quarter-source rank-gap recurrence obstruction

## Question

Can canonical globally coordinated transport be governed by a recurrence whose state depends only on source rank and endpoint gap?

## Claim boundary

Across 769 exact bounded cases, canonical augmenting signatures were grouped by source rank and endpoint gap. The first collision already occurs at rank zero and gap one: endpoints `(0,1)` have signature `(2,0,1,2)`, while endpoints `(1,2)` have `(4,0,3,2)`, where the entries record augmentation count, reverse-path count, negative-vertex count, and positive-vertex count. Thus rank and gap do not determine even the bounded canonical transport data. This rejects only rank-gap state compression, not recurrences retaining absolute endpoint position, base shape, or source weights.

## Disposition

Reject the rank-gap-only recurrence rival. Any surviving source recurrence must retain at least one additional typed coordinate distinguishing absolute endpoint placement or the induced source-weight profile. The next discriminating test is whether adding absolute left endpoint `(rank,gap,i)` suffices.
