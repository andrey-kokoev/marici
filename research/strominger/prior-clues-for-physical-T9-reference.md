    C t=unit,
    mu t=2*unit.

The actual Clifford matrix representation sends those values to I and2I respectively.

This is a NEW interpretation lead for the existing fixed reference2I: it might be a raw sewing-response convention rather than the normalized memory VALUE prepared from a two-unit resource. The factor2 is derived from four signed sewing terms per readable coefficient under the declared coefficient metric, not selected by fitting2I.

**Important boundary:** switching from C to mu changes the readout; it does not double stored resource. The same prior source proves raw mu cannot be used as a block of the conservative isometry under that metric. Reporting its doubled signal as a doubled prepared physical amplitude would be wrong. Neither the fixture nor the pinned software contract currently identifies d with this raw port.

**Next exact test:** compare both interpretations of the SAME retained unit-resource protocol, keep the norm/readout distinction and test whether the fixture's reference role is intended to be a map, preparation, or raw response calibration. This could explain the structural coefficient2 without deriving an absolute physical scale.
