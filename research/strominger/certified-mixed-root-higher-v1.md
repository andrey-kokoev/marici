# Certified mixed-root comparisons and higher producers

`agda/CertifiedMixedRootHigher.agda` supplies the missing producer layer over the established mixed-root coherence theorem. Inputs are actual mixed trees **with recursive Origins**, not arbitrary admitted trees.

## Computed boundary language

`Boundary` has only direct comparison and typed finite composition. Direct comparisons use the existing derived root views; composition must share the exact intermediate certified object. There is no constructor importing an arbitrary full boundary or equivalence.

A supplied compatible full root boundary can nevertheless receive a producer certificate: full-fiber propositionality matches it to the computed direct boundary, and the matching path preserves its actual native Closure. This does not make raw root packages or native proof spaces propositions.

## Four native producer stages

`Program` produces:

- a native full root comparison;
- its faithful envelope;
- the computed coherence path between two boundary expressions;
- the computed square between a direct coherence path and a path through a third boundary expression.

The index family, branch program, full boundary, path and square are all computed. No Type, family, native proof or higher-path import port is added. The h-level reasoning is the already justified full root-comparison fiber theorem, not assumed sethood of Resolve.

`operands-recovered` extracts both actual retained root closures. `Pair.recovered` and `Square.recovered` recover the entire computed comparison path and square from the native envelope construction.

`triangle-matches` identifies generated triangle admission with the **exact existing TriangleAdmission derivation**. The construction does not replace that theorem by a lookalike package or a supplied opaque higher parameter.

## Intermediate source and history evidence

Every checked tree supplies the earlier same-tree origin/history bundle. `Evidence` traverses every boundary composition; `ProgramEvidence` retains these bundles for all expressions used by each operation. Intermediate certified objects are not dropped merely because the outer root fibers are contractible.

The common forward initial context instantiates triangles and squares between mixed-join, imported core-composition and leaf roots using actual existing endpoints and histories, without seed reset.

## Exact scope and final gate

This is a certified actual-input producer interface for parallel mixed trees with the same actual endpoints and mode. It constructs finite comparison expressions and native path/square coherence. It is not an unchecked tree importer, a pure initial-word-only global script, arbitrary envelope endpoint certification or an unrestricted infinitely coherent Body action.

The remaining overall gate is **final common-witness assembly**. Bind the bounded policy's actual certified generated target as the input object of mixed continuations, retain raw alternative presentations and their native bridges separately, and collect these root/higher producers on the same context. Do not identify a policy output with a different mixed root package by reflexivity.
