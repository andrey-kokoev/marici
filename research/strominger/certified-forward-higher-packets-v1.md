## Exact common context and entire packet

For `InitialCertificate A d`, `certify` follows the actual native-proof equality from the generated initial word to d. Its result matches the entire higher native closure, including the Resolve derivation. It does not reset d or infer native proof irrelevance from equality of package codes.

## Reification boundary

The original next-universe reified package contains both the original Body list and the retained native closure list. `reified-matches` matches that actual data package to reification from the initial word.

This is **data-package equality**, not native admission at the next universe level. Nor does faithful-envelope certification admit the exact bare atomic higher package; the predecessor's obstruction remains unchanged.
