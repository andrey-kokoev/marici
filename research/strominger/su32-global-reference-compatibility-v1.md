# Global reference compatibility: construction and obstruction

## Question and scope

What reference structure do the existing native incidences determine globally, without postulating circular orders or payload-changing dynamics?

Source: the existing 51-cell fixture and its 36 occurrence charts, built by `su32-signed-reference-encoder.mjs`. A local reference presentation consists of its chart/occurrence, two P reference cells, two E reference cells, and a choice of which cell in each pair is labelled +. Signs remain directions, not intrinsic charges.

Two different questions must be separated:

1. Do the same native geometric reference cells remain identifiable across charts?
2. Can every physical charged cell carry one fixed sign that makes each same-role pair opposite in every chart?

The second question adds the **uniform all-cone fixed-cell-sign hypothesis**. It is not required by the operator's directional interpretation. Neither question supplies signal transport between different occurrences of a cell.

## 1. A global identity-level construction exists

First retain the complete native carrier: all 51 cell identities and roles. Then choose frames for all 36 charts at once and verify their restrictions. No wiring is generated by extending locally acceptable readers.

For chart c, let R_c be its four entrance reference cells. If c and d share a reference cell x, the canonical partial map identifies the local label of x in c with its local label in d. It does not identify any other cells.

The complete pair audit gives:

- **240 proper partial reference-set overlaps**;
- **390 empty reference-set overlaps**;
- **0 full four-reference overlaps** between distinct charts;
- **696 triple-common-reference checks**, all consistent;
- **5,040 relabelling checks**, covering all four P/E bindings at every chart against every other chart, all consistent.

These counts concern the four entrance reference cells, not every geometric cell in the charts' larger stars. Two charts with empty reference overlap can still intersect geometrically elsewhere.

On a triple-common reference x, direct identification and two-step identification both preserve x. This is the exact domain on which compatibility is established. Independent P/E sign reversals change its coordinate names, not its physical cell identity.

This construction is deliberately modest: a consistent atlas of **partial geometric-reference identifications**, not a new globally routed signal assignment or a bundle of four transported records. Choosing the same coordinate binding [0,0] in all charts does not make the same sign a fixed property of a shared cell.

## 2. Fixed cell signs: available choices and explicit obstruction

For each role separately, form the complete constraint graph before assigning anything. Vertices are physical reference cells; every chart contributes an edge requiring its two same-role cells to have opposite signs. Solve the whole graph, then verify every chart restriction.

Results on participating reference cells:

| Scope | P assignments | E assignments |
|---|---:|---:|
| Each single reading, including its six charts | 16 | 16 |
| All six incoming charts together | 64 | 64 |
| All 36 charts simultaneously | 0 | 0 |

For each single reading the role graph has four connected components, so its 16 assignments are exactly the independent component flips. P and E constraints are independent in this test, yielding 256 combined assignments per reading. The counts do not include unconstrained charged cells outside that scope, or impose extra directional boundary choices.

The all-chart obstruction has a three-cell certificate. For P, one such triple is:

```
a = proton:0,0,1,1
b = proton:0,0,2,0
c = proton:0,1,1,0
```

Actual source charts require opposite signs on each of `(a,b)`, `(b,c)` and `(a,c)`. The first two require equal signs on a and c; the third forbids them. The checker verifies the chart witnesses and exhausts all eight assignments. An independent E triangle is also retained in the receipt.

The earlier signed-reference audit already found this obstruction. This run independently verifies its minimal certificate, quantifies the satisfiable scopes' freedom, and separates it from the newly checked partial identity atlas.

**Conclusion:** the native geometry is not inconsistent. The optional extension of directional signs to permanent cell labels across every reading is inconsistent.

## 3. Why this is not already a circle bundle or holonomy

The most consequential finding is that no two distinct charts have the same complete four-reference set. Thus we cannot silently treat all charts as coordinate frames on the same four native records.

An overlap sharing one P reference says which occurrence refers to that same cell. Extending the associated sign-label change to the other P slot would pair different physical cells; that extra correspondence is not supplied by identity of the shared cell. Algebraically extending a partial label map is not evidence of native payload transport.

Likewise, walking among pairs `{a,b}`, `{b,c}`, `{c,a}` visits a different shared reference at each step. There is no P reference common to all three. A sign mismatch obtained by completing these partial maps to total binary permutations must not be reported as transport of one record around a closed loop.

Mnev's construction requires compatible oriented circular orders on an appropriate base. Neither those orders nor that base/classifying map are supplied by the results above. The odd-cycle sign obstruction is not an integral Chern class.

## Deliverable and remaining boundary

We obtained both requested kinds of result, with distinct scopes:

- **Construction:** globally consistent partial identification of native geometric references, invariant under changing local sign labels.
- **Obstruction:** no permanent physical-cell sign assignment under the explicit all-cone extension hypothesis.

What remains absent is a source-defined correspondence for records whose reference cells change between charts. That is the precise gap between the constructed identity atlas and a global four-record transport theory. It cannot be filled merely by demanding that every partial map become a permutation.

This refines the minimal account: local joins recover four records within one occurrence; global reference identity can be checked wherever actual cells coincide; the same four abstract slot names do not establish globally shared record identities.
