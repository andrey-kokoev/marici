# Original-rule geometric compiler and exact translation obstruction

## Disposition

The load-bearing bridge has a mixed answer:

- **Exact unary-extension package translation is impossible** under the unchanged original source/rules.
- **A closed, compositional original-rule compiler is constructed** for the declared directed-word/free-geometric-state task, using a different retained representation.

These are separate theorems. The positive result does not override the obstruction, identify the two packages, or prove carrier-wide full abstraction.

## 1. Exhaustive exact-signature obstruction

`agda/OriginalTransportShapeObstruction.agda` recognizes the precise Code shape

    retain (comparison ...) evidence (atom X).

This is the raw output shape of `RetainedTransportResolution.transportT` when its target is atomic, as in the existing geometric-state execution.

An exhaustive case split proves that none of the original twelve rule schemas produces this outer shape. Thus a Resolve derivation of such a package must obtain it directly from its seed policy. The original graph-pointed Seeds do not supply it.

`no-exact-transport` therefore refutes original admission for every such exact output. `OneInput.no-unary-elimination` also refutes generic exact elimination when the raw input atom is explicitly seeded: adding the input is not enough to derive the extension's retained output.

This is a Code-level obstruction, not an impossibility theorem for alternative encodings, interpreted carriers or computed observations.

## 2. Computed original-rule alternative

`agda/OriginalRuleGeometricCompiler.agda` exposes the closed entry point

    compile : Path A v -> Running v.

The only varying input is a directed endpoint-typed word in the existing six occurrences. No Type, equivalence, prepared geometric state, native packet or extension execution is accepted at this front door. Internal Running/execute helpers are not claimed to certify arbitrary client-supplied decoders.

The fixed parameter factories use the already declared free-incidence geometry and its exact occurrence binding to the native source. For an actual preceding original package q:

1. form its reflexive path package;
2. use State(target e) as the computed E index;
3. use the reflexive package of q as every branch;
4. select the state obtained by concatenating the actual edge to the decoded current state;
5. derive each branch from the ACTUAL preceding derivation, then apply the original E rule.

The root is built by the same E/reflexivity construction from the original graph-retaining A seed and the computed initial path refl.

No `transportT` constructor occurs in the compiler derivations. The old extension is used only on the comparison side of the agreement theorem, not as a compiler input or an admission premise.

## 3. Source provenance and its limits

Every compiler leaf satisfies the restricted policy q = pointQ A, which is mapped into the unchanged original Seeds with a checked source-root recovery path. The actual original graph remains retained.

Every geometric index and selected state is computed by the fixed factory from the declared source interpretation and the word. This is stronger than accepting an arbitrary already formed type/value as an E parameter.

It remains relative to the explicit free-incidence realization task. It does not prove that WG uniquely selects that task, that the original schemas intrinsically discover a HIT interpretation, or that this graph is necessary under every alternate realization policy. No general graph-ablation theorem is asserted.

E has dependent arity. Its branches may duplicate the same ancestry. **All leaves descend from source A; this is not a one-leaf, unary-cost, or physical-resource preservation claim.**

## 4. Recovery and composition

`step-parent` recovers the preceding original Closure, including its Resolve derivation, by following the actual E/reflexivity premises. It does not return a freshly reseeded endpoint with the same readout.

`execute-append` proves that compiling concatenation agrees with sequential compilation on the entire Running record: package, ancestry proof and decoder. The separate compiled record retains the original directed word exactly.

`extension-agrees` proves, for every directed word, equality of the decoded produced state with the existing retained unary-extension execution. The new representation includes reflexive-parent loop data; no proof that projection is an equivalence on all carrier values is supplied here.

`not-exact-output` independently rules out equality of a compiled package with an exact atomic-target unary-extension output. The observation comparison is not a package cast.

## 5. Observation acceptance and refusal transfer

For every declared Boolean geometric-state probe, the original-rule readout agrees with the earlier execution readout. Therefore:

- its collision-preservation certificates construct original-compiler image factors;
- its separating collisions refute original-compiler image factors;
- the independently computed BA-parity summary has a certified factor;
- the constant summary still fails on AB;BA versus AB;BC;CA, whose original-rule outputs read true and false.

The probe remains a declared mathematical observer, not a physically source-selected detector. Equal parity does not recover the complete history.
