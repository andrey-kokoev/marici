# Neutral commutator decoration is detected by a 3-adic source jet

## Constructor orbit

Let

\[
c=[x,y],
\qquad
t_n=xc^n,
\]

and insert \(t_n\) into the same magnetic C constructor while holding the opposite tail and primitive response fixed.

Every \(t_n\) has the same abelian charge. The orbit \(-3\le n\le3\) therefore probes a single augmentation fiber.

## What survives

For every tested \(n\),

\[
\operatorname{rank}(\pi A_n)=2.
\]

The diagonal snake persists. This confirms that the reflection rank defect is insensitive to the neutral decoration orbit.

## What changes

All three Smith layers respond:

\[
d_1(A_n),qquad d_2(\pi A_n),qquad d_3(A_n).
\]

The resulting seven snake indices are pairwise distinct and do not obey a constant multiplicative-character law.

So the elementary decoration does not act by simply multiplying the final discriminant. It changes the integral response before determinantal saturation and gcd reduction.

## Unexpected 3-adic law

The matrix content satisfies, throughout the tested orbit,

\[
d_1(A_n)
=
\begin{cases}
2304,&n\equiv2\pmod3,\\
768,&n\not\equiv2\pmod3.
\end{cases}
\]

This periodicity is source-visible in the decoration response matrix \(C\):

\[
C\equiv I\pmod3,
\]

but

\[
C
\]

has order three modulo \(9\).

Thus ordinary mod-three response sees nothing, while the first nontrivial 3-adic jet sees the constructor orbit. The factor-three content jump is not encoded by abelian charge; it arises one congruence layer deeper.

The exact alignment between the residue class \(n\equiv2\) and the content jump is established on \(-3\le n\le3\). Its unbounded extension remains a conjecture until derived from the nested commutator formula.

## Deutsch’s answer

The elementary source change is attachment of one neutral commutator. Its first explanatory effect is not a scalar multiplier on the readout. It changes a 3-adic response jet:

\[
C^n\pmod9.
\]

That jet then enters the nested magnetic commutators, after which Smith saturation produces the observable index.

The causal hierarchy is therefore:

1. neutral word constructor \(c\);
2. congruence response \(C^n\);
3. integral nested-commutator matrix \(A_n\);
4. Smith divisors \(d_1,d_2,d_3\);
5. snake index and square class.

The first arrow supplies the counterfactual law Deutsch requested. Changing \(n\) changes a source response jet even though exponent charge is unchanged.

## New falsifier

The next sharp test is whether the full Smith orbit is determined by a bounded collection of prime-adic jets of \(C^n\).

If two exponents agree in every proposed bounded jet but yield different Smith square classes, that finite explanatory summary fails. If a fixed jet depth suffices, the discriminant has a finite local source law.

## Evidence

Seven exact orbit points were evaluated. The commutator response is identity modulo \(3\) and has order three modulo \(9\). All seven aggregate gates pass.
