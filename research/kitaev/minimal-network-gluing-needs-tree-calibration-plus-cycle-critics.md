# Minimal network gluing needs tree calibration plus cycle critics

## Result

The conjecture that one faithful root plus constructor-complete comparisons on a spanning tree trivializes all network holonomy is false.

A spanning tree determines relative vertex frames. It does not constrain transports on edges outside the tree. Each independent cycle requires an additional critic unless a source law already derives its chord transport from the tree path.

## Typed network

Let \(G=(V,E)\) be a finite connected directed graph. Associate to each vertex a copy \(H_v\) of a finite module \(H\), an authorized constructor algebra \(A_v\), and a readout \(L_v\). Each oriented edge has invertible transport

\[
U_e:H_{s(e)}\longrightarrow H_{t(e)}.
\]

Let \(K\) be the authorized structure group acting faithfully on the complete constructor packet. Let \(Z\subseteq K\) be the subgroup declared physically equivalent, such as a common scalar phase.

A complete edge comparison determines the class \([U_e]\in K/Z\). A complete root reference fixes the remaining global \(Z\)-frame when that frame is operationally meaningful.

## Tree calibration theorem

Choose a root \(r\) and a spanning tree \(T\subseteq G\). Prescribe a frame at \(r\). Complete comparisons on the \(|V|-1\) tree edges uniquely propagate frames to every vertex, modulo one common authorized center.

Proof: every vertex has a unique path from \(r\) in \(T\). Compose the measured edge transports along that path. Uniqueness follows because a tree has no alternative path whose consistency must be checked.

This theorem establishes vertex-frame calibration only.

## Chord falsifier

Take the triangle with vertices \(0,1,2\). Let

\[
U_{10}=I,
\qquad
U_{21}=I,
\qquad
U_{02}=G,
\]

where \(G\in K\setminus Z\).

Choose the tree edges \(0\to1\) and \(1\to2\). A complete root reference and complete tests on both tree edges pass. Nevertheless the loop holonomy is

\[
\operatorname{Hol}(0\to1\to2\to0)=G.
\]

Thus root-plus-tree does not imply path coherence.

## Minimal cycle count

For a connected graph, the cycle rank is

\[
\beta_1(G)=|E|-|V|+1.
\]

After tree calibration, every non-tree edge closes one fundamental cycle. A complete critic on each chord tests a generating set of loop holonomies. Therefore the generic certificate contains:

- one root frame;
- \(|V|-1\) complete tree-edge comparisons;
- \(\beta_1(G)\) complete chord or fundamental-cycle critics.

The total number of edge comparisons is \(|E|\). This is minimal when edge transports are independent authorized data.

It can be reduced only by a source-derived relation that determines some chord transports from others.

## Exact gluing theorem

Assume:

1. all edge transports lie in \(K\);
2. every tree-edge comparison is faithful in \(K/Z\);
3. the root reference is faithful on the operational part of \(Z\);
4. every fundamental-cycle critic establishes holonomy in \(Z\), or identity when central phases are observable;
5. no hidden environment carries additional off-diagonal process data.

Then transports between any two vertices are path-independent modulo \(Z\). If the root also fixes \(Z\), they are strictly path-independent.

Proof: every closed walk in a graph is generated by the fundamental cycles associated with its chords. Triviality of those generators implies triviality of all loop holonomies. Tree calibration then supplies a unique transport from the root to every vertex.

## Nonabelian qualification

When \(K\) is nonabelian, fundamental holonomies depend on the chosen root paths and transform by common conjugation under a change of root frame. The invariant is therefore a conjugacy class of representations

\[
\rho:\pi_1(G,r)\longrightarrow K/Z,
\]

not a list of absolute group elements.

The network glues exactly when \(\rho\) is trivial. This is genuinely a nonabelian first-cohomology or local-system obstruction once the coefficient group and gauge action are frozen.

For a graph without attached two-cells, no face equation forces triviality. If two-cells encode source relations, their boundary words supply the allowed curvature laws.

## Holonomy and observability are independent

### Observable but path-incoherent

Let every vertex readout be the identity on \(H\). Every local state is fully observable. Use the triangle chord falsifier with \(G\ne I\). The network has nontrivial holonomy despite perfect observability.

### Path-coherent but unobservable

Let every edge transport be identity. All paths agree. Let

\[
L(x,y)=x.
\]

The \(y\)-direction is locally invisible despite trivial holonomy.

Therefore neither property implies the other. The fourth tower cannot be reduced to ordinary state observability.

## Scalar blindness

Even full scalar path agreement need not detect constructor holonomy. If

\[
L_vG=L_v

\]

for a nontrivial \(G\), the loop passes every scalar critic. The cycle critic must inherit the strongest coefficient lens acted on by \(K\).

## Quantitative completion gate

Finite exact gluing still does not imply stable gluing in a family \(G_N\). Let \(C_N\) be the aggregate root, tree, and cycle analysis map. Completion-stable gluing requires

\[
\inf_N s_{\min}(C_N)>0
\]

on the quotient by the authorized common center.

If this infimum vanishes, normalized gauge or holonomy defects can become asymptotically invisible even though every finite certificate has full rank.

## Consequences for three-plus-one

For four branches connected only by a tree, three relative comparisons plus one root frame are the correct incidence count. If the physical Carrier contains additional coherent routes, feedback, or recombination edges, each independent cycle adds a critic.

Thus three-plus-one is not a universal network law. It is the certificate for a four-vertex tree or for a richer graph whose chord transports are already fixed by authorized source relations.

## Main conclusion

The fourth tower is genuinely distinct from observability. Its finite obstruction is a gauge class of loop holonomy. Its minimal generic certificate factorizes into vertex-frame calibration along a spanning tree and one complete critic per independent cycle, followed by a uniform completion-margin test.
