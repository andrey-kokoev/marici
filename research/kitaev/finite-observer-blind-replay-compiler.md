# Finite observer-plane blind replay compiler

## Question

Can the current Carrier, SCC, observer-kernel, and constructor-closure structure automatically re-derive finite results previously obtained through sector-specific arguments, without placing the known minimum or witness in the input packet?

## Claim boundary

The compiler covers five exact finite modes: binary linear quotients, finite-group flux-algebra closure, Boolean zeta inversion, repetition-code fault balls, and sequential rational polarization. It receives primitive data and target predicates but no expected minimum counts or known witnesses.

This is not one universal inference algorithm. It is one typed dispatcher with coefficient-specific exact engines and a shared first-defect vocabulary. It does not discover source authority, physical apparatus, infinite completion bounds, closability, or new constructor families. The Boolean fixture tests the complete labelled Boolean route transform rather than Benincasa's independent contact-normal typing. The polarizer fixture is the crossed-polarizer visibility model, not Aspect's Bell-pair apparatus.

## Disposition

### Contract

The declarative input is `research/kitaev/contracts/finite-observer-blind-replay.v1.json`. Each benchmark declares primitive source parameters, an authorized candidate family, and a target predicate. It intentionally omits known solution sizes.

The exact compiler is `research/kitaev/checkers/compile_finite_observer_blind_replay.py`. It writes `research/kitaev/results/finite-observer-blind-replay.json`.

### Derived results

#### Toric phase-free Pauli quotient

From a periodic (L=3) incidence packet, the compiler constructs the electric and magnetic commutator rows, the stabilizer span, and four marked logical candidate probes. It derives:

- source dimension (36);
- syndrome rank (16);
- syndrome kernel dimension (20);
- legal stabilizer kernel dimension (16);
- target readout rank (20);
- minimum augmentation (4);
- maximum rank with fewer probes (19).

The discovered witness is the two primal and two dual marked logical commutator probes. The result matches the independent `toric-code-wp1-wp6.json` (L=3) audit exactly.

#### (D(S_3)) endpoint algebra

From the permutation group on three labels, gauge conjugation, and all nonidentity flux candidates, the compiler derives:

- gauge-only dimension (6);
- maximum one-port dimension (24);
- full target dimension (36);
- minimum augmentation (2);
- first missing one-port dimension (12).

Every minimum witness has one transposition and one three-cycle type. The derived minimum and one-port ceiling match `s3-minimal-flux-resolved-generators.json`. Physical executability remains explicitly false.

#### Boolean deletion routes

For five labels, the compiler generates rather than receives the (32\times32) Boolean zeta matrix. It derives rank (32), zero kernel, and its exact inverse. The inverse entries satisfy the Boolean Möbius sign law. Deleting one observation row lowers rank to (31), producing an observer-kernel hostile.

#### Classical replica controller

From only a one-flip fault radius and a search bound of five copies, the compiler enumerates the two repetition-code fault balls. It derives:

- minimum detection length (2);
- minimum correction length (3);
- failure of all smaller lengths;
- invisibility of common-mode all-replica flips;
- no implication for quantum actuator repair.

Both minima match `s3-lockstep-controller-redundancy.json`.

#### Crossed polarizers

From horizontal source polarization, vertical terminal effect, and four authorized rational projectors, the compiler derives zero direct intensity. It searches ordered insertion sequences and finds a one-step minimum. The two diagonal projectors each produce intensity (1/4); horizontal and vertical insertions remain dark. No parallel-Gramian addition is used: the observation changes through sequential constructor closure.

### What was automated

The finite engines automatically perform the relevant closure, rank, inverse, fault-ball, or sequential-product calculation; search all smaller candidate families; report a minimum witness; and retain the first unresolved kernel or algebra deficit.

The finite linear termination mechanism is dimension bounded. A constructor algebra in dimension (n) stabilizes inside an (n^2)-dimensional matrix space, and an observer row span stabilizes inside the dual (n)-space. Minimal subset search remains combinatorial but is finite for a frozen candidate family.

### Anti-circularity

The contract includes targets such as `full_crossed_product_algebra` and `nonzero_terminal_intensity`, but it does not include the expected number of probes, the required conjugacy types, the Möbius inverse, repetition minima, or a successful polarizer name. Lower-cardinality failure is computed from the same primitive packet.

The current result is re-derivation, not explanation discovery. The compiler explains a finite verdict only relative to the frozen constructor vocabulary. If the necessary constructor is absent from the authorized pool, the correct output is a typed deficit rather than an invented repair.

### Falsifiers and next extension

The programme fails if a replay minimum disagrees with an independent packet on the same frozen source, if a lower-cardinality hostile passes, if an unauthorized candidate enters a witness, if coefficient conversion changes a kernel, or if a physical capability is inferred from algebraic span.

The next valuable extension is not another sector mode. It is a common declarative intermediate representation for source modules, constructors, observers, legal kernels, calibrations, and authority. The five exact engines should then consume that shared representation, making their common structure semantic rather than only a shared result schema.
