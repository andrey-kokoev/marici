## Bounded question

What physical resource implements the cross-factor phase

\[
  K|r,s\rangle=i^{rs}|r,s\rangle,
  \qquad r,s\in\mathbb Z/4?
\]

## Native mod-four pointer

Treat each residue register as one ququart with Pauli generators (X_4,Z_4).
Then (K) is exactly generalized controlled-(Z_4). The checker verifies
that it normalizes the complete two-ququart Pauli group. Hence the full
Schmidt-rank-four interaction has one shared Clifford constructor in a native
ququart stabilizer architecture.

## Binary pointer encoding

In the frozen architecture a residue pointer is represented by two binary
coordinates. With

\[
  r=2a+b,\qquad s=2c+d,
\]

the phase exponent is

\[
  rs=bd+2(ad+bc)\pmod4.
\]

Therefore

\[
  K=CS_{b,d}\,CZ_{a,d}\,CZ_{b,c}.
\]

The two (CZ) factors are Clifford, but controlled-(S) is not. An exact
four-qubit Pauli-normalizer test fails. Thus the same abstract interaction is
Clifford under the native ququart coefficient lens and non-Clifford under the
binary tensor-product lens.

This also gives an exact optimal binary resource count in the gate library
generated by Clifford gates and controlled-(S). The displayed decomposition
is an upper bound of one controlled-(S); the normalizer failure rules out a
zero-non-Clifford realization. Hence the optimum is exactly one.

## Explanatory consequence

The interaction does not require four label-specific constructors. It has one
parameter-free mod-four constructor. But the frozen binary stabilizer
architecture cannot execute it without the already identified controlled-(S)
resource. Switching to native ququart hardware would change the coefficient
lens and must include an encoded fault-tolerance construction; it cannot be
declared free by relabelling two qubits.

Neither lens supplies coherent extraction of Wilson residues into the
pointers. The result isolates the interaction layer after extraction.

The required magic species is not new. The frozen (D(S_3)) architecture
already requires a controlled-(S)-type module for its controlled-power-two
record phase. A verified factory for that module could serve both consumers.
Thus the product kernel adds one invocation but zero additional factory
species; in the current source theory both invocations remain unavailable.

## No Pauli-preserving relabelling

A native ququart is not merely two qubits with renamed basis vectors. Modulo
central phases, their Pauli label groups are

\[
  \mathbb Z_4^2
  \qquad\text{and}\qquad
  \mathbb Z_2^4.
\]

The first has one identity, three order-two elements, and twelve order-four
elements. The second has one identity and fifteen order-two elements, with no
order-four element. Element order is an isomorphism invariant, so no
Pauli-preserving relabelling or Clifford frame change connects these lenses.

Consequently a switch that makes (K) Clifford must introduce native
four-level Pauli operations, a nontrivial code switch, or an equivalent new
hardware interface. The binary controlled-(S) cost cannot be erased by
changing notation.

## Falsifiers

- Failure of ququart Pauli normalization.
- A four-qubit Clifford decomposition in the frozen binary Pauli structure.
- A claimed binary/ququart equivalence that preserves the admitted local
  stabilizer operations without adding a code switch.
