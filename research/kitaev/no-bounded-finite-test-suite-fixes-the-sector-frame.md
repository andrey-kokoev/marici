## Finite indistinguishability theorem

Let a candidate finite-cutoff augmentation produce framed sector units
`D_{+,X}(z)` and `D_{-,X}(z)` with reciprocal sewing

\[
F_X(z)=u_X(z)D_{+,X}(z)D_{-,X}(z).
\]

Assume a bounded audit inspects:

- every sewn scalar `F_X`;
- every cutoff quotient within each sector;
- the centered basepoint;
- sector logarithmic jets only through order `r`;
- divisor data;
- reciprocal reflection.

Choose any odd integer `m>r` and any nonzero constant `c`.  Define

\[
\widetilde D_{+,X}(z)=e^{cz^m}D_{+,X}(z),
\qquad
\widetilde D_{-,X}(z)=e^{-cz^m}D_{-,X}(z).
\]

Then:

1. the sewn scalar is unchanged;
2. every within-sector cutoff quotient is unchanged because the reframe is
   cutoff independent;
3. the basepoint value is unchanged;
4. every logarithmic jet through order `r` is unchanged;
5. every sector divisor is unchanged because the exponential is a unit;
6. reciprocal reflection remains exact.

Nevertheless the `m`th logarithmic derivative changes by a nonzero constant
multiple of `c`, and generic sector-sensitive transport changes at every
nonzero parameter.

Therefore no bounded finite jet-and-sewing audit determines the sector frame.
