# A naked relative predicate recreates the hidden phase fault one layer down

## Bounded question

Can the two-rail relative holonomy bus close the hidden diagonal fault channel
using an ordinary clean comparator ancilla to implement its logical element
predicate?

No. The comparator has the same compute–phase–uncompute vulnerability as the
original holonomy bus. A single comparator phase fault returns the comparator
clean while applying a logical relative-coordinate phase to the encoded bus.

## Two-rail logical bus

Recall the code

\[
|h\rangle_L
=\frac1{\sqrt6}\sum_{a\in S_3}|a,ah\rangle.
\]

Write the two physical labels as \(a,b\), so the logical coordinate is

\[
h=a^{-1}b.
\]

The desired logical predicate phase is generated by

\[
Q_q
=\sum_a|a,aq\rangle\langle a,aq|.
\]

The previous packet treated this relative predicate as an uncompiled
constructor. This packet compiles the obvious version and audits its fault
surface.

## Five-step clean comparator

Introduce a clean six-state comparator \(c=e\). Use two controlled group
multiplications to compute the relative coordinate:

\[
c\longmapsto a^{-1}c,
\]

followed by

\[
c\longmapsto cb.
\]

Starting from identity, the comparator now holds

\[
c=a^{-1}b=h.
\]

Apply a basis-state phase when \(c=q\), then reverse the two multiplication
contacts. The comparator returns to identity. The serial architecture has:

- two compute contacts;
- one predicate phase;
- two uncompute contacts.

On ideal code states it implements exactly

\[
e^{-i\theta Q_q}.
\]

## Exact comparator phase-fault witness

Insert the sign-character phase on the comparator after compute and before
uncompute:

\[
Z_{\mathrm{sgn}}|c\rangle
=\operatorname{sgn}(c)|c\rangle.
\]

On a basis pair \(|a,b\rangle\), the comparator contains \(a^{-1}b\). After
the fault and ideal uncompute, the result is

\[
\operatorname{sgn}(a^{-1}b)
|a,b\rangle|e\rangle_c.
\]

Since \(a^{-1}b=h\) on the logical code,

\[
\operatorname{sgn}(a^{-1}b)
=\operatorname{sgn}(h).
\]

The comparator returns exactly clean. The two-rail code accepts because the
fault is already a logical function of the relative coordinate rather than a
single-rail phase.

This reproduces the original hostile endpoint phase one compiler layer lower.

## Full diagonal comparator fault space

For an arbitrary diagonal comparator operator

\[
D_f|c\rangle=f(c)|c\rangle,
\]

the clean comparator branch induces

\[
f(a^{-1}b)=f(h)
\]

on the logical bus. Every function on \(S_3\) survives, with the same
Peter–Weyl decomposition

\[
1+1+4=6.
\]

Modulo the neutral scalar direction, the comparator has five clean logical
fault directions. The two-rail encoding does not reject them because its
protection theorem covers operators confined to one physical rail, while
\(f(a^{-1}b)\) is relational and acts across both.

Thus replacing one naked bus by two protected shares plus one naked comparator
moves the six-dimensional diagonal-symbol obstruction into the comparator.

## Compiler recursion theorem

Consider any clean compute–phase–uncompute comparator that:

1. computes a nonconstant relative label \(d(a,b)\) into an ancilla;
2. applies a phase depending on that label;
3. uncomputes the ancilla;
4. verifies only its final computational label.

An inserted diagonal ancilla fault \(D_f\) before uncompute induces

\[
f(d(a,b))
\]

on the protected carrier while returning the ancilla clean.

If the code's logical coordinate is \(d(a,b)\), every nonconstant \(f\) is a
logical fault. The compiler has recursively recreated the exact operator
channel it was introduced to detect.

No finite tower of naked label-compute, phase, and uncompute buses closes this
channel. Each new unencoded comparator has its own diagonal-symbol algebra.

The recursion ends only when one layer supplies a genuinely fault-filtered
primitive: an encoded comparator, transversal gadget, verified teleportation
resource, measurement with safe rejection, or a physical fault model excluding
the diagonal sector.

## Direct relative-predicate obstruction

Treating

\[
e^{-i\theta Q_q}
\]

as a primitive two-rail gate does not solve the problem. A single overrotation
at that location,

\[
e^{-i(\theta+\epsilon)Q_q},
\]

preserves the logical code and differs from the target by

\[
e^{-i\epsilon Q_q}.
\]

No code-return syndrome detects this error because it is proportional to the
intended logical generator. A primitive interaction spanning both shares makes
a logical actuator fault elementary by definition.

Fault tolerance therefore requires decomposing the logical predicate into
locations whose individual faults remain correctable or detectable. Declaring
the full logical gate primitive assumes away the required theorem.

## Contact-fanout diagnosis

The comparator touches both protected rails in sequence. It is a common causal
ancestor of their relative predicate. A persistent comparator phase fault has
fanout two at this layer and fanout four after the holonomy rails have each
accumulated edge information.

The two-rail code protects against faults entering through one rail path. The
comparator introduces a new path crossing the separation cut. It must itself be
encoded or verified under a locality contract preventing one fault from
reaching both logical shares.

This is the physical meaning of compiler recursion: every constructor that
recombines secret shares becomes a high-authority fault location.

## Safe rejection timing

Even an encoded comparator helps only if its syndrome is checked before the
logical phase output is used. A detected comparator fault after the endpoint
operation has propagated downstream cannot be repaired by discarding the
comparator alone.

A valid extended gadget must include:

1. verified relative-coordinate extraction;
2. fault-filtered logical phase injection;
3. coherent cleanup;
4. phase-sensitive syndrome extraction;
5. acceptance or joint recovery before endpoint output release.

Clean label return is one postcondition inside this gadget, not the complete
acceptance certificate.

## Candidate termination mechanisms

The algebra leaves several possible routes, none yet admitted as executable.

### Encoded comparator

Encode the relative-label ancilla so that every elementary diagonal fault
compresses to a scalar or syndrome. Its multiplication contacts must themselves
be fault transversal relative to the chosen code.

### Verified gate teleportation

Prepare an offline resource for the relative predicate, verify both translation
and phase sectors, and couple it transversally to the two bus rails. The
resource factory becomes the new authority boundary.

### Distributed predicate check

Use a verified distributed controller whose elementary contacts touch at most
one protected share. The nonlocal correlation must be established and checked
before data contact.

### Heralded measurement

A measurement-based gadget may reject unsafe branches, but it must not reveal
the logical holonomy or dephase superpositions among endpoint sectors.

Every route requires a new constructor theorem. None follows from the ideal
relative projector alone.

## Deutschian explanation

The two-rail code hides the logical value from either share. To act on that
value, the comparator brings the shares back together. At that moment it gains
exactly the information whose separation provided protection.

A phase fault in the comparator can therefore depend on the logical relation
and return the comparator's label clean. Adding another unprotected comparator
only gives the same problem a new address. Protection ends the regress only
when the recombination itself is implemented by a fault-filtered physical
construction.
