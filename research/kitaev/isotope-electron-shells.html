Reading the table: protons and neutrons belong to the nucleus; the shell columns describe the surrounding electrons of a neutral atom. Isotopes of the same element have the same electron counts here.

The maximum capacity of principal shell n is 2n². These capacities are not a sequential filling rule: subshell energies determine the actual populations. The supplied table values are preserved.
