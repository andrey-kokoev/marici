# Fredholm index is the global logical charge of a completed mate

## Question

After essential-spectrum escape has been excluded, what topological obstruction remains to repairing a completed comparison mate by a source-native compact tail?

## Claim boundary

Let \(A:H\to K\) be the completed typed comparison mate between the authorized source and boundary spaces. Assume \(A\) is Fredholm, so its kernel and cokernel are finite-dimensional and its range is closed. Define

\[
\operatorname{ind}A
=
\dim\ker A-\dim\operatorname{coker}A.
\]

For every compact correction \(T:H\to K\),

\[
\operatorname{ind}(A+T)=\operatorname{ind}A
\]

whenever \(A+T\) is Fredholm. Therefore a nonzero index cannot be repaired by any compact modular tail. If the required final mate is an isomorphism, index zero is a necessary condition.

This produces a three-stage obstruction hierarchy.

1. Non-Fredholm obstruction: zero lies in the essential singular spectrum or the range is not suitably closed. Compact tails cannot restore a completion gap.
2. Fredholm index obstruction: the essential problem is controlled, but a finite global imbalance between hidden source modes and missing boundary modes remains. Compact tails preserve this integer.
3. Index-zero finite defect: abstract finite-rank repair to an invertible operator exists, but source authority, character covariance, seam incidence, and cutoff naturality still decide whether the repair is admissible.

The third statement is constructive at the level of operator theory. If \(\dim\ker A=\dim\operatorname{coker}A\), choose an isomorphism from the kernel to a complement representing the cokernel and extend it by zero. Adding this finite-rank map makes the Fredholm operator invertible. Nothing in that construction proves the map is generated by theta/Tate source constructors.

### Why this is a topological-sector invariant

The quotient map to the Calkin algebra sends \(A\) to an invertible element precisely when \(A\) is Fredholm. Its homotopy class carries the Fredholm index. Compact corrections change the representative but not that class.

This is the completed-operator analogue of the toric-code separation

\[
\text{local repair}
\quad\text{versus}\quad
\text{global logical sector}.
\]

Stabilizers change a chain representative without changing its homology class. Compact tails change finite defects without changing the Fredholm index. In both cases, repairing the global charge requires a constructor outside the local repair ideal.

### Character-resolved index

Suppose Fourier covariance gives

\[
H=\bigoplus_\chi H_\chi,\qquad
K=\bigoplus_\chi K_\chi,\qquad
A=\bigoplus_\chi A_\chi.
\]

An equivariant compact correction also preserves the character blocks. The relevant obstruction is therefore the vector

\[
\operatorname{Ind}_{\mathrm{Fourier}}(A)
=
\left(\operatorname{ind}A_1,\operatorname{ind}A_{-1},
\operatorname{ind}A_i,\operatorname{ind}A_{-i}\right),
\]

not merely the total index.

Opposite block indices can cancel:

\[
\operatorname{ind}A_1=1,\qquad
\operatorname{ind}A_{-1}=-1,\qquad
\operatorname{ind}A=0.
\]

The aggregate operator then has zero total index, yet no Fourier-equivariant compact repair can make both blocks invertible. A nonequivariant repair would mix characters and change the allowed constructor theory. Scalar aggregation can hide this obstruction completely.

Thus the necessary topological gate is blockwise index zero on every reachable character sector.

### Left-faithfulness versus full equivalence

If the programme needs only injective observability rather than an isomorphism, full index zero is stronger than necessary. The correct condition is upper semi-Fredholm left-invertibility: finite kernel, closed range, and removal of the kernel by an authorized finite correction. Cokernel may remain because unrequested boundary outputs need not be synthesized.

If the mate must identify the forward Ward packet with the backward Green packet as the same typed object, surjectivity is part of the claim and full Fredholm index zero is necessary.

The research contract must state which of these two tasks is intended before interpreting the index.

### Finite-cutoff approximation

Finite square matrices always have index zero, so ordinary cutoff determinants cannot reveal the completed index. The invariant appears through boundary flow:

- stabilized dimension imbalance between approximate source kernel and boundary cokernel;
- singular values crossing zero under cutoff refinement;
- spectral flow of a self-adjoint dilation;
- failure of compatible finite inverses despite individual invertibility.

A suitable self-adjoint dilation is

\[
D_A=
\begin{pmatrix}
0&A^*\\
A&0
\end{pmatrix}.
\]

The signed chiral zero-mode imbalance recovers the Fredholm index. Tracking only \(|\det A_N|\) erases this sign and grading.

### Consequences for the modular tail

Before asking whether the tiny tail equals the final Green–Ward discrepancy, the completed mate must be classified:

- Is it Fredholm in the actual P/Q-asymmetric rigged topology?
- What are its kernel and cokernel types?
- What is its index in each Fourier character block?
- Is the proposed tail compact in that same topology?

If any reachable block has nonzero index, the tail cannot close the mate unless it is noncompact, changes the domain or codomain, introduces a new boundary port, or breaks Fourier covariance. Each option is a change in constructor theory and must be source-authorized.

If every block has index zero, a finite repair exists abstractly. The remaining question becomes canonicality: does the source algebra select the kernel-to-cokernel matching, or is there a torsor of possible repairs? The tensor-unit lesson from the quantum sector then applies: a preferred frame may select one repair algebraically without constructing its physical or analytic implementation.

### Exact falsifiers

The compact-tail completion conjecture is falsified by any of:

- a weakly null approximate-kernel sequence, proving non-Fredholm escape;
- a nonzero blockwise Fredholm index;
- total index zero obtained only by cancellation between distinct characters;
- an index-zero repair requiring a map absent from the authorized source monoid;
- a repair that changes with cutoff and has no natural completed graph.

## Disposition

The completed mate problem now has a topological normal form. First exclude essential approximate kernels. Second compute the Fourier-character-resolved Fredholm index. Only when every required block has index zero is it meaningful to search for a compact tail or finite boundary incidence that makes the mate invertible.

This is the strongest current Kitaev-style prediction: if the Green–Ward obstruction is genuinely global, it should appear either as essential spectrum at zero or as a nonzero character-resolved index. If neither occurs, the missing constructor is finite-dimensional and the remaining problem is to derive its canonical incidence from the source rather than fit it from the scalar section.
