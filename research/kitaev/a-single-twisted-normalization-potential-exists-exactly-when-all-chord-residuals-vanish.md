# A Single Twisted Normalization Potential Exists Exactly When All Chord Residuals Vanish

Let a connected source graph carry affine transport data

\[
x_{t(e)}
=\varepsilon_e x_{s(e)}+\ell_e,
\qquad
\varepsilon_e\in\{+1,-1\}.
\]

A global source normalization potential is a vertex function \(\phi_v\) such
that the transported distinguished coordinate is

\[
x_v=\phi_v.
\]

The edge law becomes

\[
\phi_{t(e)}
=\varepsilon_e\phi_{s(e)}+\ell_e,
\]

or equivalently

\[
\ell_e
=\phi_{t(e)}-\varepsilon_e\phi_{s(e)}.
\]

Thus the twisted gain cocycle is generated by one vertex potential precisely
when it is a twisted coboundary.

## Loop criterion

Compose the affine transports around a loop \(C\) based at \(v\):

\[
x\longmapsto\varepsilon_Cx+\ell_C.
\]

A global potential exists if and only if every loop fixes the same base value
\(\phi_v\):

\[
\phi_v
=\varepsilon_C\phi_v+\ell_C.
\]

Therefore:

- if \(\varepsilon_C=+1\), one must have \(\ell_C=0\);
- if \(\varepsilon_C=-1\), one must have
  \[
  \ell_C=2\phi_v.
  \]

All odd loops must consequently have the same center \(\ell_C/2=\phi_v\).
This recovers both previous holonomy obstructions from one potential equation.

## Spanning-tree compiler

Choose a root \(v_0\), a proposed root value \(\phi_{v_0}\), and a spanning
tree \(T\). Propagate \(\phi\) uniquely along the tree using

\[
\phi_t=\varepsilon_e\phi_s+\ell_e.
\]

For every non-tree edge define the chord residual

\[
\Delta_e
=\ell_e-
\left(
\phi_{t(e)}-arepsilon_e\phi_{s(e)}
\right).
\]

Then

\[
\Delta_e=0
\quad\text{for every chord}
\]

if and only if the tree potential extends to the whole graph.

This is the smallest finite checker. It requires one residual per independent
cycle, not a separate audit of every possible loop word.

## Exact triangle packets

Take vertices \(0,1,2\) with

\[
(\phi_0,\phi_1,\phi_2)=(1,3,-2).
\]

On edges \(0\to1\) and \(1\to2\), choose

\[
(\ell_{01},\varepsilon_{01})=(2,+1),
\]

\[
(\ell_{12},\varepsilon_{12})=(1,-1).
\]

If \(2\to0\) has \((\ell_{20},\varepsilon_{20})=(-1,-1)\), the loop is even
and its total affine transport is the identity.

If instead \((\ell_{20},\varepsilon_{20})=(3,+1)\), the loop is odd and its
transport is

\[
x\longmapsto-x+2,
\]

whose center is \(1=\phi_0\). Both packets arise from the same vertex
potential.

Perturbing a chord gain by \(\delta\) changes its chord residual by
\(\delta\) and creates exactly that loop anomaly. This supplies the requested
counterfactual: a local constructor perturbation predicts a calculable global
holonomy defect.

## Approximate potential

If

\[
\ell_e
=\phi_t-\varepsilon_e\phi_s+\delta_e,
\]

then loop anomalies are signed sums of the edge residuals. On an infinite tail,
absolute summability of the transported \(|\delta_e|\) gives a bounded
normalization error. Merely having \(\delta_e\to0\) does not.

## Explanatory boundary

This theorem tells Grothendieck exactly what one global source principle must
produce. It does not derive \(\phi\) from theta/Tate data. A proper explanation
must identify \(\phi_v\) independently—perhaps from the product formula,
vacuum normalization, determinant transport, or another frozen constructor—and
then predict the edge gains and chord residuals.

Fitting \(\phi\) after measuring all edge gains is a cohomological solution,
not yet a source explanation.

## Falsifiers

- A nonzero chord residual under a claimed exact potential.
- Different odd-loop centers at one base vertex.
- A nonzero even-loop translation.
- Choosing a different root value for each loop.
- Fitting the vertex potential from the desired zero behavior.
- Approximate residuals that are not summable through completion.
