# Invertible tree networks correlate copies but do not shrink source freedom

## Result

The equalizer mechanism has a sharp limitation. A connected tree of invertible transports does not reduce the underlying source dimension. It merely represents one root state in several correlated vertex frames.

Domain reduction arises only from independent cycle fixed-point conditions, noninvertible incidence, or boundary/reference constraints.

## Network equalizer

Let \(G=(V,E)\) be a finite connected graph. Attach a finite-dimensional space \(H_v\simeq H\) to each vertex and an invertible transport

\[
U_e:H_{s(e)}\longrightarrow H_{t(e)}
\]

to every oriented edge.

The compatible network states satisfy the edge equation for every \(e\in E\):

\[
C_G={(x_v)_v:x_{t(e)}=U_ex_{s(e)}}.
\]

## Tree theorem

If \(G=T\) is a tree, evaluation at any root \(r\) gives an isomorphism

\[
C_T\simeq H_r.
\]

Proof: every vertex has a unique root path. Its state is uniquely determined by transporting \(x_r\) along that path. Conversely every \(x_r\in H_r\) produces one compatible network state.

Hence

\[
\dim C_T=\dim H.
\]

Adding transported copies on a tree creates no domain reduction.

## Consequence for three objects

A source object connected to two reciprocal sheet objects by a tree does not make a scalar readout more faithful merely by enforcing edge compatibility. The three vertex variables collapse to one freely chosen root variable, not to a smaller root subspace.

The third object adds useful information only if it contributes:

- an independent route closing a cycle;
- a noninvertible incidence condition;
- a boundary value or normalization constraint;
- a constructor law not implied by transport.

## Cycle fixed-point theorem

Choose a spanning tree \(T\) and root \(r\). Tree transport expresses every vertex state in terms of \(x_r\). Each chord \(e\in E\setminus T\) closes a fundamental loop with rooted holonomy \(H_e\in\operatorname{GL}(H_r)\).

Chord compatibility becomes

\[
(H_e-I)x_r=0.
\]

Therefore

\[
C_G\simeq\bigcap_{e\in E\setminus T}\ker(H_e-I).
\]

Equivalently, the admissible root states form the common fixed subspace of the holonomy group generated by the chords.

## Revised meaning of holonomy

Nontrivial holonomy is not automatically a defect. When the network law requires a state to be compatible around the loop, holonomy acts as a selector: only its fixed states survive.

If path independence is required for every state, then \(H_e=I\) is the desired law and the loop supplies no domain reduction.

If nontrivial holonomy is source-authorized, its fixed subspace can encode a logical sector, invariant state, or boundary selection rule.

Thus the same residue can be either:

- curvature violating a flatness claim;
- or a constructor whose fixed space defines admissibility.

The declaration of the composition law decides which.

## Scalar faithfulness criterion

Let \(L_r:H_r\to\mathbb C\) be the root-frame scalar readout. It is faithful on the compatible network exactly when

\[
\ker L_r\cap
\bigcap_{e\in E\setminus T}\ker(H_e-I)=0.
\]

A scalar can be injective on this linear equalizer only if its dimension is at most one.

Therefore a multi-object invertible network can make one scalar faithful only when its authorized loop holonomies and boundary laws reduce the common fixed subspace to a line or zero.

## Minimal fixtures

### Three-vertex tree: no gain

Let all spaces be \(\mathbb C^2\) and both tree transports be identity. Compatible triples are

\[
(x,x,x),
\qquad x\in\mathbb C^2.
\]

The equalizer remains two-dimensional.

### Triangle: one-rank gain

Use identity transports on two tree edges and let the chord holonomy be

\[
H=\operatorname{diag}(1,-1).
\]

Then the common fixed subspace is

\[
\operatorname{Fix}(H)=\operatorname{span}(e_1).
\]

The scalar \(L(x,y)=x\) is faithful on the network equalizer.

### Flat triangle: no gain

If the chord holonomy is identity, the triangle is path-coherent but its equalizer is all of \(\mathbb C^2\). Flatness alone does not raise scalar faithfulness.

## Boundary constraints

An independent reference or seam boundary map \(B:H_r\to Z\) can reduce the equalizer through

\[
Bx_r=0
\]

or through an affine normalization. Such a condition contributes only when it is not implied by the loop equations or tree transports.

## Quantitative completion gate

At cutoff \(N\), form the root residual stack

\[
F_N=
\begin{pmatrix}
L_N\\
H_{1,N}-I\\
\vdots\\
H_{b,N}-I\\
B_N
\end{pmatrix}.
\]

Finite scalar faithfulness on the equalizer is equivalent to injectivity of \(F_N\). Completion-stable faithfulness requires a cutoff-independent lower singular bound after the authorized gauge quotient.

## RH implication

A two-sheet or three-object theta/Tate network cannot gain faithfulness merely by duplicating a source state through invertible Fourier--Tate transports. It needs an independently authorized loop, seam, endpoint, or current equation whose fixed or kernel subspace removes a scalar-blind direction.

The decisive finite question is:

> What is the common fixed subspace of the actual source-derived sheet holonomies and boundary incidence maps, and is scalar Tate evaluation uniformly faithful on it?

## Verdict

Composition raises effective faithfulness only through genuine constraint incidence. Trees synchronize copies; cycles select common fixed states; boundary laws cut additional directions. Object count alone has no domain-reduction content.
