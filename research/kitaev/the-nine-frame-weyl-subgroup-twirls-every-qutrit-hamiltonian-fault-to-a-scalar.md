# The nine-frame Weyl subgroup twirls every qutrit Hamiltonian fault to a scalar

Owner: `marici.Kitaev`

## Bounded question

Does the finite braid-plus-cube-root gate group provide any exact protection
resource despite failing to be computationally universal?

Yes. It contains the nine-element projective qutrit Weyl group. Uniform
conjugation over those nine frames maps every qutrit operator to its normalized
trace times the identity. Under a quasistatic additive Hamiltonian fault and
ideal instantaneous frame changes, one complete cycle therefore removes every
non-scalar error at first Magnus order.

This is dynamical decoupling, not quantum error correction. It protects an
idle identity cycle under a typed slow-drift model. It does not correct pulse
faults in the Weyl gates or automatically protect a simultaneous target gate.

\[

`G(3,1,3)` gate group derived in the preceding packet.

## Exact operator-basis theorem

The Weyl operators are Hilbert--Schmidt orthogonal:

\[
\operatorname{Tr}
\left(
W_{ab}^\dagger W_{cd}
\right)
=
3\delta_{ac}\delta_{bd}.
\]

Hence every qutrit operator has a unique expansion

\[
E
=
\sum_{a,b}e_{ab}W_{ab}.
\]

Conjugation by a Weyl operator multiplies every nontrivial Weyl component by a
nontrivial character. Averaging all characters gives zero. Therefore the
uniform Weyl twirl is

\[
\mathcal T_W(E)
=
{1\over9}
\sum_{a,b}
W_{ab}E W_{ab}^\dagger
=
{\operatorname{Tr}E\over3}I.
\]

The twirl kills all eight traceless qutrit directions exactly. This is a
complete first-moment isotropization theorem, not a sampling heuristic.

## Quasistatic Hamiltonian-decoupling cycle

Let an idle protected qutrit experience an unknown constant Hermitian defect

\[
H_{\rm err}=E.
\]

Divide one control cycle into nine equal free-evolution intervals. In interval
`a,b`, toggle the carrier into frame `W_ab`, so the error Hamiltonian in the
toggling frame is

\[
E_{ab}=W_{ab}^\dagger E W_{ab}.
\]

Choose the frame-change pulses so the ideal control path closes at the end of
the cycle. The first Magnus term is proportional to

\[
\sum_{a,b}E_{ab}
=
3\operatorname{Tr}(E)I.
\]

It contributes only a global phase. Every non-scalar coherent drift is absent
to first order in the interval duration.

The next Magnus terms contain commutators

\[
[E_{ab},E_{cd}]
\]

and are generally nonzero. Shorter cycles suppress them; the exact convergence
bound depends on the error norm, pulse duration, and time dependence.

## What is and is not corrected

The theorem removes a quasistatic additive Hamiltonian during a declared idle
window under ideal frame changes. It does not establish any of the following.

- Correction of a stochastic fault occurring in one interval.
- Correction of an error acting during a nonzero-duration Weyl pulse.
- Protection against leakage outside the fusion qutrit.
- Protection of the fusion--wait--unfusion corridor that is needed to compile
  the continuous vacuum actuator.
- Preservation of an arbitrary target Hamiltonian applied during the same
  cycle.
- Exact cancellation of higher Magnus orders.

Ordinary topological syndrome and Weyl dynamical decoupling address different
fault classes. The former detects charge and local excitation errors. The
latter averages slow accepted logical drift that stays inside the code space.

## Target-gate compatibility

If a target Hamiltonian `H_tar` is left on during the uniform twirl, it is
averaged by the same map:

\[
\mathcal T_W(H_{\rm tar})
=
{\operatorname{Tr}H_{\rm tar}\over3}I.
\]

The desired logical action disappears with the error. A protected active gate
requires a covariant dynamically corrected sequence whose toggled target
accumulates while the fault cancels.

No such sequence is derived here. Idle decoupling cannot be promoted to gate
protection merely because both use the same frames.

## Common-mode frame behavior

Conjugating the entire Weyl subgroup by one fixed unitary produces another
unitary error basis and leaves the scalar-twirl theorem true. In particular,
global `G/H` conjugation replaces `Z` by `Z^{-1}` but does not change the set of
nine projective frames.

Thus an unoriented but stable magnetic character frame still decouples
arbitrary drift. Absolute logical-axis naming is not required for idle
protection.

By contrast, a time-dependent frame fault that changes the implemented Weyl
set within one cycle destroys the uniform character cancellation. Controller
redundancy must protect the schedule, while an independent actuator audit must
protect the actual phase gates.

## Relation to the primitive-overrotation obstruction

A nontrivial continuously driven logical Hamiltonian cannot have its own
arbitrary amplitude error exactly corrected by the same inner code: both the
command and the fault act inside the logical space.

The Weyl cycle does not contradict that obstruction. It protects an idle
identity by averaging an unwanted Hamiltonian through multiple frames. During
an intended vacuum-channel pulse, the same averaging would erase the command
unless a stronger dynamically corrected gate construction is supplied.

## Minimal apparatus assumptions

The exact decoupling target requires:

1. completed electric braids implementing the qutrit shift `X`;
2. an independently verified resolved magnetic cube-root phase implementing
   `Z`;
3. coherent frame composition and inverse pulses;
4. a cycle time short relative to drift variation;
5. bounded leakage and pulse error;
6. return to the protected storage geometry after the cycle.

The present source has the algebraic gates but not a fault-tolerant magnetic
phase corridor. The decoupling theorem is therefore conditional at the same
physical cut as the resolved bridge.

## Exact falsifiers

- The displayed `X,Z` failing the Weyl commutation relation.
- The nine Weyl operators failing Hilbert--Schmidt orthogonality.
- A traceless operator surviving the uniform conjugation twirl.
- First-order idle cancellation claimed without a closed toggling cycle.
- Higher Magnus terms claimed identically zero for arbitrary error.
- Pulse errors or leakage included in the theorem without an additional
  Eulerian or encoded construction.
- Uniform twirling claimed to preserve an arbitrary simultaneous target gate.
- Random `G/H` conjugation within one cycle called a harmless fixed frame.
- Algebraic Weyl membership promoted to a physically compiled decoupler.

## Result

The finite magnetic-braid gate group contains an exact nine-frame decoupling
subgroup. If those gates are cleanly executable, it removes every quasistatic
accepted qutrit Hamiltonian fault to first order during idle storage. This is
a real protection capability, but it neither corrects the magnetic bridge's
own faults nor protects the continuously driven vacuum gate required for
universal qutrit control.
