# Testers and equivalences form a Galois connection

## Bounded question

Can the relation between probe families and predictive quotients be made
canonical, so that redundant tests, missing contexts, and complete readout
packets are distinguished algebraically?

## Frozen experiment universe

Let \(X\) be a state set and let \(\mathcal U\) be a declared universe of
admissible tests

\[
t:X\to Y_t.
\]

Different tests may have different codomains. Only equality of their values is
used below.

For a test family \(T\subseteq\mathcal U\), define its indistinguishability
relation

\[
\operatorname{Eq}(T)
=
\{(x,y):t(x)=t(y)\text{ for every }t\in T\}.
\]

For an equivalence relation \(R\) on \(X\), define the admitted invariant tests

\[
\operatorname{Inv}_{\mathcal U}(R)
=
\{t\in\mathcal U:xRy\Longrightarrow t(x)=t(y)\}.
\]

These are exactly the admitted tests that descend through the quotient \(X/R\).

## Antitone Galois connection

Order test families by inclusion and equivalence relations by inclusion as
subsets of \(X\times X\). Then

\[
T\subseteq\operatorname{Inv}_{\mathcal U}(R)
\quad\Longleftrightarrow\quad
R\subseteq\operatorname{Eq}(T).
\]

The statement simply says: every test in \(T\) is constant on every \(R\)-class
exactly when every pair related by \(R\) is indistinguishable by \(T\).

Both maps reverse order:

- more tests produce a finer equivalence;
- a coarser state quotient admits fewer descending tests.

This is the canonical algebra behind port-relative equivalence.

## Tester saturation

Define

\[
\operatorname{Sat}_{\mathcal U}(T)
=
\operatorname{Inv}_{\mathcal U}(\operatorname{Eq}(T)).
\]

This is a closure operator on test families:

\[
T\subseteq\operatorname{Sat}_{\mathcal U}(T),
\]

it is monotone, and applying it twice changes nothing.

The saturation contains every admitted test whose value is already determined
by the distinctions made by \(T\). Adding a test from the saturation does not
refine the equivalence relation.

Thus there are two meanings of “new probe”:

- a syntactically new but saturated-redundant test;
- a genuinely refining test outside the saturation.

Only the second adds predictive information.

## Observational closure of a quotient

Define

\[
\operatorname{Obs}_{\mathcal U}(R)
=
\operatorname{Eq}(\operatorname{Inv}_{\mathcal U}(R)).
\]

Because the admitted universe may be incomplete,

\[
R\subseteq\operatorname{Obs}_{\mathcal U}(R).
\]

The observational closure merges every pair that no admitted quotient-respecting
test can separate. A relation is observationally closed when

\[
R=\operatorname{Obs}_{\mathcal U}(R).
\]

These are exactly the equivalences realizable as \(\operatorname{Eq}(T)\) for
some admitted test family \(T\).

If \(\mathcal U\) contains every Boolean-valued function on \(X\), every
equivalence relation is observationally closed. With a restricted physical
tester universe, many mathematically conceivable quotients cannot be resolved.

## Closed-pair theorem

The saturated test families and observationally closed equivalences correspond
order-reversingly:

\[
T=\operatorname{Sat}_{\mathcal U}(T)
\quad\Longleftrightarrow\quad
T=\operatorname{Inv}_{\mathcal U}(R)
\]

for the closed equivalence \(R=\operatorname{Eq}(T)\), and symmetrically

\[
R=\operatorname{Obs}_{\mathcal U}(R)
\quad\Longleftrightarrow\quad
R=\operatorname{Eq}(T)
\]

for the saturated family \(T=\operatorname{Inv}_{\mathcal U}(R)\).

This pair is the complete operational packet at the frozen tester universe:
all tests that descend through the quotient and exactly the distinctions those
tests can preserve.

## Constructor-context closure

Now freeze authorized constructors \(G_a:X\to X\). For a base readout family
\(T_0\), define its future-context closure

\[
\operatorname{Ctx}(T_0)
=
\{t\circ G_w:t\in T_0,\ w\text{ an authorized word}\}.
\]

The predictive equivalence generated by \(T_0\) is

\[
R_{\rm pred}(T_0)
=
\operatorname{Eq}(\operatorname{Ctx}(T_0)).
\]

It is automatically a constructor congruence. The context closure supplies the
counterfactual future tests; the Galois saturation then supplies every admitted
test redundant with the resulting predictive quotient.

These closures answer different questions:

- \(\operatorname{Ctx}\) adds tests obtainable by authorized operation order;
- \(\operatorname{Sat}\) adds all admitted tests carrying no new distinction.

Confusing them treats observational redundancy as executable construction, or
vice versa.

## Contextual completeness

A base readout packet \(T_0\) is contextually complete relative to a target
equivalence \(R\) when

\[
\operatorname{Eq}(\operatorname{Ctx}(T_0))=R.
\]

If the left side strictly contains \(R\), some desired distinctions remain
invisible to every admitted future context. If it is strictly smaller, the
packet distinguishes more than the proposed quotient retains.

A probe-enlargement theorem must therefore identify a test outside the current
saturation whose context closure splits a specified unresolved class.

## Finite separator bound

Let \(X\) be finite, and suppose a possibly large tester family \(T\) induces
\(q\) equivalence classes. A finite subfamily inducing the same partition can
be chosen greedily.

Start from one block. Whenever the current partition is coarser than
\(\operatorname{Eq}(T)\), choose a test in \(T\) that splits one current block.
Each choice strictly increases the number of blocks. Therefore at most

\[
q-1
\]

tests suffice.

This is an elementary upper bound, not always minimal. Finding the smallest
subfamily is a set-cover-like probe-compression problem.

## Information gain of a probe

Given the current equivalence \(R\), a candidate test \(t\) refines it to

\[
R'=R\cap\operatorname{Eq}(\{t\}).
\]

Raw finite information gain can be recorded without choosing a composite score:

- number and sizes of classes split;
- number of new classes;
- named source sectors separated;
- shortest constructor context required to realize \(t\);
- and experimental or computational cost.

A test in \(\operatorname{Inv}_{\mathcal U}(R)\) has zero partition gain. It may
still improve noise robustness through repeated or better-conditioned
measurement, which is a metric/frame question rather than equivalence
refinement.

## Toric-code instance

Let the base tests be local star and plaquette syndrome coordinates. Their
equivalence merges error chains differing by noncontractible cycles. Local
repair contexts do not refine that logical ambiguity.

Adding two independent noncontractible loop probes lies outside the saturation
of local syndrome and refines the readout to the four logical classes on the
smallest torus.

Any additional loop probe whose value is a function of those two logical bits
belongs to the saturation: it may be operationally useful or redundant against
noise, but it adds no new exact logical distinction.

The topology supplies the candidate probe family. The Pauli coefficient lens
supplies their commutation readouts and joint faithfulness.

## Polarizer instance

Endpoint intensity after one fixed polarizer word is one test. Allowing insertion
of intermediate polarizers enlarges the context family because ordered projector
products define new tests of the input polarization.

Two inputs equal under the original endpoint test may split under an inserted
context. Once the induced input partition is fixed, another analyzer producing
only a function of the same classes is saturated-redundant.

Loss and conditioning determine robustness and cost; they do not change the
exact Galois relation unless zero/nonzero distinctions themselves change.

## Software instance

An API read model supplies a base tester family. Future commands followed by
queries generate its constructor-context closure. Two domain states can be
merged exactly when this closure cannot distinguish them, subject to separate
audit and safety authority.

Adding an endpoint that merely reformats existing response fields is saturation,
not predictive enrichment. Adding an audit or provenance query outside the old
saturation refines the operational equivalence—provided the underlying data was
retained and the new port is authorized.

## Quantum tester universe

For quantum states, tests are effects and equality means equal state–effect
pairings. A tomographically complete effect universe makes observational
closure coincide with density-operator equality. A restricted effect algebra
induces a coarser operational quotient.

For channels or combs, the tests are superchannel or tester functionals. The
same Galois construction applies to their real vector spaces, while positivity,
causality, and reference access determine the admitted universe.

The theorem is set-theoretic; the coefficient lens determines which tests are
physically meaningful and how their values compose.

## DPC: closed experiment packet

The conjecture is:

> A mature operational theory should publish a Galois-closed pair: the
> predictive equivalence it claims and the saturated source-authorized tester
> family supporting that equivalence. A proposed new probe advances the theory
> only if it lies outside current saturation, improves robustness under a named
> metric, or opens a separately authorized interface.

The Galois statements are exact. The source problem is establishing the tester
universe and constructor-context closure without importing desired probes after
seeing the ambiguity.

## Critics

### Saturation may be enormous or uncomputable

Correct. It is a semantic closure. Finite bases, symbolic representations, and
source invariants are separate compression results.

### A redundant test can be experimentally valuable

Correct. Exact partition redundancy does not imply zero Fisher information,
conditioning value, fault-detection value, or implementation advantage.

### Test values can be probabilistic rather than deterministic

Correct. Use equality of complete probability functionals. Approximate
equivalence requires a metric and does not automatically form a quotient.

### Constructor contexts may not all be executable

Correct. \(\operatorname{Ctx}\) must use only source-authorized words with the
declared domain, cost, and loss semantics.

## Exact falsifiers

- A test called informative while it is constant on every current equivalence
  class and no robustness criterion is supplied.
- A quotient through which an admitted test does not descend.
- A claimed observationally closed relation strictly refined by an admitted
  invariant test.
- A context closure containing an unauthorized constructor word.
- A Galois-closed packet that omits an admitted test constant on its quotient.
- A finite separator family inducing fewer or more classes than claimed.
- Exact redundancy confused with statistical or fault-tolerance redundancy.
- A tester universe enlarged after observing ambiguity without recording the
  interface change.

## Deutschian explanation

Tests and equivalences determine one another only after the admissible experiment
universe is frozen. A quotient says which substitutions are harmless; its
invariant tests are exactly the questions that survive those substitutions.

The closed pair explains both absence and sufficiency. Missing distinctions are
absent because every authorized question is constant on their class. A new probe
matters because it breaks that constancy. Redundant probes remain inside the
same saturation and cannot change the exact predictive carrier.

## Claim boundary

This packet proves the set-theoretic Galois connection, closure operators, and
finite separator bound. It does not derive a sector's physical tester universe
or optimize noisy experiments.
