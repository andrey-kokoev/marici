# Conormal phase response requires a source-fixed gauge

## Claim boundary

The first conormal derivative of a doubled wavefunction is a phase-gradient connection. It is not determined by the projective wavefunction line. A mixed temporal–conormal response is therefore unauthorized until a physical period, cycle, or other source constructor fixes the relevant phase gauge.

This packet establishes the local gauge law and its smallest falsifier. It does not construct the required physical normalization.

## Doubled kernel

Let

\[
D(\Phi,\delta)
=
\Psi(\Phi+\delta/2)
\overline{\Psi(\Phi-\delta/2)}.
\]

At \(\delta=0\),

\[
D(\Phi,0)=|\Psi(\Phi)|^2.
\]

Differentiating in the branch-difference direction gives

\[
\left.\partial_\delta D\right|_{\delta=0}
=
\frac12\Psi'\overline\Psi
-
\frac12\Psi\overline{\Psi'}
=
i\,\operatorname{Im}(\Psi'\overline\Psi).
\]

Where \(\Psi\neq0\), the source-normalized conormal jet is

\[
J_\Psi
=
\frac{\left.\partial_\delta D\right|_{\delta=0}}
{D(\Phi,0)}
=
i\,\operatorname{Im}\!\left(\frac{\Psi'}{\Psi}\right).
\]

## Gauge transformation

Under a nonvanishing rescaling

\[
\Psi\longmapsto \widetilde\Psi=f\Psi,
\]

the normalized jet transforms as

\[
J_{f\Psi}
=
J_\Psi
+
i\,\operatorname{Im}\!\left(\frac{f'}{f}\right).
\]

Therefore the projective line of \(\Psi\) does not determine \(J_\Psi\).

The harmless rescalings are exactly those with zero local phase gradient:

\[
\operatorname{Im}(f'/f)=0.
\]

Positive-real rescalings satisfy this condition. So do nonzero constant phases and, more generally, rescalings whose phase is locally constant. Positivity is sufficient but not necessary.

## Smallest gauge falsifier

At one base point, choose jets

\[
\Psi=1,
\qquad
\Psi'=i,
\qquad
f=1,
\qquad
f'=2i.
\]

Then

\[
J_\Psi=i,
\qquad
J_{f\Psi}=3i.
\]

The projective state is unchanged at the base point, yet the conormal response changes. Any proposed construction using only the projective line must assign the same value to these two presentations and is therefore falsified.

## Mixed-grade consequence

Let \(E\) denote the temporal or Stokes normal. A coefficient extracted from

\[
\partial_E^p J_\Psi
\]

inherits the same gauge problem unless the source normalization controls the \(E\)-dependence of the phase. In particular, a candidate \(E^2\delta\) class cannot be admitted merely because the formal mixed derivative exists.

The correct order is:

1. construct the physical period or cycle;
2. derive its normalization and allowed residual gauge;
3. verify that the conormal jet descends under that residual gauge;
4. only then expand in the temporal normal and inspect mixed grades.

## Finite descent gate

For a proposed normalization family \(\mathcal G_{\mathrm{res}}\), compute

\[
g_f=i\,\operatorname{Im}(f'/f)
\]

for every admitted residual rescaling. The conormal jet descends exactly when

\[
g_f=0
\]

throughout the declared domain.

One nonzero residual gauge shift disproves descent and blocks every mixed coefficient built from that jet.

## Disposition

The doubled construction exposes phase response, but it does not normalize itself. The durable conclusion is:

> A conormal phase jet is connection data. It becomes an observable only after a source-derived gauge constructor makes it invariant under the admitted residual rescalings.
