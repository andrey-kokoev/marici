# The canonical omega self-modeling completion

## Construction

Start with a finite strict typed dependency graph \(X_0=X\) and iterate the
already defined endofunctor:

\[
X_0\xrightarrow{\eta_0}X_1=\mathsf U(X_0)
\xrightarrow{\eta_1}X_2=\mathsf U^2(X_0)\longrightarrow\cdots.
\]

Every \(\eta_n\) is the canonical induced-subgraph inclusion. Define

\[
X_\omega=\operatorname*{colim}_{n<\omega}X_n
          =\bigcup_{n<\omega}X_n.
\]

This uses no fitted saturation and introduces no new morphism type. It is the
free term tower generated by repeated applications of the same strict
self-modeling operator.

## Normal form

For one base node \(x\), nodes at depth \(n\) have words in the alphabet
\(\{m,r\}\) of length at most \(n\):

\[
w x,\qquad |w|\le n.
\]

For every existing word \(w x\), the next stage contains

\[
mwx\xrightarrow{\rm models}wx,
\qquad
rwx\xrightarrow{\rm classifies}mwx.
\]

Consequently, for a one-node base,

\[
|X_n|=2^{n+1}-1,
\qquad
|E_n|=2(2^n-1).
\]

The reflection deficit at every finite stage is exactly its frontier:

\[
\delta_n=2^n.
\]

Thus finite completion never finishes. It moves every unresolved reflection
obligation one level outward while resolving all previous levels.

## Omega closure

Every node of \(X_\omega\) is a finite word \(wx\). Its witnesses \(mwx\) and
\(rwx\), with both required edges, occur one finite stage later. Therefore
every node has a reflection witness in the union.

Moreover, applying \(\mathsf U\) to the union adds no new node or edge: the
prefixes \(mw\) and \(rw\) already belong to the set of all finite words.
Hence, for this canonical presentation,

\[
\boxed{\mathsf U(X_\omega)=X_\omega}
\]

literally, not merely by cardinality or an untyped bijection.

This is the first exact fixed-point result for the finite self-modeling
operator. It is a theorem about the formal typed-graph construction, not yet
about the physical Marici Carrier.

## What is and is not universal

The tower is canonical from \(X\). It is free as a term-generated completion:
no witnesses are selected from an external target. A universal mapping
property into arbitrary reflection-complete graphs would require those target
graphs to carry **chosen** reflection witnesses; without choices, extensions
need not be unique. We therefore do not yet call \(\mathsf U\) a monad or
\(X_\omega\) a final coalgebra.

## Interpretation

Three regimes now separate cleanly:

1. an ordinary finite system is not reflection-complete and does not split;
2. a hand-saturated finite system can split if it already contains witnesses;
3. canonical iteration never completes at finite depth but reaches an exact
   fixed point at the omega union.

Metaphysically, complete self-absorption is not a finite achievement. Every
finite act of reflection creates a new frontier, but the union of all finite
reflection depths is closed under one further act of the same kind.

The next falsifier is structural: test whether the fixed point persists when
the model carries nontrivial higher coherence, source authority, and
obstruction cells rather than only two generated edge roles.
