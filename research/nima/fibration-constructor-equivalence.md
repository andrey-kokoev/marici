previous complete-package system. This is checked for all eight constructor
forms and at every universe level. It retains the original Code directly.

This target is richer than the bare three-column regrouping kernel. In
particular, Pi is interpreted by sections, not by simply grouping the other
endpoint. This work does not supply a serialization of the original Code into
only the three columns, or an independent implementation of all resolution
rules using regrouping alone.

The distinction is necessary to state what was actually proved.

## The constructor dictionary

For a dependent family F over I, form the display map

\[
R=\sum_{i:I}F(i),\qquad p:R\to I,\qquad p(i,x)=i.
\]

An actual incidence table has rows R, label r, from-label p(r), and to-label r.
The typed row address in the last column ensures endpoint-pair uniqueness.
Grouping by from exposes

\[
\operatorname{Fiber}(i)=\sum_{r:R}(p(r)=i).
\]

The checked dictionary is

\[
\sum_{i:I}F(i)\simeq\sum_{i:I}\operatorname{Fiber}(i),
\]

\[
\prod_{i:I}F(i)\simeq\prod_{i:I}\operatorname{Fiber}(i).
\]

The first target consists of total rows. The second consists of sections:
a compatible choice of one row over every index. These are different uses of
the same fibration, not simply its two endpoint groupings.

The fiber equivalence transports a row value along its membership path. Its
inverse laws retain that path; there is no conversion to mere inhabitation.

For the old complete input family, the selected E value maps to its canonical
fiber row, and the selected Pi value maps to its canonical section. Both selected
value equations are proved by `refl`.

## Boundaries, derivations and operations

The previously checked comparison question has type

\[
K(a,b)=\sum_{e:A_a\simeq A_b}(e(v_a)=v_b).
\]

The bridge proves equivalence of this actual filler type with the corresponding
filler type for encoded packages. Composition of fillers commutes with the
translation by a checked path. Package path spaces also transfer by equivalence.

For every original rule, all encoded input and output packages roundtrip. For
every seed family S, the existing closure is equivalent to its transported
family over encoded packages:

\[
\operatorname{Closure}(S)
\simeq
\sum_{v:Q_{\mathrm{fib}}}
\operatorname{Resolve}(S,\operatorname{decode}(v)).
\]

This transports the original derivation theory; it does not replace its twelve
schemas by a new graph execution engine. Separately, encoding a reified original
derivation retains that actual derivation by `refl`. In this statement the
original derivation remains the atom payload used by `reify-history`.

For any original readout f, a generic theorem proves

\[
f(\operatorname{decode}(\operatorname{encode}(q)))=f(q).
\]

That justifies transporting a given readout. It does not establish equality
with a separately proposed new readout without its own comparison proof.

## The Boolean law is exercised through the bridge

`FibrationSigmaPiBridge.agda` defines a table NAND using sections of empty
fibers over the product of its input types:

\[
N_{\mathrm{fib}}(A,B)
=\prod_{z:A\times B}\operatorname{Fiber}_{\pi_1}(z),
\qquad
\pi_1:\sum_{z:A\times B}\mathbf0\to A\times B.
\]

The generic section equivalence gives

\[
N_{\mathrm{fib}}(A,B)\simeq((A\times B)\to\mathbf0).
\]

The complete Wolfram word built with this operation is then proved equivalent
to double negation of C, by an operation-level path and the existing theorem:

\[
W_{\mathrm{fib}}(A,B,C)\simeq\neg\neg C.
\]

For a stable proposition C it is equivalent to C. The previous restriction is
preserved: the unrestricted claim for an arbitrary value type C is not made.

## Three guards against an overbroad equivalence claim

**Regrouped rows are not Pi values.** For two indices with one value each, the
row type has two values and the product has one. Agda proves they cannot be
equivalent. In the incidence table above, taking sections at the address
endpoint also fails in general: that endpoint is identity on rows, so its
section space is contractible, whereas the intended product can have several
values.

**Empty rows do not determine an active index domain.** An empty index family
and a one-index family with an empty fiber both have empty row types. Their
section types are different: the former has its empty section and the latter
has none. An explicit row equivalence and a proof of section inequivalence are
checked. This retained domain information is essential to NAND.

**Value-only tables do not recover construction metadata.** An atom of function
type and a maps constructor can have definitionally identical value types,
selected values and incidence tables while their complete packages are unequal.
The module proves no inverse recovers both through that value-only encoding.
This does not exclude a graph encoding that also retains the constructor code.
