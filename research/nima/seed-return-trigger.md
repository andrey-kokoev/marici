# The actual four-edge seed cycle can supply the return trigger

## Recovered prior routing

`seed-endpoint-sections-and-unique-return-cycle.md` already proves that the six-arrow seed has exactly one simultaneous source/target section under the declared one-in/one-out cover criterion:

    A -> D -> B -> C -> A.

This criterion is an explicit routing objective, not a physical law inferred merely from the existence of the seed. AB and BA remain in the retained source; they are not deleted because the selected routing does not use them.

## Conditional controller construction

Mark the initial vertex A. Each controller step follows the selected occurrence. When its target is the marked root, invoke the previously checked reference-flip/exchange operation. Otherwise the numerical reference and body state are unchanged.

The resulting event pattern is false,false,false,true. It is computed from the pointed cycle, rather than supplied as a separate stream of timed flip instructions. The operation chosen for that event—flip one reference, then exchange—is still an explicit coupling hypothesis. No payload action is inferred for the intermediate primitive edges.

Given the routing, mark and return action, this is a deterministic autonomous discrete controller. It is not a source-selected physical clock or a proof that every witnessed return must execute that action.

## Checks

- Recover the unique cover directly from the original PACKETS, not from a manually supplied cycle list.
- Check all 24 vertex renamings, transporting the root with the labels.
- Check inverse recovery for all controller phases, all reference sign states and all twenty numerical basis states.
- Check the coefficient budget on every tested step.
- Trace the ordinary and twisted preparations through twelve primitive traversals, producing exactly three body-response events.
- At every root return, compare with the independently executed prior controlled-response function.
- Retain every parent state and occurrence; reverse each trace exactly.

The three-response bound matches the preceding retained-state trials. No additional twelve-response execution is admitted by the separate matrix-period theorem. Numerical response periods, primitive traversal counts and physical time remain distinct.

## Disposition

The trigger now has a concrete relationship to the user's proposed four-cycle return to its starting vertex. It need not be supplied as an independent metronome once this routing policy is chosen.

The unsolved part is what the return is authorized to DO: the current controller attaches an existing reference operation and exchange as a declared response. It has not derived that coupling, its initial reference, a physical metric, or gravitational coefficients from the path data. It also does not make the controller's chosen route into a filled tetrahedral face equality.

This is a checked conditional assembly of recovered source constructions, not a claim that the entire Machian mechanism is now forced by WG.

## Follow-up: the trigger does not derive the intervention

`tetrahedral-return-transport.md` proves that ordinary dependent transport around the corresponding already-filled tetrahedral boundary returns any reference unchanged. The flip used here is therefore an additional active operation on the retained state, not automatically the transport effect of completing that boundary.
