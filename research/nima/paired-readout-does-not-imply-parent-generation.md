# Paired Readout Does Not Imply Parent Generation

Three sectors now support the common form

\[
\mathcal C_S\otimes\mathcal B_S\longrightarrow\mathcal R_S.
\]

This does not imply that the shared Carrier uniquely generates
\((\mathcal C_S,\mathcal B_S)\).

The existing evidence points the other way:

1. **Cosmology.** The five-site Kummer system contains 32 coefficient sheets
   and a 32-element Betti orbit.  The source selects a local chamber vector;
   the Carrier does not collapse the two regular modules to one preferred
   pair.
2. **Five-point strings.** The Parke--Taylor class and oriented chamber have
   separately nontrivial reflection signs.  At general arity, the combined
   scalar character admits multiple coefficient/Betti factorizations until
   the source transports both factors independently.
3. **Radiative gravity.** The detector \(f\) is a variable
   supertranslation test function.  Holding it fixed while transporting the
   memory field fails, whereas transporting both factors succeeds.  The
   Carrier does not choose one universal detector.

Therefore the supported inference is

\[
\boxed{
\text{shared calculus of admissible pairings}
+
\text{sector/source-supplied paired objects}.
}
\]

The stronger parent-object hypothesis would require a new construction
functor

\[
\mathfrak P
\longmapsto
(\mathcal C_S,\mathcal B_S,\langle-,-\rangle_S)
\]

whose output is canonical up to declared equivalence and whose sector
specializations reproduce the sourced pairs.  No such functor has been
constructed.

This leaves open a larger parent object that includes physical source data.
It rules out only the inference that the currently frozen Carrier and
calculus, by themselves, already generate the multiplicity of sector
experience.
