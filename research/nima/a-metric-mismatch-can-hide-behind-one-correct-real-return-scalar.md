# A metric mismatch can hide behind one correct real return scalar

## Question

Can agreement of one real radial return distinguish the analytic transpose from a Hermitian adjoint formed in an undeclared G4 metric?

## Claim boundary

No. A two-dimensional exact hostile has a real synthesis and one correctly matched real return scalar while its Euclidean analytic transpose differs from its target-metric Hermitian adjoint. The equality proved in the radial source metrics therefore cannot transfer to G4 from scalar agreement.

## General finite formulas

Let

\[
U:V\to H
\]

be represented by a real matrix. Give \(V\) and \(H\) positive Hermitian Gram matrices \(G_V\) and \(G_H\). The metric adjoint is

\[
U^{*_{G}}
=G_V^{-1}U^*G_H.
\]

If the analytic transpose is formed in the retained Euclidean bilinear frames, then

\[
U^\top=U^{\mathsf T}.
\]

These returns agree exactly when

\[
G_V^{-1}U^{\mathsf T}G_H=U^{\mathsf T},
\]

or equivalently

\[
U^{\mathsf T}G_H=G_VU^{\mathsf T}.
\]

This is a metric intertwining identity, not a consequence of real matrix entries.

The predecessor theorem uses bilinear forms associated with the same Real-compatible Hermitian metrics. In that setting the metric factors are part of the transpose definition and the Real synthesis gives

\[

\]

The hostile changes the target metric while leaving the Euclidean analytic frame fixed. It models precisely the unresolved G4 situation: the source metric is known, but the target metric and its comparison are absent.
