# The full oriented radial feature is faithful while its codiagonal needs a separate kernel audit

## Question

Can the six-coordinate oriented radial feature itself create the Green radical that G4 is expected to quotient?

## Claim boundary

Not on the rapid radial graph when the endpoint, endpoint-source, and Wronskian coordinates are retained as complete entire Laplace families. Those data recover each oriented graph state, so the full feature map is injective. A nonzero radical can appear only after applying a nonfaithful metric, quotient, or codiagonal. Whether the fixed bilateral codiagonal has a kernel on the source-generated subspace is a separate question and cannot be inferred from its ambient linear kernel.

## One oriented graph

Let

\[
x=(\rho,e,w,\rho(0))
\]

satisfy

\[
D_t\rho=e-\frac12w
\]

in the rapid radial space. Define the complete feature

\[
Jx=
\left(
\rho(0),
E(\,\cdot\,),
W(\,\cdot\,)
\right),
\]

where

\[
E(z)=\mathcal L_z e,
\qquad
W(z)=\mathcal L_z w
\]

are retained as entire functions, not evaluations at one parameter.

## Faithfulness

Suppose \(Jx=0\). Then

\[
E(z)=0,
\qquad
W(z)=0
\]

for every \(z\). Injectivity of the Laplace transform on the rapid source gives

\[
e=0,
\qquad
w=0.
\]

The graph law then gives

\[
D_t\rho=0.
\]

Thus \(\rho\) is constant on its oriented half-line. Rapid decay forces that constant to vanish; the retained endpoint agrees:

\[
\rho=0.
\]

Therefore

\[
\ker J=0.
\]

The same argument applies to the opposite orientation.

## Doubled feature

For the two oriented graph states, define

\[
J_{\rm or}(x_+,x_-)
=
\bigl(
-\rho(0),E_+,W_+;
+\rho(0),E_-,W_-
\bigr).
\]

Each component is faithful, and the directed wall pair retains the common endpoint with opposite incidence signs. Hence

\[
\ker J_{\rm or}=0
\]

on the doubled rapid graph.

If a positive definite feature metric is pulled back through \(J_{\rm or}\), its radical is zero. Any claimed nonzero G4 radical must therefore arise from a later feature metric with null directions, an explicit gauge relation, a mixed Green form, or compression of this feature.

## Codiagonal distinction

The bilateral readout is

\[
D(E_+,W_+;E_-,W_-)
=E_++E_--\frac12(W_++W_-).
\]

As a linear map on the ambient six-coordinate feature carrier, \(D\) is not injective: it forgets wall coordinates and retains only one combination of four entire response coordinates. Therefore

\[
\ker D\ne0
\]

on the ambient feature space.

This does not by itself prove a nonzero kernel on the source-generated graph range. The graph law, half-line support, reflection transport, and ordered-pair constraints may eliminate some ambient null directions. The relevant radical is

\[
igl(\operatorname{ran}J_{\rm or}\bigr)
\cap\ker D,
\]

which requires an explicit source-range audit.

## G4 conformance consequence

G4 must state whether its Green form is built from:

1. the faithful full oriented feature \(J_{\rm or}\);
2. a metric on that feature with declared null directions;
3. the codiagonal \(D J_{\rm or}\);
4. another feature map with a separately identified kernel.

Only cases 2--4 can supply a nonzero radical. Calling the full oriented source feature degenerate without exposing one of those later operations is false.

## Direction rescore

- Faithfulness of the full oriented radial feature: completed.
- Radical of a positive pullback feature metric: zero.
- Ambient codiagonal kernel: nontrivial.
- Codiagonal kernel on the source-generated graph: 8/10; requires exact source-range constraints.
- Identification with G4's radical: interface-blocked.

## Disposition

The six-coordinate radial packet is a faithful feature, not a quotient. Radical descent begins only after G4 declares a metric, gauge relation, or codiagonal and proves its kernel on the actual source range. The next local calculation is the source-range kernel of the fixed bilateral codiagonal; G4 comparison remains blocked until its feature placement is exposed. No RH conclusion is authorized.
