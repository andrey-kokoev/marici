# qRB microstep 126: endpoint projective bonding

For a finite pair packet `F` and endpoint levels `b_1 <= b_2`, define the endpoint row

$$
 e_{F,b}(n,m)=\int_0^b e^{-\pi(n^2+m^2)x^2}\,dx.
$$

The projective bonding map is coordinate restriction from the larger retained endpoint graph to the smaller finite pair packet. It preserves each existing coordinate exactly; it does not assert that the numerical row at `b_2` equals the row at `b_1`.

This distinction prevents confusing projective compatibility with endpoint-value invariance. The endpoint parameter is part of the boundary object and must remain typed.
