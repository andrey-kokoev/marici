# A native-admitted transition query, selected by its stated task

## Concrete operation, not another numerical carrier

The prior `RetainedComparisonSeries` already evaluates the actual retained
filler and proves agreement with its native-table translation. The new
`agda/NativeSeedTransitionProbe.agda` applies that architecture to the ACTUAL
Vertex type from `SeedAttachedObserver`.

For a supplied vertex equivalence e, a prepared source x and queried target y,

    transition(e,x,y) = [equivFun(e,x) == y].

The module forms the genuine `BoundaryGeneratedQuestions.Filler` from the
complete package prepared(x) to prepared(e(x)), including its marked-value
attachment. It evaluates that SAME filler through
`NativeTableRegression.actual-filler-equivalence` and proves that the answer
agrees. It also proves retention preserves the answer and composition gives
the corresponding sequential transport query.

This is a native-admitted OBSERVATION of a supplied transport, not yet an
interaction or physical detector. The prepared package names its marked
vertex; it does not prepare a nonzero oscillator amplitude.

## Exact source attachment

The two triangle permutations ABC and ADB are constructed as equivalences of
the actual four-vertex source, fixing the unused vertex. Six equalities bind
their nontrivial branches to the actual seed edge targets. This does not make
each primitive arrow a global equivalence, nor identify distinct path histories.

Crucially these are fillers BETWEEN changing pointed packages. A permutation
moving x cannot be silently declared a pointed automorphism of prepared(x).
The type of the constructed attachment records that distinction.

## What this selects

For the explicit task "where does the retained transport send x?", the
old directed-transition probe `1[g(x)=y]` is its actual Boolean query table.
The checker binds all 72 seed-role/group-element entries to the existing
probe dictionary and the source-extracted twelve-element group.

The alternative endpoint-fixing query is NOT another realization of this
same task. On the identity and the seed edge AB it answers true, whereas
the transition query answers false. The formal module proves that mismatch;
the checker verifies it on all six off-diagonal seed roles. On ABC the
native A-to-B transition query is true while fixing A and B is false.

Thus there is now a source-attached, task-relative way to choose the directed
probe. We are no longer choosing it because it produces a desired response.

## What this does not select

Native admissibility of the query does not show that nature performs this
task instead of another admitted task. It does not choose uniform counting,
unit normalization, physical energy pairing, record preparation, the exchange
event law, pulse duration, charge coupling, masses or detector calibration.

The preceding source-group ambiguity remains correct without this stated
task. It is refined, not contradicted: after specifying actual transport
interrogation, endpoint-fixing is excluded as the wrong question. A physical
interpretation must still justify that task and its instrument/back-action.

The existing exchange apparatus could conditionally implement a selected
probe, but its update is not derived by evaluating this native Boolean query.
Do not conflate the newly proved observer with an autonomous impulse law.
