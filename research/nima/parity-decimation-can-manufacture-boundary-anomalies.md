# Parity decimation can manufacture boundary anomalies

## Cross-sector pattern

Strominger's full-depth audit shows that restoring omitted odd pole depths
collapses a large parity-decimated current quotient to width one or two.
Grothendieck's Hardy audit shows that two aggregate half-line readouts vanish
identically at every scalar zero. Together they identify the wrong abstraction:
discarding mediator grades and retaining only aggregate boundary values can
manufacture apparent anomaly classes while erasing the label-sensitive current
that decides whether they are genuine.

## Minimal complex

Let the visible even sector be

\[
C_0=\langle e_0,e_1\rangle
\]

and let the odd mediator sector be

\[
C_1=\langle z\rangle.
\]

Define

\[
dz=e_1-e_0.
\]

In the full complex, \(e_0\) and \(e_1\) represent the same quotient class,
so \(H_0\) has rank one.

If the odd mediator is deleted, the differential disappears and the two even
currents become independent. The decimated quotient has rank two. The extra
class is an alias created by deleting the relation carrier.

## Survival criterion

A proposed boundary anomaly is authentic only if its class remains nonzero
after restoring every source-authorized mediator grade and incidence map.

Equivalently, compute the class in the full typed complex before projecting to:

- even depths;
- scalar half-line aggregates;
- endpoint-only data;
- primitive-only or square-only channels;
- a finite presentation that omits completion mediators.

If the class becomes a boundary in the restored complex, it was a
decimation artifact.

## RH consequence

The scalar Hardy cross-current cannot be the missing RH anomaly because the
zero equation kills it identically. Any surviving current must retain the
label-sensitive primitive, square, and archimedean continuation sectors.

The immediate audit is:

1. build the full graded incidence complex;
2. include both parity cosets and all declared boundary mediators;
3. locate the candidate reciprocal-odd class;
4. test whether it survives the restored differential;
5. only then compute its Klein-four character and completion behavior.

This order matters. A character assigned before mediator restoration may type
an alias rather than a source class.

## Finite falsifier

For any claimed anomaly represented by \(k\), find an omitted mediator \(z\)
with

\[
dz=k.
\]

That single incidence relation disproves the anomaly claim in the full source
complex.
