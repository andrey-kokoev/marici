# The endpoint-depth observer scale is a continuous contragredient module

## Result and scope

Outer source actions and their prescribed Green mates preserve the combined endpoint-radius/depth-moment observer scale. The mate actions make its observer differential complex a continuous conjugate-opposite source representation. The paired attachment and fixed finite normalization squares are compatible with these actions.

This concerns the typed coefficient seam carriers. It does not multiply independently prepared root states, identify a scalar continuous dual with Hom into the source algebra, or prove a perfect-duality equivalence.

## 1. Combined all-order scale

A normal-form shape has outer endpoint length n, total seam factor count r, active edge count k and feature count m. Keep them distinct. Define

`O_(R,s,b,q)(y)=sum_shapes R^n (1+r)^q b_s(k) b^m ||y_shape||_raw`,

where R,s,b>=1, q>=0, and b_s(k)=(2 lambda s)^k k!. Take the intersection over integer parameters. All slot multipliers, signatures and endpoint labels are unchanged.

The weighted l1 intersection is complete and finite endpoint/depth/feature support is dense in each finite collection of seminorms. The existing all-depth estimate, with n absorbed by doubling R, gives

`O_(R,s,b,q)(d^sharp y)
 <= lambda^2 s O_(2R,s,b,q+2)(y)`.

The forward differential retains its bound 1/s. Insert the declared cochain-dual sign to obtain the observer differential delta_O. It is continuous and squares to zero. Thus this is an explicit all-order subcomplex of the representable-mate graph complex.

## 2. A fixed source word changes only the outer coefficient buffer

Let w be a composable marked path of length l with d retained events. Its terminal record is the ordered tensor of its d actual analytical feature letters; forgotten events contribute vacuum and retain their endpoint transport. Put

`M(w)=product_(retained e in w) tau ||g_e||`.

Choose A>=1 with tau||g_e||<=A uniformly. Then M(w)<=A^l.

Left source action concatenates rho(w) into the first coefficient buffer; right action uses the last buffer. On every admissible input shape it:

- increases outer event length by l;
- increases total feature count by d;
- leaves r and k unchanged.

Incompatible endpoints give zero. Fixed homogeneous tensor concatenation has norm M(w). Therefore either outer action satisfies

`O_(R,s,b,q)(L_w y) <= R^l b^d M(w) O_(R,s,b,q)(y)
 <= (R b A)^l O_(R,s,b,q)(y)`.

No source path is inserted into a seam slot and no additional root factor is produced.

## 3. The mate is a fixed contraction, not a sum over cuts

The Green mate removes that specified outer endpoint transport and contracts exactly the d feature slots contributed by w. If the buffer is too short or has incompatible types, the result is zero.

For one retained letter g, on a homogeneous memory buffer its mate is the prescribed signed contraction, with the memory-weight factor tau^2. In tensor coordinates this is tau^2 times contraction against g through the fixed signature J. Its positive Hilbert operator norm is tau||g||, the same as creation, since J has norm one.

For a word, the operator norm is at most M(w). The mate decreases n by l and m by d, leaving r,k fixed. Hence

`O_(R,s,b,q)(L_w^sharp y)
 <= R^(-l) b^(-d) M(w) O_(R,s,b,q)(y)
 <= A^l O_(R,s,b,q)(y)`.

The right action has the analogous suffix contraction. There is no incidence or word-splitting multiplicity: w fixes the transported endpoints, the contraction side and the number of contracted slots. This is precisely what differs from a differential mate or a normalization mate.

The formula uses the admitted untruncated homogeneous carrier. It is not an assertion that inclusions between arbitrary truncated capacities intertwine creation on top-degree states.

## 4. Which completed source acts

For a source coefficient family x define

`a_C(x)=sum_w (C A)^(length(w)) |x_w|`, C>=1.

The all-radius intersection S_exp is the common exponential path source, equivalently allowing any fixed polynomial path weight after radius enlargement. Its multiplication is continuous, since event lengths add and the l1 convolution bound is valid at each exponential radius. No global infinite vertex identity is adjoined.

Summing the word estimates gives

`O_(R,s,b,q)(L_x y) <= a_(R b)(x) O_(R,s,b,q)(y)`,

`O_(R,s,b,q)(L_x^sharp y) <= a_1(x) O_(R,s,b,q)(y)`.

The same holds on the right. Noninteger source radii are rounded upward. These estimates prove absolute convergence of the operator sums and joint continuity of both actions on the indicated intersections. The factorial source is a continuous subalgebra of this acting source; factorial control is not required merely for outer coefficient action.

There is also an actual-letter version. With gamma_e=sqrt(w_seam)||f_e||_beta and Gamma(w) its product, choose kappa=max(1,lambda C_feature). Then M(w)<=kappa^l Gamma(w). The same proofs give

`O(L_x y) <= Q_(ceil(R b kappa))(x) O(y)`,

`O(L_x^sharp y) <= Q_(ceil(kappa))(x) O(y)`.

Here Q includes its existing factorial factor, which only strengthens these inequalities. Thus the declared actual-letter coefficient algebra acts as well. This uses direct word estimates, not an unproved Gamma-weighted relation-factorization theorem.

## 5. Contragredient module and chain identities

The mate reverses products and conjugates source scalars:

`L_(xz)^sharp=L_z^sharp L_x^sharp`,

`L_(alpha x)^sharp=conjugate(alpha) L_x^sharp`.

Left and right mate actions commute in the corresponding opposite order. These are the conjugate-opposite actions, not opposite-history creation. The source relation ideal acts by zero on the outer terminal-record actions and hence on their mates; the same holds for its closure in each declared acting source domain.

The primal differential commutes with the primal outer action. Taking the finite Green transpose gives commutation of delta_O with the mate action. All these identities extend by density and the estimates above.

One must not interchange these assertions: no claim is made that primal creation itself commutes with the observer differential. The observer chain representation is the contragredient one.

The identity

`beta(L_x^sharp y)=L_x^vee beta(y)`

is now an identity of continuous maps on this explicit observer space, with the strong scalar-dual topology used in the earlier attachment square. Therefore the transposed attachment square is compatible with the continuous source actions, rather than merely a square of unstructured scalar complexes.

The primal attachment remains an extension roof. An I-annihilated outer target action does not turn its nonsplit source middle object into a direct sum of graded modules.

## 6. Normalization compatibility

For one artificial-cut removal, the existing bounds remain valid with (1+r)^q: r is preserved. Thus

`O_(R,s,b,q)(N y)<=O_(R,s,b,q)(y)`,

`O_(R,s,b,q)(N^sharp y)<=O_(2R,s,2b,q)(y)`.

Every fixed finite diagram follows by iterating these losses. Balanced associators preserve the same counts. Since normalization intertwines primal outer actions, its mate intertwines the corresponding contragredient actions. The finite identity follows by Green transposition; the completed identity follows from the displayed continuity bounds.

No bound is asserted for a sum over arbitrarily many artificial-cut presentations. The corrected relative form is still not inverted to define these mates.

## 7. Boundaries

Established: an explicit complete all-order observer differential complex, continuous outer actions and mate actions for specified completed source algebras, and action-compatible paired attachment/normalization comparisons.

Still not asserted: equality with the maximal graph domain, surjectivity onto the full source dual, strict strong-dual exactness of every completed source sequence, completed projectivity, or a perfect-module tensor-Hom beta equivalence. The translated fixed-length source functional obstruction survives these endpoint-length and depth weights.

Analytical ambient observers do not automatically have forcing-resolved preimages. Separate bulk/forcing current claims retain their own declared forcing domains.
