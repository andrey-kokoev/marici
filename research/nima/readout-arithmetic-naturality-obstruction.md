# Formal repetition does not define a common physical arithmetic action

## Candidate operation

The conditional Carrier semiring suggests testing the multiplicative monoid
of natural numbers through \(n\)-fold substrate maps.  This is not yet a
physical operation; the test asks whether it is compatible with the two
closed sectorwise readout squares.

## Radiative memory

The memory difference plane is linear, so

\[
[n](a,b)=(na,nb).
\]

Its invariant algebra transforms homogeneously:

\[
[n]^*q_2=n^2q_2,
\qquad
[n]^*q_3=n^3q_3.
\]

Thus memory admits a graded monoid action at this linear level.

## Five-site cosmology

For the deck-difference group \(G=(C_2)^5\), \(n\)-fold addition is

\[
[n]d=
\begin{cases}
d,&n\text{ odd},\\
0,&n\text{ even}.
\end{cases}
\]

This commutes with the difference quotient

\[
F(g,h)=g\oplus h.
\]

But it does not commute with the physical selection \(E=\delta_0\).  For
every even \(n\),

\[
[n]^*\delta_0(d)=\delta_0([n]d)=1
\]

for all \(d\), whereas \(\delta_0(d)\) vanishes on the 31 nonidentity
differences.  At each even \(n\), 992 of the 1,024 coefficient--Betti label
pairs change their selection value.

## Result

The formal \([n]\) maps obey

\[
[m]\circ[n]=[mn]
\]

and are natural at the quotient layer in both examples.  Nevertheless,

\[
\boxed{
\text{they do not define one common selection-compatible physical
arithmetic action.}
}
\]

This is precisely the resource gate predicted by the constructor-principle
interpretation.  An algebraically available repetition of deck labels is not
automatically a physical constructor on the coefficient--Betti pairing.

The obstruction does not falsify the conditional \(\pi_0\) semiring.  It
shows only that transporting it into sector readout algebras requires an
independently derived sectorwise operation and selection-coherence cell.
