# Prior clues: do not make curvature a mandatory interaction gate

## Correction to the latest proposed bottleneck

The last status table called the source origin of curved overlap geometry the
critical gate. That is a gate for ONE existing trial action, not a necessary
condition for every interaction of the retained whole. Prior research already
contains state-dependent back-action at fixed overlap geometry.

The clock/overlap-phase comparison remains valid for its stated two models.
It does not establish that the programme must now generate a curved metric.

## 1. Fixed-metric exchange already changes later comparisons

`seed-seam-backaction-source-comparison.md` derives, from the existing event,

    delta'_i=-delta_i,
    delta'_j=delta_j-<u_j,u_i> delta_i.

The current six-port adapter and full-turn action instantiate precisely this
law. The shared state changes the next comparison even with every u_i and
its Gram held fixed. Introducing a dynamical overlap phase is therefore an
additional possible feedback channel, not the first possible interaction.

`prior-feedback-recovery-after-free-seed-detour.md` had already explicitly
warned against treating the absence of a new adapter as absence of back-action.

## 2. Separate the feature Gram from the retained-state Gram

`gram-selection-principle.md` formulates an overlap matrix of retained
alternative/filler record states:

    G_history(i,j)=<f_j|f_i>.

That is not automatically the comparison-direction Gram <u_i,u_j> used in
the fixed exchange law. Distinct addressed histories acting on one admitted
preparation can give distinct record states even when all operation features
stay fixed. A COMMON unitary on every state preserves their Gram; different
ordered actions on the different records need not.

This is a concrete clue, not an already verified identification with the
curved 137 model. The inspected Gram-selection checker uses five Boolean
maps and a chosen numeric image-vector encoding. It does not prove source
selection of the physical pairing or derive the dynamics of our current
path-family overlaps. Its implementation also records an unnormalized
intensity alongside differently normalized pairwise expected values without
asserting their equality, so its advertised interference claims should not
be used as a calibration certificate here.

The useful next object is the actual retained-state Gram under the EXISTING
source-labelled actions and pairing, not another assigned phase in a fixed
feature Gram. No Born or detector rule is required simply to calculate it.

## 3. Cycle phase, not only pairwise magnitude, is the discriminator

`relational-certificates-have-an-arity-ladder.md` separates norms, pairwise
magnitudes and cyclic Bargmann phases. Complex conjugation preserves all
pairwise magnitudes but conjugates the triple product. A genuinely new
oriented phase must therefore be tested on a closed cycle with retained
source attachments, rather than inferred from rank or positive energy.

`tetrahedral-native-rotation-loop.md` supplies the matching operation warning:
coherent frame and selected-line transport telescope to identity, while bare
projection routes can yield other amplitudes. Substituting projection for
transport changes the operation. A sign or phase from one is not evidence
for the other. This is directly relevant when evaluating history overlaps.

## 4. Native feedback already specifies a nontrivial allowed change

`native-feedback-change-permission.md` proves the actual tetrahedral update
exchanges ordered retained routes while preserving decoded payload:
(1,2)->(2,1). It retains the complete comparisons and certificates, not only
those lengths. `prior-feedback-recovery-after-free-seed-detour.md` additionally
recovers a native iteration using the WHOLE previous comparison as the next
input, and a separate finite carrier/record feedback that returns initially
hidden information to the carrier.

These are source-level clues about which records may change. Their identity-
presentation routes are not automatically the six-arrow seed paths, so their
comparison must preserve the actual source types instead of matching labels.

## 5. The action-selection test has already been done in another small sector

`graph-action-selection-audit.md` constructs retained action packages and
exact gradients. Locality, additive assembly, endpoint symmetry and shift
covariance allow both quadratic and quartic actions. Quadratic restriction
plus those conditions gives a*(u-v)^2, but does not fix a. The successor
`dsc-action-selection-countermodels.md` is explicitly listed there.

This tells us to test an action-selection claim rather than silently infer
one from coherent records. It does not require abandoning an action already
identified on a particular source sector.

## 6. What the existing gauge-feedback examples do supply

`record-gauge-feedback-loop.md` gives an actual closed matter/link Hamiltonian
with continuity and a conserved Gauss constraint, using exact subflows.
`137-comparison-phase-backreaction.md` instead couples comparison mismatches
directly to an overlap phase. Both are useful existing targets, with distinct
carriers and declared laws. Neither should be promoted to a mandatory model
just because it contains a variable named phase.

`source-derived-recursive-action-assembly.md` concerns a Gysin/connection
source and action-authority objects, not a source-derived Hamiltonian for
this seed. Its title is not evidence that this physical gap is closed.

## Recommended concrete reuse

Compute the Gram and gauge-invariant cycle products of ACTUAL retained
alternative record states generated by the already bound exchange/pulse
histories. Keep one typed preparation, explicit common boundaries, the old
pairing, and the distinction between full exchange endpoints and intermediate
complex Hamiltonian transport. Check source covariance and history recovery.

This would determine whether retained interaction already generates changing
relational phase data at fixed feature geometry. If it does, compare that
output with the prior phase/charge constructions. If it does not, retain the
actual failure; do not repair it by selecting a new curvature phase.

## Verification scope

This was a source/document and implementation search. No new dynamics or
checker was added, and no new formal verification pass is claimed. The
previous fixed-feature phase test is not withdrawn; its interpretation as a
necessary universal bottleneck is corrected.
