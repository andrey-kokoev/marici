# Many-many coupling Schur criterion

For a finite block

$$
\mathfrak Q
=\begin{pmatrix}Q_{\rm int}&L^*\\L&Q_{\rm end}\end{pmatrix},
$$

with `Q_end` strictly positive, the block is positive exactly when

$$
Q_{\rm int}-L^*Q_{\rm end}^{-1}L\succeq0.
$$

The relative construction retains the block and its signed coupling without imposing this inequality. If the inequality holds on a source-derived finite packet, it supplies an ordinary positive Schur realization for that packet.

The global Schur estimate requires a source-uniform bound for `L` relative to both diagonal graph forms. It is an optional upgrade above the relative qRB admission.

Status: finite Schur criterion isolated; no global Schur positivity claim.
