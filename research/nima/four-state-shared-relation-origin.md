# Two overlapping presentations from the four-state carrier

## Finite starting point

Start with the existing Bool x Bool carrier, with states00,01,10,11 and all12
directed nonidentity arrows. This construction assumes no proton, quark or larger
precursor packet. The existing comparison-slot checker is freshly rerun.

The obligation is forward realization: identify what two coordinate presentations
inherit, construct their shared relation, and distinguish overlap from enforced
joint dependence. This is a finite state/operation construction, not a physical
particle identification.

## Enumerating the arrows

Write each state as(a,b). Every nonidentity arrow changes the first coordinate,
the second coordinate, or both:

| Class | Directed arrows | Count |
|---|---|---:|
| First only |00->10,10->00,01->11,11->01|4|
| Second only |00->01,01->00,10->11,11->10|4|
| Both |00->11,11->00,01->10,10->01|4|

The first presentation inherits every arrow changing a: eight arrows. The second
inherits every arrow changing b: eight arrows. The four simultaneous-change
arrows belong to both. Therefore

    8+8-4=12,
    2/3+2/3-1/3=1.

This is a partition by the actual action of the twelve arrows on the two Boolean
coordinates. No equal division into particle masses has been introduced.

All six invertible binary coordinate charts yield the same counts. They can
permute which four arrows are called simultaneous; cardinality alone does not
select a physical coordinate chart.

## A shared relation generated by these states

Define the agreement/parity record

    r=a XOR b.

The two parts carry a and b; their shared relation says whether they agree.
Recording can be reversible:

    (a,b,r_blank) -> (a,b,r_blank XOR a XOR b).

With a blank zero record this gives(a,b,a XOR b). On all eight three-register
basis states the gate is an involutive permutation. Information is preserved.

Only four triples satisfy r=a XOR b. The relation is determined by the original
two coordinates, so three syntactic entries do not mean three independent bits.
For these classical labels, (a,r) determines b and (b,r) determines a. This
basis-label statement does not assert that two reduced quantum subsystems each
recover an arbitrary coherent state.

## When joint dependence appears

If a cycle requires its current state to remain compatible with a FIXED record,
the possibilities are:

| Fixed shared record | Allowed states | Nonidentity transitions |
|---|---|---|
|r=0|00,11|00<->11|
|r=1|01,10|01<->10|

Every permitted transition changes both parts. A private change would change r,
so it requires a relationship update. These are exactly the two two-state
relations for which each Boolean coordinate still takes both values and either
coordinate determines the other. The checker exhausts all16 subsets of the
four-state product to verify that statement.

Retaining a HISTORY of r is a different rule. For example00->10 changes only a
while the retained record history becomes(0,1). Both old and new records remain
available. Thus information retention alone does not impose joint dependence.
The specific additional rule is compatibility with a fixed retained relation
during the relevant part of a cycle.

In a two-cycle interpretation, a first cycle can produce and retain r; a later
cycle can use that record as a compatibility constraint. Which cycle boundary
freezes or updates it must come from the stated dynamics. The finite construction
establishes both alternatives without identifying a particular complex-plane
collapse with the parity-record operation.

## Traceable lift to the existing comparison count

Once the previously declared comparison programme is added, the primitive
8+8-4 decomposition has a precise lift. Classify the first compared arrow by its
nonzero XOR displacement01,10,11. Each class has four directed arrows. Classify
its nonreference state alternative by its displacement from reference00 as well.
Each of the three classes then contributes

    12*(4*12+1*3)=612

labelled comparison instances. The two coordinate presentations contain two
classes each, sharing the simultaneous-change class:

    first presentation: 1224,
    second presentation: 1224,
    shared: 612,
    union: 1836.

The factor4*12 now has an explicit origin: four arrows with the same coordinate
change pattern compared against the second carrier's twelve arrows. The1*3 term
uses one state alternative in that class against the second carrier's three
alternatives. The outer twelve copies are still the existing programme's input.

This lift counts instances of an admitted comparison programme. It does not show
that one isolated four-state carrier dynamically creates that whole programme,
or that these counts are quark charges or rest energies.

## Seed-cycle compatibility follow-through

The existing checker now also applies the actual vertex cycles (ABC) and (ADB), with A,B,C,D identified with00,01,10,11. Each changes the parity reading on two of the four inputs. Exhausting all16 binary functions on the four states shows that only the two constant functions are invariant under BOTH cycles. Equivalently, the group generated by these cycles acts transitively, so any common invariant scalar function is constant.

Thus this nontrivial relation cannot be held fixed as a function on the carrier while admitting both whole-cycle actions on every state. This does not rule out a fixed-record subphase, a restricted input sector, or a retained time-dependent relation.

Indeed transporting the relation along any permutation g gives r'=r composed with g^-1 and exactly r'(g x)=r(x). The checker verifies this for both seed generators. This preserves the evaluated relation without keeping its coordinate function fixed. It is passive/covariant record transport, not proof that the state dynamics is constrained to jointly change the two original coordinates.

This narrows the existing next question: specify when the intended cycle fixes the relation in the physical reference presentation, and when it transports or updates it. The whole seed action alone does not provide fixed-parity locking. The prior conditional joint-dependence result remains valid within its fixed-record phase; no particle identification or physical freezing rule follows from this extension.
