# Aspect's prior optical candidates for the interval realization gap

## Question and disposition

Which existing optical source contracts should be examined before inventing an interval realization experiment?

Aspect already supplies a named path–marker instrument, an explicit environment-assisted inverse, acquisition protocols and loss hostiles. My generic suggestion to begin by designing reversible optics omitted this prior work. Reuse these source contracts first. Their existence changes candidate selection, not the physical WG-I3 verdict: none of the inspected packets identifies its optical operations with the interval edits or reports a calibrated interval realization.

Scope: source-note review and inspection of two Python checkers, not fresh execution, apparatus acquisition or an exhaustive census of current hardware records. SCC obligation for any proposed next bridge: forward realization and operation/record compatibility before causal readout interpretation. No new comparison is constructed here.

## Selected first candidate: path–marker mate interferometer

Sources: `research/aspect/path-marker-mate-interferometer.md`, its `-preregistration.md` companion, `research/aspect/mate-interferometer-no-click-calibration-gate.md`, and `research/aspect/checkers/check_path_marker_mate_interferometer.py`.

The independently specified instrument uses a single photon's path and marker degrees of freedom. A path-controlled marker flip uncomputes the joint marking before signal detection. The source contrasts that intervention with late classical conditioning and a post-record timing control. It therefore already distinguishes physical reverse incidence from reverse manipulation of records.

At environment overlap gamma and phase phi:

- untouched unconditional signal probability is 1/2;
- complementary conditioned probabilities are (1 +/- gamma cos(phi))/2, whose equal-weight total remains 1/2;
- coherent pre-detection uncomputation gives unconditional probability (1 + gamma cos(phi))/2;
- post-record continuation cannot change the stored signal probability.

The checker explicitly defines the four-dimensional controlled unitary, verifies its square is identity and computes density-matrix probabilities at four phases and three overlaps. This is a finite ideal-instrument calculation, not hardware evidence. Its record-order distinction is not reversed physical time.

The existing preregistration retains herald keys, both clicks and no-clicks, marker/reset probes and calibration epochs. It includes a false-positive control: phase-dependent efficiencies make a flat unconditional state appear to have visibility 1/3 if no-click records are discarded. Thus a fringe alone is not evidence for the intended inverse intervention.

## Companion candidate: retained-environment channel recovery

Sources: `research/aspect/environment-assisted-channel-recovery.md`, `research/aspect/checkers/check_environment_assisted_channel_recovery.py`, and `research/aspect/imperfect-environment-access.md`.

The explicit complete-transfer dilation sends alpha|00>+beta|10> to alpha|00>+beta|01>. Its inverse on the joint carrier restores the input, while the reduced system channel is constant. The code retains the full four-dimensional matrix and uses its transpose as inverse. This is a concrete comparison between a reduced noninvertible channel and a larger reversible instrument, not permission to invert the reduced channel.

Partial-access analysis distinguishes deterministic joint recovery, monitored heralded recovery and unmonitored inference. For collection efficiency eta<1, the orthogonal-input trace distance contracts to eta, forbidding deterministic exact recovery by a physical channel. The ideal monitored filter construction can instead recover conditionally with success probability eta. Any interval protocol must preserve that distinction in its operation labels and domains.

## Consequence for the next research choice

Prefer the path–marker instrument for distinguishing coherent inverse action from conditioning, with retained-environment recovery as the full-state recovery benchmark. There is already an experiment design; another generic experiment proposal is unnecessary.

A new executable mathematical bridge would need a frozen, independently motivated encoding of interval records into a stated optical state family and a matching operation dictionary. A single involutive controlled flip is not automatically the partial pair L/l, nor does it supply a variable-length path register or shared R action. The decisive test would compare actual source/control transitions and complete records on their declared domains, without quotienting execution words or claiming that laboratory order equals either supplied chart time.

No such encoding is supplied by this search. Do not rank a still-unspecified bridge as an executable test. If constructed later, it would first establish a controlled optical realization or simulation; source-selected metric, causal interpretation and WG-I3 promotion would remain separate obligations.
