# None/None Is Not a Native Completed Response

For the completed lawful operations currently modeled, the response algebra
has three states:

\[
(1,0),\qquad(1,R),\qquad(0,R).
\]

The fourth state \((0,0)\) does not occur natively. A zero value is still a
value; empty support has a support certificate; a contractible class has a
homotopy; incompatibility has an obstruction.

However, \((0,0)\) can appear after a nonconservative projection forgets the
residue of an obstruction:

\[
(0,R)\longmapsto(0,0).
\]

Thus an observed undefined has several possible meanings:

- the operation has not completed or was never executed;
- transport lost the response;
- a UI/API projection erased the residue;
- the response protocol is mistyped.

It is not evidence that the source operation produced “nothing.”

This yields the scoped no-silent-response conjecture:

> Every completed lawful source operation returns a typed value, a typed
> residue, or both. None/None can arise only outside that source-complete
> response algebra.
