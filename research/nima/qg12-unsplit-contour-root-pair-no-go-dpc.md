## Risky consequences

The exact denominator test in `research/nima/qg12-occurrence-branch-label-dpc.md` removes the only apparent implicit bridge: `q_g31` and `q_g23` are generic units in the conductor branch coordinate and cannot serve as root labels. Benincasa's inverse-Euler theorem constructs the algebraic connecting coefficient but explicitly does not construct the physical relative chain.

Therefore the regulator prescription fixes the unsplit distributional boundary value but does not supply the local root-pair chain map. The bold conjecture is falsified.

## Disposition and residual conjecture

The algebraic conductor connecting coefficient is established, including its sign. Its promotion to a physical period remains undefined because the first missing typed object is a source-derived relative-chain declaration: chain type, endpoint/root trivialization, and orientation. Existing positivity, regulator, occurrence, and inverse-Euler data do not determine it.

Residual conjecture: a physical source contour, if supplied, will select the even root-pair cycle because the conductor local system is trivial and the transported wall class is even. This is not executable from current evidence. Reopening requires an explicit source contour or inequality packet that maps to the local roots and fixes orientation.
