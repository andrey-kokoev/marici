# Additive window translation does not intertwine the multiplicative theta-label orbit

The next window-to-theta comparison cannot identify one translated Gaussian
front with one theta label. The two source actions are different.

## Half-density logarithmic pullback

Let

\[
(Uf)(u)=e^{u/2}f(e^u)
\]

from the positive additive ray to logarithmic scale. For the Gaussian

\[
f_0(x)=e^{-\pi x^2},
\]

one has

\[
Uf_0(u)=e^{u/2}e^{-\pi e^{2u}},
\]

which is exactly the \(n=1\) nonzero theta precursor.

More generally, theta labels arise from multiplicative dilations. With the
unitary dilation

\[
(D_af)(x)=a^{1/2}f(ax),
\]

one computes

\[
UD_aU^{-1}=\tau_{\log a},
\]

up to the frozen sign convention for logarithmic translation. Thus the
theta-label orbit is a Mellin/dilation orbit.

## Window fronts use additive translation

The adjacent-window derivative contains

\[
g_t^\pm(q)=e^{-\pi(q\pm t)^2}.
\]

These are additive translates

\[
g_t^\pm=T_{\mp t}f_0,
\qquad
(T_bf)(x)=f(x-b).
\]

Under logarithmic pullback,

\[
(UT_bf_0)(u)
=
e^{u/2}e^{-\pi(e^u-b)^2}.
\]

By contrast, a logarithmic theta translate is

\[
(\tau_LUf_0)(u)
=
e^{(u+L)/2}e^{-\pi e^{2(u+L)}}.
\]

These expressions are not equal for any identification \(b=L\) or
\(b=e^L\) valid for all \(u\).

## Exact intertwining residual

Define

\[
\mathcal R_{b,L}
=
UT_b-\tau_LU.
\]

On the Gaussian witness,

\[
(\mathcal R_{b,L}f_0)(u)
=
e^{u/2}e^{-\pi(e^u-b)^2}
-
e^{(u+L)/2}e^{-\pi e^{2(u+L)}}.
\]

For \(b>0\), evaluate at \(u=\log b\). The first term is \(b^{1/2}\), while
the second is

\[
e^{L/2}b^{1/2}e^{-\pi b^2e^{2L}}.
\]

Hence

\[
(\mathcal R_{b,L}f_0)(\log b)
=
b^{1/2}
\left(
1-e^{L/2}e^{-\pi b^2e^{2L}}
\right),
\]

which is generically nonzero. Therefore the direct front-to-label
intertwiner fails already on one Gaussian.

## Categorical consequence

The window path is generated by the additive translation representation,
whereas the theta labels are generated by the multiplicative dilation
representation. A comparison must carry both actions, not replace one with
the other.

The minimal common source geometry is therefore the affine group generated by

\[
x\mapsto ax+b.
\]

Its logarithmic realization contains:

- Mellin translation for \(a\);
- a nonlinear logarithmic action for \(b\);
- the semidirect relation
  \[
  D_aT_bD_a^{-1}=T_{b/a}
  \]
  under the present dilation convention.

Any proposed comparison cell must satisfy this relation before theta label
summation or Green polarization.

## Fourier qualification

Ordinary Fourier transform converts additive translation into modulation:

\[
\mathcal FT_b\mathcal F^{-1}=M_{e^{-2\pi ib\xi}}.
\]

It does not convert additive translation into multiplicative dilation.
Therefore Fourier covariance alone cannot repair the residual. A lawful route
must include an affine-to-Mellin integral decomposition or another
source-authorized induction functor.

## Refined smallest packet

The first finite comparison packet must contain at least:

1. the Gaussian \(f_0\);
2. one additive translate \(T_bf_0\);
3. one multiplicative dilation \(D_af_0\);
4. the mixed word \(D_aT_bf_0\);
5. the semidirect comparison with \(T_{b/a}D_af_0\);
6. the wall-kernel coordinate;
7. the three completion-Jordan grades.

A map that works separately on the translation and dilation columns but fails
the mixed word is not constructor coherent.

## Frontier

The Wronskian connecting morphism closes the relative wall face. The open
window-to-theta face is now more precise:

\[
\text{affine Gaussian orbit}
\longrightarrow
\text{Mellin theta-label jet}.
\]

Before a finite jet intertwiner \(K\) can be asserted, the source must supply
the affine-to-Mellin comparison and prove the semidirect square. Only then can
the completion differential and endpoint jets be applied.

No mixed Green form or Adams type edge is promoted.
