# A Reference Port Creates Relative Phase Rather Than Revealing Absolute Phase

Two uncoupled histories carry independent presentation phases
\((\alpha_0,\alpha_1)\).  Without a comparison map, their difference has no
invariant meaning.

A cross-history port supplies the character

\[
(\alpha_0,\alpha_1)\longmapsto\alpha_1-\alpha_0.
\]

Its kernel is exactly the diagonal phase direction.  Thus the port reduces
the independent gauge action \(U(1)^2\) to the common diagonal \(U(1)\), and
the quotient retains one relative phase.

This corrects loose language around Entries 2102 and 2122.  The interferometer
does not expose an absolute state phase that was secretly observable all
along.  It adds a source-labelled comparison relation under which a relative
phase becomes gauge invariant.

The physical sequence is therefore

\[
\text{two independently framed histories}
+
\text{comparison coherence}
\longrightarrow
\text{one relative-phase coefficient}.
\]

Both quadratures may then reconstruct that relative coefficient.  They still
cannot reconstruct the common phase, which remains gauge.

For cosmology, the standard equal-time source supplies only diagonal gluing.
An off-diagonal history comparison would be new source structure and must be
derived independently; it cannot be described as a more accurate measurement
of the same diagonal observable.
