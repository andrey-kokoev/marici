# Every completed-theta pair shell is a product-weighted ratio translate of one base correlation kernel

## Question

Does the ordered-pair incomplete-gamma family contain independent kernels for
every \((n,m)\), or does source dilation reduce it to one base kernel?

## Claim boundary

It reduces exactly to one base completed-theta kernel. Product degree supplies
a half-density coefficient, while ratio degree translates the separation
coordinate. A remaining common-label translation moves the shell endpoints.
This constructs the exact product--ratio intertwining law for the localized
polarized synthesis. It does not construct the G4 response current.

## Label translation law

Let \(\Phi_1\) be the first completed atom. Direct substitution gives

\[
 \Phi_1(u+\log n)
 =n^{1/2}\Phi_n(u).
\]

Therefore

\[
 \Phi_n(u)
 =n^{-1/2}\Phi_1(u+\log n).
\]

The coefficient is forced by the half-density factor. It is not an adjustable
normalization.

## Ordered-pair shell reduction

Define the base localized correlation for any real separation \(d\) by

\[
 K_{[A,B]}(d)
 =\int_A^B\Phi_1(v)\Phi_1(v+d)\,dv.
\]

For the ordered pair,

\[
 \rho_{nm}^{[a,b]}(t)
 =\int_a^b\Phi_n(u)\Phi_m(u+t)\,du.
\]

Set \(v=u+\log n\). Then

\[
 \rho_{nm}^{[a,b]}(t)
 =(nm)^{-1/2}
 K_{[a+\log n,\,b+\log n]}
 \left(t+\log\frac mn\right).
\]

This identity is exact.

## Product and ratio degrees

Let

\[
 \ell_\Sigma=\log n+\log m,
 \qquad
 \ell_\Delta=\log m-\log n.
\]

Then the amplitude is

\[
 (nm)^{-1/2}=e^{-\ell_\Sigma/2},
\]

while the separation translation is

\[
 t\longmapsto t+\ell_\Delta.
\]

Thus product degree and ratio degree act through distinct source operations:

- product degree gives the half-density character;
- ratio degree translates relative separation;
- the first-label coordinate translates the shell itself.

Neither degree may be erased before the response current is formed.

## Swap orientation

Swapping \((n,m)\) preserves the product coefficient and sends

\[
 \ell_\Delta\longmapsto-\ell_\Delta.
\]

It also changes the shell translation from \(\log n\) to \(\log m\). Hence
ordered-pair reversal is a genuine ratio reflection plus a base-coordinate
change, not scalar symmetry at fixed shell.

## Common dilation

Under \((n,m)\mapsto(pn,pm)\),

\[
 \ell_\Delta
\]

is unchanged, while

\[
 (nm)^{-1/2}\longmapsto p^{-1}(nm)^{-1/2}.
\]

The shell interval translates by \(\log p\). This is the exact correlation
shadow of common prime transport: ratio degree is fixed, product half-density
acquires \(p^{-1}\), and the base shell moves covariantly.

## Relation to the incomplete-gamma formula

The incomplete-gamma kernel is the direct evaluation of this translated base
identity. In its coefficients,

\[
 A=\pi n^2,
 \qquad
 C=\pi m^2e^{2t}
\]

have common factor \(n^2\) after writing

\[
 C=\pi n^2e^{2(t+\log(m/n))}.
\]

Rescaling the integration endpoints by \(n^2\) reproduces the translated shell
limits.

## Response-current constraint

A source-derived pair response must intertwine:

1. half-density multiplication by \(e^{-\ell_\Sigma/2}\);
2. separation translation by \(\ell_\Delta\);
3. shell translation by \(\log n\);
4. adjacent-shell concatenation.

A response depending only on \(nm\), only on \(m/n\), or only on the scalar
summed theta forcing fails this exact basis-pair law.

## Disposition

The localized polarized correlation synthesis is generated by one base
completed-theta kernel under typed product, ratio, and shell translations. The
remaining candidate-one problem is whether the reciprocal/linking construction
carries the same three actions and cancels the resulting Laplace section. No RH
conclusion is authorized.
