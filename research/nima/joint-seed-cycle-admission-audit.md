# Joint seed cycle: derived compatibility certificate versus supplied admission

## Native source audit

`WholePackageResolution.Resolve` is parameterized by a source predicate S. Its literal constructor requires S(q); its application constructor requires a formed rule and derivations at all its input ports. `NativeTableResolution.ForOldSeeds` transports arbitrary S along the package equivalence; it does not choose S. `NativeTableRules.compose-comparisons` retains its actual pointed equivalences and parents, with no scalar seam readout in its generic signature.

The inspected shared-triangle result explicitly declares oriented-cochain gluing and synchronized versus serial protocols. The later six-occurrence result instead preserves three cycle readings under a specified simultaneous update. Neither is an instantiated native source-admission policy generated by the generic resolver.

Consequently writing Admit(x)=the synchronized equations would encode a chosen policy, not prove it is the intended source law. This audit does not claim exhaustive absence of another physical policy elsewhere in the repository.

## What follows without fitting the synchronized equations

Take the existing simultaneous local half-phase U and the existing shared-edge reading h(x)=AB+BA. If the contract is that this reading remains fixed under every allowed continuation U, the admissible subspace is determined, not freely chosen:

    A = intersection_(k=1..6) ker(h U^k-h).

The exact checker now proves that its first two rows have rank two, equal to the full constraint rank. Hence

    x in A iff h(Ux)=h(x) and h(U^2 x)=h(x).

The earlier parameterization A=im(K) with x=(a,b,c,h-b,h-c,h-a) follows. Its dimension is four. U and U^-1 preserve A, so admitted continuations and returns remain within it. This supplies a finite closed continuation certificate, matching the principle in `contextual-equivalence-needs-stabilized-congruence.md`, without relying on an unbounded prefix test.

The conservation contract is still an input. The derived result is its maximal compatible domain for the actual U, not an independent physical argument for conservation.

## Full retained interface: no admission choice needed to represent a state

The same checker now gives an invertible coordinate map on all six directed values. Write l=(AB,BC,CA), t=(BA,AD,DB), z=l+t, and define

    hbar=(z0+z1+z2)/3,
    d1=z1-z0, d2=z2-z0.

Retain (l,hbar,d1,d2). Reconstruction is

    z0=hbar-(d1+d2)/3,
    z1=z0+d1, z2=z0+d2,
    t=z-l.

Under the already specified simultaneous U, both l and t transform by S, so this map derives rather than postulates the record dynamics:

    l'=S l, hbar'=hbar,
    (d1',d2')=(d2,-d1+d2).

The defect operator has exact order six and cube -I. It preserves d1^2-d1*d2+d2^2, a positive quadratic form. Nonzero disagreement therefore persists under this update; it does not relax into the synchronized sector.

The entire state is now represented as four compatible coordinates plus two evolving defect records. This is a block decomposition of the given operator, not dimensional information loss. The synchronized sector is exactly d1=d2=0. The actual shared reading remains the FIXED function AB+BA, reconstructed at each phase as hbar-(d1+d2)/3; no phase-dependent redefinition of that observable is necessary.

This resolves a representation issue without pretending to choose a physical policy. Arbitrary inputs can be retained and evolved exactly; requiring the actual shared value to stay fixed additionally selects the defect-zero sector. The four-coordinate summary alone cannot reconstruct a general seed state. As in the prior mean/fluctuation constructions, keeping the residual matters.

## Precise remaining source identification

There are two different meanings of a retained relation:

1. a fixed observable value protected under the declared phase continuation;
2. a transported observation, h_k=h U^-k, with h_k(U^k x)=h(x) for all x.

The second imposes no synchronized-subspace restriction, since it changes the observation along with the state. The existing moving-reference model shows why that distinction matters. Neither policy is selected merely by keeping old witnesses.

To connect this certificate to the intended cycle, locate the actual source rule that either protects h as a fixed reading or transports its reference. It must specify this at the same phase/port interface as U. Generic native admission transport cannot supply that choice. This is the exact boundary between the new mathematical certificate and the still-unconstructed physical admission law.
