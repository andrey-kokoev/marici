# qRB microstep 149: residue-free local kernel domain

For translation differences satisfying

$$
|d|<2\sigma,
$$

the imaginary continuation crosses no digamma pole. On this domain the translate-Gram kernel is given directly by

$$
G_{ab}
=4\pi\sigma e^{-d^2/(8\sigma)}
\Theta\left(2\sigma,-\frac{id}{4\sigma}\right),
\qquad d=a-b.
$$

This provides an honest residue-free analytic neighborhood of the diagonal. Rank-two and higher Toeplitz tests can first be formulated there without contour ambiguity.

Global separation requires adjoining the finite residue corrections from the preceding microsteps.

Status: local analytic kernel domain closed; global continuation remains piecewise and residue-corrected.
