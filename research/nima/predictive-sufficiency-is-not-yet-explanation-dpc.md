# Deutsch--Popperian conjecture: predictive sufficiency is not yet explanation

## Status

This packet sharpens the versioned-counterfactual-memory conjecture. It separates a
minimal state that predicts every declared experiment from a source-typed model
that explains why those experiments have their outcomes.

## 1. Predictive quotient

Fix admissible interventions \(\mathcal W\) and readouts \(\mathcal R\). For source
histories \(h_1,h_2\), write

\[
h_1\sim_{\mathcal W,\mathcal R}h_2
\]

when every continuation made from \(\mathcal W\) and observed through
\(\mathcal R\) gives the same result. The quotient

\[
X_{\mathcal W,\mathcal R}=\mathcal H/\!\sim_{\mathcal W,\mathcal R}
\]

is the coarsest state sufficient for those future experiments.

This is a theorem about predictive sufficiency. It is not by itself a theorem
about explanation.

## 2. Lookup-table critic

For a finite experiment family, define a table

\[
T(h,w,r)=r(w(h)).
\]

The row of \(T\) indexed by \(h\) determines the class of \(h\) in
\(X_{\mathcal W,\mathcal R}\). Consequently a lookup table can realize the minimal
predictive quotient without representing any plant, carrier, coefficient lens,
or constructor composition.

Therefore the following implication is false:

\[
\text{counterfactually sufficient record}
\Longrightarrow
\text{explanation}.
\]

The quotient says which histories may be merged. It does not say what produced
the surviving distinctions.

## 3. Realization layer

An explanatory realization must add a source module \(S\), a family of typed
constructors \(C_w\), an evolution law, and readout maps \(O_r\):

\[
S\xrightarrow{C_w}S\xrightarrow{O_r}Y_r.
\]

It must reproduce the predictive state while preserving constructor
composition. There is a comparison map

\[
\pi:S\longrightarrow X_{\mathcal W,\mathcal R}
\]

such that, whenever composition is typed,

\[
\pi C_{w_2}C_{w_1}
=
\overline C_{w_2}\overline C_{w_1}\pi.
\]

The predictive quotient is thus the behavioural image of the realization. It
need not determine the realization.

## 4. Explanatory excess

The source realization contains explanatory information when it supports
counterfactual changes not obtained by independently editing entries of the
behaviour table. Three requirements isolate this excess.

### 4.1 Composition

The response to a composite intervention is generated by composing the same
constructors that generate its parts.

### 4.2 Modularity

A permitted local modification changes the constructors in its declared module
while preserving the stipulated invariants of the other modules.

### 4.3 Extension

When the experiment interface is conservatively enlarged, the old realization
extends to the new experiments without replacing its old laws by an unrelated
table.

Composition prevents arbitrary table fitting. Modularity provides localized
error attribution. Extension makes the explanation risky beyond the data used
to identify it.

## 5. Strengthened DPC

An adequate understanding of a problem is a versioned counterfactual memory
together with a source-typed generative realization whose constructor
composition, modular interventions, and conservative extensions produce that
memory's observable distinctions.

In abbreviated form:

\[
\text{understanding}
=
\text{predictive quotient}
+
\text{source-faithful realization}
+
\text{risky extension law}.
\]

The plus signs here denote jointly required structure, not scalar addition.

## 6. Carrier interpretation

Carrier geometry supplies the places and admissible routes along which state can
be transported. The coefficient lens supplies the algebra of transported
values. Closure supplies the accumulated record. None of these alone specifies
the full realization.

An interaction can therefore leave three increasingly strong traces:

1. a behavioural trace sufficient for an existing readout;
2. a typed state update preserving the relevant coefficient algebra;
3. a constructor-level record showing which source operation produced the
   update and how it composes with later operations.

Only the third is naturally explanatory. The first can be a diagnostic shadow;
the second can be an unexplained state transition.

## 7. Toric-code witness

On the smallest torus, syndrome plus two noncontractible loop probes identifies
the four logical classes. This gives a jointly faithful predictive record modulo
local repairs.

It still does not select a decoder. A decoder additionally realizes a map from
syndromes and chosen logical conventions to repair chains. Different decoders
can agree on every stored syndrome and logical probe while differing in cost,
locality, fault propagation, and response to an enlarged noise model.

Thus:

\[
\text{faithful logical readout}
\neq
\text{explanatory decoder realization}.
\]

The former classifies the residual state. The latter proposes a constructor for
changing it.

## 8. Three-lens witness

The same carrier route may be evaluated through:

- an additive lens, which retains accumulated current;
- a determinant-line lens, which retains an orientation or phase class;
- an ordered holonomy lens, which retains noncommutative composition.

If closure stores only the additive shadow, two differently ordered histories
may have the same record. If the future interface admits only additive probes,
that merger is predictively legitimate. If a later controlled interference or
ordered-loop probe is admitted, the old quotient was too coarse.

The explanatory realization should already state which distinctions were
discarded and under what interface enlargement they return. This is more than
successful prediction under the current interface.

## 9. Exact falsifiers

### Predictive failure

There exist \(h_1,h_2\) with the same stored record and an admitted experiment
that distinguishes them.

### Realization failure

The model predicts each primitive experiment correctly but fails a typed
composition:

\[
\widehat C_{w_2w_1}
\neq
\widehat C_{w_2}\widehat C_{w_1}.
\]

### Modularity failure

No intervention changes one claimed explanatory component without an
unprincipled rewrite of unrelated components.

### Extension failure

Every enlargement of the interface requires an unrelated refit even when the
new experiment uses the same declared constructors.

### Source non-identifiability

Two inequivalent realizations satisfy every admitted composition, intervention,
and extension test. Then the evidence fixes only a realization torsor or moduli
class, not one explanatory source.

## 10. Critic

The strengthened conjecture may demand too much. Some domains may admit robust
prediction and control while no unique modular source factorization exists.
Realizations are often nonunique even up to similarity, gauge, or Morita-type
equivalence. The correct target therefore cannot always be a unique internal
mechanism.

The repair is to type the authorized equivalence. Understanding identifies the
smallest realization class invariant under transformations that preserve every
admitted composition, intervention, and extension. Claiming more requires a new
source reference.

## 11. New bottom line

Closure makes past interaction available to later source operations only to the
extent that the closure retains a sufficient typed state. Explanation begins
one level higher: the retained state must be the behavioural image of a reusable
constructor system, and that system must survive criticism by composition,
modular change, and interface extension.

So the central distinction is:

\[
\text{memory answers future queries};
\qquad
\text{explanation generates and constrains the answers}.
\]
