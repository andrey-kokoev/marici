# Certified family selection as a Witness Generator

`agda/WitnessSelectionGenerator.agda` makes **selection/execution itself** a Layer-1 Witness Generator. A request retains a Boolean index and actual derivations of a native P-family of two-step witnessed histories and of that index. The selection WG sends the request to the derivation produced by `NativeApplicationExtension.execute`, paired with an equality tracing that derivation to execution from precisely those two premises. The WG witness retains the request; completed responses are stationary. The false-index fixture admits only the family and index packages, not the selected result, and the native endpoint reads back the nonempty two-step history.

This is a higher-universe WG because its states contain derivations and packages. It shows that WG language can describe the **certified elimination** operation as well as pointwise generation. It does not make application derivable in the original twelve-rule closure; the selection WG delegates to the separately added application schema. It also does not turn a raw Pi-family value into a family derivation, nor provide an unbounded composition law for successive native selections. The old-rule negative control for bare atomic component selection is in `witness-history-family.md`.
