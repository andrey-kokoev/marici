# Prime-diagonal return is exact before codiagonalization and conditional after it

## Question

Does the source-derived radial synthesis force the reciprocal return to preserve prime and grade labels?

## Claim boundary

Yes on the retained labelled direct-sum carrier with its orthogonal source metric. The synthesis and its adjoint are block diagonal, and their Gram return descends through the synthesis radical labelwise. After codiagonalization into a common analytic history or an undeclared G4 metric, prime diagonality is no longer automatic. This separates a closed source theorem from the remaining G4 return gate.

## Labelled synthesis

Let \(\lambda=(p,k)\) and retain orthogonal decompositions

\[
V=\bigoplus_\lambda V_\lambda,
\qquad
H^{\rm lab}=\bigoplus_\lambda H_\lambda.
\]

The completed reciprocal theta-history incidence satisfies

\[
P_\mu^HUP_\lambda^V
=\delta_{\mu\lambda}U_\lambda.
\]

Because the projections are orthogonal in the declared direct-sum metrics, taking adjoints gives

\[
P_\lambda^VU^*P_\mu^H
=\delta_{\lambda\mu}U_\lambda^*.
\]

Therefore

\[
U=\bigoplus_\lambda U_\lambda,
\qquad
U^*=\bigoplus_\lambda U_\lambda^*,
\qquad
U^*U=\bigoplus_\lambda U_\lambda^*U_\lambda.
\]

Prime and grade diagonality of the source return is exact before scalar readout.

## Radical descent

The labelled synthesis Gram has

\[
\ker(U^*U)=\ker U
=\bigoplus_\lambda\ker U_\lambda.
\]

Hence its radical is labelwise. The form

\[
\langle Uv,Uw\rangle_H
\]

descends canonically to

\[
V/\ker U
=\bigoplus_\lambda V_\lambda/\ker U_\lambda.
\]

At finite cutoff, source faithfulness gives \(\ker U_\lambda=0\). At completion, this proves well-defined radical descent but not a uniform lower frame bound. Closed range and quotient faithfulness remain separate quantitative gates.

## Codiagonalization changes the question

Let

\[
C:H^{\rm lab}\longrightarrow H^{\rm common}
\]

sum labelled histories into a common analytic carrier. The compressed synthesis is

\[
\widetilde U=CU.
\]

Its Gram is

\[
\widetilde U^*\widetilde U
=U^*C^*CU.
\]

For \(\lambda\ne\mu\), the cross block is

\[
P_\lambda^V\widetilde U^*\widetilde UP_\mu^V
=U_\lambda^*P_\lambda^HC^*CP_\mu^HU_\mu.
\]

It vanishes only if \(C^*C\) preserves the label projections or the two images are orthogonal after codiagonalization. Neither follows from diagonality of \(U\).

Thus common-history overlap may create analytic cross-prime Gram entries even though the source incidence is exactly prime diagonal. Such entries are not automatically defects, but G4 must declare whether its return is formed before or after this codiagonal.

## Metric version

An undeclared target metric \(G_H\) gives return

\[
U^{*_{G}}=G_V^{-1}U^*G_H.
\]

Prime diagonality then requires

\[
P_\lambda^HG_HP_\mu^H=0
\qquad(\lambda\ne\mu)
\]

on the source-generated ranges, or an equivalent annihilation after sandwiching by \(U_\lambda^*,U_\mu\). A globally coupled Green metric can therefore create cross-prime return even without cross-prime source incidence.

## Exact G4 alternatives

G4 must select one of three typed architectures:

1. labelled return before codiagonalization, which is source-prime-diagonal;
2. common-history return with a proved label-orthogonal metric;
3. common-history return with explicit cross-prime blocks and a Schur, Hilbert--Schmidt, or form bound.

Silently using source diagonality to justify the second architecture is invalid.

## Disposition

The source-level prime-return question is closed. The live issue is the placement of G4's return relative to codiagonalization and its target metric. Further cross-prime analysis without that choice would test an undeclared architecture. No RH conclusion is authorized.
