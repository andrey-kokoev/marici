# Global Maslov winding is an exact zero count, not yet an explanation

## Exact global invariant

The source-derived boundary line is

\[
L(s)=\operatorname{span}(X(s),1),
\]

and the endpoint reference line is

\[
L_0=\operatorname{span}(0,1).
\]

The Maslov cycle relative to \(L_0\) is the set of lines intersecting
\(L_0\). Therefore

The line \(L(s)\) lies in the Maslov cycle exactly when

\[
X(s)=0.
\]

On a boundary loop where \(X\ne0\), the relative Maslov index is the winding
number of \(X\).

## Positive local multiplicity

For a holomorphic section \(X=U+iV\), every simple zero has real Jacobian

\[
\det d(U,V)=|X'|^2>0.
\]

A multiple zero contributes its positive multiplicity. Hence the boundary
Maslov index equals the number of enclosed zeros counted with multiplicity.

This is an exact provenance theorem.

## Noncircularity gate

For a domain \(D\) in one open half-plane,

\[
\operatorname{Maslov}(L|_{\partial D},L_0)=0
\]

is equivalent to saying that \(D\) contains no zeros.

Therefore proving zero winding from the already assembled scalar boundary loop
is not an independent explanation. It is the argument principle in symplectic
coordinates.

The route becomes explanatory only if the source supplies a null-homotopy

\[
H:D\times[0,1]\longrightarrow
\operatorname{Lag}(V)\setminus\mathcal M_{L_0}
\]

constructed without dividing by \(X\), inspecting its zeros, or fitting its
phase. Such a homotopy would keep the entire disk away from the Maslov cycle
for a source reason.

## Hostile model

Let

\[
X(z)=z-a.
\]

Around a circle centered at \(a\), every local intersection orientation is
positive and the boundary line has Maslov index one.

For

\[
X(z)=1,
\]

the corresponding index is zero.

The local symplectic architecture is identical. The global divisor changes the
winding. Thus local orientation and determinant provenance cannot determine
the global index.

## Remaining admissible target

Construct one of:

1. a source-derived contraction of the boundary-line map in the Maslov-cycle
   complement;
2. a cross-germ conservation law that supplies that contraction;
3. a completed acyclic boundary complex whose contracting homotopy induces it;
4. a positive-real transfer law proving the full disk remains in one
   transverse Lagrangian chamber.

Absent such a constructor, the winding lane is an exact reformulation of the
zero-count problem.
