# Live costed cells and retained boundary modes

## Full closed two-cell state

The rank2 incidence complex has1152 rectangle cells, boundary rank113, and
closed2-chain dimension1039. Its two harmonic orientation classes leave a
1037-dimensional subspace of zero-class closed chains, generated by the2496
local3-boundaries.

The live store represents a closed cell state as

    x = Z1*h1 + Z2*h2 + b,
    d2*b=0,  <Zi,b>=0.

Here b is retained directly as a sparse source-cell vector. It is not restricted
to a selected small set of modes. The closure and harmonic-orthogonality tests
admit the entire boundary subspace. Since <Zi,Zj>=delta_ij/14, the parent
coordinates can be recovered as hi=14*<Zi,x>.

Under rectangle weight84, the chosen budget splits exactly:

    Q(x)=84*||x||^2=6*(h1^2+h2^2)+84*||b||^2.

The full state therefore retains independently changeable data invisible to the
two orientation coordinates. One local3-boundary has three coefficients +/-1;
adding that mode at zero b contributes cost252 while leaving h unchanged.

## Live parent propagation

The hierarchy has two primitive parent coordinates and one derived rank2 node.
A parent edit validates its expected version, changes that coordinate, and
rebuilds the source cells, triangle view, minimum source lift and complementary
residual. The internal vector b remains unchanged. Parent links immediately
record the new versions.

A root request can change both parent coordinates and b in one serialized
transaction. It carries store identity, root revision and both parent versions.
All version, arity, closure, zero-class and exact reconstruction checks run before
mutation. A parent change invalidates previously issued root requests.

Changing a parent does not erase the derived record's internal modes. An edit
presented as a b-only change must have zero harmonic coordinates; attempting
to disguise a class change as an internal mode is rejected.

## Full derived representation and retained cost

For each proposed closed state, the target triangle chain is T2*x. Its minimum
unconstrained source lift is certified by exact rational normal equations. The
residual reconstructs x and restores its source closure. The complete weighted
cost splits between that lift and residual after every update.

A direct full rebuild at the same (h,b) matches the live derived values exactly.
The tests also reject nonclosed edits, stale parent/root requests and disguised
class edits without changing any store field. LIFO compensation restores values
and costs while incrementing revisions and retaining the event sequence.

## Structural result

The costed comparison record now has a live interface with two parent classes
and a full1037-dimensional internal boundary-mode space. Parent changes and
internal changes have distinct scopes, with closure and metric budgets maintained
by the same commit path.

This exposes the next observation question: an orientation-only readout ignores
b even though b carries cost and changes retained cell values. A full quadratic
budget sees its magnitude but may still miss its direction. The intended system
readout must specify which internal changes it detects and how its return acts
on those modes.
