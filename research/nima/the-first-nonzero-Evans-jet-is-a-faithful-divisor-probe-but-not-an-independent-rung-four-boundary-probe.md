# The first nonzero Evans jet is a faithful divisor probe, but not an independent rung-four boundary probe

## Test

Let `z0` be a zero of exact multiplicity `m`, with normalized first nonzero jet

\[
\tau_m=\frac{\Xi^{(m)}(z_0)}{m!}\ne0.
\]

The sheet-paired Clark rows

\[
R_+=(1,\gamma_m\tau_m),
\qquad
R_-=(1,-\gamma_m\tau_m)
\]

have determinant

\[
-2\gamma_m\tau_m.
\]

They are jointly faithful on the rank-two endpoint/source state whenever
`gamma_m` is an authorized nonzero coefficient. The corresponding Gramian is

\[
G_m=
\begin{pmatrix}
2&0\\
0&2|\gamma_m\tau_m|^2
\end{pmatrix}.
\]

Thus the first nonzero jet can normalize a left/right terminal pair and prevent
loss of the source coordinate.

## Failure as the missing boundary relation

Write the completed section as

\[
\Xi=A Z,
\]

with `A` holomorphic and nonzero at the nontrivial zero. Then

\[
\Xi^{(m)}(z_0)=A(z_0)Z^{(m)}(z_0).
\]

The first nonzero jet is changed only by a nonzero frame factor. It detects the
divisor and multiplicity but contains no archimedean or Green term capable of
forcing the rung-four Hermitian residual to vanish.

Consequently a left null covector normalized by `tau_m` is a faithful divisor
observer. It is not independent evidence for

\[
\mathcal R_p(b_{z_0})=0.
\]

A Lagrange identity pairing this covector with the corrected state would still
need a separately derived global boundary concomitant whose value vanishes at
the terminal zero. Defining that value from the jet would reproduce the target
scalar rather than derive the missing relation.

## Disposition

The adjoint-jet route passes terminal faithfulness and multiplicity handling.
It fails the independence test for rung-four closure. It can serve as one leg
of a future nonlocal boundary law, but it does not construct that law.
