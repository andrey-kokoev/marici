# Native application bridge for a specialized Witness Generator

`agda/MetaWitnessNativeBridge.agda` encodes a compiled Layer-1 generator as a dependent function `s ↦ Σ(t : State) Witness(s,t)`. For a given state it constructs a `NativeApplicationExtension.Application` using a native P-family node for the function and atom nodes for the argument and dependent result. In the separately declared **extended** runtime, derivations of the function and argument produce a derivation of the computed result, its beta coherencer, and their combined native P package. The Boolean fixture uses only these two seed constructors; it derives the step result without admitting it. Its native result value retains the law evidence in the compiled generator witness, and the Boolean double-negation readout is proved from that actual witness.

This is a genuine bounded bridge into the *application-extended* native rule system, not into the frozen twelve-rule closure. The application rule is a separately justified extra primitive (`adapters/application-extension/README.md`); the old endpoint obstruction (`adapters/native-application/README.md`) still applies. `old-step-needs-result-seed` specializes that old exhaustive invariant to this actual WG result endpoint: any old-rule derivation of its principal atom would supply an admission certificate. The positive certified-family alternative uses the existing P-kind rule, but its premise family already contains a derivation of **every** result; it does not evaluate an opaque WG seed. Thus family selection cannot replace application under the tested seed policy.

The richer P presentation is **definitionally** the native `Pi-package State component`, where every `component s` contains the computed output value and witness as a retained package. This makes values visible in the syntax but supplies **no derivations** of those components. A `P-kind` derivation of that function from scratch requires a derivation of every component; seeding the P package alone does not turn those embedded values into certified premises. The old-rule selected premise is available only after those proofs have been supplied. The representation does not compile an arbitrary domain specification into old native rule constructors, prove cross-domain universal generation, or identify external Layer-2 history with native derivation history. The input and law certificate of the specialized step are recoverable in the typed output, while the extended derivation records the two input premises and the application rule.
