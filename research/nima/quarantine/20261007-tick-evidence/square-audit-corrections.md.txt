# Bool square audits: corrections

## Checkers corrected

### `check_general_square_generator.py`

**Earlier claim withdrawn:** "The full Tick (schedules, comparison, return)
provides no additional spectral constraint beyond what the corner parity
gives."

**Correction:** The Tick provides the FULL COMBINATORIAL SQUARE (source, two
intermediates, target, comparison, return).  This is faithfully captured by
the two-parameter evolution U(alpha,beta) = exp(-i alpha PL) . exp(-i beta PR)
at all four corners and along both boundary paths.  What the Tick does NOT
provide is a continuous rate/clock — the path parameterization itself is
conventional.  The spectral constraint analysis (centralizer + parity) is
correct for the diagonal path (one generator), but the square itself is
two-parameter and does not reduce to a single generator.

### `check_intermediate_states.py`

**Earlier claim withdrawn:** "The continuous path under H0 = PL+PR does NOT
match the Tick's sequential record" and implied this is a failure.

**Correction:** The path under H0 = PL+PR is the DIAGONAL path
alpha(t) = beta(t) = t through the (alpha,beta) square.  It does not visit
the schedule intermediates because it follows the diagonal, not the
boundary.  This is not a failure — it is a CHOICE of path.  The boundary
paths (leftFirst, rightFirst) DO visit the intermediates.  The two-parameter
evolution provides a structure in which all three paths (diagonal, leftFirst,
rightFirst) are valid, each with different intermediate behavior.

### `check_individual_logarithms.py`

**Earlier claim withdrawn:** The "modular arithmetic" parity proof was
invalid — it treated real-valued angles as integers.

**Correction:** The claimed conclusion (no single H generates L and R
individually) IS correct, but for a different reason:
A one-parameter subgroup {exp(-i theta H)} is isomorphic to S^1 / U(1),
which contains at most one nontrivial involution (element of order 2).
Since L and R are two DISTINCT involutions, no single H can contain both
in its one-parameter subgroup.  This is a group-theoretic obstruction,
not a parity/arithmetic one.

## What remains valid

1. The centralizer of {L,R} is 4-dimensional, spanned by I, PL, PR, PLPR.
2. The parity constraint `c even, a,b odd, d even` from exp(-i pi H) = LR.
3. All external choices (coordinate symmetry, independence, zero offset,
   unit gap) remain conventional, not Tick-derived.
4. H0 = PL + PR remains the simplest diagonal-path generator.

## Conditional evolution bridge

`agda/TickEvolutionBridge.agda` consumes actual Bool-valued retained Ticks.
Its `EndpointModel` contract supplies an encoding, a two-parameter evolution,
and four exact endpoint laws. Given that contract, the bridge proves source,
intermediate-corner, target, both actual schedule executions, and retained
return-section endpoint preservation. A concrete finite Boolean instance
inhabits the contract and evaluates both fresh and swapped Ticks.

This is a conditional realization theorem, not yet a continuous matrix
instantiation. The parameter type has no assumed topology, `encode` need
not be injective, and the dependent return-section interior is not mapped.
The remaining obligation is an exact real/complex evolution instance with
endpoint proofs and continuity; Python's floating-point checks do not
supply those proofs. Thus this does not establish faithfulness or the
stronger dynamics non-uniqueness claim.

## Exact four-coordinate polynomial realization

`agda/TickPolynomialRealization.agda` now instantiates `EndpointModel`
over any small ring, using vectors indexed by `Bool × Bool`, basis-vector
encoding, and the two bit-flip permutation operators. Its formula is
`U(a,b) = ((1-b)I+bR) ((1-a)I+aL)`. All four endpoint laws are derived
from ring laws; none are assumed as model-specific axioms. Applying the
existing bridge proves corner, actual schedule-execution, and return-endpoint
preservation for actual Bool-valued Ticks. A fresh `--ignore-interfaces`

is generally not unitary. The completion instance and limited continuity results below extend this
algebraic layer; no full dependent return-section interpretation or
faithfulness theorem is claimed.
