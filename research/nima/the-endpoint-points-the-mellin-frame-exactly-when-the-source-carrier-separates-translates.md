# The Endpoint Points the Mellin Frame Exactly When the Source Carrier Separates Translates

## Dual form of the character twist

The surviving relative-frame freedom is multiplication by

\[

\]

translation of the boundary coordinate:

\[
(T_aF)(q)=F(q+a).
\]

Let the endpoint incidence be evaluation at the actual source boundary,

\[
\delta_0(F)=F(0).
\]

After the twist, the incidence becomes

\[
\delta_0(T_aF)=F(a)=\delta_a(F).
\]

Thus a character twist preserves the endpoint incidence exactly when
\(\delta_a=\delta_0\) on the admitted source carrier.

## Endpoint stabilizer theorem

Let \(\mathcal F_{\mathrm{src}}\) be the boundary-bearing source function
space. Its endpoint stabilizer is

\[
\operatorname{Stab}(\delta_0)
=
\{a:\delta_a|_{\mathcal F_{\mathrm{src}}}

The logarithmic-origin torsor is pointed precisely when

\[

\]

Equivalently, for every nonzero \(a\), there must be a source-admitted

\[
F_a(a)\ne F_a(0).
\]

This is a separation theorem. No positivity or zero-location information is
needed.

## Why the full carrier matters

A single distinguished source vector need not separate the endpoint from all
of its translates. Accidental equality \(F(a)=F(0)\) at one nonzero \(a\)
does not establish a residual symmetry of the source system.

The incidence must be tested on the complete source-generated carrier,
including the tail, seam, endpoint augmentation, and any derivative channel
declared by the constructor. Restricting first to one scalar readout can create
a false stabilizer.

Conversely, inventing arbitrary test functions would falsely trivialize the
stabilizer. Each separating function must be generated by an admitted source
operation.

translation does not preserve both its endpoint and its support geometry.

This strengthens the pointing mechanism, but only if the incidence and domain
are retained through completion. A scalar Mellin transform that forgets
