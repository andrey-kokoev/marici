# The independent Tate current is place diagonal, so any retained cross-prime Green block is an explicit interface residual

## Question

Does the independent `C34` Tate current contain cross-prime Green blocks?

## Source decomposition

On the distinguished factorizable source, the completed Tate scattering factor
is a product of local factors. Its logarithmic derivative is additive:

\[
\partial_s\log\Gamma_{\rm Tate}(s)
=
\sum_v\partial_s\log\gamma_v(s).
\]

Accordingly the relative boundary current decomposes as

\[
q_{C34}^{\rm pol}
=
q_\infty^{\rm pol}
+
\sum_p q_p^{\rm pol}
+E_{\rm end}.
\]

Each local term acts on its own place-labelled observer coordinate. No term of
the form

\[
q_{p,q}(x_p,x_q),
\qquad p\ne q,
\]

is generated by the logarithmic derivative. Such a term would require a
nonfactorizable source operation or a separate Schur feedback coupling.
Neither belongs to the independent Tate construction.

The polarized principal-value/residue extension preserves this property: it
changes the boundary distribution in the spectral variable but does not mix
place labels.

## Interface consequence

Let the retained Green form be decomposed into diagonal and off-diagonal prime
blocks,

\[
G_{\rm ret}=\bigoplus_p G_{p,p}+G_{\rm off}.
\]

Packet equality with the independent Tate current requires

\[
G_{\rm off}(\Delta_\Xi,\Delta_\Xi)=0,
\]

and a functorial comparison requires the stronger vanishing of `G_off` on the
entire source-generated comparison domain.

Thus cross-prime return is no longer merely “uncontrolled.” It is an explicit
interface residual absent from the target current.

## Finite falsifier

At any two-prime cutoff `{p,q}`, evaluate the retained mixed block on the two
source-generated shell vectors. One nonzero value

\[
\langle x_p,G_{p,q}x_q\rangle\ne0
\]

refutes place-diagonal packet sewing. Vanishing only on the Xi state is
insufficient for a natural comparison; it may be accidental scalar
cancellation.

## Disposition

The independent Tate side is place diagonal by source construction. The next
executable retained-side test is the two-prime off-diagonal Green block. This
test is upstream of the RH-strength diagonal bulk equality and can falsify the
interface without evaluating a zero.
