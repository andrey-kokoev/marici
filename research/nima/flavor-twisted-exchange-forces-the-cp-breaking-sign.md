# Twisted exchange forces the CP-breaking sign

## Advance over the conditional two-doublet result

The earlier two-doublet audit left one binary obligation: D4 permits either equal or opposite quartic-anisotropy signs. Opposite signs remove every common generalized CP, but the representation did not select them.

A quarter-twisted exchange supplies exactly that selector without choosing a vacuum angle from data.

## Source operation

Let \(R_{\pi/4}\) rotate a doublet by \(\pi/4\), and define

\[
T(\phi_1,\phi_2)
=
\left(R_{\pi/4}\phi_2,R_{-\pi/4}\phi_1\right).
\]

This operation is an involution. If \(A_i\) denotes the D4 quartic angular invariant of doublet \(i\), a quarter-turn reverses it. Therefore

\[
T:(A_1,A_2)\longmapsto(-A_2,-A_1).
\]

Invariance of the general linear anisotropy \(\lambda_1A_1+\lambda_2A_2\) forces

\[
\lambda_1=-\lambda_2.
\]

The remaining overall sign only exchanges which doublet occupies the axis sector and which occupies the diagonal sector. Either branch has odd relative parity and the same CP conclusion.

## Full generalized-CP audit

The sign argument alone is insufficient because adjoining \(T\) enlarges the symmetry group. The new operation could have generated a disguised generalized CP stabilizer.

The checker constructs the full action generated by common D4 rotation, bare CP reflection, and \(T\) on all 64 labelled angle pairs. The generated group has 32 elements, 16 of them CP-odd. It then tests every CP-odd element against all 16 vacua selected by opposite anisotropy signs.

No selected vacuum has a CP-odd stabilizer.

Thus the same source relation that forces misalignment does not undo it through an enlarged generalized-CP group.

## Hostile deletion

Deleting \(T\) restores independent equal-sign coefficients. The aligned vacuum is then fixed by bare CP. This makes the twisted exchange load-bearing in two separate ways:

- it forces the relative coefficient sign;
- it removes the equal-sign CP-preserving branch from the invariant potential.
