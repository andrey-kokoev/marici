# The free reciprocal radial double is zero-free and cannot carry the Xi divisor

## Question

Does the reciprocally doubled radial derivative acquire an Xi-bearing kernel from maximal-isotropic wall sewing alone?

## Claim boundary

No. For every constant unitary wall sewing, the free doubled derivative has no \(L^2\) eigenvector at any complex parameter. It is the minimal conservative carrier, but its point spectrum is empty. Any Xi-bearing state must therefore use the declared source coupling and boundary response; it cannot be attributed to the free radial differential or a fitted sewing phase.

## Free doubled equation

Use

\[
\mathbb D=
\partial_t\oplus(-\partial_t)
\]

on \(L^2(\mathbb R_+)\oplus L^2(\mathbb R_+)\), with domain

\[
\operatorname{Dom}\mathbb D_u
=
\{(f_+,f_-)\in H^1\oplus H^1:f_-(0)=u f_+(0)\},
\qquad |u|=1.
\]

The homogeneous spectral equation

\[
(\mathbb D-z)F=0
\]

has solutions

\[
f_+(t)=a e^{zt},
\qquad
f_-(t)=b e^{-zt}.
\]

## Right and left parameter half-planes

If \(\operatorname{Re}z<0\), then \(f_+\in L^2\), while \(f_-\in L^2\) only if \(b=0\). Sewing gives

\[
0=b=u a,
\]

so \(a=0\).

If \(\operatorname{Re}z>0\), then \(f_-\in L^2\), while \(f_+\in L^2\) only if \(a=0\). Sewing then gives \(b=0\).

If \(\operatorname{Re}z=0\), neither nonzero exponential belongs to \(L^2(\mathbb R_+)\). Thus again \(a=b=0\).

Consequently

\[
\ker(\mathbb D_u-z)=0
\qquad\text{for every }z\in\mathbb C.
\]

The free doubled conservative block has empty point spectrum.

## Boundary-response interpretation

The two decaying Weyl channels exist in opposite parameter half-planes. At any fixed off-seam parameter only one is an \(L^2\) channel, while unitary sewing demands both boundary amplitudes. This mismatch prevents a free bound state.

Therefore a nonzero conservative kernel vector can arise only after adding a source-authorized interaction that changes the boundary response. In the radial programme those interactions include the endpoint forcing, Wronskian incidence, arithmetic synthesis, and their typed return.

A constant sewing phase cannot carry the Xi divisor. Making \(u=u(z)\) singular or defining it from \(\tau(z)\) would insert the desired zero set into the boundary condition and is circular unless derived independently from the source response.

## Relation to the exact radial section

The shell state solves an inhomogeneous equation

\[
D_t\rho=e-\frac12w.
\]

Its nonzero Laplace section comes from this forcing and the retained border:

\[
zR(z)-\rho(0)=E(z)-\frac12W(z).
\]

The free no-point-spectrum theorem does not constrain that response to vanish. It says only that the response must enter through the off-diagonal source and boundary blocks before a conservative kernel can occur.

This is the radial analogue of the earlier result that a strict same-sign passive complement cannot manufacture Xi zeros.

## Consequence for the finite G4 block

In

\[
\mathbb T_X^{\rm rad}(z)=
\begin{pmatrix}
\mathbb D_u-z&U_X^{\rm rad}\\
N_X^{\rm rad}&B_X(z)
\end{pmatrix},
\]

the diagonal radial operator is a zero-free conservative carrier. Any kernel must be detected by the Schur interaction

\[
B_X(z)-N_X^{\rm rad}(\mathbb D_u-z)^{-1}U_X^{\rm rad}
\]

where the resolvent exists, together with its continuation across the continuous-spectrum seam. Hence both source links and the border are mathematically essential; triangular incidence cannot affect the zero locus.

The displayed Schur expression is not yet the G4 response law. Its use requires the canonical return type, source-derived arithmetic block, and determinant-line continuation.

## Multiplicity consequence

Because the free radial kernel is always zero, Xi multiplicity cannot come from a Jordan chain of \(\mathbb D_u\). It must be transported by the parameter derivatives of the coupled response. Therefore the full jet identities remain mandatory after reciprocal doubling.

## Hostiles

A checker must reject:

1. a claimed free eigenvector using the growing channel in either parameter half-plane;
2. an oscillatory seam exponential treated as \(L^2\);
3. a nonunit sewing multiplier used to create decay imbalance;
4. a parameter-dependent sewing phase defined from the target Xi section;
5. a triangular source link claimed to alter the determinant;
6. Xi multiplicity assigned to the free radial diagonal rather than the coupled response jets.

## Disposition

Reciprocal doubling repairs the conservative boundary index but does not create spectral zeros. The radial diagonal is a zero-free carrier. The exact next object is the source-derived two-sided boundary response whose Schur interaction realizes the fixed radial bordered section while preserving all Xi jets. No RH conclusion is authorized.
