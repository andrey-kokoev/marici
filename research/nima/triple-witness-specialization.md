# Three-stage WG specialization: bounded rebracketing test

`agda/TripleWitnessSpecialization.agda` takes a supplied first compatible WG/domain pair, a second domain that uses exactly the first compiled generator, and a third domain that uses exactly the second compiled generator. Each stage supplies its own agreement and admission closure; none is inferred from matching carrier types. The three-stage state can be presented by flattening the inner two layers first (`LeftGrouped`) or all layers into one dependent tuple (`RightGrouped`). `left-as-right` checks those presentations agree. `right-iso` and `step-reassociate` give inverse maps on the full state and endpoint-plus-relation-witness types, respectively; `generated-step-agrees` checks that the *actual generated witness* follows the same comparison, not just the state labels.

The checked fixture starts with certified selection and its execution-trace admission, then adds two unit-admitted layers to exercise the three-stage result. These last two layers do not introduce new independent domain operations; they test retention and rebracketing. The result is **not** a generic associativity theorem for a composition operator on arbitrary domain specifications, a four-stage pentagon, or proof of elimination under the original twelve native rules. A later algebra of view composition would need its own operation on domain presentations and coherences among these rebracketings.
