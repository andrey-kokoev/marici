# Restricted invertibility of grouped 2-packets on the tetrahedral carrier

## Correction: scope of this model

The maps called alpha and beta below are copy/expansion and averaging readout, **not** the lossless group-by-from/to operations documented in `incidence-rung-tower.md`. The restricted-inverse theorem remains valid for this separate model. The inference that signed subtraction is missing from the actual grouping cycle is withdrawn. See `grouping-is-reindexing-not-averaging.md` for the corrected cycle and current synthesis status.

## Result and scope

Index four scalar states by the vertices of K4 and twelve packet slots by its directed nonidentity edges. Define source and target incidence matrices by

    S[i,(u->v)] = delta(i,u),
    T[i,(u->v)] = delta(i,v).

The proposed packet primitives are

    alpha = S^T : R^4 -> R^12,
    beta = T/3 : R^12 -> R^4.

Alpha copies each source into its three outgoing packets. Beta averages the three packets arriving at each target. Thus

    b = beta alpha = (J-I)/3.

Here 'admissible packet space' means im(alpha), by definition of this model. Identifying these matrices with existing executable Marici packet operations is a separate implementation audit. No physical admissibility or particle identity is inferred merely from the matrix construction.

## Two-dimensional operator algebra

The exact identities are

    b^2 = I/3 + 2b/3,
    (b-I)(b+I/3) = 0,
    P = (I+3b)/4 = J/4,
    Q = 3(I-b)/4 = I-P.

P and Q are complementary orthogonal projectors with ranks one and three. In particular P is not I; it selects the uniform mode. Both eigenvalues 1 and -1/3 occur, and

    b = P-Q/3,
    b^-1 = P-3Q = 3b-2I = J-3I.

The operator algebra span{I,b}=span{P,Q} has dimension two while acting invertibly on the entire four-dimensional state space. This is compact operator description, not compression of four independent scalar values into two values.

## Explicit forward and return

For y=bx,

    y_i = sum_{j != i} x_j / 3,
    sum_i y_i = sum_i x_i = s,
    x_i = s-3y_i.

The forward operation retains every contrast while multiplying it by -1/3. Return multiplies contrast by -3, and b^-1 b=I. No stored copy of x is necessary for exact reconstruction from y. Inversion amplifies errors; invertibility does not imply Euclidean unitarity or noise-free implementation.

## Restricted inverse and packet-space splitting

Define

    gamma = alpha b^-1 : R^4 -> R^12.

Then

    beta gamma = I4,
    gamma beta alpha = alpha.

Consequently beta restricted to im(alpha) is an isomorphism onto R^4, with inverse gamma. Since alpha has rank four, the twelve generated packet values are constrained, not independent.

The packet-space map

    Pi = gamma beta = alpha b^-1 beta

satisfies

    Pi^2 = Pi,
    im(Pi) = im(alpha),
    ker(Pi) = ker(beta).

Thus

    R^12 = im(alpha) direct-sum ker(beta),
    12 = 4+8.

Pi is an oblique projector, not the Euclidean orthogonal projector onto im(alpha). Every packet vector p decomposes uniquely as Pi p + (I-Pi)p. The second term lies in ker(beta). No nonzero kernel vector is generated by alpha. Calling those eight directions extraneous is justified relative to this declared generated subspace, not for an arbitrary physical packet model.

Explicitly, with s=sum_i y_i,

    (gamma y)_(u->v) = s-3y_u.

All three reconstructed outgoing packets from u recover the same source value. No separate copy of the twelve-packet state is required on the generated subspace.

## Positivity obstruction and implementation target

Composition, addition with nonnegative coefficients, and positive averaging of entrywise nonnegative matrices remain entrywise nonnegative. They cannot produce the inverse J-3I, whose diagonal entries are -2, on these same scalar coordinates. The same obstruction applies to gamma, whose rows contain a -2 source entry.

The return needs the operational equivalent of recovering s and forming s-3y_i. A signed encoding could relocate that operation into encoding or decoding, but would not remove the need to account for it.

The exact packet expression is

    gamma = alpha(3 beta alpha - 2I)
          = 3 alpha beta alpha - 2 alpha.

Therefore no new map generator is needed in a calculus closed under signed linear combinations. In a calculus allowing only positive grouping and composition, the expression is not yet executable. This distinction separates information sufficiency from operational availability.

Local inspection establishes that the documented group-by-from/group-by-to operations are reindexings, not these maps. The prior identification is therefore withdrawn. Only an independently specified averaging reduction would make this inverse relevant to that cycle. Matrix support counts likewise do not establish a pruning-minimal execution graph or a particle-pair cost.
