# qRB microstep 84: readout-identification test

The previously proposed equality was too strong and is withdrawn. The correct test is block placement on a common source core:

$$
K_{\rm link}=-\frac12J_{\rm link},
\qquad
\omega_{\rm link}(u,v)=\langle J_{\rm link}u,v\rangle,
$$

with the bounded skew response block inserted alongside, not identified with, the old Green boundary form.

The test must preserve the ordered prime half-density, endpoint terms, and Wronskian orientation. Comparison with the old symmetric Green form is invalid: prior research gives explicit compact witnesses on which those forms differ.

A finite source packet must therefore test block placement and skew cancellation, not equality of the linking form with the Green/source form.

Status: equality gate withdrawn; bounded skew-block placement is the valid target.
