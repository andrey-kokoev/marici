# Paw → tetrahedron: local 3D cycle

Open `index.html` directly in a browser. No server, build or internet connection
is required. Keep `app.js` and `vendor/` alongside the HTML.

- Play/pause or use the timeline scrubber.
- Stage buttons jump to the initial paw, the end of each rotation, or closure.
- Drag to orbit; scroll/pinch to zoom; Reset view restores the camera.
- Toggle orientation traces and tetrahedral faces.
- Space toggles playback when a form control is not focused.

## Construction

Uses the same rotation/completion sequence as `../../paw-rotor-tetrahedron.md`,
with an updated unit-edge seed:
A=(0,0,0), B=(1,0,0), C=(1/2,sqrt(3)/2,0), D=(-1/2,sqrt(3)/2,0).
The original AB,AC,BC,AD edges all have length1. Body rotation preserves these
lengths; leg rotation about transported AC preserves AD and the candidate CD.
The condition BD=1 gives cos(theta)=-1/3, so the leg rotates approximately
109.47 degrees. The body rotates60 degrees about AD.
The closure phase displays BA+AD and CA+AD, then fades in complete unit-length
BD and CD. It never draws partial-length structural edges. The result is a
regular tetrahedron with volume sqrt(2)/12. The initial four edges each
represent reciprocal packets; completion takes the directed count from8 to12.
Face filling is shown only at closure. The volume display reports enclosed volume after the new edges
complete, while the inspection interface also reports the vertex-hull volume
during motion.

Animation duration is illustrative. The continuous-family quotient suggested
by the many:1 stage is not implemented; orientation traces and the transported
frame show the tested geometric operations.

## Validation

From the repository root:

```
node research/nima/demos/paw-cycle/check.mjs
```

Uses the repository's Playwright dependency and installed Chromium. Checks:

- direct `file://` loading with all HTTP(S) requests blocked;
-201 timeline samples against independent Rodrigues coordinates and volume;
- every visible structural edge has length1, including during closure fading;
- all six final edges and regular-tetrahedron volume sqrt(2)/12;
- stage selection, play/pause, reset and display toggles;
-390-pixel mobile layout without horizontal overflow;
- no page errors.

`preview.png` and `preview-mobile.png` are generated by this check.
