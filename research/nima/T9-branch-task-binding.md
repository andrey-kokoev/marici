## A shared-leg hostile, not independent writable record memory

To test whether retained members are necessary, construct TWO separate mathematical shared-leg preparations with the same labels/endpoints/weights and d=2I.

Baseline: all leg maps are I.

Let n_u be the number of selected arrow legs with target u; in the current marked view

    n=(3,2,3,3).

For epsilon=1/10, change only:

    arrow left leg X_i=(1+epsilon/n_target(i))*I,
    state right leg T_v=(1-epsilon*n_v)*I.

Leave arrow right legs and state left legs at I. All maps remain invertible. These are finite shared-leg assignments; no independent137-record correction coordinates are introduced.

For observed endpoint pair(u,v), the merged family contains n_u n_v arrow records and one state record. Its total change is

    n_u n_v*(epsilon/n_u)*I - epsilon*n_v*I = 0.

Consequently ALL16 outer endpoint-family means, masses, labels and endpoints are identical between the two preparations. J4 is identical too.

But their branch means change by

    delta J_arrow=(4/11)*epsilon*I=(2/55)*I,
    delta J_state=-(11/4)*epsilon*I=-(11/40)*I.

The weighted aggregate changes cancel. The full retained member packets distinguish the preparations.

This proves that no function of those16 outer mean rows alone recovers both branch means on the supplied shared-leg input class. It is a nonlinear factorization obstruction as well as a linear one: the entire input table to such a function is identical.

These controls are different admissible mathematical preparations, not a claimed physical evolution or recalibration of the original frozen fixture.

## What now determines the endpoint choice

A concrete specification can choose between:

1. **Inherited member readout:** query branch information through retained leaves. All tested policies preserve it; branch preservation does not select T9.
2. **Direct tagged endpoint task:** outer routing keys expose both observed endpoint pair and branch tag. Within the endpoint-preserving context class, this excludes arrow/state merges and selects inherited keys up to renaming.
3. **Outer mean-only branch response:** merged means are insufficient for the tested shared-leg class; retain additional branch summaries or members. Adding those summaries is a declared observation interface, not a physical selection of a transport law.

Branch-uniformity by itself does not imply32 families among ALL possible partitions: different arrow endpoint fibres could still merge. The32-fibre conclusion additionally requires preserving the endpoint-pair task.

Thus the input still missing is no longer simply "preserve the tag?" It is:

**Must the protected question factor through the OUTER promoted interface, or may it read the retained members?**

The organizing architecture guarantees retained members, but does not currently select that restricted outer-only observation task. Numerical J4 alone cannot decide it.
