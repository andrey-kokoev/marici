# A Fourth RH Observer Requires a Nondegenerate Boundary Pair

## Refinement

Splitting the seam into a value channel \(M\) and a flux channel \(J\) is not
enough by itself. Two names can describe one degree of freedom. The exact test
is whether the source supplies a nondegenerate boundary pairing

\[
\omega((M,J),(M',J'))=MJ'-JM'.
\]

If this form is nonzero on some pair of admissible seam states, value and flux
are genuinely independent ports. If every seam state lies on a scalar graph

\[
J=LM,
\]

then the restriction of \(\omega\) vanishes identically and the alleged fourth
observer is only another coordinate on the original seam port.

## Reciprocal action

The candidate reciprocal reflection acts on seam data by

\[
(M,J)\mapsto(M,-J).
\]

It reverses the boundary form:

\[
R^{T}\Omega R=-\Omega,
\qquad
\Omega=
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix}.
\]

This is the correct typing for an interface reflection. The value channel is
even, the flux channel is odd, and their alternating pairing records directed
crossing orientation.

## DPC

Candidate principle: the seam contributes a fourth independent observer.

Required source evidence:

- two boundary traces are constructed before scalar completion;
- their admissible state space contains a pair with nonzero boundary pairing;
- reciprocal sewing fixes the value trace and reverses the flux trace;
- cutoff extension preserves the boundary form;
- neither trace is reconstructed from the other by a source graph law.

Finite falsifier: evaluate the determinant

\[
\Delta_{\partial}=MJ'-JM'
\]

on two source-generated seam states. If it vanishes for every tested state and
a source law \(J=LM\) is found, the fourth-port proposal collapses. A single
nonzero source-generated determinant proves that one seam scalar is
insufficient.

## Conservation architecture

If the pair is genuine, the doubled system should be typed as a boundary
relation, not as a collection of independently positive channels. The natural
law is a matching of odd currents,

\[
J_{\mathrm{tail}}+J_{\mathrm{seam}}=0,
\]

while the even seam value supplies the conjugate boundary coordinate. A
lossless admissible boundary condition should define an isotropic or Lagrangian
relation in the combined tail–seam boundary space.

This makes the earlier endpoint warning concrete. Endpoint, gamma, and prime
currents are not separate positive ports; they may jointly construct the seam
flux required to close the boundary relation.
