# No behaviour-only test can certify source explanation

## No-go theorem

Let

\[
E=(X,\{T_u\}_{u\in\mathcal U},\{R_j\}_{j\in\mathcal J})
\]

be any deterministic intervention system, with state set \(X\), admitted
transition maps \(T_u\), and readouts \(R_j\).

Construct a table realization \(E_{\mathrm{tab}}\) whose stored transition
table contains every value \(T_u(x)\) and whose output table contains every
value \(R_j(x)\). The identity map on \(X\) is an isomorphism of intervention
systems:

\[
E\cong E_{\mathrm{tab}}.
\]

They consequently have identical behaviour under every finite intervention
word and every declared probe.

Therefore no criterion invariant under complete intervention behaviour can
distinguish a source mechanism from its extensional table realization.

This remains true after minimal realization. The table can be formed on the
minimal future-equivalence state itself.

## What the theorem does and does not say

The theorem does not say that lookup tables and mechanisms are equally useful
to a human investigator. It says that their difference is not contained in
the frozen extensional behaviour.

The distinction can lie in:

- how the transition law was derived;
- which state coordinates have source meaning;
- how the model extends when the intervention vocabulary changes;
- which neighbouring systems share the same constructor;
- which conservation, locality, or typing laws generated the table;
- what evidence authorizes the state-to-source interpretation.

These are provenance and intensional-structure data.

## Explanation is a relation, not a bare realization

An explanatory object must therefore contain at least

\[
(S,E,\pi),
\]

where:

- \(S\) is the independently specified source packet;
- \(E\) is an intervention realization;
- \(\pi\) is a checkable derivation of the state types, transitions, ports,
  and lower-lens readouts of \(E\) from \(S\).

The realization alone can be behaviourally adequate. The pair \((E,\pi)\)
can additionally carry explanatory provenance.

A compiled lookup table may retain explanatory status when \(\pi\) records a
valid compilation from a source-derived mechanism. The same table presented
without that derivation has only behavioural authority. Thus explanatory
status is not determined by surface implementation form.

## Proof-carrying realization gate

The derivation object \(\pi\) must establish:

1. source typing of states and intervention ports;
2. constructor laws for the transition generators;
3. descent of those generators through declared source relations;
4. derivation of Product and Sum readouts from the ordered action;
5. covariance under authorized source re-presentations;
6. prospective composition beyond the observations used to select the model;
7. completion or domain control where infinite limits are admitted.

The derivation must be independently criticizable. A certificate that merely
restates the transition table in source vocabulary supplies no explanatory
gain.

## Anti-circularity test

Let \(\mathcal G_{\mathrm{src}}\) be the source grammar and let
\(\operatorname{Eval}(\pi)\) be the realization generated by a derivation.
The explanatory direction is

\[
S
\xrightarrow{\pi}
E
\xrightarrow{\Sigma}
\mathcal Y.
\]

A backward fit

\[
\mathcal Y
\longrightarrow
E
\longrightarrow
\pi_E
\]

does not acquire source authority merely because \(\pi_E\) is formatted as a
derivation. At least one load-bearing source law used by \(\pi\) must be
frozen independently and must exclude an otherwise behaviour-compatible
hostile continuation or neighbouring system.

## Control-theoretic interpretation

Minimal realization theory identifies the smallest state machine for a
declared input-output behaviour. It answers:

> What internal state dimension is sufficient and necessary for this
> behaviour?

It does not by itself answer:

> Which physical or computational mechanism gives those states their source
> meaning?

The first is a realization theorem. The second is a constructor derivation.
They are complementary and neither should impersonate the other.

## Hostile cases

1. **Table compilation:** compile a proposed mechanism into an extensionally
   identical table and erase the compilation record.
2. **Semantic relabelling:** rename table states using physical nouns without
   deriving the correspondence.
3. **Certificate replay:** encode every observed transition as a separate
   source axiom.
4. **Vocabulary lock:** declare only interventions already present in the
   fitted table.
5. **Neighbour failure:** the proposed source law gives no prediction for a
   nearby system generated by the same grammar.
6. **Completion patch:** add a limit-state rule only after finite convergence
   fails.

Any behaviour-only explanation criterion passes the first hostile by
construction.

## Revised Deutsch--Popperian conjecture

Understanding is carried by a proof-bearing intervention realization
\((S,E,\pi)\) for which:

- \(E\) is minimal and completion-stably identifiable from the declared
  intervention behaviour;
- \(\pi\) derives \(E\) from independently constrained source constructors;
- the same derivation restricts the hostile class and predicts prospective
  compositions;
- every non-gauge variation preserving the source grammar changes a declared
  or prospectively derived consequence.

The hard-to-vary property belongs to the entire source--derivation--realization
triangle, not to a scalar prediction or state-space model in isolation.

## Consequence for the three lenses

The Endo lens is necessary but not sufficient for explanation. It supplies
the intervention machinery missing from Sum and Product shadows. Explanatory
authority arrives only when a source derivation constructs that Endo action
and derives the lower lenses from it.

The hierarchy therefore ascends from Sum/Product agreement, through minimal
Endo realization, to proof-carrying source realization.
