# The scale-order virial is reciprocal-even and cannot confine zeros

## Strict crossing

For a finite Mellin packet, a scalar zero produces a nonzero zero-mean state
\(v\). With scale operator \(\Lambda\) and order operator \(S\), define

\[
J=-i\langle v,Sv\rangle.
\]

The source flow gives

\[
J'=\langle v,[\Lambda,S]v\rangle.
\]

The finite calculation shows strict positive crossing at every scalar Mellin
zero. Because this also holds for hostile sources and every horizontal
parameter, it is an orientation theorem, not a confinement theorem.

## Reciprocal parity

On a centered two-label fiber, reciprocal exchange reverses both scale and
order:

\[
\Lambda\longmapsto-\Lambda,
\qquad
S\longmapsto-S.
\]

Consequently,

\[
[\Lambda,S]
\longmapsto
[-\Lambda,-S]
=[\Lambda,S].
\]

The virial operator is reciprocal-even. The two reciprocal sheets therefore
carry the same crossing sign after the genuine source transformation.

Flipping only \(S\) would reverse the virial sign, but that operation is not
the full reciprocal source map because it leaves scale orientation unchanged.
Using it would manufacture the desired contradiction by mistyping the
transport.

## Consequence

Reciprocal sheet sewing cannot confine zeros using the scale-order commutator
alone. A zero on either sheet can cross with the same positive orientation.

Any RH-bearing contradiction requires a source channel with genuinely odd
reciprocal parity after all transported structures are included. Candidate
locations are:

- endpoint incidence;
- archimedean boundary orientation;
- primitive or square boundary currents;
- a relative determinant comparison between the two completed sheets.

The parity must be computed on the complete coupled packet. It cannot be
assigned to the order operator in isolation.

## Finite falsifier

For every proposed opposite-sheet virial law, apply reciprocal exchange to both
\(\Lambda\) and \(S\). If the claimed sign changes while the exact
commutator remains invariant, the law is mistyped.
