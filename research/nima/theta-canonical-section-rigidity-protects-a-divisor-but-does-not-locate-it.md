# Canonical-section rigidity protects a divisor but does not locate it

## What presentation rigidity proves

Let \(M(s)\) be a finite source-derived bordered matrix. An independently
authorized change of input and output frames has the form

\[
M(s)\longmapsto P(s)M(s)Q(s),
\]

where \(P\) and \(Q\) are holomorphically invertible. Then

\[
\det(PMQ)
=
\det P\,\det M\,\det Q.
\]

The two new factors are holomorphic units. Contractible invertible
stabilizations likewise multiply the determinant by a unit. Therefore all
authorized presentations of one fixed operator object have the same divisor.

This is a real theorem. It removes the earlier exponential frame ambiguity
once the source object and admissible presentation category are fixed.

## What it does not prove

Divisor invariance does not constrain the location of the intrinsic divisor.
The one-dimensional family

\[
M_a(s)=s-a
\]

already has a canonical divisor at \(s=a\). Every authorized invertible
presentation preserves that zero. Presentation rigidity is fully satisfied
for arbitrary \(a\).

Thus the implication

\[
\text{hostile divisor requires a new block}
\]

means only that the hostile section is not another presentation of the same
fixed object. It does not show that the original object has no off-seam
divisor.

A new block is precisely what a genuine source perturbation should produce.
Rejecting it merely because it is new would make the hostile test vacuous.

## Two distinct hostile classes

The programme must distinguish:

1. presentation hostiles, which change coordinates or stabilization while
   claiming to represent the same source object;
2. source hostiles, which alter admitted primitive weights or boundary
   incidence while preserving the declared grammar, symmetry, and completion
   laws.

Canonical-section rigidity rejects the first class. An RH-bearing orientation
law must reject or control the second class for a source-local reason.

The actual prime source may possess a special property absent from hostile
sources. That property must be named and derived. It cannot be replaced by
the assertion that the actual source object is fixed.

## Completion theorem and its missing premise

Suppose finite sections \(\sigma_X\) are nowhere zero on an open domain and
converge locally uniformly to a nonzero limit \(\sigma\). Hurwitz then implies
that \(\sigma\) is nowhere zero there.

The essential premise is finite zero-freeness of the assembled boundary
sections. Local prime-chain acyclicity supplies this only for the eliminated
interiors. It does not yet prove that

\[
M_X(s)=A_X(s)-R_X(s)D_X(s)^{-1}C_X(s)
\]

is invertible.

Convergence of comparison units between presentations also does not supply
that premise. It proves that equivalent presentations have the same limiting
divisor.

## Relative extension information

Benincasa's corrected source object is the relative-cohomology extension

\[
\widetilde H^0(D_i)
\longrightarrow
H^1(E_i,D_i)
\longrightarrow
H^1(E_i).
\]

Its Abel–Jacobi class specializes to an order-two point in the generalized
Jacobian. The bridge term is presently an external cup product of relative
extension generators. This proves that coarse scalarization can retain a
mixed de Rham or symbol-level channel while forgetting its labelled genesis.

It does not yet prove the existence of a physical deck-parity observable or a
\(\mu_2\) character. That claim requires a source-derived Kummer or Betti
realization and a relative-cycle pairing.

Therefore the boundary carrier must retain the relative extension class until
the comparison map determines whether it becomes a discrete character,
specializes diagonally, is traced, or remains unobservable.

## Sharp remaining theorem

The current RH gate has two independent parts:

1. construct the canonical completed boundary operator \(M(s)\), including
   every source-retained relative boundary coordinate;
2. derive a source law that makes every finite \(M_X(s)\) invertible in each
   open half-strip and survives completion.

Presentation rigidity then makes the conclusion frame-independent, and
Hurwitz can transport finite invertibility to the limit. It cannot replace
either part.

## Finite falsifiers

For any claimed rigidity proof:

- test the scalar family \(M_a(s)=s-a\); if the proof would exclude its zero
  using presentation invariance alone, it is invalid;
- insert a new source-authorized block rather than a frame change; if the
  proof rejects it solely for changing the object, the hostile class was
  defined circularly;
- retain the labelled relative-cohomology extensions until a Kummer or Betti
  comparison and relative-cycle pairing determines whether they carry a
  discrete physical distinction;
- compute finite boundary invertibility before invoking Hurwitz.

## Disposition

Canonical-section rigidity is the correct gauge theorem for a fixed
source-derived operator. It closes presentation ambiguity and identifies
completion escape with failure of stable unit comparison.

It is not an orientation theorem. The unresolved content remains finite
boundary invertibility for the actual source and a noncircular property that
distinguishes that source from admitted hostile perturbations.
