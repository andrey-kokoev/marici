# The native tail determinant has one moving line and one null line

## Proven symplectic bridge

The theta tail system supplies the source-selected boundary vector

\[
b(s)=(X(s),1)
\]

and the endpoint condition line

\[
\ell_0=(0,1).
\]

Their bilinear symplectic determinant is

\[
\omega(b(s),\ell_0)=X(s).
\]

Therefore a scalar zero is exactly loss of transversality of two
source-derived boundary lines. This is a genuine zero-to-rank-loss bridge.

## Signature audit

For

\[
q(u)=i\omega(u,\overline u),
\]

the fixed endpoint line is null:

\[
q(\ell_0)=0.
\]

The moving line has

\[
q(b(s))
=
i(X(s)-\overline{X(s)})
=
-2\operatorname{Im}X(s).
\]

Thus the current construction does not provide two nonzero opposite
signatures. It provides one moving line and one permanently null reference
line.

## Consequence

To prove the moving line cannot meet the null reference line off seam, one must
show

\[
\operatorname{Im}X(s)\ne0
\]

with a fixed sign in each open sector.

That is precisely the scalar Herglotz orientation problem in symplectic
coordinates. The native determinant explains the divisor geometrically but
does not independently confine it.

## Noncircular next target

The opposite-signature theorem becomes new only if reciprocal doubling supplies
a second moving boundary line

\[
b_-(s),
\]

not the fixed null endpoint line, such that:

\[
q(b_+(s))>0,
\qquad
q(b_-(s))<0
\]

off seam and

\[
\Xi(s)=u(s)\omega(b_+(s),b_-(s))
\]

for a source-derived nowhere-zero unit \(u\).

Then nonintersection follows from opposite signatures without requiring either
individual scalar coordinate to be Herglotz.

## Finite falsifier

For any claimed two-sector signature proof, compute the signature of both
actual trace lines. If either line is the fixed endpoint line or remains null
off seam, the opposite-signature argument does not apply.
