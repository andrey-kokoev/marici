# Five-port minimality is objective-indexed

## Question

Are signal, observer, gate, body/reference, and resource genuinely necessary,
or can the five-role architecture be varied freely without changing its
predictions?

## Capability contract

Minimality is meaningful only relative to a declared objective. The full
active relational objective requires:

1. distinguishing injected source states;
2. independently modulating source-to-observer transfer;
3. resolving an oriented rather than merely unsigned response;
4. accounting for output resource or gain provenance;
5. producing an empirical readout.

For this objective, the five roles are candidates for conjunctive minimality.
A passive transport objective does not require a gate or gain resource. An
unsigned invariant objective need not select a body orientation. Therefore
there is no universal theorem that every coherent system has five ports.

## Ablation predictions

Each role has a distinct deletion witness.

### Delete source

Two admitted source values map to the same null injection. Source
distinguishability fails.

### Delete gate

Two admitted gate settings produce the same fixed transfer. Independent
modulation fails.

### Delete body/reference

The signed body values (b) and (-b) become identical under the even
readout (b^2). Orientation selection fails while unsigned detection may
survive.

### Delete resource

An amplitude gain from one to three changes quadratic energy from one to nine
without a balancing supply or exported flow. Active provenance fails while the
input-output map may remain algebraically writable.

### Delete observer

Distinct internal outputs have the same empty empirical record. Testability
fails while internal dynamics may remain well defined.

These failures are not interchangeable. Adding an observer does not restore a
resource balance; adding a resource does not construct a gate; adding a gate
does not select orientation.

## Hard-to-vary theorem boundary

The architecture is hard to vary only after each role is tied to:

- an independent intervention or source constructor;
- a distinct failure signature;
- a readout or balance equation;
- and an explicit objective requiring that capability.

Naming a boundary current “resource” or a chamber “gate” supplies none of
these. The live sector must construct the intervention and reproduce the
ablation signature.

## RH application

The theta compiler presently has a narrower exact result. Within its declared
fixture, valuation/Fock boundary incidence with completion and one fixed finite
Clark-dominating constructor family are conjunctively minimal: neither alone
produces a completed path, while both produce exactly the three paths allowed
by seam-before-completion precedence.

This is a compiler sufficiency theorem conditional on the two constructors. It
does not establish that the theta source supplies them. Nor does it yet prove
the full active five-role objective.

## DPC

For any proposed sector device:

1. freeze the claimed capability vector;
2. ablate each proposed role independently;
3. record the first failed capability, not merely endpoint inequality;
4. test all combinations needed for conjunctive versus alternative sufficiency;
5. require source existence separately from compiler sufficiency;
6. reject a role whose deletion changes no declared prediction.

## Disposition

The five-role architecture passes a finite objective-indexed ablation DPC. It
is minimal for the full active relational capability vector used by the
checker. It is not universally minimal for every system, and RH currently
establishes only a smaller conditional two-constructor ablation theorem.
