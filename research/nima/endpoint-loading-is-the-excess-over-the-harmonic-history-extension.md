# Endpoint loading is the excess over the harmonic history extension

## Variational decomposition

Fix the Laplace relative graph energy

\[
E_\sigma(f)
=
\int e^{2\sigma|u|}|f'(u)|^2\,du
+
|f(-\infty)|^2
+
|f(+\infty)|^2.
\]

For prescribed endpoint traces, the unique minimum-energy derivative is proportional to the inverse weight:

\[
f'_{\min}(u)
=
\frac{d}{I_\sigma}
e^{-2\sigma|u|},
\qquad
d=f(+\infty)-f(-\infty),
\]

where

\[
I_\sigma=\frac1\sigma.
\]

Let \(P_{\min}\) denote the harmonic endpoint extension and write

\[
f=P_{\min}f+f_0,
\]

where \(f_0\) has zero endpoint traces.

The Euler--Lagrange equation makes the decomposition energy-orthogonal:

\[
E_\sigma(f)
=
E_\sigma(P_{\min}f)
+
E_\sigma(f_0).
\]

## Schur interpretation

The resolved boundary return is exactly the minimum endpoint energy

\[
R=E_\sigma(P_{\min}\,cdot).
\]

If the endpoint block \(A\) is the full source history energy, then

\[
A=R+Q,
\]

with

\[
Q=E_\sigma((I-P_{\min})\,cdot).
\]

Therefore the endpoint Schur complement is the excess-energy Gram:

\[
G_{\mathrm{eff}}=Q.
\]

Positivity is automatic. Strict positivity on a source incidence plane holds precisely when that plane contains no nonzero harmonic minimum extension.

## Theta source plane

On the two-dimensional theta plane, the conjugated derivatives are generated by weighted versions of \(\Phi\) and \(\Phi'\). Every harmonic minimum derivative is proportional to

\[
e^{-2\sigma|u|}.
\]

No nonzero linear combination of the theta derivatives equals this profile:

- theta derivatives are smooth across \(u=0\);
- \(e^{-2\sigma|u|}\) has a cusp at \(u=0\);
- theta derivatives have superexponential tails;
- the harmonic profile has only exponential tails.

Hence

\[
operatorname{span}\{\mathcal I\Phi,\mathcal I\Phi'\}
\cap
\operatorname{ran}P_{\min}
=
\{0\}.
\]

Thus \(Q(\sigma)>0\) on the theta incidence plane for every \(\sigma>0\).

## Uniform compact margin

The excess-energy Gram depends continuously on \(\sigma\). On each compact interval

\[
\sigma\in[\sigma_0,\sigma_1]
\subset(0,\infty),
\]

finite dimensionality gives

\[
Q(\sigma)\ge q_0G_0
\]

for some \(q_0>0\).

Mellin transport and Euler scaling carry this to every prime-power fiber. Therefore endpoint loading is uniformly strict on compact off-seam regions.

## Authority qualification

The variational theorem identifies the endpoint return only if the source Schur incidence is the harmonic extension map for the same Green energy. If the actual return uses another resolvent, the equality

\[
R=E_\sigma(P_{\min}\,cdot)
\]

must be proved rather than inferred.

## Consequence

Conditional on the natural harmonic-resolvent identification, the endpoint-loading residual is not an added energy. It is the source history's nonminimal interior shape. Theta superexponential structure makes that residual strictly positive.

The remaining local check is to derive the harmonic-resolvent identification from the actual two-window Green block.
