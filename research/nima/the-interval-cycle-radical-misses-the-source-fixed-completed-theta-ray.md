# The interval-cycle radical misses the source-fixed completed-theta ray

## Question

Do the multi-shell interval cycles produce a null packet for the actual source-fixed rank-one completed-theta loading?

## Claim boundary

No. The interval-cycle radical is nontrivial on the full polarized ordered-pair carrier, but its intersection with the shell-weighted source-fixed completed-theta ray is zero. On that ray, summing the ordered labels first reconstructs one fixed analytic forcing \(\Phi\); distinct shell lower endpoints then have strictly ordered separation tails.

## Two source spaces

The polarized carrier permits independent coefficients

\[
c_{p,q;n,m}
\]

for every consecutive-prime shell and ordered theta pair. Its unlabelled synthesis has the four-term cycle kernels already constructed.

The actual completed-theta source fixes one coefficient vector \(d=(d_n)\). Allowing only shell weights \(w_{p,q}\), its polarized coefficients have the restricted form

\[
c_{p,q;n,m}
=
w_{p,q}d_n\overline{d_m}.
\]

This is a linear shell-weighted subspace generated by one fixed rank-one label tensor. It is much smaller than the full polarized carrier.

## Reconstruction before shell summation

For each shell,

\[
\sum_{n,m}d_n\overline{d_m}
\rho_{nm}^{[\log p,\log q]}(t)
=
\int_{\log p}^{\log q}
\Phi(u)\overline{\Phi(u+t)}\,du
=:\rho_{p,q}(t).
\]

Therefore a source-fixed packet in the common-history kernel would satisfy

\[
\sum_{p<q\ {m consecutive}}
w_{p,q}\rho_{p,q}(t)=0.
\]

No independent label coefficient remains available to fit an interval cycle.

## Endpoint extraction

The lower endpoints \(\log p\) are distinct and strictly ordered. If the shell-weight packet is nonzero, it has a least active prime \(p_0\). The corresponding completed-shell density has asymptotic scale

\[
\exp\left[-\pi p_0^2e^{2t}\right]
\]

up to a nonzero finite-power endpoint factor. Every later shell with lower prime \(r>p_0\) has the faster scale

\[
\exp\left[-\pi r^2e^{2t}\right].
\]

The projective shell majorant permits passage through the infinite sum. Division by the \(p_0\) shell and the large-separation limit force

\[
w_{p_0,q_0}=0,
\]

a contradiction. Repetition removes every shell weight.

Thus

\[
\ker B_{\rm common}
\cap
\left\{
(w_{p,q}d_n\overline{d_m})_{p,q;n,m}
\right\}
=\{0\}.
\]

## Direct check against the four-term square

The square relation uses, within each participating shell, independently chosen diagonal labels and zero off-diagonal entries. The completed-theta vector has infinitely many nonzero labels, so its rank-one tensor also has nonzero off-diagonal entries. The four-term coefficient pattern cannot equal a nonzero shell multiple of \(d\otimes\overline d\).

This support check rejects the elementary square; endpoint extraction rejects every possible linear combination of cycles on the source-fixed ray.

## Interpretation

Two statements now coexist without contradiction:

1. common unlabelled radial history is not faithful on the full polarized carrier;
2. it is faithful on the source-fixed shell-weighted completed-theta ray.

Candidate-one response laws are formulated on the polarized carrier because they must retain ordered labels and reject generic rank-one hostiles. Faithfulness only on the physical source ray is therefore insufficient to justify erasing labels before constructing the response.

## G4 consequence

If G4 needs only recovery of the single source-fixed completed-theta loading, interval cycles do not obstruct injectivity. If G4 claims a polarized source functor, universal response law, or labelwise adjoint cancellation, the cycle radical remains and must be retained, quotiented, or observed explicitly.

G4 must state which claim it makes; source-ray faithfulness cannot be promoted to polarized-carrier faithfulness.

## Disposition

The interval-cycle radical does not null the actual source-fixed completed-theta shell loading, but it blocks any unqualified claim that common history is faithful on the polarized carrier. The next depth-first task is to identify the minimal retained observer that separates cycle classes without restoring the entire redundant label packet. No RH conclusion is authorized.
