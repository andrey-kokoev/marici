# The Rank-One Endpoint Seam Factorization Is a Tautological Unit Loop

## Canonical finite factorization

For a normalized finite Euler cutoff, let

\[
b_X(p)=\frac{1}{\sqrt{pH_X}},
\qquad
\lVert b_X\rVert_2=1.
\]

The endpoint seam carrier is

\[
K_X=b_Xb_X^*.
\]

It has the natural analysis and synthesis factorization

\[
B_X(c)=\langle b_X,c\rangle,
\qquad
C_X(z)=zb_X.
\]

Then

\[
C_XB_X=K_X.
\]

The endpoint pointing theorem fixes the positive source frame for \(b_X\), so
this factorization no longer has an arbitrary common phase.

## Reverse composition is automatically the identity

On the one-dimensional endpoint seam,

\[
B_XC_X(z)
=
\langle b_X,zb_X\rangle
=z.
\]

Hence

\[
B_XC_X=I_{\mathbb C}.
\]

This unit return is tautological. It follows from normalization of a rank-one
analysis--synthesis pair and contains no spectral information.

## Why this cannot be the completed seam packet

If \(B_X,C_X\) are substituted for the entire seam incidence while the
one-sided bulk responses are omitted or scalarized, the resulting return map
has eigenvalue one for every cutoff and every spectral parameter. It would
predict a zero-state everywhere.

Therefore the endpoint rank-one port is only one boundary grade. The completed
incidence maps must also carry:

1. translated tail and seam geometry;
2. both one-sided Green responses;
3. primitive and square distributional currents;
4. archimedean and polar incidence;
5. the nontrivial character residual before Haar projection.

The full return map becomes informative only after these typed response maps
intervene between analysis and synthesis.

## Relation to conditional expectation

The identity

\[
C_XB_X=K_X
\]

explains the coherent seam carrier, while Mellin conditional expectation gives

\[
\mathbb E_{\mathrm M}(C_XB_X)=D_X.
\]

Neither identity determines the Schur return

\[
R_s=A_-^{-1}C_sA_+^{-1}B_s.
\]

Replacing \(C_s,B_s\) by the endpoint factors discards the domains and
response geometry that make \(R_s\) spectral.

## Finite falsifier

The smallest falsifier is the normalized two-label vector. Its endpoint
analysis--synthesis loop is exactly one regardless of the labels or their
weights. Any proposed RH mechanism whose unit-return test is already decided
by this rank-one normalization is tautological.

The next incidence constructor must produce a return that changes when the
one-sided response or translated seam geometry changes while preserving the
same endpoint carrier.
