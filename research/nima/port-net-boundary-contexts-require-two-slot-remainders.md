# Named boundary contexts require two-slot remainders

The first port net retained only the summed two-component value of each family. That contract is insufficient if future observers may query EB and FB separately. An explicit synthetic payload control adds one to EB's first component and subtracts one from FB's: the joint remainder is identical, but named-channel answers differ. This is an abstract interface counterexample, not a second physical amplitude or target.

The replacement rule now optionally retains two fixed channel records attached to its boundary slots. Each stores the original component vector, normalized pole record and source identity. The joint pole still cancels; the separate channel pole records are not deleted. Both reduction orders preserve every named channel and the joint observer. All 16 subsets of four outputs were checked after each step in each order (64 checks). Swapping remainder slots preserves the joint answer but fails the named-channel test.

The coarse mode explicitly refuses channel queries rather than inventing answers. Existing joint-observer regression checks also pass. This establishes a small read-only observation contract, not arbitrary contextual equivalence or runtime support for repeated destructive queries. Exact arithmetic remains attributed payload data; no physical contour weight has been inferred.
