# qRB microstep 63: labelled return and radical descent

On the labelled carrier, write the feature map as a direct sum

$$
U=\bigoplus_p U_p.
$$

Its labelled return is block diagonal:

$$
U^*U=\bigoplus_p U_p^*U_p.
$$

Therefore the labelled Gram radical decomposes labelwise:

$$
\operatorname{Rad}(U^*U)=\bigoplus_p\operatorname{Rad}(U_p^*U_p).
$$

The return descends through this quotient before any common-history codiagonalization. This is the exact place where source diagonality is valid.

After codiagonalization, cross-prime blocks may appear and must not be discarded. The present construction therefore postpones that operation until the labelled relative quotient has been formed.

Status: labelled return and algebraic radical descent closed; physical codiagonal pushout remains a separate gate.
