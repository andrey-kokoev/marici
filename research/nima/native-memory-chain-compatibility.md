# Native recording, history memory, and reference return: compatibility audit

## Question

Can the existing native transition recorder, the native-history field realization, and the retained-reference mechanism be chained into the confirmed rung interface without supplying another adapter?

Fresh checks find a real positive interface and two precise one-step obstructions. The three mechanisms are not successive stages of an already implemented pipeline. Their source objects, memory carriers, and update schedules differ.

## 1. Native recorder to actual route orbit: fixed-point mismatch

The existing fully protected recorder is

    R(x,b)=(x,b XOR answer(x)).

For the actual ABC-to-B query, the answer is true only at A. Consequently R has one two-cycle, (A,0)<->(A,1), and six fixed states at B,C,D.

The actual route-count orbit used in the history-memory realization is

    (1,2)<->(2,1).

It has no fixed point. An equivariant map from the ENTIRE eight-state recorder into this two-point orbit cannot exist: a fixed input must have a fixed image. The checker also exhausts all256 assignments and finds zero equivariant maps.

Restricting to the true-query two-cycle permits two abstract orientations. Neither orientation identifies Boolean memory with the full retained route comparison, and the restriction itself is an extra task/preparation policy. This result does not exclude a map into a larger route space containing fixed comparisons, or a controlled rather than unconditional route swap.

The existing exhaustive instrument census is rerun:36 reversible repeatable recorders satisfy the measured-query task; full source protection selects the XOR recorder with zero source back-action. This does not select an exchange pulse.

## 2. The existing history-to-field interface really does work

The native feedback module supplies the route readings and their swap. Reuse the existing encoding, without changing its gain or fields:

    beta=g(a-b), Phi(a,b)=(u+beta*d,-beta*d),
    U Phi(a,b)=Phi(b,a), x+r=u.

At gain one, the actual two route readings give distinct numerical states, swapped by the unchanged field law. The extra initial budget is exactly80/3 above the empty-bank baseline80. It is preparation, not excitation generated by the conservative update.

The map remains coarse: counts(1,2) and(2,3) encode identically. The full source comparison must remain attached. The formal source payload and numerical u are not silently identified as types.

## 3. History fields to reference return: period mismatch

Let U be the existing24-coordinate history-memory update and V the existing20-coordinate rotated reference-return update. Exact rational matrix calculations give

    U^2=I,
    V has order6,
    dim ker(U-I)=13, dim ker(U+I)=11,
    dim ker(V-I)=6, dim ker(V+I)=6,
    dim ker(V^2-I)=12.

Any linear one-step intertwiner M satisfying V M=M U must obey

    (V^2-I)M=0, hence rank(M)<=12.

It cannot cover the full20-coordinate reference-return state. This is stronger than merely observing different coordinate dimensions.

More concretely, the EXISTING unit-carrier/empty-bank initialization has period three under V. No map, even nonlinear, intertwining a two-periodic source with one V step can hit that trajectory: its image would have to return after two steps.

The reference-lineage identities nevertheless pass unchanged:

    C t_(n+1)=R x_n,
    C L t_(n+2)=R x_n.

They describe a valid conditional mechanism for returning old carrier data. They are not the history-field involution under another name.

Three V steps form an involution, so rescheduling can remove the operator-period obstruction. That observation is a diagnostic, not a selected clock, constructed binding, or permission to replace the original schedule. Restricting to an invariant sector would likewise require a source justification and a reader comparison.

## 4. What reaches the rung chain

The existing seed/instrument binding comparison is freshly rerun as part of this audit. Its exact positive interface survives:

    mean(initial prepared X)=(1/4) tr(J4).

Its echo/rectangle observation collision and scoped shared-leg/memory obstructions also survive. No new map from the Boolean recorder, retained route comparison,24-coordinate field, or20-coordinate reference bank into the actual137-record current-state interface is supplied by their individual successes.

In particular:

- A native Boolean writable register does not contradict the inability of the fixed-boundary additive DG reader to supply independently writable numerical corrections.
- A conservative bank that returns earlier values does not create its initial carrier budget or prepare the history encoding for free.
- A matching initial aggregate does not bind current addressed detector responses.

## Disposition

Do not concatenate these mechanisms as an established descent. Reuse the actual successful native-route-to-field intertwiner, but first specify a common source task, protected observables, memory preparation, and one-step or rescheduled operation contract. An eventual proposal must then bind that contract to the intended T9 and current rung observation—not merely to the initial preparation mean.

This audit narrows the missing data to actual operation compatibility. It does not show that all controlled, restricted-sector, or extended-memory completions fail.
