# Redundant record formation converges to interface closure

## Result

The static record/control closure has a canonical dynamical realization. For a
two-sector record with real pointer overlap \(g\), the induced channel keeps
diagonal blocks fixed and multiplies off-diagonal blocks by \(g\).

Write this channel as \(E_g\). Independent record fragments compose by

\[
E_g^N=E_{g^N},
\qquad
E_aE_b=E_{ab}.
\]

When \(|g|<1\), the complementary control decays as \(|g|^N\), and the channels
converge to the idempotent conditional expectation \(P\) onto the diagonal
record algebra:

\[
P^2=P,
\qquad
\lim_{N\to\infty}E_g^N=P.
\]

The fixed algebra of the limiting channel is exactly the control algebra that
commutes with the sharp record projectors. Repeated record formation therefore
converges to the formal-concept interface closure.

## Iteration is not automatically time

The index \(N\) counts source-authorized record fragments or constructor depth.
It becomes physical time only when a source clock or causal process identifies
record depth with temporal succession. The semigroup law itself does not confer
that interpretation.

## Phase-only obstruction

If \(|g|=1\), no contraction occurs. For \(g=-1\), the channel alternates:

\[
E_{-1}^2=I.
\]

The pointer states remain indistinguishable in magnitude, yet the off-diagonal
system component changes phase. Thus logical back-action can occur without
record distinguishability, and the process does not converge to the diagonal
closure.

This separates three notions:

- record distinguishability;
- disturbance of complementary control;
- convergence to an idempotent closed interface.

## Architectural consequence

Closure can be either declared statically by a double-commutant fixed point or
reached dynamically by a source-authorized contraction semigroup. The dynamic
route still needs an admitted pointer constructor, independence law, and
completion proof. A fitted decay factor does not authorize the channel.

## Falsifier

Any claim that repeated records always converge is refuted by the phase-only
case \(g=-1\). Any claim that distinguishability is necessary for back-action
is refuted by the same two-cycle.
