# Higher-coherence topology iteration 35: a spectral sequence can kill the Haar class only from an independently populated incoming bidegree

## Candidate topology

Filter the complete coherence complex by rung, cone depth, prime grade, or
boundary codimension and use the associated spectral sequence

\[
E_r^{p,q}\Longrightarrow H^{p+q}(\operatorname{Tot}C).
\]

A residual surviving lower coherences may vanish globally if it is hit by a
higher differential

\[
d_r:E_r^{p-r,q+r-1}\longrightarrow E_r^{p,q}.
\]

This is the natural algebraic model for “another system absorbs the remaining
incoherence.”

## Haar class as a Toda obstruction

The rung-four packet defines a Toda-type class

\[
\omega_p
=\langle S,A,C,G\rangle_{\mathfrak d}
\]

whose retained-state evaluation is

\[
\operatorname{ev}_{p,b_z}(\omega_p)
=
(1-p^{-2\operatorname{Re}z})E_p(b_z).
\]

Changing lower nullhomotopies moves the representative only within the usual
Toda indeterminacy. A higher differential can kill the class only if its source
bidegree contains an independently defined element with exactly the required
boundary.

## Degree inventory

Adding a formal cone shifts degrees but does not populate the incoming group.
The analogous sourced-horn audits show the key issue: an abstract generator may
have the right degree and differential column while no source object realizes
it.

Therefore a declaration

\[
d_r h=\omega_p
\]

is not evidence unless `h` is constructed before evaluating at Xi zeros and
its lower faces reproduce the frozen defining system.

## Relative-class rigidity

The relevant prism is contractible absolutely but has

\[
H^4(P,\partial P)\cong\mathbb R.
\]

Absolute totalization can always invent side cochains and make a top defect
exact. Relative totalization freezes those sides, and the class survives until
a sourced comparison changes the boundary data. Spectral-sequence language
does not alter this distinction.

## Evaluation pairing

If the Haar observation defines a cocycle on the total complex and annihilates
all admitted boundaries, then its nonzero scalar pairing proves that
`omega_p` is a permanent nonzero class. Establishing that boundary-annihilation
property is itself the Green energy-cycle theorem.

If the observer does not descend to cohomology, killing `omega_p` in the
spectral sequence has no implication for the physical scalar residual.

## Convergence

Even if every finite page eventually kills the visible class, unbounded
nullhomotopies can survive as a `lim^1` obstruction in the completed filtered
complex. Strong convergence requires completeness, separatedness, and bounded
or compatible higher fillers—the same completion gates found in the Rees and
pro-Hilbert tests.

## Verdict for topology 35

Derived/spectral-sequence topology precisely expresses how a higher system
could absorb the rung-four obstruction: a sourced incoming class supports a
higher differential hitting it. It does not create that source class, and the
current inventory does not contain one with the required complete boundary.

The next nonredundant topology to test is an operadic `A_infinity` or
`L_infinity` completion, where the needed incoming differential might arise
from a higher multiplication constrained by lower source operations rather
than from a new arbitrary generator.
