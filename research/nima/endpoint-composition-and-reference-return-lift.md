# Endpoint composition and a typed reference-return lift

## Source obligation

Before selecting a composition/readout law, distinguish record-port typing
from matrix composability. This tests the actual137-slot rung fixture, including
its two promotion endpoint policies. Literal endpoint matching is a candidate
operation under test, not an asserted requirement of the tower architecture.

## Literal path composition fails two gates

The rule target(left)=source(right) admits916 ordered pairs of the original
records. It cannot support a joint weight law with both original uniform leaf
marginals. At carrier endpoint ('a',0,0), nine incoming records and four outgoing
records would require that the same block of pairs have both masses9/137 and
4/137. This contradicts marginal conservation regardless of pair weights.

At either promoted stage, both candidate policies have disjoint source and target
namespaces. Consequently there are **zero literal composable pairs**. Those
policies were retained-presentation fixtures, not already closed path generators.
The fact that their matrix values compose through d4^-1 does not supply missing
record-level arrows.

Two controls locate the first obstruction: restoring the excluded directed edge
balances the ports but changes the assembly to160 records; positive circulation
weights on the existing137 records also work but change total leaf mass to185.
Neither change is adopted. A consistent weighted pair/triple law is checked for
the latter control; it is not the original equal-slot law.

## A conditional typed repair using the reference

For each record a:s_a->t_a, explicitly attach a parallel reference

    d_a:s_a->t_a,   r_a:t_a->s_a.

The return belongs to the reference, not to the actual comparison a. In the
invertible-reference sector, d_a and r_a are inverse; in a weak-return sector,
the earlier unit and higher witnesses would be required instead.

Now define

    b odot a = b r_b a,   provided t_a=t_b.

This is a path s_a->t_a. Its reference is d_a: the composite retains the first
operand's source and reference. Two triple bracketings flatten to

    c r_c b r_b a.

They agree by typed associativity. Thus **incoming-family membership**, rather
than ordinary target-to-source matching, supplies the allowed operand pairs for
this declared reference-return operation.

A well-typed family mean can be formed on a common target port by first using
the endomorphisms a r_a:t->t. Averaging these endomorphisms and choosing a declared
family reference d_F reconstructs its comparison value. With all reference
matrices represented by the fixture's d4, this recovers the already tested mean
C_F. This explains the required reference identifications; it does not derive
those physical attachments from a label count.

## Result and remaining source input

There is a concrete conditional operation connecting incoming families,
reference returns, and the comparison response. It avoids the literal path-join
obstruction without changing the137 records or their original masses.

What is still required is source authority for attaching and transporting these
per-record references from the fixed rung4 reference, and a next-level endpoint
policy. The architecture has not selected either horizontal candidate merely
because both now admit this typed completion. Physical normalization and the
weak-return extension are not derived here.
