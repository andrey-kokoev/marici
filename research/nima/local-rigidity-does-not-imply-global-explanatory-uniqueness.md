# Local rigidity does not imply global explanatory uniqueness

## Status

The relation-locked deformation audit is infinitesimal. This packet identifies
its global blind spots: disconnected rivals, finite covering ambiguities,
monodromy, and singular branches.

## 1. Local deformation result

For a realization \(\theta\), the local explanatory deformation space was

\[
H_\theta=Z_\theta/B_\theta,
\]

where \(Z_\theta\) contains relation-preserving infinitesimal changes and
\(B_\theta\) contains infinitesimal gauge changes.

If \(H_\theta=0\), the realization is locally rigid. This means that no
sufficiently small non-gauge deformation passes the linearized relation audit.

It does not imply that the global realization class contains only one authorized
gauge orbit.

## 2. Smallest disconnected witness

Let a source parameter satisfy

\[
x^2=1.
\]

The realization space is

\[
\mathcal E=\{-1,+1\}.
\]

At either point the tangent space is zero because

\[
D(x^2-1)=2x
\]

is nonzero. Both points are locally rigid. If the observation is

\[
N(x)=x^2,
\]

they are also observationally identical.

Unless the sign flip is authorized gauge, this is a two-point explanatory
torsor invisible to every infinitesimal audit.

## 3. Finite-cover ambiguity

Consider

\[
N(z)=z^m
\]

on nonzero complex source parameters. The derivative

\[
DN_z=mz^{m-1}
\]

is nonzero, so the map is locally identifiable. Globally, every generic
observation has \(m\) preimages related by multiplication by an \(m\)th root of
unity.

This ambiguity can represent:

- authorized phase gauge;
- a reference torsor requiring a frame;
- or genuinely distinct source sheets.

The derivative cannot decide which. Source typing must classify the deck
transformations.

## 4. Monodromy

Suppose locally reconstructed source states are continued along a loop in
observation space. They may return transformed by a deck action

\[
g\in G_{\mathrm{deck}}.
\]

Even when every local chart is fully abstract, global continuation can permute
sheets. A canonical frame exists globally only if the resulting cocycle is
trivial or is killed by an authorized source reference.

Thus local inverse maps do not automatically glue to a global explanatory
inverse.

## 5. Singular branches

The opposite failure also occurs. A Jacobian may lose rank at a point even when
the global map remains injective. For example,

\[
N(x)=x^3
\]

is globally injective on the real line, but

\[
DN_0=0.
\]

The inverse is not Lipschitz at the origin, yet there is no second source state
with the same observation. This is a robustness singularity, not an exact
explanatory kernel.

The audit must therefore distinguish:

- global nonuniqueness;
- local hidden tangent directions;
- and an injective but ill-conditioned singularity.

## 6. Global explanatory fibre

For an observation \(y\), define the source fibre

\[
F_y=N^{-1}(y)/G,
\]

where \(G\) is authorized gauge. The explanatory classification is:

1. \(|F_y|=1\): globally unique up to gauge;
2. \(F_y\) is a free transitive finite group action: a finite reference torsor;
3. \(F_y\) has positive-dimensional components: continuous hidden moduli;
4. \(F_y\) has several unrelated components: disconnected rival explanations;
5. \(F_y\) changes type with \(y\): a stratified or branched interface.

This fibre classification is global. The tangent space describes only the local
geometry of one component.

## 7. Path and loop audit

Given a parameterized observation path \(y(t)\):

1. lift it locally to source realizations;
2. classify every continuation through chart overlaps;
3. compare the endpoints after closed observation loops;
4. record the induced deck or torsor action;
5. test whether the action lies in authorized gauge;
6. identify a source-derived reference that trivializes it, if one exists.

A non-gauge endpoint after a closed observation loop is a monodromy witness
against global full abstraction.

## 8. Toric-code interpretation

Local syndrome measurements place all four logical sectors in one fibre. The
fibre is discrete, so tangent or perturbative analysis sees no hidden direction.
Two loop probes globally split it into four labelled classes.

This is the cleanest demonstration that a zero local deformation space does not
imply global state identifiability: topological sectors are disconnected rather
than infinitesimally separated.

The primal--dual loop pairing supplies the global discriminator. No local
syndrome Jacobian can reconstruct it.

## 9. Phase and sheet interpretation

An even scalar readout may identify two sign sheets. Each sheet can be locally
rigid and the scalar derivative can be nonsingular within each sheet. The
missing information is a discrete origin, not a tangent coordinate.

A tensor unit, vacuum orientation, or trusted phase reference can select the
origin when independently authorized. Such a reference kills the finite torsor;
it does not reconstruct an arbitrary continuous amplitude.

## 10. Finite algebraic audit

For polynomial finite realizations:

1. solve the source relations exactly;
2. quotient solutions by the authorized gauge action;
3. compute the fibres of the contextual observation map;
4. decompose each fibre into connected or algebraic components;
5. compute stabilizers and deck actions;
6. compare this global result with the tangent audit at each representative;
7. identify the smallest authorized context separating distinct orbits.

Required hostile fixtures include:

- two isolated observationally identical points;
- an \(m\)-sheet finite cover with nonsingular derivative;
- a globally injective cusp with vanishing derivative;
- a loop with nontrivial source monodromy;
- a reference that selects a sheet but fails to recover continuous coordinates.

## 11. Global DPC

An explanation is globally adequate only when every contextual fibre is one
authorized gauge orbit over the claimed regime, and local inverse charts glue
without non-gauge monodromy.

If the fibre is a torsor, the correct conclusion is not unique explanation but
explanation relative to one source frame. If it has unrelated components, the
programme has genuine rival explanations even when each is locally rigid.

## 12. Critic

Global fibre classification can be computationally impossible for large or
infinite realization spaces. Requiring an exact global solution may halt useful
local science.

The repair is a bounded claim. State the connected region, cutoff, or homotopy
class over which uniqueness is proved. Then separately enumerate known discrete
symmetries, boundary strata, and untested loops. Local rigidity remains valuable
when it is not promoted to global uniqueness.

## 13. Bottom line

Jacobian tests find infinitesimal flexibility. They cannot find disconnected
logical sectors or finite phase sheets. Global explanation requires both a
deformation audit and a fibre or monodromy audit.

The decisive question is:

> After quotienting authorized gauge, does each complete contextual record have
> one source realization, a finite reference torsor, continuous hidden moduli,
> or disconnected rivals?
