# v200: X03 is not the soft deformation coordinate

The complete endpoint/Q source identifies each `X_a` as a radial occurrence parameter and each `u_a` as a normal-circle boundary parameter for a labelled hexagon diagonal. Its base is

`Z[X_a,u_a,(1+u_a)^-1 | a in D]`.

The ramified qg2 construction uses `x` as the soft specialization coordinate in the physical energy chart. No source statement identifies that energy deformation with the radial occurrence parameter `X03`. Consequently the tempting assignment `X03 -> x` is ill typed and is rejected.

The established graph `u03=lambda*X03` relates two K6 coefficient layers; it does not map either layer to `(p,kappa,x)`. A valid specialization must separately derive the nine radial occurrence functions `X_a(p,kappa,x,...)` and nine normal-circle functions `u_a(p,kappa,x,...)`, preserve the inverted monodromy units `1+u_a`, and only then pull the endpoint connector to the quadratic cover.

This leaves the seven-variable reduction valid but blocks the proposed direct scalar assignment at its first generator.
