# Can the existing Machian responding body realize the seam square?

## Result

Not by a direct restriction of the existing law. The responding object is real within its declared finite model, but its dependency ports and scale semantics do not match the proposed primitive seam-path response.

This audit extends the existing one-cycle checker with controls, rather than implementing a new evolution. The original full-update and alignment laws are unchanged.

## 1. Responding object and actual operation

The seed's two vertex cycles generate the twelve-element permutation group. Group averaging with the declared counting metric gives H=I-J/4 and points q_p=H e_p. Normalized projectors P_p then enter

    K_p = sum_(q != p) w_q P_q.

The declared operation selects a lowest contrast-space eigenline for EACH anchor and reconstructs q'_p=P'_p e_p. Changing one source weight changes other anchors' selected lines. It is a global body-response map, not an assignment of a composable linear action to each directed primitive edge.

The seed provides the group-generating cycles and labels here. Group closure and the rest-of-body sum are additional construction steps; the twelve remote dependencies are not the original six directed occurrences.

## 2. Literal restriction to the seed changes and degenerates the source law

The original response depends on all twelve ordered distinct anchor pairs. Masking this sum to the actual six seed edges gives source-operator ranks

    A:2, B:2, C:1, D:1

in the four-coordinate realization, on a contrast space of dimension three. All four masked source metrics lose strict contrast positivity; at C and D the minimum contrast eigenvalue has at least a two-dimensional zero eigenspace. Thus the earlier unique lowest-line/positive-source construction cannot simply be reused on that restricted incidence.

The checker computes these exact ranks from the original P_p and actual seed PACKETS. This is a control of the proposed restriction, not an adopted new dynamics. It does not rule out another source-derived way to construct richer operators from the same six rows.

## 3. Full normalized-source spectra do not repair radial information loss

For any nonzero radial factor a,

    P_p(a q_p)=P_p(q_p).

With weights fixed, K_p is therefore unchanged, not merely its lowest eigenline. Keeping every eigenvalue and eigenprojector of these normalized K_p cannot recover the missing radius. New exact controls test a=2 and a=3/2; the algebraic invariance holds for all nonzero a.

This sharpens the earlier recommendation to retain richer spectral records: radial data must be retained BEFORE normalization, or supplied through an independently justified scale-sensitive source operation. Merely keeping more of the normalized spectrum is insufficient. Remembering a radius as metadata also does not make this existing law respond to it.

The reconstruction q_p=P_p e_p is valid on the model's selected representative slice; it is not recovery of arbitrary radially rescaled input points from P_p alone.

## 4. Seam-square mismatch

The seam response hypothesis needs interpretations of

    x0=AB, x1=AD DB : A->B,
    y0=BA, y1=BC CA : B->A,

with composition along the retained paths. The current Machian operation takes an entire body and weights to another body; it does not supply X_AB, X_AD or the other primitive response maps, nor prove that an indirect two-step effect equals the corresponding ordered composition.

Calling a source contribution w_q P_q an edge transport would change its type and semantics: it is an endomorphism on one shared contrast space used additively in K_p. It is not already an admitted A-to-B path action. Choosing asynchronous anchor updates or path-dependent weight perturbations would be a new protocol.

Thus no numerical seam rectangle can be extracted from this model without an additional operation binding paths to body interventions. No such binding was introduced.

## 5. Existing failures remain in force

Fresh execution of the original dynamics checker confirms the two unstable -5/3 shape modes for full replacement, the numerical approaches to source degeneration, and the tested positive alignment behavior of the separate continuous flow. Neither law is selected as physical gravity, and neither supplies a seam-path action.

## Next useful requirement

If the body is retained as the candidate responding object, require an actual source-defined path intervention on it, with preserved pre-normalization geometric data. Its response must be checked for composition and stability BEFORE reading a mixed seam effect. The current body model is evidence that a conditional geometric response can be computed; it is not yet that intervention.

Do not mask its source sum or rename its projectors as primitive arrow maps merely to fill the seam formula.
