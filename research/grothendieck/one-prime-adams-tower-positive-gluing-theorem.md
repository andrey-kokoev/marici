# Exact Adams composition positively glues an entire one-prime tower

Consider logarithmic cells at

```
0, log p, 2log p, ..., n log p.
```

If translation invariance gives a first-edge correlation `r` and exact
Adams/Mackey composition gives the `m`-step correlation `r^m`, the normalized
Gram matrix is

```
G_n(i,j)=r^|i-j|                 (real case).          (1)
```

For `|r|<=1`, this matrix is positive semidefinite. When `|r|<1`, it is
positive definite and

```
det G_n=(1-r^2)^n                               (2)
```

for the `(n+1)x(n+1)` matrix.

One proof is the autoregressive dilation

```
X_0=epsilon_0,
X_j=r X_(j-1)+sqrt(1-r^2) epsilon_j,                  (3)
```

with independent unit vectors `epsilon_j`. Then
`<X_i,X_j>=r^|i-j|`; the triangular innovation map gives (2).

## Meaning for prime-power gluing

This is the all-length extension of the three-cell defect theorem. Exact
composition removes every higher cycle defect: one edge contraction plus the
Adams law positively completes the entire `p,p^2,...` tower. No separate
positivity test is needed for each repetition.

For nonexact composition, the higher correlations are governed by successive
Schur/Verblunsky defect parameters. Positivity is equivalent to every such
normalized innovation being contractive. The triangle parameter

```
kappa_2=(c-r^2)/(1-|r|^2)
```

is the first member of this hierarchy.

## Source gate

The Weil cross correlations are not known to obey the geometric law. The
theorem therefore supplies a falsifiable target rather than a conclusion:

1. normalize the short-support prime-`p` cross operator;
2. compare the prime-`p^m` edge with the `m`-fold Mackey composite;
3. either prove exact composition or extract the Schur defect contraction;
4. reject the one-prime gluing program at the first defect norm exceeding one.

Mixed-prime cycles remain separate. Even successful one-prime towers require
coherence between the `p` and `q` dilations on rectangles generated by
`log p` and `log q`.
