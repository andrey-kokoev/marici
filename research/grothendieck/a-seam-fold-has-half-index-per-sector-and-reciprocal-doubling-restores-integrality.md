# A Seam Fold Has Half-Index per Sector and Reciprocal Doubling Restores Integrality

## Local branch charge

At a simple zero of the completed readout,

\[
X(z)=X'(z_0)(z-z_0)+O((z-z_0)^2).
\]

For an interior zero, a full positively oriented circle around `z_0` changes
the argument of `X` by `2 pi`. Its local index is one.

For a zero on the seam, one open reciprocal sector contains only a
semicircular indentation around the point. Along that half-circle the argument
changes by `pi`. The relative local index seen by one sector is therefore

\[
\frac12.
\]

The opposite sector supplies the complementary semicircle. Reciprocal
doubling restores the integral branch charge

\[
\frac12+\frac12=1.
\]

This is the precise integrality effect of splitting the completed object into
two half-plane sectors.

## Relation to the quadratic fold

The potential `Y` has local degree two at the same point, while its derivative
`X/2` has index one. In a single sector, the branch lies on the boundary and
only half of its derivative winding is visible. The missing half is not lost;
it belongs to the reciprocal sector.

Thus the seam is not where integrality fails. It is where an integral global
branch charge decomposes into two relative half-charges. Treating either
half-sector as a closed absolute object would misclassify the fold.

## Interior branch packets

An off-seam simple zero lies inside one sector and contributes a full positive
index there. Reciprocal reflection supplies a partner in the other sector;
conjugation and evenness generate the familiar quartet when the point is not
fixed by either symmetry.

Consequently a generic off-seam quartet contributes four full local indices
to the unfactored divisor. This is perfectly integral. Integrality alone does
not forbid it.

The source theorem must instead provide a relative index budget whose boundary
folds and infinity current already exhaust the allowed charge. Only then would
an interior branch force an impossible excess.

## Relative accounting target

For a truncated right half-domain, the argument principle should be organized
as

\[
N_{\rm interior}
+\frac12N_{\rm seam}
=
W_{\rm outer}+W_{\rm source\ boundary},
\]

with orientations and multiplicities treated explicitly. Reciprocal doubling
turns this into an ordinary integer identity.

The missing noncircular theorem is to derive the right-hand side from the
labelled theta source and its weighted infinity port without already counting
the zeros. If it equals the seam contribution, the nonnegative interior count
must vanish.

## Scope boundary

This result explains the operator's integrality intuition but does not prove
the required budget. The ordinary argument principle computes the right-hand
side from `X` itself and would be tautological. A useful proof must obtain the
boundary winding from source transport, modular sewing, or a conserved current
defined before scalar aggregation.

## Result

A critical-line fold carries half-index in each reciprocal sector and unit
index after sewing. Off-line branches are not nonintegral; they add full
positive charges. RH would follow from a source-derived relative index budget
showing that boundary folds already saturate the available charge.
