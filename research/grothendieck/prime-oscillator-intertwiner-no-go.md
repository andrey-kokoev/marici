# Covariance cancellation does not extend by diagonal prime--oscillator pairing

The logarithmic cutoff theorem pairs the growth scales of two positive
traces. It does not identify their individual modes.

On the prime one-particle space, height translation is generated by

```
L_prime e_p=(log p)e_p,                                (1)
```

so `exp(-iT L_prime)` produces the arithmetic phases `p^(-iT)`. On the even
gamma oscillator,

```
A e_k=(k+1/4)e_k.                                      (2)
```

Suppose a bounded or algebraic mode-pairing operator `X` exactly intertwines
the generators on a common invariant core:

```
A X = X L_prime.                                       (3)
```

In the atomic bases, every matrix coefficient satisfies

```
(k+1/4-log p) X_(k,p)=0.                               (4)
```

There are no spectral coincidences. If `log p=k+1/4`, then
`p=exp(k+1/4)`. The exponent is a nonzero algebraic number, so its exponential
is transcendental by Lindemann--Weierstrass, contradicting that `p` is an
integer. Hence

```
X=0.                                                   (5)
```

The same conclusion holds for an algebraic nonzero rescaling of the
oscillator generator. Thus the canonical scale cannot support a nontrivial
diagonal spectral identification between prime logarithms and oscillator
levels.

## Meaning for the relative Gaussian target

The cancellation

```
sum_(p<=P)1/p - sum_(k<log P)1/(k+1/4) -> finite       (6)
```

is a density/asymptotic correspondence, not an eigenvalue-by-eigenvalue
duality. Attempting to extend it by matching `p` with `k=floor(log p)` loses
the exact phase: many primes occupy one logarithmic cell, and
`exp(-iT log p)` is not `exp(-iT(k+1/4))`.

Consequently a completed block determinant cannot use a diagonal coupling
that simultaneously cancels covariance and transports height dynamics. The
coupling must be genuinely off-diagonal and noncommuting—an integral kernel,
incidence transform, or relative resolvent that compares spectral densities
without identifying atomic eigenvalues.

## Smallest permissible type

A source kernel may map a prime atom at `u=log p` into a superposition of
oscillator modes,

```
X e_p = sum_k K(k,log p)e_k.                            (7)
```

It must not satisfy strict generator intertwining. Instead, the completed
two-channel Schur complement must combine the commutator defect

```
Omega=A X-X L_prime                                   (8)
```

with endpoint and gamma terms so that the final relative determinant has the
correct logarithmic derivative. The nonzero commutator is not an error to be
removed; it is the only place nontrivial prime--archimedean interference can
live after the spectral no-go.

## Falsifiers

A proposal fails if it:

1. claims an exact prime-to-oscillator eigenmode bijection;
2. replaces `log p` by `floor(log p)+1/4` while claiming exact phase
   preservation;
3. assumes a nonzero operator satisfying `AX=XL_prime` at canonical scale;
4. proves only the diagonal covariance cancellation and infers the full
   height-dependent determinant;
5. leaves the commutator defect out of the completed Schur complement.
