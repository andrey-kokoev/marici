# A singular spectral weight still confines positive-weight states

## Weighted seam theorem

Let (A) be skew-adjoint and let (P=P^*\ge0). The operator (P) may be
singular. If

\[
(A+zP)\psi=0
\]

for a state satisfying

\[
\langle P\psi,\psi\rangle>0,
\]

then

\[
\operatorname{Re}z=0.
\]

Indeed, taking the real part of the inner product with (psi) gives

\[
0=\operatorname{Re}\langle A\psi,\psi\rangle
+\operatorname{Re}z\,\langle P\psi,\psi\rangle.
\]

The first term vanishes by skew-adjointness, and the second weight is strictly
positive.

## Correction to the fifth-wall diagnosis

The tail pencil need not be regularized into (D-zI). Its singular spectral
weight is compatible with exact confinement. The null channel matters only if
an admissible zero-state can live entirely inside it.

For the homogeneous tail augmentation, the weighted coordinate is the tail
itself. A nonzero source amplitude with nonzero forcing cannot produce the
identically zero tail. Hence the candidate zero-state has positive integrated
(P)-weight whenever it is a genuine nonzero tail state.

The obstruction is therefore narrower than singularity:

\[
D_0+D_0^*\ne0.
\]

Its triangular source coupling contains the forward incidence (c\mapsto f c)
but not the adjoint reverse incidence. Adding the reverse arrow would make the
bordered coupling skew only with the source-determined sign and boundary
orientation. That arrow cannot be inserted merely because the theorem needs
it.

## Revised missing wall

The next constructor is now sharply typed:

1. retain the singular nonnegative weight (P);
2. derive the adjoint reverse incidence from reciprocal theta/Tate sewing;
3. prove the completed bordered carrier is skew-adjoint on the source boundary
   domain;
4. verify positive (P)-weight for every nonzero scalar-null state.

If these hold, the weighted seam theorem confines the state without a compact
resolvent, a determinant construction, or uniform coercivity.

## Null-weight falsifier

The condition on (P) is essential. A nonzero vector in (ker P\cap\ker A)
solves the pencil for every (z), including off the seam. Therefore every
proposal must expose and exclude the common null state using source incidence,
not by quotienting it away.

## Exact remaining obstacle

The present source equation supplies only one direction of the required
adjoint pair. The next attack is to test whether reciprocal half-line sewing,
the primitive current, or the square current produces the missing reverse map
with exactly the Green-form sign. If none does, the singular-pencil
confinement route closes.
