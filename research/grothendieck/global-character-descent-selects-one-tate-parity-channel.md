# Global Character Descent Selects One Tate Parity Channel

## Local doubling does not imply global doubling

On the real multiplicative ray, a state has even and odd additive lifts. The
associated local Tate gamma factors form a clean parity double. But a global
Tate zeta integral is indexed by an idele-class character, whose local
components must descend through the diagonal copy of \(\mathbb Q^\times\).

For the Riemann zeta function, the global character is trivial. Its
archimedean parity is therefore even. The sign character at infinity satisfies

\[
\operatorname{sgn}(-1)=-1
\]

and does not descend as the trivial global character unless another local
component supplies the compensating parity.

Thus the odd archimedean Tate lift is a valid local test channel, but it is not
a second channel of the same global Riemann zeta source.

## Consequence for the equal-weight wall

The identity

\[
\left|\frac{m_-(s)}{m_+(s)}\right|=1
\quad\Longleftrightarrow\quad
\Re s=\frac12
\]

inside the critical strip remains exact. It describes the balance wall between
the two local archimedean parity types. It does not, by itself, explain why a
zero of the globally even Riemann zeta section must balance those types.

The proposed implication

\[
\Xi(s)=0
\quad\Longrightarrow\quad
|m_-(s)|=|m_+(s)|
\]

has no source authorization in the trivial-character sector as currently
constructed. The odd side is absent rather than hidden.

## The legitimate ways the odd port could return

There are only two source-respecting possibilities.

1. Enlarge from one zeta function to a character family in which finite and
   archimedean parities satisfy the global descent condition.
2. Derive an odd boundary or derivative channel inside the completed even
   source complex whose global character remains trivial because the total
   construction, not its archimedean component alone, compensates parity.

The second option would need an explicit incidence map. Merely adjoining the
odd Gaussian derivative is not enough: its scalar Tate integral against the
trivial character vanishes by parity.

## Real obstacle

The current local parity-double route does not reach RH. Its durable gain is a
typing theorem:

Local Fourier parity and global automorphic character are different rungs.
The global descent constraint decides which local ports coexist in one scalar
section.

Any future doubled construction must exhibit the compensating finite or
boundary character before using even--odd balance as a zero-confinement law.
