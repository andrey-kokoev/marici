# The current repair compiler has no executable reverse-incidence path

## Required capability

Let (F) denote the forcing/source channel and (Y) the tail or endpoint
state. The native tail constructor supplies

\[
p:F\longrightarrow Y.
\]

Weighted skew-adjoint confinement requires a source-authorized adjoint
incidence

\[
q:Y\longrightarrow F.
\]

The question is whether the existing repair packet already generates (q) by
composition.

## Capability audit

The current operations have these source-derived types.

| Operation | Capability |
|---|---|
| Tail actuation | (F_+\to Y_+) |
| Dual tail actuation | (Y_-\to F_-) |
| Clark differentiation | (F_+\oplus Y_+\to O) |
| Primitive and square incidence | (L\to B_1,B_2) |
| Archimedean completion | boundary extension and endpoint jets |
| Seam retention | preserves independent boundary coordinates |
| Fourier--Tate sewing | comparison correspondence between (+) and (-) sectors |
| Doubled Green operation | constructs a form/current from an already declared domain |

None is an executable morphism (Y_+\to F_+).

The dual arrow has the right variance but the wrong authority locus. Promoting
the Fourier--Tate comparison to writable cross-sector feedback is not licensed
by the source construction. If it is promoted provisionally, the result is the
indefinite exchange-current double proved in the preceding packet, not a
positive skew-adjoint carrier.

The remaining operations terminate in observation or boundary-current
objects. Composing them cannot create a morphism whose codomain is the forcing
state, because none has that codomain.

## No-path theorem

In the executable capability graph generated by the currently constructed
theta/Tate operations, (F_+) is reachable from labels and from itself, while
(Y_+) reaches observers and retained boundary packets. There is no directed
path

\[
Y_+\rightsquigarrow F_+.
\]

This is a typing obstruction, not a failed inequality. Adding more scalar
moments, currents, or endpoint observations cannot repair it.

## Relation to the five-component Fourier cell

The constant--delta exchange plane looks like the desired source--observer
pair, but even Fourier conjugation of the forward incidence leaves a full-rank
residual. Fourier identifies boundary presentations; it does not turn the
endpoint observer into dynamical feedback on the forcing coordinate.

Thus the fifth wall is not merely the fifth component. It is a new executable
arrow between already-known components.

## Required new constructor

The next admissible contribution must declare, from source data and before
scalar compression,

\[
Q_{mathrm{rev}}:Y_+\longrightarrow F_+,
\]

with all of the following:

1. its domain in the exponential/Schwartz/Hilbert/distributional rigging;
2. its adjoint relation to the forward tail incidence;
3. its primitive, square, seam, and archimedean boundary deltas;
4. compatibility with finite Euler cutoff inclusions;
5. a projection recovering the original one-way tail equation;
6. a hostile-source test that fails before zero inspection.

Absent such a constructor, the weighted skew-adjoint route is blocked.

## Machine falsifier

The checker encodes constructed operations as typed executable edges and
comparison-only correspondences. It verifies that (Y_+\to F_+) is
unreachable. It then demonstrates that falsely promoting the two sewing
correspondences makes a path appear, thereby identifying the exact authority
smear required to hide the defect.
