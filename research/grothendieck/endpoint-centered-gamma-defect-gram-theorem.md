# Endpoint centering turns the singular gamma density into a positive defect Gram

Consider the positive gamma log-time density

```
dnu(u) = 2 e^(-u/2)/(1-e^(-2u)) du,       u>0.        (1)
```

It has infinite mass because `dnu(u)~du/u` at zero, so it cannot directly be
normalized into the latent probability model. Nevertheless, for every
`n>1`, the endpoint-centered vector

```
v_n(u)=1-n^(-u)                                      (2)
```

belongs to `L2(nu)`. Near zero, `v_n(u)=u log n+O(u^2)`, making
`|v_n|^2 dnu=O(u)du`; at infinity the density decays exponentially.

Therefore

```
G(m,n)=integral_0^infinity
       (1-m^(-u))(1-n^(-u)) dnu(u)                    (3)
```

is finite and positive semidefinite on every finite collection of integers.
This is an unconditional Gram theorem for the archimedean defect sector.

## Canonical mixed correlation

For distinct primes,

```
G(p,q)=integral [1-p^(-u)-q^(-u)+(pq)^(-u)] dnu(u).   (4)
```

The `(pq)^(-u)` term is forced by polarization of endpoint differences. It is
a continuous gamma correlation, not an arithmetic atom; hence it coexists
with `Lambda(pq)=0`. The mixed term sought by the squarefree completion
problem is thus already present in a canonical source-derived positive Gram
sector.

Equivalently, if

```
Psi(t)=integral_0^infinity (1-e^(-tu)) dnu(u),         (5)
```

then the individually divergent terms cancel in

```
G(m,n)=Psi(log m)+Psi(log n)-Psi(log(mn)).             (6)
```

Formula (3), rather than three separately regularized copies of (5), fixes
the endpoint subtraction without counterterm freedom.

## What this does and does not solve

This proves that the gamma endpoint singularity is harmless after the
source-natural difference operation, and that the archimedean sector can
supply coherent mixed-prime correlations. It does not yet prove that the
full gamma contribution to the Weil form is exactly this Gram, nor that its
coupling to the negatively signed von Mangoldt evaluations preserves
positivity.

The next hostile gate is concrete: express the prime evaluation map on the
Hilbert space generated by the vectors `v_n`, and test whether its norm is at
most one (or whether a source-derived auxiliary channel makes the Schur
complement positive). This is the first remaining place where negativity can
enter; the pure centered gamma block is already positive.
