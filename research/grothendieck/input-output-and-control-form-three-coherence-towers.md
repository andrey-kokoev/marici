# Input, output, and control form three coherence towers

## Operator stimulus

The operator asked whether the repeated missing rungs belong to one tower or
to three towers: input, output, and control. The accumulated no-go results
support the three-tower interpretation.

## The input tower

The input tower governs constructibility and provenance:

- integer and prime-power labels;
- positive Fock formation;
- multiplication maps (T_p);
- primitive, square, and connected-current grades;
- finite-cutoff packets and their compatible inclusions;
- the pro-object retaining every prime-exclusion port.

Its strongest present theorem is joint faithfulness of the exclusion family.
It determines which source distinctions exist.

## The output tower

The output tower governs observation and scalarization:

- theta tails and seam values;
- Clark value and derivative ports;
- constant--delta and principal-value boundary coordinates;
- scalar aggregation into (X(z));
- the incidence divisor where the selected transmission coordinate vanishes;
- moment, jet, and projective readouts.

Its central defect is that scalar aggregation has a large kernel. It
determines which source distinctions remain visible.

## The control tower

The control tower governs authorized transformations and comparisons:

- Fourier--Tate sewing;
- reciprocal direct--dual comparison;
- adjoint-mate cells;
- Green and Ward identities;
- multiplication/division commutator curvature;
- restriction coherence among finite cutoffs;
- conservative or relative colligations.

It determines which changes of presentation or dynamics are legal and which
quantities they conserve.

## Shared state base

The towers are not independent systems. They are three fibrations over the
same labelled internal-state object. A state can be:

- constructible in the input tower;
- transformed coherently in the control tower;
- invisible in the output tower.

This is exactly what the two-label packet (c=(1,-1)) demonstrates. The input
curvature detects it, a conservative control may preserve it, and scalar
output aggregation kills it.

## Why one-tower reasoning failed

Several previously tempting inferences crossed towers without a comparison
cell:

- input faithfulness does not imply output noncancellation;
- control unitarity does not imply output nonvanishing;
- output nullity does not imply input-curvature nullity;
- a dual control arrow does not authorize direct input feedback;
- compatible finite input packets do not automatically define a completed
  scalar output.

Each failed inference was a missing horizontal coherence law, not a missing
vertical rung.

## The RH-bearing cross-tower cell

The desired theorem must compare all three towers. For every finite cutoff
(X), it needs a source-derived cell taking the output zero-state boundary
condition to

\[
\mathcal W_X(c_z)=0,
\]

where (mathcal W_X) is the input-curvature Ward packet and the implication
is derived by the control Green identity. These cells must be natural under
cutoff restriction.

Thus the proof architecture is triangular:

1. output nullity supplies a boundary state;
2. control coherence transports its boundary condition into Ward nullity;
3. input joint faithfulness kills the labelled state.

No tower can replace either of the others.

## Possible categorical home

The smallest useful formalism is not a single linear category. It resembles a
double or equipment-style category with:

- input preparations as one class of arrows;
- output observations as the opposite class;
- control correspondences as horizontal arrows;
- mate, Ward, and cutoff-natural transformations as higher cells.

The pro-completion acts on all three towers simultaneously.

## Falsifier

Any purported RH mechanism fails if it proves closure within only one tower.
The finite hostile checker exhibits a nonzero packet that is input-detectable,
control-preserved, and output-null. A successful proposal must supply the
missing cross-tower cell and reject that packet through source-specific data.

## Result

The programme has three coherence towers over a shared state base. The next
advance is not another rung in isolation; it is the first natural cross-tower
Ward cell connecting output nullity, control conservation, and input
faithfulness.
