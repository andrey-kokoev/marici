# The Current Boundary Packet Does Not Yet Form an Evans Row Module

## Proposed descent test

The desired finite theorem has the form

\[
\ker M_X(z)\subseteq\ker R_X(z),
\]

or equivalently

\[
R_X(z)=L_X(z)M_X(z)
\]

over a declared ring of regular source coefficients. Here \(M_X\) should
contain the state, seam, primitive, square, archimedean, and scalar endpoint
equations, while \(R_X\) is the full sum-carrier port.

This equation is meaningful only if every declared row is a morphism from one
common state object and if \(L_X\) is an authorized morphism from the combined
row object back to the carrier.

## Actual constructed types

The current theta/Tate packet has the following signatures:

| Constructor | Source | Target |
|---|---|---|
| tail equation | forcing plus tail graph domain | tail residual |
| Evans endpoint | tail graph domain | scalar wall |
| seam retention | source cut | independent interval state |
| primitive current | labelled valuation module | distributional boundary |
| square current | labelled valuation module | Hilbert boundary |
| archimedean completion | test-source boundary | endpoint-jet extension |
| doubled Green operation | declared doubled domain | form or current |
| Fourier–Tate sewing | direct sector | dual-sector correspondence |

These are not rows of a single matrix. They have different domains,
regularities, and targets. In particular, no constructed operation maps the
combined scalar and boundary observations back to the positive sum carrier.

## Typed factorization obstruction

An authorized factorization

\[
R_X=L_XM_X
\]

requires two missing pieces:

1. a common-domain incidence map embedding every boundary current into one
   bordered state complex;
2. an executable recovery map \(L_X\) from its row object to the sum carrier.

The existing capability graph contains neither. The known Fourier–Tate arrow
has the right contragredient flavor but is a cross-sector correspondence, not
a writable recovery morphism in the direct sector.

Therefore the row-module membership question cannot yet return true or false
as a source-authorized theorem. A numerical matrix formed by aligning these
outputs would add precisely the missing comparison maps by hand.

## Why pointwise linear algebra is misleading

At any fixed spectral value, one may choose bases, concatenate scalar
coordinates, append \(R_X\) itself, or solve for a pseudoinverse. Each move can
manufacture a matrix \(L_X\). None establishes descent over the regular source
ring.

Three failures can be hidden this way:

- an endpoint inverse introduces a pole at the divisor being studied;
- an identification between distributional, Hilbert, and endpoint rows
  erases the regularity filtration;
- a transported conclusion is inserted as one of its own premises.

The correct first remainder is therefore a typing residual, not a scalar
polynomial remainder:

```text
code: common_evans_row_module_unconstructed
missing_domain: completed bordered source complex
missing_recovery: boundary_packet -> sum_carrier
forbidden_shortcut: concatenate projected scalar rows
```

## Relation to the bordered zero-state

The bare bordered Evans map is well typed and its zero-state is
\((-u,1)\), with nonzero sum carrier \(u\). Adding current values as extra
coordinates does not change this unless their incidence on that same kernel
state is derived. Merely knowing the currents exist does not supply those
rows.

Thus the next source theorem is more primitive than kernel inclusion:

> Construct one bordered source complex on which tail, seam, primitive,
> square, archimedean, and endpoint operations are simultaneous continuous
> morphisms.

Only after that construction may one compute \(\ker M_X\), test regular
module membership, or estimate the norm of \(L_X\).

## Falsifier for a proposed common domain

Reject a proposed row module at the first occurrence of:

- a boundary row with no action on the declared state domain;
- a distributional current forced into a Hilbert row without a rigged trace;
- a comparison correspondence treated as executable feedback;
- an endpoint inverse or divisor-bearing denominator;
- a recovery row inserted without independent source authority;
- cutoff-dependent graph norms with no transition law.

## Scope

This proves that the currently constructed operations do not yet type-check
as the row module required by the evaluation-descent theorem. It does not
prove that no common domain exists, compute the eventual kernel, establish
descent, confine zeros, or prove RH.
