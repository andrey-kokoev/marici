# Distinct Z2 gradings in the cubic/Rees comparison

The exact cubic orbit has the parameter involution `t -> -t`.  Its first two
connected grades obey

\[
\kappa_3(-t)=-\kappa_3(t),
\qquad
\kappa_4(-t)=\kappa_4(t).
\]

The conditioning Rees cover independently has `u -> -u`, with

\[
\operatorname{Sym}^2(-u)=\operatorname{Sym}^2(u).
\]

These representations have the same parity pattern, but they arise from
different source operations.  No map currently identifies either cover with
the cosmological time-root local system.
