# Finite-rank density operators are not closed under Cut reduction

For

\[
|\psi_N\rangle=\sum_{i=1}^N|i,i\rangle,
\]

the global projector has rank one, while

\[
\operatorname{Tr}_E|\psi_N\rangle\langle\psi_N|=I_N
\]

has rank (N). The reduced rank is therefore unbounded even on rank-one global
inputs.

The normalized vector

\[
|\psi\rangle=\sum_{n\ge1}2^{-n/2}|n,n\rangle
\]

is a Hilbert-space vector whose reduced density matrix has eigenvalues
(2^{-n}), hence infinite rank.

Thus exact unitary evolution preserves global rank, but the source partial
trace/Cut operation does not preserve finite rank.
