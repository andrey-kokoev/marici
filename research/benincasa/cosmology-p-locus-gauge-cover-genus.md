# The minimal gauge cover is elliptic

Conjecture: `y^2=D(u)`, with
`D=-4u^4+12u^3+u^2-12u+4`, is a smooth genus-one cover.

Exact Euclidean reduction gives `gcd(D,D')=1`, so the quartic has four simple
geometric roots. The degree-two map to the `u` line is branched at those four
finite points and not at infinity. Riemann–Hurwitz gives genus one. Since
`D(0)=4`, the point `(u,y)=(0,2)` is rational, so the smooth projective model is
an elliptic curve over `Q`.

The binary-quartic invariants are `I=241`, `J=-2450`, with
`4I^3-J^2=49987584`, confirming nonsingularity.

Thus removing the connection residual requires an elliptic function field, not
a rational chart gauge. This extension remains unauthorized. The next test
compares its invariant with existing source elliptic covers and requires a
typed base-compatible isomorphism.
