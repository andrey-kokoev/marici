# Universal minimal formal integral source extension

Adjoin a formal generator `u` with column \((1,0)\) in
\((\Xi_{\log},-\sigma_{123})\) and ordered boundary \((0,-2,2)\). With the
existing exceptional generator `e` of column \((0,1)\), the element
`w=u+e` has target column \((1,1)\).

The boundary cancels \((0,2,-2)\), has zero component sum, and therefore is a
cocycle in the ordered triangle complex; the resulting differential squares to
zero. Its two nonzero entries explicitly route `g23` and `g31`. The determinant
of the `u,e` columns is one, so `w` is integrally primitive despite the
boundary's content two.

For every integral shear `u -> u+k e`, the expression
`u+(1-k)e` still has column \((1,1)\). Thus `u=(1,0)` is a normal form, not a
preferred geometric representative.

This is initial only in the category of integral extensions equipped with a
chosen generator having this column and boundary. It is formally consistent
but not source-authorized: no geometric object or comparison morphism realizes
`u`.
