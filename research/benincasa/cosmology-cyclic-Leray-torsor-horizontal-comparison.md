# The Leray torsor does not select an absolute horizontal comparison

Conjecture: the closed three-frame torsor and its explicit logarithmic edge
determine a horizontal A2-to-E6 comparison.

The torsor fixes transition functions and relative equations
`A_j-A_i=dlog(g_ij)`. It does not fix a common additive global one-form. If
`{A_i}` is compatible, then `{A_i+omega}` has the same transition residuals.
On the punctured line, `omega=dlog(v/(v-2))` is nonzero, with residues `(1,-1)`,
so two distinct compatible families exist.

The conjecture is falsified. The surviving result is narrower: the torsor
source-types occurrence descent and relative logarithmic connection
differences, not an absolute horizontal comparison or rank-twelve shear.

Next conjecture: the `C2` normalization and known E6 corner coefficient remove
the additive freedom.
