# The frozen scalar-cubic source has no derivative-ordering parameter

The active finite cosmology models use the scalar interactions

\[
H_{\rm int}=\frac{q^3}{3}
\]

and, for three labelled occurrences,

\[
H_{\rm int}=q_1q_2q_3.
\]

Both are polynomials in mutually commuting position generators. Their primitive
forces are therefore fixed before Cut sewing; no ordering of mixed \(q,p\)
letters is required.

Entries 1662--1664 instead study the hostile derivative-interaction family

\[
H_\lambda=qpq+\lambda\hbar q.
\]

That family establishes a conditional gate for a future source containing
derivative interactions. It is not a parameterization of the currently frozen
scalar-cubic source. In particular, the Bunch--Davies time orientation cannot be
used to set \(\lambda=0\) in a model in which \(\lambda\) never occurs.

The active conclusion is narrower:

\[
\boxed{
\text{the scalar-cubic cosmology lane has no primitive derivative-ordering ambiguity.}
}
\]

Reopen the ordering question only after an independently sourced interaction
containing noncommuting field and momentum generators is admitted.
