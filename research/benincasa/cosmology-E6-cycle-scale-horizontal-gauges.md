# E6 cycle scales are homogeneity data, not connection gauges

The recorded scales `2,3,1/6` multiply to one and close the weighted cyclic
transport. Their checker uses only the common homogeneity `-2`; it does not type
them as transition functions for a connection.

If constant scales were connection gauges, their logarithmic derivatives would
vanish, so horizontality would require literal equality of consecutive
occurrence-line connection forms. Those forms are not serialized. A deliberate
model with equal weights and constant scale but connection coefficients zero
and one has nonzero residual one, showing that common homogeneity does not
supply horizontality.

The next gate is a census for the three occurrence-line connection restrictions
and their chart identifiers in the bivariate E6 connection.
