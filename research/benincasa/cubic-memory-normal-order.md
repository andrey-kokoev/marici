# Cubic memory appears before Gaussian covariance detects it

For independent centered unit-variance Gaussian quadratures (X,Y,Z), the cubic interaction generated by (XYZ) gives the momentum kicks

\[
P_X'=P_X-gYZ,
\qquad
P_Y'=P_Y-gXZ.
\]

Parity kills every first-order correction to the linear covariance blocks.  In particular, the ordinary observed--internal quadrature cross block remains zero at first order.

However, the mixed supported observable (YZ) detects memory immediately:

\[
\operatorname{Cov}(P_X',YZ)
=-g\,\mathbb E[Y^2Z^2]
=-g.
\]

Thus the full state fails to factorize at first order even though its Gaussian covariance projection still appears factorized.

At second order, the internal covariance itself moves:

\[
\operatorname{Var}(P_Y')-operatorname{Var}(P_Y)
=g^2\mathbb E[X^2Z^2]
=g^2.
\]

Therefore

\[
\boxed{
\text{full Markov failure begins at }g,
\qquad
\text{Gaussian-covariance Markov failure begins at }g^2.
}
\]

Entry 1646 is exact within the Gaussian category, but a cubic interaction immediately leaves that category.  Testing only covariance would miss the first non-Gaussian memory grade.
