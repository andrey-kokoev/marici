# The endpoint sign character is not the gauge local system

Conjecture: existing occurrence monodromy supplies the sign twist required by
the elliptic gauge.

The endpoint object has occurrence swap matrix `[[0,1],[1,0]]` and
anti-invariant generator `(1,-1)`, so its abstract character is `-1`. Its base
support is the endpoint pair `xi=+1,-1`. The gauge local system instead lives on
`p=0` and has monodromy `-1` around each of the four roots of `D(u)`.

The abstract characters agree, but no typed base map identifies the endpoint
support with `D=0`, and no square-class comparison exists. A character value
alone does not identify local systems. The conjecture is therefore falsified as
a source identification.

The next test asks whether formally adjoining the gauge sign system can descend
back to the untwisted integral rank-twelve target.
