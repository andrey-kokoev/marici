# Global descent of the supported Born scalar

For nonzero tangent \(v\) and normalized state direction \(\psi\),

\[
c([v],[\psi])
=\frac{|\langle v|\psi\rangle|^2}
{\langle v|v\rangle\langle\psi|\psi\rangle}
=\operatorname{Tr}(P_vP_\psi).
\]

Because it depends only on the two projectors, this is a global scalar on
projective tangent space and has trivial loop holonomy.  The unsquared overlap
is still a section of a comparison line and can carry phase holonomy.  The
Born scalar therefore descends by Hermitian squaring rather than by choosing a
global amplitude frame.
