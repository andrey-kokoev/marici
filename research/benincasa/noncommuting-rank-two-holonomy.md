# Noncommuting rank-two projector holonomy

In \(\mathbb C^4\), start with \(E=\langle e_1,e_2\rangle\).  Horizontal
quarter-turns through vacant auxiliary directions construct two closed
projector loops with fiber holonomies

\[
H_A=\begin{pmatrix}-1&0\\0&1\end{pmatrix},
\qquad
H_B=\begin{pmatrix}0&1\\1&0\end{pmatrix}.
\]

They do not commute.  Both loops return the same projector, so endpoint
principal angles see neither matrix.  A source-labelled fiber reference can
read the ordered matrices; without such a frame, only conjugacy-invariant
Wilson data are canonical.
