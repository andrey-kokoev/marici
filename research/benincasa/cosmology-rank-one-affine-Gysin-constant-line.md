# No nonconstant affine line has nonzero constant Gysin denominator

Conjecture: a rank-one assignment `s_i(t)=c_i+d_i*t` can make the Gysin
denominator a nonzero base function.

If `s1*s2*s3*Lambda_P` is a nonzero constant in `Q[t]`, each factor is a unit
in `Q[t]`. In particular every `s_i` is constant, forcing the line direction
to vanish. A nonconstant line can have constant pullback only when that
constant is zero, meaning the line lies in the Gysin divisor and the support
pullback is degenerate.

The conjecture is falsified for every affine line over `Q`. A bounded census of
15,500 nonconstant lines found 1,740 zero pullbacks and no nonzero constant
pullback. Rank one therefore cannot repair the missing base map; rank zero has
no fiber comparison.

checks whether any primitive integral route survives.
