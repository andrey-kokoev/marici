# The six-axis map is formally coherent but requires absorption

The six-cube has 64 vertices, 192 edges, and 240 squares. Boolean OR on each
two-axis fiber defines a monotone map to the three-cube. Its vertex fibers have
sizes `1,3,3,3,9,9,9,27`, and every square commutes formally.

Of the 240 source squares, 192 involve different target axes. The remaining 48
use the singleton-complement and same-pair axes belonging to one target fiber.
Each such square requires the first deletion to become the target deletion and
the second to become identity, independently of order.

Thus there is no combinatorial commutator obstruction. The obstruction is a
source descent condition: the two distinct labelled deletions in each fiber
must become one idempotent target operation. No source quotient proving these
48 absorption relations exists.
