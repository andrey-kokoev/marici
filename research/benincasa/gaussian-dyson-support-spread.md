# Gaussian Dyson support spread

The source cutoff condition is a Wilsonian domain prescription, not an
invariant pointwise subspace of the interacting Dyson map.

At first order in one internal state variation, the middle self-energy has one
excited occurrence \(q\) and one vacuum occurrence
\(k=|\mathbf p-\mathbf q|\).  If both internal EFT momenta obey

\[
0\le q,k\le\Lambda,
\]

then momentum incidence permits

\[
0\le p\le2\Lambda.
\]

In particular, every external momentum in the physical EFT domain
\(0\le p\le\Lambda\) can receive a state-dependent loop correction, even
when the original pointwise coordinate \(\beta_p\) vanishes there.

This does not violate the source cutoff: no prediction above the admitted EFT
domain is required.  It shows instead that the correct preserved object is the
CTP/Keldysh coefficient system **over the cutoff carrier**, not the literal
support of the tree-level function \(\beta_p\).
