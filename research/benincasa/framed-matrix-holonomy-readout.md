# Framed matrix holonomy readout

Let a labelled reference frame be an isomorphism \(F:R\to E\).  It reads a
fiber holonomy \(H\) as

\[
M_F(H)=F^{-1}HF.
\]

Under a physical fiber gauge \(G\), \(H\mapsto GHG^{-1}\) and \(F\mapsto GF\),
so the readout is unchanged.  Under a reference relabelling \(F\mapsto FS\),
it conjugates by \(S\).  With the reference basis labels frozen, the readout
distinguishes \(AB\) from \(BA\) exactly.
