# Untwisted integral descent kills the sign line

Conjecture: the sign-twisted horizontal comparison yields a nonzero untwisted
integral rank-twelve lift.

A rank-one integral descent map is multiplication by an integer `m`.
Equivariance from character `-1` to character `+1` requires `-m=m`. Since the
target lattice is torsion-free, `m=0`; the conjecture is falsified.

The norm does descend: `g*sigma(g)=-g^2`, and its logarithmic correction is
`2*dlog(g)`. It therefore gives only a doubled, nonprimitive comparison.
Recovering the original correction requires division by two. Reduction modulo
two trivializes the character but is not an integral lift.

This has the same parity type as the existing principal `2Z` obstruction to the
required unit column, but no source map yet identifies the mechanisms. The next
test either constructs that map or retains two parallel parity obstructions.
