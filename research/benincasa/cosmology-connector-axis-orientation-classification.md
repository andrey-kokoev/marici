# Connector axis assignments form an unpointed torsor

There are six bijections between the three deletion axes and three occurrence
axes. Adding an orientation sign on each axis gives 48 assignments, an
\(S_3\times(C_2)^3\) torsor.

Strict typed-label preservation selects none because denominator and cyclic
`e6` chart labels have different kinds. If types are erased and the text `G12`
is forced to match, two assignments remain. The complement-name heuristic
`q_g1 -> G23:e6`, `q_g2 -> G31:e6`, `q_G12 -> G12:e6` chooses one, but no
source morphism derives it.

The shadow normalization is stated only in the occurrence basis, so it cannot
select an axis assignment without source-axis coordinates. Thus the formal
connector has no admitted basepoint. The remaining possible selector is cyclic
equivariance, which must be tested against the nonuniform deletion labels.
