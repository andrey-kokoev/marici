# A two-colour occurrence target preserves deletion provenance

Refine each occurrence axis into singleton-complement (`S`) and same-pair (`P`)
colours. The six deletion axes then map bijectively to
`G12:S/P,G23:S/P,G31:S/P`; all 64 masks remain distinct. This removes the
absorption congruence.

Forgetting colour sums the `S` and `P` coordinates on each occurrence pair. Its
kernel has rank three, generated by the colour differences. The physical shadow
`(0,-1,1)` has four minimal integral coloured lifts: each nonzero component may
lie in either colour.

Thus the refined target is formally faithful, but the existing uncoloured
shadow does not select a lift. Actual coloured occurrence modules and a
source-derived splitting remain absent. Cyclic equivariance can further
constrain the four minimal choices.
