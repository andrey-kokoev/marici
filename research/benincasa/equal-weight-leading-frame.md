# Equal-weight reference-frame test

For a labelled two-column reference frame (F_\varepsilon=\varepsilon F_0),
the common Rees weight cancels:

\[
F_\varepsilon^{-1}HF_\varepsilon=F_0^{-1}HF_0.
\]

If (F_0) is invertible and retained as labelled source data, the full based
holonomy is regular and no flag or splitting is needed. If the labels are
forgotten, (F_0\mapsto F_0S) changes the matrix by (S^{-1}(-)S); only the
conjugacy class descends.

Equal column valuations are not sufficient when the leading frame drops rank.
For

\[
F_\varepsilon=\varepsilon
\begin{pmatrix}1&1\\0&\varepsilon\end{pmatrix},
\]

the source column operation (c_2\leftarrow c_2-c_1) exposes weights
((1,2)). The next jet, rather than an arbitrary split of the equal-weight
grade, supplies the missing direction.

The durable checker exhausts small integer holonomies against six unimodular
leading frames and four labelled frame changes, and separately verifies the
rank-deficient refinement.
