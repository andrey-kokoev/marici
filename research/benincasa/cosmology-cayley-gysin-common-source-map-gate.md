# Common Cayley–Menger provenance does not define the comparison map

The contour current and Gysin connection use the same broad Cayley–Menger
polynomial geometry and compatible weighted exceptional coordinates. Their
typed objects differ:

- the contour is an oriented semialgebraic relative homology/current;
- the Gysin object is a four-dimensional de Rham master connection.

A common polynomial is not a homology-to-de Rham arrow. The required chain is:
identify one relative pair and boundary map, identify the Gysin master forms on
that geometry, construct the cycle-form integration pairing, prove its weighted
specialization and orientation compatibility, and project the coefficient
current to \((\Xi_{\log},-\sigma_{123})\).

None of those arrows is materialized. Consequently shared source vocabulary and
chart coordinates cannot authorize the primitive comparison. The missing datum
is a relative homology–de Rham pairing compatible with weighted specialization.
