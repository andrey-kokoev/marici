# Unbounded quotient absorption is path-independent

Uniform reachability supplies an exact contraction for every K target at every
even ambient degree at least 12. Unchanged inclusions and the squared-axis
constructor maps commute, so two transport paths with the same endpoint
evaluate to the same target. Their source words therefore differ by an exact
kernel element and determine the same contraction-fiber quotient class.

Kernel-preserving ambient maps carry this singleton class to the singleton
class at the next endpoint. Hence the quotient witness system is
path-independent and compatible at all even cutoffs, although no canonical
source word is selected.

Two quotients must remain distinct:

- in the physical target quotient, every K target vanishes because it lies in
  the exact relation image; its directed colimit is the zero absorption class;
- the contraction-fiber quotient retains a canonical witness class conditional
  on the source presentation.

Neither object is a surviving p-normal line, and neither supplies a map to the
primitive integral \((1,1)\) \(\tau_p\) column.
