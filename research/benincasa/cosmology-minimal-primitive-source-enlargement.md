# Minimal source enlargement for a primitive tau column

The audited source reaches the principal logarithmic coordinate through the
lattice \(2\mathbb Z\). The available blow-up exceptional cell has column
\((0,1)\). Therefore adjoining one new column \((a,b)\) can make the
logarithmic coordinate primitive only if

\[
\gcd(2,a)=1,
\]

or equivalently, only if \(a\) is odd.

This lattice condition is necessary but not sufficient. A viable source
enlargement must also supply an ordered boundary contribution cancelling the
existing Čech obstruction \((0,2,-2)\), route both exceptional marks `g23` and
`g31`, define an integral chain map, and satisfy \(d^2=0\). Neither the existing
\((0,1)\) exceptional cell nor another even-principal source can do so.

The criterion identifies the minimal type of missing source datum; it does not
construct that datum or authorize division by two.
