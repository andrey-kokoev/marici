# Interference detects relative flat holonomy

Let \(L\) be a signal amplitude line and \(R\) a labelled reference line.
Density sees \(L\otimes\bar L\), so its central flat twist cancels.  The
interference coefficient instead lies in

\[
\operatorname{Hom}(R,L)=L\otimes R^*,
\]

and has holonomy

\[
\operatorname{Hol}_{\rm int}
=\operatorname{Hol}_L\operatorname{Hol}_R^{-1}.
\]

Thus interference recovers relative, not absolute, phase topology.  Detection
requires a source-defined reference and a nonzero overlap pairing; without
them the comparison class is not physically activated.
