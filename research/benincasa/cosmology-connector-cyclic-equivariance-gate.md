# Cyclic equivariance forces a six-axis closure

The sourced cyclic relabelling sends
`q_g1,q_g2,q_G12` to `q_g2,q_g3,q_G23`. The three-axis deletion set is
therefore not closed. The complement heuristic satisfies its only testable
square, from `q_g1` to `q_g2`, but the other two rotated axes are absent. No
source-authorized equivariant three-axis bijection exists.

The minimal cyclic closure contains the singleton orbit
`q_g1,q_g2,q_g3` and pair orbit `q_G12,q_G23,q_G31`. There is a canonical
formal equivariant map: singleton labels go to their opposite occurrence pair,
and pair labels go to the same occurrence pair. Every occurrence axis then has
a two-element fiber.

Thus cyclic symmetry does not select the original connector. It replaces it by
a six-axis, two-to-one problem whose fiber identifications must be checked
against deletion-cube coherence.
