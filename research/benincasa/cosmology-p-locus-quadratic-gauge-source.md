# No sourced quadratic gauge exists on the p divisor

Conjecture: an existing source two-cover supplies `sqrt(D)` for
`D=-4u^4+12u^3+u^2-12u+4` on `p=0`, identified by `v=2u`.

The source-envelope census found no preexisting artifact containing this square
class and no declared quadratic cover with a typed map to the `p` divisor.
Generic discriminant and Kummer artifacts use different variables and bases;
equal cover degree cannot identify their square classes with `D`.

The conjecture is falsified under the active source envelope. The formal
minimal enlargement is `y^2=D(u)`, but the underlying bivariate connection is
typed only over `Q(u,v)` and explicitly supplies no integral or physical-chain
compatibility.

The next test classifies the minimal cover. Four simple branch points would
make it genus one rather than a rational two-cover.
