# Source realization fails at object assignment

A realization of the formal generator `u` requires one source object carrying
all five fields: an odd principal leg, ordered boundary `(0,-2,2)`, both
`g23/g31` labels, and a comparison map.

No audited candidate has that conjunction. The literal and antisymmetric cells
have principal coefficients `-2` and `0`; the blow-up cell has column `(0,1)`;
the Cayley–Menger complement is unlabelled; the weighted relative pair is
undefined; the conductor cospan is combinatorial rather than geometric; and
the Rees factors have no accepted labelled extraction.

Hence the realization fiber is empty on the audited candidate subcategory. A
source-realization functor is obstructed already at object assignment, before
naturality or coherence can be tested. This does not exclude a source object
outside the audited envelope.
