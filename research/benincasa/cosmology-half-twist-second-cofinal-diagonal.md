# The second cofinal diagonal kills the complete prior image

For the physical half-twist presentation, the map

`(ambient,K_DEPTH)=(10,3) -> (12,4)`

sends the rank-nine source image to zero in the rank-fifteen target image over
both primes. Every labelled source generator is special-exact at the target.
This reproduces the complete death previously observed for `(8,2)->(10,3)`.

Two consecutive cofinal diagonal steps therefore have zero transition rank,
while each target contains newly born replacement directions. This is stronger
than either one-coordinate barcode but remains a finite repetition, not an
induction or colimit theorem. The next gate is a uniform labelled homotopy for
`(A,K_DEPTH)->(A+2,K_DEPTH+1)`.
