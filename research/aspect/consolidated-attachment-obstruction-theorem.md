# Consolidated attachment-obstruction theorem schema

## Question

Can the established attachment and readout gates be consolidated into one typed decision theorem without conflating optional representability with general correspondence transport?

## Claim boundary

This is a theorem schema over declared equipment and record-module data. It consolidates proved finite certificates; it does not promote finite models to an unbounded physical theorem.

## Statement

Let \(f:R\to S\) be a declared realization map, \(P_f:\operatorname{Att}(S)\nrightarrow\operatorname{Att}(R)\) an attachment correspondence, and \(Q_R,Q_S\) record modules. A claimed instrument-attached transport is admitted only on the intersection of these gates:

1. **source identity:** attachment generators and coefficient objects have source-derived identities;
2. **existence:** the required correspondence fibers are inhabited where transport is claimed;
3. **composition:** identity and composite correspondences carry declared unitors and compositors;
4. **naturality:** comparison cells commute with attachment morphisms;
5. **associativity:** triple-composition routes agree;
6. **gauge equivariance:** admitted frame changes preserve the structure;
7. **transport–coherencer compatibility:** internal transport respects the comparison cells;
8. **pairing descent:** transported state–effect values agree;
9. **record descent:** the stable physical-record square commutes.

Representability by a backward functor, and adjoint realization by a forward left adjoint, are optional strengthening gates. Their failure does not invalidate a lawful branching correspondence.

## Obstruction theorem schema

A failed gate blocks exactly the claims downstream of that gate. Missing source identity blocks interpretation; empty fibers block existence; failed naturality or associativity blocks coherent composition; failed gauge equivariance blocks presentation-independent meaning; failed pairing blocks probability transport; failed record descent blocks stable physical readout. No later numerical fit repairs an earlier failed gate.

Conversely, finite data satisfying all nine gates define a coherent instrument-attached system at that declared cutoff. This converse certifies only the supplied finite equipment/module diagram.

## Independence and minimality boundary

Forward realization, backward attachment, transport–coherencer compatibility, and readout descent are mutually independent in the declared finite scalar model class. The nine-gate list is not claimed absolutely minimal: source laws can derive several gates jointly, and equivalent axiom systems can package them differently.

## DPC disposition

The conjecture that one universal pullback functor and one scalar coefficient control every interface is rejected. The retained explanation is correspondence-first transport with optional representable/adjoint sectors and an independent record module.

## Decision procedure

Type the source and codomain; construct the correspondence; test composition, naturality, associativity, and gauge; test comparison-cell compatibility; test pairing; test records. Stop at the first defined failed gate and report its exact residual. If a comparison map is absent, report an undefined comparison rather than a nonzero residual.

## Disposition

The consolidated schema is retained as the bounded decision theorem. Its residual is universality: physically constrained and unbounded promotion requires separate source-derived arrows.
