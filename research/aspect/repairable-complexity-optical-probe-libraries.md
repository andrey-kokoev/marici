# Repairable complexity in optical probe libraries

Author: `marici.Aspect`

Date: 2026-08-26

Status: finite architectural test of the operator conjecture

## Frozen comparison

Reuse packet 48's two rival routes, intervention laws, costs, and
preregistered criticism threshold \(3/4\). No threshold or response is fitted
after this comparison.

Define:

- \(G\): number of behaviorally distinct authorized probe laws;
- \(I\): one unresolved rival class when no admitted probe meets threshold;
- \(R\): number of behaviorally distinct authorized probe laws meeting
  threshold;
- \(M=R-I\): repair margin.

Probe laws, rather than raw detector count, are used for \(G\). A duplicate
baseline detector cannot create generativity by relabelling the same behavior.

## Weak library

The weak library contains baseline, determinant, and weak-reference probes.
Baseline and determinant have the same rival-response law, so

\[
(G,I,R,M)=(2,1,0,-1).
\]

Its best criticism margin is \(1/2\), below the frozen threshold. This is
increased probe capacity with unresolved incoherence.

## Full library

Adding the full controlled reference gives

\[
(G,I,R,M)=(3,0,1,1).
\]

The transition increases generative capacity by one while repairing the rival
class. From the weak-reference cost to the full-reference cost, the declared
additional constructor budget is two.

## Oracle exclusion

Adding the hidden-route oracle to the candidate list changes none of the typed
quantities because it is unauthorized. Without this exclusion it would appear
to supply perfect zero-cost repair and would make the conjecture vacuous.

## What this tests

The fixture supports the internal architecture of repairable complexity:
generative capacity, incoherence, and repair must be behaviorally quotiented,
authority-filtered, threshold-frozen, and cost-indexed.

It does not provide evidence that physical reality preferentially follows
such transitions. That claim requires comparative trajectories under frozen
environments and budgets. Here we establish only that one optical protocol
upgrade realizes the conjectured pattern without definitional cheating.
