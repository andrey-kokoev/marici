# Unrestricted higher-cell adjunction makes the network conjecture vacuous

## Target

The latest repair said:

> Whenever an admitted constructor fails to descend to the current quotient, retain the residual as a lift cell at the next categorical depth.

As a grammar-building rule this is valid. As a Deutschian conjecture it is unfalsifiable.

## Exact hostile

Take any comparison square with two composite matrix paths

\[
P=DA,
\qquad
Q=CB.
\]

Strict coherence requires \(P=Q\). For an arbitrary hostile packet define

\[
\alpha=P-Q.
\]

Then the lax square

\[
P=Q+\alpha
\]

closes identically. Every failed square can be accepted by naming its residual as a new cell. If a relation among those cells later fails, the same rule adds another cell one depth higher.

The checker applies this procedure to one coherent square and two distinct incoherent matrix squares. Strict coherence rejects both hostiles. Adaptive cell adjunction accepts all three.

## The categorical reason

Every finite typed graph generates a free category. Adding declared transformations generates a free 2-category; iterating generates a free higher category. Therefore the existential claim that some sufficiently enlarged higher diagram contains a finite packet excludes nothing.

The grammar can encode the world, but encoding is not yet explanation.

## Deutschian failure

The proposal became easy to vary:

- a minus sign appears: add a lift cell;
- a pentagon fails: add a higher associator;
- contextual equivalence fails: enlarge the context doctrine;
- factorization disappears: retain provenance;
- a new residual appears: raise categorical depth.

No finite observation can contradict that adaptive schema. It is a universal completion procedure, not a conjecture about physical structure.

## Required repair

A falsifiable network conjecture must preregister a theory signature before examining the hostile packet:

1. object and interface types;
2. permitted generating arrows;
3. permitted cell types;
4. equations among generators;
5. maximum categorical depth or a source-derived stabilization law;
6. which residuals are forbidden;
7. which contexts and constructors are admitted;
8. a complexity or minimality functional fixed independently of the result.

Only then can a packet fall outside the theory.

## Surviving conjecture candidate

The nonvacuous conjecture is not that a higher network always exists. It is:

> There exists a source-derived, finitely presented network theory whose preregistered generators and coherence laws cover multiple physical sectors, stabilize at a bounded depth, and correctly forbid specified hostile compositions without adding packet-specific cells.

This predicts reuse. A cell type derived in theta optics must classify a flavor, braid, or gravitational packet without being renamed after seeing the answer. The first unexplained residual outside the frozen signature falsifies the theory.
