# Convex admissibility reduces remainder width to extreme lifts

## Question

If source constraints define a bounded admissible lift set, how can its intrinsic omitted-route width be computed by a finite exact test?

## Extreme-point certificate

Let the source-admissible displacement set be a compact convex hull

\[
\mathcal A_0=\operatorname{conv}\{w_1,\ldots,w_m\}
\]

in absolute lift space, and let \(R\) be the omitted physical route map. Since

\[
w\longmapsto\|Rw\|
\]

is convex, every convex combination obeys

\[
\left\|R\sum_j\lambda_jw_j\right\|
\le
\sum_j\lambda_j\|Rw_j\|
\le
\max_j\|Rw_j\|.
\]

Therefore

\[
\omega_R(\mathcal A_0)
=
\max_{1\le j\le m}\|Rw_j\|.
\]

A finite exact list of source-certified extreme lifts converts the intrinsic supremum into finitely many route evaluations.

## Rational model

Take the diamond with extreme displacements

\[
(1,0),
\quad(-1,0),
\quad(0,2),
\quad(0,-2)
\]

and scalar omitted route

\[
R(x,y)=\frac{x}{5}+\frac{y}{10}.
\]

Every extreme image has magnitude at most \(1/5\), and the width is exactly \(1/5\). Interior samples cannot increase it.

## Convexification boundary

If the physical admissible set \(S\) is nonconvex, replacing it by \(\operatorname{conv}(S)\) gives the same supremum for a norm of a linear image when the convex hull is generated by points of \(S\), so it is a safe width computation. But the convexified set must not be reinterpreted as additional physically admissible lifts; it is only a bounding device.

A coordinate box inferred from sampled coefficients is not a source-certified convex hull. Every listed vertex must arise from proved source inequalities or a complete vertex enumeration of those inequalities.

## Prime-uniform gate

For prime-dependent polytopes and routes, testing finitely many primes remains insufficient. One needs a common symbolic vertex family or a prime-uniform bound on every extreme image:

\[
\sup_p\max_j\|R_pw_{p,j}\|<1-q_0.
\]

Changes in combinatorial type with the prime must be included rather than frozen from a cutoff.

## Verification

`research/aspect/checkers/check_convex_lift_width.py` verifies the exact vertex width, interior bound, and a convex-combination witness with rational arithmetic.

## Disposition

The intrinsic width request becomes executable if the source owner can express q_G12 admissible lifts as a compact convex hull or bounded polytope with complete extreme points. Without source inequalities or a finite extreme representation, no width follows from sampled lifts.
