# Coherently controlled refinement-loop Bell experiment

## Question

Can locally coarse-equivalent measurement implementations carry a coherent constructor-loop phase while the inclusive spatial Bell obstruction remains unchanged?

## Apparatus

An entangled photon pair enters two separated Bell wings. At each wing, a path-control qubit coherently selects the identity implementation or a registered refinement implementation. The refinement couples the photon to a local ancilla label. A second compiler can invert the coupling before the ordinary polarization analyzer. Control X and Y are read after recombination.

The registered modes are:

- `identity`: bypass implementation;
- `closed_refinement`: refinement followed by its inverse, with a calibrated route phase;
- `equivalent_dilation`: the same coarse instrument with a different local environment realization;
- `dephased_control`: the refinement path is deliberately dephased as a negative control.

Every trial retains the Bell outcome, no-click state, refinement label, control readout, compiler digests, setting-source health, frame, coincidence policy, reset identity, and immutable event identity.

## Two simultaneous observables

The inclusive Bell witness is computed only after forgetting the local refinement and control fields and passing the exact same-ledger auditor.

The constructor-loop observable is the complex control fringe `L = X + iY`. It reads coherent overlap between implementations. Coarse-equivalent implementations can therefore have identical Bell statistics yet distinct `L`.

## Preregistered prediction

All honest modes have the same inclusive correlations and CHSH value. The identity fringe is one. The closed refinement has unit visibility and its calibrated loop phase. The equivalent dilation has reduced visibility but the same coarse Bell packet. Deliberate control dephasing sends the fringe to zero without changing inclusive CHSH.

The experiment is falsified if exact pushforward passes but inclusive CHSH changes beyond tolerance between modes, if a fringe attributed to constructor geometry survives classical path-leakage hostiles, or if either local control marginal depends on the remote Bell setting.
