# Executable-context obstruction for the interaction-net pilot

An algebraic context basis can separate every prequotient state: record the
chart, five occurrence bits, and the three fiber coordinates k, u, and v. This
basis is fixed, target-independent, and source-generated.

It is not yet a physical instrument. Exact readout of unbounded integers is not
an admitted finite-resolution operation.

The direct optical translation uses three spatial chart ports, five spectral
marker ports, range-R mode sorters for k and u, and a range-2R sorter for v. At
any fixed calibrated range R, it separates the source resource truncation
through grade R. It fails on the unbounded source category. In particular,

    (G12, empty, R+1, 0, 0)
    (G12, empty, R+2, 0, 0)

produce the same k-saturated record.

Thus a cutoff-dependent apparatus can be faithful on each finite truncation,
but the family is not one fixed context basis across the filtration. Allowing a
new probe after seeing the target would recover algebraic separation only by
using a full-Yoneda witness, which is not executable and carries no
explanatory authority.

This already fails object faithfulness, a necessary condition for faithfulness
of the restricted enriched nerve. No claim about morphism-level faithfulness is
needed. The pilot verdict remains useful but incomplete.
