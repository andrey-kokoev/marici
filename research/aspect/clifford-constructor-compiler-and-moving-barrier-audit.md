# Clifford constructor compiler and moving-barrier audit

## Compiler contract

The compiler represents a finite Clifford module in a declared coordinate
basis. States are columns, calibrated effects are rows, and constructors act
on states by exact rational matrices. An effect transported through a
constructor `C` is the Heisenberg row `E C`.

Starting from admitted effects, the compiler closes their span under every
source-authorized executable constructor. It reports:

- the generated effect module `W`;
- the behavioral annihilator `W-perp`;
- rival-package differences lying in that annihilator;
- candidate effects outside the current span;
- exact pairing, sign, and magnitude class against each rival difference;
- source-authority, executability, perturbation, calibration, completion, and
  authority-locus gates.

A candidate is returned as the first source-authorized transverse effect only
when every declared gate passes. Algebraic rank repair alone is insufficient.
Contracts are dimension-checked before compilation, so no short vector or
ragged constructor can be silently truncated by coordinate pairing. Candidate
order is the declared source-priority order; “first” always means first in
that preregistered order, never smallest after inspecting the desired result.

## Generic Clifford fixture

In the Pauli grade-one basis `(e1_X,e2_Y,e3_Z)`, a `Z` readout leaves the
`plus-minus` difference `e1_X` in the behavioral kernel. A duplicated `Z`
effect does not enlarge the span. An authorized `X` analyzer does, with exact
positive unit pairing. This verifies that the compiler can find a real
transverse effect when one is present.

## Moving-barrier rival encoding

The minimal source-typed carrier uses

```text
X = Y_plus endpoint ⊕ F_plus forcing.
```

The forcing sensor is `(0,1)`. The admitted forward tail incidence is
`F_plus -> Y_plus`; its Heisenberg words do not reveal the pure endpoint mode.
The current effect module has rank one and behavioral kernel generated by
`(1,0)`. The moving-barrier and tangent-native packages are encoded as agreeing
on existing records while differing in that endpoint/reverse-incidence mode.

The gate assignments are sourced as follows:

- Kitaev’s `bottom-the-missing-rh-explanation-is-an-authorized-transverse-reverse-incidence.md`
  proves that the admitted graph contains `F_plus -> Y_plus` but no executable
  `Y_plus -> F_plus`, and specifies the same-locus, perturbation, and
  completion-stability requirements for the missing constructor.
- Grothendieck’s
  `the-source-forcing-has-a-canonical-rigged-transpose-before-any-hilbert-adjoint.md`
  constructs the boundary-dual transpose and explicitly leaves its dynamical,
  domain, completion, and determinant realization open.
- Grothendieck’s
  `arithmetic-reciprocal-incidence-matches-the-rigged-transpose-but-is-not-a-core-for-the-seam.md`
  proves arithmetic-grade matching but rules out extension to the continuum
  seam by density.
- Grothendieck’s
  `canonical-adjoint-completion-realizes-source-autocorrelation-not-the-evans-section.md`
  separates the canonical adjoint completion from the required Evans endpoint
  observer.
- Nima’s `rh-source-generators-close-sl3-only-after-dual-wall-incidence.md`
  proves finite closure after adjoining the primal shadow while explicitly
  leaving its continuous theta/Tate authorization conditional.

## Compiler result

The first algebraically transverse candidate is the canonical rigged transpose
constructed by Grothendieck. Its induced effect pairs positively with the rival
difference. But the source packets explicitly establish it only as a boundary
dual correspondence. It is not yet:

- an executable perturbation of the plus bulk system;
- an operator at the required authority locus;
- completion-stable as one global dynamical lower incidence.

The source-typed odd inverse derivative is likewise transverse algebraically,
but lives on the reciprocal source core and lacks the required completed
same-locus realization. The dual-wall primal shadow is analytically
unauthorized. A fitted reverse incidence repairs rank but fails source authority.

Therefore the exact compiler output is:

```text
first algebraically transverse candidate:
  canonical rigged transpose boundary return

first eligible source-authorized transverse effect:
  none
```

This is not a search failure. It is the machine-readable form of the current
frontier: boundary transpose coherence has been derived, while executable bulk
incidence, endpoint/source collocation, and completion remain separate gates.

## First required source effect

The first admissible effect must be generated by a constructor word containing
a source-derived same-locus map

```text
Q_rev: Y_plus -> F_plus
```

whose Heisenberg action sends the forcing sensor to an endpoint-sensitive row.
It must pair nontrivially with the endpoint rival difference and predict its
sign and magnitude class before Evans-scalar evaluation. The current source
graph contains no such eligible word.

This is an exact finite rational effect-module compiler and a faithful audit of
the currently recorded source authority. It does not construct the missing
continuous `Q_rev`, prove a barrier sign, or prove RH.
