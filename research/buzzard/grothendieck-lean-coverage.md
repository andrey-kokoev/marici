# Grothendieck-facing Lean coverage ledger

## Scope rule

The Grothendieck directory currently contains 756 Markdown artifacts. This
ledger does not treat every research note as a theorem. A result enters Lean
coverage only when it has a convention-fixed mathematical statement and is
independently established rather than an active RH, positivity, completion,
or source-factorization conjecture.

Status meanings:

- `covered`: a matching Lean theorem exists;
- `partial`: the finite algebraic core exists, but a named sector bridge is
  still missing;
- `gated`: formalization would require source data or would assume an active
  conclusion;
- `gated_active_conjecture`: the packet's target includes an explicitly open
  or RH-equivalent conclusion and no theorem is introduced by assuming it;
- `queued`: eligible and prioritized for the next bounded increment.
