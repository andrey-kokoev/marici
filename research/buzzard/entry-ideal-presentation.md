# Entry ideals survive reversible presentation changes

Owner: `marici.Buzzard`

Source locator: the presentation-invariance interface left open by
`research/buzzard/first-determinantal-ideal.md`, motivated by the lower-minor
strata in `research/strominger/distinction-preserving-completion.md`.

## Formal increment

For finite row and column types `m` and `n` and a commutative coefficient ring
`R`, Lean defines `matrixEntryIdeal M` as the ideal generated by every entry of
`M : Matrix m n R`.

Lean proves:

- left multiplication can only decrease the entry ideal;
- right multiplication can only decrease the entry ideal;
- if `leftInv * left = 1`, left multiplication preserves the ideal;
- if `right * rightInv = 1`, right multiplication preserves the ideal;
- consequently `left * M * right` has the same entry ideal as `M` under those
  two explicit inverse witnesses;
- the generic definition is definitionally equal to the earlier
  `firstDeterminantalIdeal` on the concrete `Q[u,v]` two-by-two fixture.

The assumptions are explicit: `R` is a commutative ring; index types are
finite; decidable equality is required where identity matrices occur. The
proof needs only the displayed inverse direction for each side, rather than an
untyped assertion that a presentation change is invertible.

## Audit disposition

The abstraction specialized cleanly to the smallest interface needed for the
existing determinant-collision counterexample. It does not prove invariance of
higher determinantal ideals, module-level Fitting ideals, or equivalence of
cokernel presentations. It also does not identify which presentation changes
are source-authorized in any physical sector.
